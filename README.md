# Nibomo Website

Marketing website for [Nibomo](https://github.com/kirill-markin/flashcards-open-source-app), formerly Flashcards Open Source App. Static Next.js site deployed on Vercel.

**Live:** [nibomo.com](https://nibomo.com/)

## Tech Stack

- Next.js 16 with App Router, TypeScript, React 19 Server Components
- Tailwind CSS v4 + CSS Modules
- Markdown processing: gray-matter, remark
- Deployed on Vercel

## Local dev

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Commands

- `npm run dev` — Development server with Turbopack
- `npm run build` — Production build
- `npm run lint` — ESLint linting
- `npm run test:catalog` — Catalog test suite
