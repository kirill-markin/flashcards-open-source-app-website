# Inter for social images

These regular and bold TTF files are provided by [Google Fonts](https://fonts.googleapis.com/css2?family=Inter:wght@400;700&text=Nibomo%20Open%20Source%20Spaced%20Repetition), subset to the text in the generated Open Graph and Twitter images: `Nibomo Open Source Spaced Repetition`. Update the subset when that text changes. The font license is included in `OFL.txt`.

Website pages use the full variable Inter font through `src/lib/siteFont.ts`.
