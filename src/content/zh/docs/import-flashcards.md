---
title: 将闪卡导入 Nibomo
description: 将 Quizlet、Anki 或其他闪卡应用里的卡片迁移到 Nibomo。了解该用哪种导出格式，以及如何在批量导入前检查卡片。
---

打开 [Nibomo](https://app.nibomo.com/?locale=zh-Hans)，切换到要存放卡片的工作区，然后进入**资料库 > 导入**。在**来自其他应用**下选择原来使用的应用。即使文件格式相同，每个应用也有自己的导入入口。

以下选项在网页版中可用。如果在 iPhone、iPad、Mac 或 Android 上找不到菜单或需要的入口，请使用网页版。如果你在设备上以访客身份使用 Nibomo，请先在该设备上登录，再用同一个 Nibomo 账号登录网页版，并在导入前选好目标工作区。

## 选择来源

| 来源 | 需要准备什么 | 导入方式 |
| --- | --- | --- |
| Quizlet | 复制导出的文本 | 粘贴到 Quizlet 导入界面 |
| Anki | `.apkg` 牌组或 `.colpkg` 集合 | 选择文件 |
| Noji | `.csv` 或 `.ofc` | 选择文件 |
| Knowt | `.pdf` | 选择文件 |
| RemNote | `.apkg`、`.md` 或 `.txt` | 选择文件 |
| Brainscape | `.csv` | 选择文件 |
| StudySmarter | `.csv` | 选择文件 |
| Cram | `.csv` | 选择文件 |
| Mochi | `.mochi` | 选择文件 |
| SuperMemo | `.xml` | 选择文件 |
| AlgoApp（原名 AnkiApp） | `.zip` 或 `.xml` | 选择文件 |
| 其他应用 | `.csv`、`.txt`、`.xlsx`、`.pdf`、`.json`、`.xml`、`.md`、`.docx` 或 `.zip` | 在**从其他应用导入**中选择文件 |
| 电子表格 | 复制表格行，每行包含一张卡片的正面和背面 | 粘贴到**从电子表格导入**界面 |
| Nibomo | 由 Nibomo 导出的 `flashcards.zip` | 在**从 Nibomo 导入**中预览 |

如果菜单还在使用 AlgoApp 的旧名称，请找 **AnkiApp**。Anki 有单独的入口。

如果手头是旧版 Excel 的 `.xls` 文件，请先另存为 `.xlsx` 或 `.csv` 再导入。也可以复制正面和背面两列，[粘贴到电子表格导入界面](#从电子表格粘贴)。

## 从其他闪卡应用导入

1. 在原应用中导出要迁移的卡片。如果使用 Quizlet，打开自己的学习集，选择**导出**并复制文本。术语和定义之间可用制表符分隔，每张卡片另起一行。导出功能仅在 Quizlet 网站上提供，且仅适用于你自己新建的学习集。
2. 在 Nibomo 中进入**资料库 > 导入**，打开对应的入口。Quizlet 需要粘贴复制的文本，其他来源需要选择导出的文件。如果你的应用没有单独的入口，但能导出 PDF 等受支持的格式，可以用**从其他应用导入**。
3. 选择**开始导入**。Nibomo 会新建一个 AI 对话，并将导入请求连同文件或粘贴的文本一并发送。此步骤需要联网。通过 AI 导入时，单个文件最大为 **30 MiB**。如果文件太大，可以把较小的牌组或学习集分别导出。
4. 在**资料库**里检查结果。AI 对话可能会在导入过程中分批保存卡片。如果导入中途停了，先查看哪些卡片已经保存，再让 AI 处理剩余部分，之后如有需要再重试整份导出。

### 先用少量卡片试导入

保留原始导出文件，先试一个小牌组或学习集。核对卡片数量，抽查几张卡片的正反面、标签，以及你需要的图片或特殊格式。如果想在保存前看样例，可以让 AI 先展示一小批卡片，暂不保存。为此，请在新建的 AI 对话里手动附上导出文件并写下要求，无需点击**开始导入**。

AI 导入的卡片会作为新卡片加入 Nibomo，原来的复习记录和到期日期不会迁移。能保留多少原来的组织结构、格式和媒体，取决于导出文件包含什么，以及 AI 对话能读取哪些内容。请先检查结果，再依赖导入的卡片或删除原应用中的内容。

## 从电子表格粘贴

请先登录 Nibomo。如果卡片只有正面和背面的纯文本，请进入**资料库 > 导入 > 从电子表格导入**。复制表格中的两列，不要带表头，然后粘贴到导入界面。粘贴表格单元格时，可先用**制表符**分隔正面和背面，用**换行**分隔卡片。如果文本采用其他分隔方式，请调整相应选项。

预览卡片，补全不完整的行，选择要添加的标签，然后点击导入按钮保存卡片。此方式无需使用 AI 对话。

## 导入 Nibomo 的 ZIP 文件

请先登录 Nibomo。如果要导入之前从 Nibomo 导出的 `flashcards.zip`，请进入**资料库 > 导入 > 从 Nibomo 导入**。直接选择 ZIP 文件，无需解压。在预览中核对卡片和媒体文件的数量，并查看是否有警告。确认导入后，在**资料库**中查看具体的卡片和媒体文件。此方式可以迁移包里的卡片、标签和媒体，无需使用 AI 对话。
