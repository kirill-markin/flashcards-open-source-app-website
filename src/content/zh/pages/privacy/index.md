## 分析与 Cookie

营销网站使用 Vercel Web Analytics 衡量页面浏览量和部分网站点击事件。该服务本身不使用分析 Cookie，但网站会设置一个下文所述的自有 Cookie。对于页面浏览，Vercel 可能接收事件时间、页面 URL 和过滤后的查询参数、来源页面、大致位置、浏览器、操作系统和设备类型。我们的自定义点击事件仅包含区域语言、平台、链接位置或交互类型等有限属性。我们不会有意在其中加入姓名、电子邮箱地址、卡片内容或账户标识符。Vercel 会汇总数据，不会将单个数据点与个人或 IP 地址关联；其每日访客哈希会在24小时后丢弃。如果你的浏览器发出 Global Privacy Control 信号，网站不会向 Vercel Web Analytics 发送任何内容。

另外，网站会向我们自己的产品分析收集端发送事件：你打开的每个页面都会产生一个页面浏览事件；当你点击链接前往网页应用、应用商店或安装目录卡组时，会产生一个点击事件；你在公开卡组目录中的搜索、筛选、排序、翻页以及打开卡组的操作；点击离开本站的链接；复制面向智能体的接口地址；语言建议横幅的展示以及你对它的回应；还有下文所述的同意横幅和收集开关本身。视事件而定，其中包含页面类型、目录卡组页面和安装链接上的公开软件包版本标识符、链接位置、前往网页应用的点击是登录、注册还是打开应用、语言建议横幅所建议的语言、页面界面语言、浏览器提供的设备语言、来源类别、设备类别，以及在你的浏览器持有时下文所述的 `analytics_visitor` 标识符。页面浏览事件还会包含你来源网站的主机名，取自已知搜索引擎和社交网站的名单，其余一律报告为 `other`，以及你到达时所用地址中的 `utm_source`、`utm_medium` 和 `utm_campaign` 参数。目录中的搜索、筛选、排序和翻页事件会包含你看到的结果数量以及你的选择：筛选操作（添加、选中、移除或清除）连同其类别和操作后已选筛选条件的数量、排序方式，或者页码连同总页数。从目录中打开卡组的事件会包含卡组的公开标识符和你在页面上打开它的位置，不含结果数量。目录搜索还会包含你输入内容的长度；只有当规范化后的文本不超过 64 个字符且只含字母、数字、空格和连字符时，才会包含该文本本身；其他查询只报告长度，绝不会为了符合要求而截断。我们的服务器会根据每个事件到达时的地址推断出两位字母的国家代码并随事件保存；它不保存该地址，也不会为下文所述完全不带标识符的事件推断国家。如果你的浏览器发出 Global Privacy Control 信号，网站不会请求访客标识符，也不会显示同意横幅；而上述事件仍会在不带该标识符的情况下到达我们自己的收集端；其中除完全不带标识符的那些之外，都会获得下文所述的每日标识符。我们不读取 Do Not Track 设置。

托管网页应用使用 `otp_session`、`session`、`refresh` 和 `logged_in` 等严格必要的 Cookie，以完成身份验证、维持会话、刷新访问权限并显示登录状态。禁用这些 Cookie 后，浏览器登录流程将无法工作。

营销网站和托管网页应用共用一个我们自己的分析 Cookie `analytics_visitor`。它保存一个随机的访客标识符，可由我们在浏览器中的脚本读取，13个月后过期。我们用它在多次访问之间识别同一浏览器，使事件体现为回访访客，而不是每次都算作新访客。该 Cookie 并非严格必要。这一选择只决定你的浏览器是否携带该标识符；网站是否收集任何信息，由下文所述的另一个开关决定。在需要征得同意的地区，包括欧盟/欧洲经济区和英国，我们只在你同意后才设置：网站会以横幅询问，在你作出回答之前不会请求标识符，也不会附加标识符；上文所述的事件在此期间仍会发送，只是不带该标识符；其中除完全不带标识符的那些之外，都会获得下一段所述的每日标识符。在无需同意的地区，我们不询问即设置。无论哪种情况，你都可以随时通过网站每个页面角落的分析控件或网页应用的设置将其关闭；之后我们会从你的浏览器中清除该 Cookie 并停止使用。你的回答会保存在你的浏览器中，以免重复询问。如果你的浏览器发出 Global Privacy Control 信号，我们会清除该 Cookie，并一并清除曾经允许它的回答；因此若日后关闭该信号，我们会把该浏览器当作新的浏览器：在需要征得同意的地区再次询问，在无需同意的地区不询问即设置。拒绝的回答会保留，并继续有效。我们也会把横幅本身记录为事件：它被展示过，以及你作出的回答。横幅展示的事件和拒绝回答的事件完全不带标识符；同意回答的事件会带上你刚刚允许的标识符。事件本身只在本政策所述目的仍有需要时保留。

当事件在不带 `analytics_visitor` 标识符的情况下到达我们的收集端时（例如你拒绝了该 Cookie、尚未作出回答或已将其关闭），我们的服务器会根据该请求的 IP 地址和浏览器用户代理，结合一个每个 UTC 日更换、并在当日结束后删除的随机值，生成一个临时标识符。IP 地址本身不会保存在我们的分析数据中。该标识符只会关联同一天内来自同一浏览器和同一 IP 地址的事件。它从不保存在你的浏览器中，从不与 `analytics_visitor` 标识符或任何账户关联，从不附加到你的同意回答记录上，并且在当天的随机值删除后无法再被重新计算。我们使用它来了解访客如何使用网站，依据是“处理目的与法律依据”一节所述的我们的合法利益。发出 Global Privacy Control 信号的浏览器从不携带 `analytics_visitor` 标识符，因此它的事件会像任何没有该 Cookie 的浏览器一样获得这个每日标识符。完全不带标识符的事件既不会获得这个每日标识符，也不会获得国家：同意横幅的展示、拒绝的回答，以及关闭和重新开启本网站的收集。它们只告诉我们这件事发生过。

网站每个页面角落的分析控件包含关闭本网站收集的开关，以及与之并列的上文所述分析 Cookie 同意；在你回应横幅之后，收集处于开启状态时控件也会提供该 Cookie 选择，你重新开启收集后，它也会再次出现。如果你的浏览器发出 Global Privacy Control 信号，该控件只包含这个开关：我们不会给该浏览器任何分析 Cookie，因此没有可供选择的 Cookie 选项。关闭时会发送最后一个事件，仅记录它被关闭这件事；重新开启时会发送与之对应的事件。两者都不带标识符、不带每日标识符，也不带国家。收集关闭期间，网站不会再发送任何关于你本次访问的其他事件，既不发送给我们的收集端，也不发送给 Vercel Web Analytics，并且不会请求访客标识符；由于此外没有任何数据到达我们的收集端，也不会生成每日标识符。除非你将其关闭，它默认开启，依据“处理目的与法律依据”部分所述的正当利益。本网站没有账户，因此你的回答保存在该浏览器中，并且仅在该浏览器生效；托管网页应用有自己的设置，iOS 和 Android 应用则从引入该设置的应用版本起具备，二者详见“产品分析”部分。

## 产品分析

托管的网页、iOS 和 Android 应用会向我们发送产品使用事件。这些事件进入我们自己的基础设施，并存储在我们自己的数据库中；我们不会为此使用第三方分析服务商。

事件描述界面、复习会话的时长与数量，以及操作成功或失败的情况。它们可能包含安装和会话标识符，并在适用时包含工作区和账户标识符。这些应用事件不包含自由文本、卡片或卡组内容以及您的电子邮箱地址。

在客户端版本支持的情况下，每个事件发生时就会记录界面语言，随后才进入离线队列。设备语言单独记录，可能与界面语言不同。安装配置记录保存当前技术信息，包括客户端提供的平台、应用和操作系统版本、设备语言及时区。为兼容现有客户端，部分技术信息也保留在单个事件中。旧客户端或旧事件可能没有界面语言；我们不会根据设备语言或时区推断缺失值。

为分析受众，我们对符合条件的应用直接请求，根据 API 网关收到的 IP 地址估算连接所在国家；每个安装实例在有连接的每个 UTC 日最多进行一次。我们使用自有 AWS 基础设施中的 MaxMind GeoLite Country 数据库查询地址。地址仅在请求处理的内存中使用，不存入产品分析，也不发送给 MaxMind。我们配置的 API Gateway 访问日志不包含原始 IP 地址；网络基础设施仍会处理 IP 地址以完成请求。国家只是估算结果，可能未知或受到 VPN 影响，不代表居住地、国籍或精确位置。服务器转发、AI 客户端和网站事件请求不提供安装实例的国家信息。另外，凡是不带账户凭据到达我们收集端的事件——上文所述的网站事件、托管网页应用在未登录状态下的事件，以及我们登录服务的事件——都会带有两位字母的国家代码：由我们的服务器在接收时根据请求到达的地址推断，而该地址可能是转发方的地址而非你自己的地址；我们将该代码随事件保存，不保存地址，也不会为完全不带标识符的事件推断国家。我们不会将上传时的国家赋给更早的离线事件。

国家历史由间断的观测组成：观测国家不变时延长一个时段，变化时开始新时段。时段的起止点不能证明观测之间每天都有活动或持续处于该国。反馈会另行记录首次接受提交时的连接国家，而不是创建离线草稿时的国家。

本产品包含 MaxMind 创建的 GeoLite 数据，来源为 [MaxMind](https://www.maxmind.com)。

分析 Cookie 与产品分析是两个互相独立的选择，二者都不会由另一方推导出来。拒绝上文所述的分析 Cookie，或之后撤回同意，只会停止共享的访客标识符：事件本身仍会继续收集，并在你登录期间仍与你的账户关联。

产品分析有单独的设置可以关闭这类收集。关闭期间，应用不会记录也不会发送任何产品使用事件；对于已关闭该设置的账户或访客会话，若仍有数据到达，我们的 API 会将其丢弃。除非你将其关闭，它默认开启，因为我们处理这些事件的依据是“处理目的与法律依据”部分所述的正当利益，而不是同意，所以我们不会就此征询你，拒绝了分析 Cookie 的人这项设置也仍然开启。它只涵盖各应用发送的产品使用事件；错误与崩溃报告，以及我们服务器端关于服务完成工作的记录，不在其范围内。

在托管网页应用中，该设置位于网页应用的设置里：你的回答保存在该浏览器中，你登录期间也会同时保存在你的账户上；已关闭该设置的浏览器，不会被一个仍处于开启状态的账户重新开启。iOS 和 Android 应用会将回答记录在设备上；一旦存在可供保存的账户或访客会话，也会保存到那里，直到保存成功为止会持续重试；由该设备自己的回答决定它发送什么，因此在别处记录的回答无法在该设备上重新开始收集。在这些应用中，该设置从引入它的应用版本起出现在应用的设置中；发布时不含该设置的应用版本会继续发送事件，而对于已关闭该设置的账户或访客会话，我们的 API 会丢弃仍然到达的任何批次。这种丢弃依赖于保存着你的回答的账户或访客会话，因此在两者都不存在的安装上，阻止发送的是设备自身的记录。营销网站有自己的开关，详见“分析与 Cookie”部分，它仅对该浏览器生效。

关闭该设置会停止后续收集，但不会删除已经记录的事件：产品分析事件只追加。删除账户会删除关联的安装配置记录，并对保留的事件做匿名化处理，而不是将其抹除，具体见“保留与删除”部分。

## 托管 AI 与外部 AI 客户端

OpenAI 是为托管聊天、语音转录和图片生成功能配置的 AI 提供商。当您选择这些功能时，我们会向 OpenAI 发送完成请求所需的数据，其中可能包括您的提示词、相关聊天与工作区上下文、附件或图片、口述音频以及经假名化的安全标识符。托管文本请求使用 `store: false`，因此不会存储响应对象供日后检索。由于这些请求同时使用提示词缓存，OpenAI 可能会将加密的缓存应用状态保留最多24小时。根据 OpenAI 当前的 API 控制措施，适用的滥用监控日志可能保留最多30天；语音转录端点则声明既不保留滥用监控内容，也不保留应用状态。除非账户持有人明确选择加入，否则 OpenAI 不会使用 API 数据训练模型。

为调试和分析服务质量，托管 AI 请求也会通过 Langfuse Cloud 进行观测。Langfuse 跟踪可能包含提示词、模型回复、工具活动、用户、工作区和会话标识符以及运营元数据。实现会遮蔽电子邮箱地址和类似机密信息的字段；自定义语音转录跟踪不包含原始音频字节和附件数据。

我们的管理员可以读取存储在我们自己的数据库中的托管 AI 聊天内容，包括您的提示词、模型回复和聊天输入框中的建议提示词，用于分析 AI 功能的使用方式并加以改进。访问这些内容的权限仅限于运营方的管理员。

当您通过远程 MCP 服务或 Agent API 将 Nibomo 连接到外部 AI 客户端时，您要求该客户端获取的数据也会由该客户端及其 AI 或模型提供商处理。此项独立处理由客户端运营者控制，并受其条款和隐私政策约束。

## 处理者与接收方

托管服务使用以下类别的服务提供商：

- Amazon Web Services（AWS），用于托管、Cognito 身份验证、Postgres、文件存储、备份和运营日志；
- Resend，用于发送身份验证事务邮件；
- OpenAI，用于可选的托管 AI 请求；
- Langfuse Cloud，用于托管 AI 可观测性；
- Sentry，在相关托管服务或应用构建中启用时，用于经过清理的错误与诊断报告；
- Vercel，用于营销网站和不使用 Cookie 的 Web Analytics；以及
- Cloudflare，用于 DNS 和域名管理。目前 Nibomo 的 DNS 记录为仅 DNS 模式，因此 Cloudflare 不代理托管网站或应用的 HTTP 流量。

根据服务的协作功能，数据还可能披露给共享工作区的其他成员、您授权的外部客户端、负有保密义务的专业顾问，或在法律要求时披露给公共机关。

## 国际传输

主要托管应用运行在 AWS 的欧盟基础设施中。配置的 Resend 邮件区域、Sentry 数据区域和 Langfuse 端点也位于欧洲。包括 OpenAI 和 Vercel 在内的部分提供商可能会在您所在国家或欧洲经济区以外处理数据。必要时，我们会通过适用的充分性决定、数据处理协议、标准合同条款或同等保障措施来保护此类传输。

## 保留与删除

- 只要您的账户或相关共享工作区仍处于活动状态，我们就会保留账户与托管工作区数据。删除账户会从在线数据库中删除您当前的账户数据、凭据、成员关系和只有您一名成员的工作区。仍有其他成员的工作区内容会继续向这些成员提供。
- 删除账户后，产品分析事件仍会保留。对于关联到您的账户及已关联访客身份的事件，我们将账户标识符替换为随机值，移除身份关联，并清空安装、会话、工作区、请求、设备型号、操作系统、设备语言、界面语言、时区和国家字段。关联的安装配置记录及其国家历史会被删除。这说明的是标识符移除方式，并不保证保留事件在所有情况下都是匿名的。
- 删除账户还会使执行删除操作的那个浏览器中的 `analytics_visitor` Cookie 过期，并重置该浏览器的分析会话标识符。此后该浏览器将作为新的匿名访客继续，使用与此前无关联的新标识符，前提是您的分析选择允许。这仅限该浏览器；其他浏览器或其他设备中保存的副本不受影响，而阻止写入或在执行前被关闭的浏览器会保留旧标识符，直到其自行过期。这也不会改变已收集的事件：在退出登录状态下记录且从未关联到您账户的事件，仍保留记录时使用的标识符，只有上述身份关联的移除才使该标识符无法再指回您。
- 当某个详细国家时段的最后一次观测早于90天前时，受众查询会将其排除。每日清理会删除这些时段，但实际删除可能延迟至清理成功完成。一个未发生变化的时段可能始于90天以前，但它不是每日位置记录。首次已知国家单独保留，在安装配置记录的整个存续期间保存，直到该记录被删除。
- 反馈的国家信息与反馈记录一起保留，并在账户删除流程中随该记录删除；国家历史的90天规则不适用于反馈。
- 只要相关的活动工作区内容仍需要已存储媒体，我们就会保留这些媒体；不再被引用后，会通过存储清理流程删除。未完成的临时上传会在7天后过期。
- 数据库设有7天的 RDS 自动备份，并另设保留35天的每日 AWS Backup 计划。从在线服务中删除的记录可能会保留在加密恢复备份中，直至备份到期；备份用于灾难恢复，而非日常服务访问。
- API Gateway 访问日志会在7天后到期。其他 CloudWatch 应用日志目前未配置自动到期时间，会保留至手动删除。我们将其用途限制在运营、安全和调试，并在为履行适用的数据保护权利而必要时删除相关记录。
- 当前 Sentry Developer 套餐提供30天的事件回溯。根据当前标准服务设置，Resend 会保留已发送邮件的数据30天。
- OpenAI 的保留方式在“托管 AI”部分说明。Langfuse Cloud 中的 AI 跟踪会在30天后删除：适用于我们项目的提供商访问限制会每晚移除更早的跟踪，且该删除无法撤销。为履行有效删除请求而必要时，我们会删除可识别个人的跟踪。
- 支持通信以及法律或安全目的所需的记录只在相关目的所需期间保留。Vercel 访客哈希会在24小时后到期；汇总的网站统计数据按 Vercel 项目设置保留。

删除账户不会立即删除已经存在于定期备份或提供商日志中的副本。除非法律要求更长的保留期，这些副本会按照上述期限到期或删除。
