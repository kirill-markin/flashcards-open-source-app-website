## 摩尔斯电码数字 0–9

每个数字都由五个信号组成。看懂其中的规律，这十项就不再像十个毫无关联的答案。

| 数字 | 摩尔斯电码 | 规律提示 |
| :---: | :---: | --- |
| 0 | `− − − − −` | 五个 dah |
| 1 | `· − − − −` | 一个 dit，接着四个 dah |
| 2 | `· · − − −` | 两个 dit，接着三个 dah |
| 3 | `· · · − −` | 三个 dit，接着两个 dah |
| 4 | `· · · · −` | 四个 dit，接着一个 dah |
| 5 | `· · · · ·` | 五个 dit |
| 6 | `− · · · ·` | 一个 dah，接着四个 dit |
| 7 | `− − · · ·` | 两个 dah，接着三个 dit |
| 8 | `− − − · ·` | 三个 dah，接着两个 dit |
| 9 | `− − − − ·` | 四个 dah，接着一个 dit |

从 `1` 到 `5`，每向前一步，开头就多一个 dit，同时少一个 dah。从 `6` 到 `9`，开头连续的 dah 越来越多，末尾的 dit 越来越少。`0` 用五个 dah 补全了这个序列。

这个结构可以用来核对，但不能代替主动回忆。如果听到一个数字后还得从头顺着整行数一遍才能认出它，说明答案仍由表格顺序提示。随机练习能去掉这层提示。

## Dit、dah 与字符计时规则

**Dit** 是以点表示的短信号，**dah** 是以横线表示的长信号。在纸上，`· −` 和 `− ·` 只差顺序；听起来，它们却是两种紧凑、完整的节奏。

ITU 的计时规则以一个 dit 的持续时间作为基本单位：

| 信号组成部分 | 时长 |
| --- | :---: |
| dit | 1 个单位 |
| dah | 3 个单位 |
| 同一个字符内，dit 与 dah 之间的静默 | 1 个单位 |
| 字符之间的静默 | 3 个单位 |
| 单词之间的静默 | 7 个单位 |

因此，`A` 先发一个短信号，静默一个单位，再发一个长信号。完整的 `A` 结束后，要再间隔三个单位才开始下一个字符；单词之间的间隔更长，为七个单位。

所以，用口头念出的“点横”代替音频，只能传达一部分信息。印刷符号能表示顺序和相对时长，却无法训练你识别完整的声音、字符与单词之间的间隔，以及连续的信号流。

表格用来核对，音频用来训练听觉。

## 双向练习，别把表格顺序当成记忆

字母表很适合查阅，却也会悄悄把答案递到眼前。如果 B 总是跟在 A 后面，或者 `4` 总在 `5` 上方，你可能靠位置和顺序答对，而不是真正记住了这个字符。

可以分三轮使用这套卡组：

1. **核对对应关系。** 先主动回忆，再用表格纠正。把正确组合重新说或写一遍，别让刚才的猜测成为最后一次练习。
2. **练正向回忆。** 回答字符到组合的卡片时，不要在脑中沿着字母表或数字顺序找答案。评分要看每个元素的准确顺序，不能只看数量是否正确。
3. **再练反向回忆。** 回答组合到字符的卡片时，不要先把组合翻译成一句助记口诀。看到书面组合，就要直接联想到一个字符。

答错一张卡时，先判断错误类型，再增加重复次数：

| 发生了什么 | 可能的问题 | 针对性修正 |
| --- | --- | --- |
| 知道有哪些信号，却把顺序颠倒了 | 顺序混淆 | 并排比较原组合和颠倒后的组合 |
| 漏掉或多加了一个信号 | 长度混淆 | 纠正时数一遍，再完整回忆一次 |
| 能解码，却不能编码 | 只熟悉一个方向 | 补练字符到组合的方向 |
| 能编码，却不能解码 | 只熟悉一个方向 | 补练组合到字符的方向 |
| 只有按字母顺序时才能答对 | 依赖顺序 | 打乱卡组，从不相邻的字符开始 |
| 看得懂组合，却听不出声音 | 视觉与听觉脱节 | 暂停增加视觉卡片，用音频练同一组字符 |

## 专练易混组合，不必把全部内容重刷一遍

有些错误总是成对出现。与其把 72 张卡片从头再刷一遍，不如缩小范围，直接对比这两个字符，把差别练清楚。

先处理外形相近或顺序恰好相反的组合：

| 字符对 | 书面组合 | 要分清的差别 |
| --- | --- | --- |
| A / N | `· −` / `− ·` | 短—长与长—短 |
| U / D | `· · −` / `− · ·` | dah 在末尾与 dah 在开头 |
| V / B | `· · · −` / `− · · ·` | 一个 dah 分别位于两端 |
| W / G | `· − −` / `− − ·` | 一个 dit 分别位于两端 |
| R / K | `· − ·` / `− · −` | 都是交替排列，但起始信号不同 |
| F / L | `· · − ·` / `· − · ·` | dah 的位置相差一格 |

接着做一轮简短的针对性练习：

1. 面前只保留这一组易混字符。
2. 看字符，写出各自的书面组合。
3. 再看组合，把它们解码回字符。
4. 以随机顺序听这两个字符的完整声音。
5. 最后把它们放回更大的混合卡组。

第 4 步不能省。视觉对比只能纠正视觉错误，听觉上的混淆可能一点没变。练声音时要比较字符的完整节奏，不要一直数零散的信号元素。

练数字时，可以先抓住几个清楚的锚点：`4` 是四个 dit 加一个 dah，`6` 是一个 dah 加四个 dit；`5` 全是 dit，`0` 全是 dah。记牢这些锚点后，再把十个数字全部混在一起，免得顺序替你作答。

## 从第一天起建立声音到字符的直接联系

ARRL 的[学习摩尔斯电码（CW）建议](https://www.arrl.org/files/file/Morse/LearningMorseCode.pdf)提醒初学者：把每个字符当作一个完整声音来学，听的时候不要同时写下点和横。它建议使用 Farnsworth 练习法，即字符本身按每分钟 15 个单词的速度发送，但字符之间留出更宽的间隔；掌握字符后，再逐步缩短间隔。

这条建议与视觉卡组并不冲突，只要让两种工具各自解决一个问题。

### 第 1 阶段：把一小组字符和音频配对

选择一个能随机播放同一小组字符的 CW 训练器、录音、课程或练习伙伴。先听完整字符，再用字母或数字作答；答错就重放，作答之后才查看表格。

同时从两个视觉方向练习这些对应关系。这样既能读懂书面符号，也不会误把看符号当成听力训练。

不要因为当前的卡片都见过一遍，就急着加入更多字符。等顺序打乱后仍能听出已有字符，再扩大练习范围。

### 第 2 阶段：别再经过点和横来翻译

播放音频时，直接用字符回答。如果脑中的路径仍是“短、长，所以是 A”，说明你还在借助书面电码，声音和答案之间尚未建立直接联系。

在 ARRL 介绍的 Farnsworth 方法中，字符本身始终保持每分钟 15 个单词的速度，只通过拉宽字符间隔来留出更多作答时间。学会字符后，再逐渐缩短间隔。这样既能保留字符内部 1:3 的计时比例，也不会把一个字符拖成几声彼此割裂的哔声。

视觉复习可以继续，但要单独安排时段。听音频时，尝试作答之前不要打开书面对照表。

### 第 3 阶段：混合已学字符，记下具体混淆

把学过的全部字符打乱。记下 `A/N`、`U/D` 或其他实际答错的字符对，不要笼统地写“今天摩尔斯电码练得很差”。先用音频纠正这组混淆，再用卡组核对书面对应关系。

简单的错误记录可以只设三列：

| 听到 | 回答 | 正确答案 |
| :---: | :---: | :---: |
| `A` 的声音 | N | A |
| `U` 的声音 | D | U |

这份记录不需要分数，也不需要预测速度；它只负责找出下一组要对比的字符。

### 第 4 阶段：从单个字符过渡到字符组合

识别单个字符只是基础，真实接收不会等你每答完一次才继续。等你能比较稳定地跟上随机字符后，就开始听短小的随机组合，不要每个字符后都暂停。之后再通过音频工具或练习伙伴加入空格和简单单词。

这套 72 张卡片只覆盖单个字符的视觉对应关系。抄收字符组合、单词、呼号、标点符号、程序信号和真实通信信号，都要在卡组之外另行练习。

### 第 5 阶段：把发送作为独立的反馈环节

字符到组合的卡片可以检验你是否知道该发什么，却无法评估间隔、节奏、发报键调节、手部动作，或其他操作员实际收到的信号。把发送列为学习目标后，还需要进行带监听的发报练习，并请合格人员给出反馈。

## 一套可直接照做的组合练习

视觉与听觉训练可以放在同一次练习中，但两者要分别评分：

1. **复习一小组视觉卡片。** 先给出准确组合，再翻面核对答案。
2. **听同一组已学字符。** 直接用字符作答，不要写出点横字符串。
3. **记录一项具体混淆。** 找出反复出错的字符对或长度问题。
4. **用视觉和听觉分别纠正。** 先对比书面组合，再以随机顺序听声音。
5. **最后听一组不间断的音频。** 漏掉一个字符也继续往下听，不要让整段信号流停住。

只有在本次练习还留得出时间做混合听力时，才加入新字符。否则，视觉卡组会越滚越大，听力进度却一直跟不上。

## 摩尔斯电码 A–Z 字母表常见问题

### 这是完整的国际摩尔斯电码字母表吗？

这是 ITU-R M.1677-1 定义的完整 A–Z 和 0–9 子集，包括 26 个基本拉丁字母和十个数字。完整建议书还包含带重音符号的 `é`、标点符号、其他符号和操作规定，这些都不在这份入门表中。

### 摩尔斯电码中的点和横一样长吗？

不一样。按照 ITU 的计时比例，一个 dah 的时长是一个 dit 的三倍。字符内部的静默为一个 dit 单位，字符之间为三个单位，单词之间为七个单位。

### 这套摩尔斯电码闪卡包含音频吗？

不包含。这套免费卡组有 72 张视觉回忆卡，覆盖 36 个字符的两个练习方向，不含音频或计时练习。如果目标是练听力，请从一开始就配合独立的 CW 音频来源。

### 我应该先通过表格学习摩尔斯电码吗？

用表格核对准确的书面对应关系。练视觉解码时，表格和双向卡片都能直接派上用场；练 CW 接收时，则要从第一天起听声音，让每个字符形成听觉模式，而不是每次都要先转换一幅图形。

### 我应该怎样记住摩尔斯电码数字？

先掌握五个信号的结构，再按随机顺序练数字。`1` 到 `5` 会逐步增加开头的 dit，`6` 到 `9` 会逐步增加开头的 dah，`0` 则是五个 dah。随机回忆才能检验你是否真的记住了某个数字，而不是沿着整行顺序找答案。

### 视觉闪卡能让我流畅接收 CW 吗？

不能。视觉闪卡能帮助你更快回忆字符与组合的对应关系，也能找出具体的视觉混淆。要流畅接收 CW，还得反复听完整的字符声音、字符组合和间隔，最终再练习真实通信。
