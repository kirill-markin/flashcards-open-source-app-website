## 开始背诵前，先划清范围

学习目标是**美国宪法中已经批准的 27 条修正案**。前 10 条合称《权利法案》，于 1791 年 12 月 15 日一同获得批准。美国国家档案馆解释了一个很容易混淆的细节：第一届国会在 1789 年提出了 12 项条文，其中第 3 至第 12 项成为《权利法案》；原第 2 项最终于 1992 年成为第二十七修正案；原第 1 项则从未获得批准。

学习修正案 I–X 时，可以查阅[美国国家档案馆《权利法案》全文](https://www.archives.gov/founding-docs/bill-of-rights-transcript)；其余修正案可查阅该馆的[修正案 11–27 全文](https://www.archives.gov/founding-docs/amendments-11-27)。如果需要带法律和历史注释的修正案文本，请使用 [Congress.gov《宪法评注》索引](https://constitution.congress.gov/browse/)。

下面的简要释义只是帮助回忆的线索，不能替代完整原文。它们可以帮助你想起正确的修正案，却不能用来判断某个条款在具体情形中如何适用，也不能说明现行法律学说的要求。

## 27 条修正案速查表

| 修正案 | 便于学习的核心含义 |
| --- | --- |
| I | 禁止国会确立国教或妨碍宗教信仰自由，并保护言论、出版、和平集会和请愿的自由。 |
| II | 规定管理有序的民兵为保障自由州的安全所必需，人民持有和携带武器的权利不得受到侵犯。 |
| III | 和平时期，未经房主同意不得让士兵驻扎民宅；战时驻扎必须依照法律规定。 |
| IV | 保护人民免受不合理搜查和扣押；令状必须以合理根据为基础，并具体说明搜查地点以及要扣押的人或物。 |
| V | 除规定的军事例外外，死罪或其他重大罪行须经大陪审团起诉；禁止一罪两审和强迫自证其罪；保障正当法律程序，并要求征用私人财产作公共用途时给予公正补偿。 |
| VI | 保障刑事被告在犯罪发生的州和地区，由公正陪审团迅速、公开审判的权利，以及知悉指控、与控方证人对质、强制传唤有利证人和获得律师协助的权利。 |
| VII | 在争议金额超过二十美元的联邦普通法民事诉讼中保留陪审团审判权，并限制重新审查陪审团认定的事实。 |
| VIII | 禁止过高的保释金、过重的罚金以及残酷和异常的刑罚。 |
| IX | 规定宪法列举某些权利，不得被解释为否认或贬低人民保留的其他权利。 |
| X | 宪法未授予联邦、也未禁止各州行使的权力，保留给各州或人民。 |
| XI | 限制联邦法院对另一州公民，或外国公民、臣民起诉某州的案件行使管辖权。 |
| XII | 要求选举人分别投票选举总统和副总统，并规定无人取得选举人票多数时，由众议院和参议院进行选举的程序。 |
| XIII | 废除奴隶制和强迫劳役，但经定罪后作为刑罚的情形除外，并赋予国会实施该修正案的权力。 |
| XIV | 确立在美国出生或归化并受其管辖者的公民身份；通过特权或豁免权、正当法律程序和平等保护条款约束各州；同时涉及国会席位分配、叛乱后的公职资格和公共债务。 |
| XV | 禁止联邦和各州因种族、肤色或曾受奴役的身份而剥夺或限制公民的投票权。 |
| XVI | 允许国会征收所得税，无须在各州之间分摊，也无须以人口普查为依据。 |
| XVII | 规定美国参议员由选民直接选举，并确立参议院席位空缺的处理程序。 |
| XVIII | 禁止生产、销售、运输、进口和出口供饮用的酒精饮料；后来由修正案 XXI 废除。 |
| XIX | 禁止联邦和各州因性别而剥夺或限制公民的投票权。 |
| XX | 规定总统、副总统和国会议员任期在一月开始和结束的日期，要求国会召开会议，并处理若干与当选总统有关的特殊情况。 |
| XXI | 废除修正案 XVIII，并禁止把酒精饮料运输或进口至某州、领地或属地而违反当地法律。 |
| XXII | 一个人当选总统不得超过两次；若曾在他人当选的总统任期内担任总统超过两年，则只能再当选一次。 |
| XXIII | 使哥伦比亚特区拥有总统和副总统选举人，其人数不得超过人口最少州拥有的选举人数。 |
| XXIV | 禁止把缴纳人头税或其他税款作为在联邦选举中投票的条件。 |
| XXV | 规定总统被免职、死亡或辞职时由副总统继任总统；规定如何填补副总统职位空缺；并建立总统无法履职时的处理程序。 |
| XXVI | 禁止因年龄而剥夺或限制年满 18 岁的美国公民的投票权。 |
| XXVII | 任何改变国会议员薪酬的法律，都要等下一次众议员选举之后才能生效。 |

有些修正案包含的内容，远非一句回忆提示所能概括。第十四修正案就是最明显的例子：它的五款涉及公民身份、对各州的限制、席位分配、叛乱后的公职资格、公共债务和国会的实施权。先用简短提示想起编号，再根据课程要求通读全部五款。

## 把 27 条修正案分成八组

如果把 27 条修正案当成一个整体来背，你会同时面对太多缺少规律的“编号—含义”对应关系。下面八组为每条修正案提供一个历史坐标。它们只是方便记忆的非正式分组，并非官方历史分期或法律分类。

| 学习分组 | 修正案 | 记忆锚点 |
| --- | --- | --- |
| 《权利法案》 | I–X | 个人权利、刑事与民事程序、未列举权利和保留权力 |
| 共和国早期的制度调整 | XI–XII | 针对州的诉讼和总统选举程序 |
| 重建时期 | XIII–XV | 奴隶制、公民身份、对各州的约束，以及与种族相关的投票权 |
| 二十世纪初的变革 | XVI–XIX | 所得税、参议员直选、禁酒令，以及与性别相关的投票权 |
| 20 世纪 30 年代的转折 | XX–XXI | 政府任期起止日期和废除禁酒令 |
| 战后政府制度 | XXII–XXV | 总统当选次数限制、哥伦比亚特区选举人、联邦选举中的人头税，以及总统继任或无法履职 |
| 投票年龄 | XXVI | 年满 18 岁公民的投票权 |
| 等待最久的修正案 | XXVII | 国会议员薪酬变更须等众议员选举之后才能生效 |

先按顺序记住这八组。学习组内内容时，大声说出编号和线索：`13—奴隶制`、`14—公民身份、正当法律程序、平等保护`、`15—投票权与种族`。这些对应关系准确后，再打乱各组，避免分组标题继续提示答案。

这种分组很适合 AP Government 和 APUSH 修正案闪卡，因为编号始终与相应的历史时期相连。[AP 美国史闪卡指南](/zh/blog/how-to-use-flashcards-for-ap-us-history/)介绍了如何加入课程所需的史料和论证练习，而不把所有内容都塞进一张卡。如果目前只需要学习《权利法案》，可以先把 I–X 拆成每组三四条的小批次，最后再混合全部 10 条。

## 两个方向都要练

看到编号回忆含义，与看到含义回忆编号，是两种不同的任务。

```text
正面：第二十四修正案（修正案 XXIV）的核心含义是什么？
背面：禁止把缴纳人头税或其他税款作为在联邦选举中投票的条件。
```

```text
正面：哪条修正案禁止把缴纳人头税或其他税款作为在联邦选举中投票的条件？
背面：第二十四修正案（修正案 XXIV）。
```

老师、教科书或考试题直接给出修正案编号时，第一个方向很有用。题目给出一个概念、要求你写出编号时，反向练习则更有用。如果考核可能从任一方向提问，一套完整的 27 条修正案闪卡就需要同时包含两种卡。

同一对正反向卡不要紧挨着。几秒后再次看到同一个答案，主要测试的是短时重复。免费卡组采用固定的交错顺序，让每对正反向卡的间距至少达到 21 个卡位。对于已经确定的易混项，包括投票权、酒类和总统及政府制度几组，任意两张易混卡之间还会插入至少三张其他卡。

自己制卡时，可以用更简单的方式遵循同一原则：把正反向卡分开；完成初步学习后混合相关类别；并且[让每个问题只考一个明确的回忆目标](/zh/blog/how-to-make-better-flashcards/)。

## 对比最容易记串的修正案

直接回忆已经比较准确后，可以加入简短的对比练习。每道题都应迫使你找出两个看似都对的答案之间的区别，而不只是认出一个宽泛的主题。

### 投票权：XV、XIX、XXIV 和 XXVI

| 修正案 | 区分线索 |
| --- | --- |
| XV | 种族、肤色或曾受奴役的身份 |
| XIX | 性别 |
| XXIV | 联邦选举中的人头税或其他税款 |
| XXVI | 年满 18 岁公民的年龄 |

回答时要说清适用范围，不能只答“投票权”。学习相关公民知识时，可以参考[美国公民入籍考试闪卡指南](/zh/blog/us-citizenship-test-flashcards/)，了解如何把稳定的宪法知识与会随公职人员或所在地而变化的答案分开。

### 审判与刑罚：V、VI、VII 和 VIII

- V 汇集了多项保护，包括禁止一罪两审和强迫自证其罪，以及正当法律程序与公正补偿。
- VI 涉及刑事诉讼中的保障，包括迅速、公开审判，公正陪审团、证人对质、强制传唤证人和律师协助。
- VII 在某些联邦普通法民事诉讼中保留陪审团审判权。
- VIII 涉及过高的保释金、过重的罚金以及残酷和异常的刑罚。

好的对比题会直接点明分界：`哪条修正案规定的是联邦普通法民事诉讼中的陪审团审判，而不是刑事诉讼中的陪审团审判？` 这样你就必须在 VII 和 VI 之间作出选择。

### 总统与选举制度：XII、XX、XXII 和 XXV

- XII 要求总统和副总统的选举人票分别投出，并规定无人取得选举人票多数时的选举程序。
- XX 调整任期时间，并处理若干与当选总统有关的特殊情况。
- XXII 限制当选总统的次数。
- XXV 涉及总统继任、副总统职位空缺和总统无法履职。

“总统相关规定”太宽泛，不能算有效答案。题目应明确考查的是选举过程、任期开始时间、当选次数限制，还是继任与无法履职。

### 三组简短对比

- IX 规定，列举某些权利并不等于否认人民保留的其他权利；X 则把未授予联邦、也未禁止各州行使的权力保留给各州或人民。
- XVI 授权征收无须按州分摊的所得税；XXIV 禁止把缴税作为在联邦选举中投票的条件。
- XVIII 确立禁酒令；XXI 废除 XVIII，同时也涉及违反某州法律把酒类运入该州的情形。

只有当某一对修正案反复答错时，才为它添加一张对比卡。把整套卡片复制一遍改成对比题，只会增加复习量，却没有给每张卡分配新的任务。

## 用四个阶段完成学习循环

### 1. 核对来源和课程要求的深度

先确认课程要求掌握的是修正案编号、大意、准确原文、批准日期、历史背景、判例，还是其中几项的组合。以美国国家档案馆和 Congress.gov 的文本为起点，再按照老师、教学大纲或考试规定的范围学习。

### 2. 每次学习一个年代分组

先在一个小组内练习看到编号回忆含义。翻到背面前先作答，并说出完整的区分短语。对于修正案 XV，只答“投票权”并不完整，因为这套内容中还有三条修正案也涉及投票权。

### 3. 混合两个方向和相邻易混项

基本对应关系稳定后，去掉分组标签。把“编号到含义”和“含义到编号”两种卡混在一起，再有意比较相似的修正案。即使想起了正确主题，只要修正案编号答错，也应按错误计分。

### 4. 离开卡组，默写整张地图

每周一两次，在空白纸上写下 `I` 到 `XXVII`，再在每个编号旁写一个核心线索。这样可以消除卡组固定措辞和版式带来的提示。你也可以打乱纸质卡片，或使用美国国家宪法中心的[《27 条修正案配对游戏》](https://constitutioncenter.org/education/classroom-resource-library/classroom/15.3-27-amendments-matching-game)。最后，在不看答案的情况下，大声解释两条容易混淆的修正案。

完成第一轮学习后，只在卡片到期时复习，不必每天从头刷完全部 54 张。[这篇闪卡复习频率指南](/zh/blog/how-often-should-you-review-flashcards/)解释了间隔复习与按固定日程反复刷完整套卡的区别。

## 把法律解释和实际应用分开练

编号与含义卡组能帮你搭起宪法学习的基本框架，但它无法覆盖整个学科。

学习公民学或美国史时，要把每条修正案与课程中的事件和论点联系起来。备考 APUSH 时，要练习把修正案放进历史背景，并在 SAQ、DBQ 或 LEQ 中准确地用作证据。学习 AP Government 或法律入门课程时，则要阅读指定判例、法律学说和教师材料。[法学院闪卡指南](/zh/blog/how-to-use-flashcards-for-law-school/)解释了为什么规则回忆、判例之间的关系和实际应用需要使用不同的题目。

逐字背诵也需要另一种卡片设计。如果课程要求准确原文，请以官方文本为准，围绕指定条款制作更小的问题。简洁的学习摘要应当始终只是回忆线索，不能被当作某条修正案在现行法律中全部含义的结论。

## 美国宪法修正案闪卡常见问题

### 怎样才能记住全部 27 条修正案？

先按非正式历史时期分成小组，练习从编号回忆含义和从含义回忆编号，再混合各组并对比易混项。同时用空白纸默写或做配对练习，让回忆不再依赖卡组熟悉的措辞和版式。

### 《权利法案》就是前 10 条修正案吗？

是的。修正案 I–X 构成《权利法案》，并于 1791 年 12 月 15 日获得批准。国会最初在 1789 年提出 12 项条文，其中 10 项在当时获得批准。

### 我需要逐字背诵每条修正案吗？

只有课程或其他实际要求规定必须掌握准确原文时才需要。编号与核心含义卡组不会训练逐字背诵。需要学习准确措辞时，请以美国国家档案馆的文本为准。

### 修正案的批准日期也应该做成闪卡吗？

只有考核涉及日期时，才需要添加日期题。在免费卡组中，准确的批准日期会作为参考信息显示在背面，但不会反过来考查“日期对应哪条修正案”。

### 这些卡片能代替判例阅读或法律分析吗？

不能。它们只涵盖修正案编号和简洁的学习摘要，不教授判例、现行法律学说、争议或法律适用。
