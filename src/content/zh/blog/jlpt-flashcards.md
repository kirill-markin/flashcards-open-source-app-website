2025 年两次 JLPT 考试共有来自 92 个国家和地区的 1,940,852 人报名，比 2024 年增长 12.9%（[官方历年考试数据](https://www.jlpt.jp/e/statistics/archive.html)）。但主办方已不再发布包含固定词汇、汉字和语法清单的《考试内容规范》。

真正有用的 **JLPT 闪卡** 要围绕官方题型中的具体判断来设计：读出单词中汉字的读音、根据语境选择近义表达、把句子片段排成符合语法的顺序，再记录阅读或听力练习中漏掉的确切线索。完整篇章、限时训练和不看文字稿先听音频的练习应留在闪卡之外，继续按完整题型练习。

## 按官方题型设计闪卡

JLPT 主办方公布了各级别的[考试科目与题型](https://www.jlpt.jp/e/guideline/testsections.html)，还为每种题型提供了[一道样题](https://www.jlpt.jp/e/samples/forlearners.html)和两册内容更完整的[官方练习册](https://www.jlpt.jp/e/samples/sampleindex.html)。

与其下载一套号称包含“全部 JLPT 词汇”的牌组，不如用这些官方页面来规划自己的牌组。

官方常见问题解释了为何 2010 年考试修订后不再发布《考试内容规范》。JLPT 考查语言知识，以及在交际任务中运用这些知识的能力。因此，主办方认为不适合再发布列有词汇、汉字和语法项目的规范（[JLPT 常见问题](https://www.jlpt.jp/e/faq/#anchor28)）。

这并不意味着第三方教材或词表没有用。它们仍可提供实用的学习路径，但需要准确标注来源：某家出版社的 N3 词表只是该出版社对相应级别范围的理解，不是完整的 JLPT 官方词表。

官方题型提供了一张可靠的备考地图：

| 官方题型组 | 出现级别 |
| --- | --- |
| 汉字读音、根据语境判断词义、近义表达 | N1–N5 |
| 书写形式 | N2–N5 |
| 词汇用法 | N1–N4 |
| 构词 | 仅 N2 |
| 语法形式选择、句子组合、篇章语法 | N1–N5 |
| 短篇、中篇、信息检索类阅读 | N1–N5 |
| 长篇阅读理解 | N1 和 N3 |
| 综合理解与主题理解类阅读 | N1 和 N2 |
| 任务理解、要点理解、即时应答类听力 | N1–N5 |
| 概要理解类听力 | N1–N3 |
| 话语表达类听力 | N3–N5 |
| 综合理解类听力 | N1 和 N2 |

这张表也说明，报考级别变化后，牌组的一部分必须随之调整。N5 没有词汇用法题，只有 N2 考构词。N1 和 N2 会要求比较、整合多篇文本或多个听力信息来源。通用日语牌组可以提升语言能力，却不一定覆盖你所在 JLPT 级别要求的具体判断。

如果你还在学习日语文字，可以用[包含全部 46 个基本平假名及罗马字的闪卡组](/catalog/packages/basic-hiragana-romaji/)练习 46 个现代基本平假名；卡组共 92 张，分别训练“假名 → 面向学习者的赫本式罗马字”和“罗马字 → 假名”。它只是基础文字练习，不是 JLPT 官方词表，也不能替代针对相应级别的词汇、语法、阅读和听力训练。

## 把汉字和词汇拆成小判断

刚开始时，`提出 = 提交` 这样的卡片可能有用。但官方题型要求的不只是翻译。根据级别不同，词汇题可能要求你读出汉字、选择正确字形、根据语境理解词义、寻找近义表达、判断用法，或识别构词方式。

让每张卡片只完成其中一项任务。

### 在真实单词中读汉字

使用简短的原创句子，让读音与具体单词和语境绑定：

**正面**

```text
申込書を提出してください。

「提出」の読み方は？
```

**背面**

```text
ていしゅつ
提交；递交
```

不要把背面写成一整页词典。如果一个词有多个常用读音或含义，就只考当前句子中的用法；第二种用法确实重要时，再单独制作一张卡片。

对 N2 至 N5 而言，书写形式值得单独做成反向卡片：在句子中给出读音，要求回忆对应汉字。N5 还会考查用片假名写出以平假名提示的词。识别和输出是两种能力，可能各自出错。

### 询问语境中的含义或近义表达

五个级别都包含根据语境判断词义和选择近义表达的题型。有效的提示应保留足够语境，让你能够作出判断：

**正面**

```text
会議は来週に延期になった。

「延期」に近い意味は？
```

**背面**

```text
予定していた日を後に変えること
延期；把原定日期向后调整
```

中文释义只是辅助，不应成为完整答案。随着级别提高，应更多使用日语解释和意思更接近的日语替代表达。

### 用需要判断的句子考查词汇用法

备考 N1 至 N4 时，可以加入这种卡片，用来区分“看得懂一个词”和“能自然地把它放进句子”。

**正面**

```text
「支障」の使い方として自然なのはどちら？

A. 電車が少し遅れたが、仕事に支障はなかった。
B. 電車が少し遅れたが、仕事を支障しなかった。
```

**背面**

```text
A

「支障がある／ない」または「支障を来す」の形で使う。
```

这些例句均为原创内容。保存前，请用可信的词典、老师或资料检查含义和自然度。AI 可以提供候选句，但日语看起来流畅，不代表卡片内容一定正确。

如果答案确实依赖视觉信息，例如标志、物品或相似字形之间的区别，图片和其他媒体会有帮助。不要给每个单词都配一张装饰图片。隐藏答案后，卡片仍应要求你主动回忆。

## 语法闪卡应要求选择或组句

每个 JLPT 级别都包含三类语法题：选择语法形式、组合句子，以及判断篇章中的语法。比起堆一叠只写语法名称的卡片，用三种对应的卡片形式能覆盖更多实际能力。

练习语法形式选择时，隐藏真正需要判断的部分：

**正面**

```text
この資料は初心者___分かりやすい。

选项：に / にも / には
请选择表示“即使对初学者来说也”的选项。
```

**背面**

```text
にも

この資料は初心者にも分かりやすい。

にも 在这里表示“即使对初学者来说也”。
```

只有在简短说明能帮助你排除一个容易混淆的选项时，才需要添加解释。如果一张卡片可以接受多个合理答案，就需要补充语境或把问题写得更明确。

练习句子组合时，把所有片段放在正面：

**正面**

```text
並べ替える：
駅 / まで / 歩いて / どのくらい / かかりますか
```

**背面**

```text
駅まで歩いてどのくらいかかりますか。
```

翻面前，先完整说出或写出句子。只在脑中认出顺序，会让排序卡显得比实际更容易。答案必须使用每一个片段；如果多种顺序都能组成自然的句子，就修改提示。

篇章语法至少需要两个相连的句子：

**正面**

```text
電車が止まっていた。___、約束の時間に間に合わなかった。

选项：しかし / そのため / たとえば
请选择表示“因此”并连接原因与结果的表达。
```

**背面**

```text
そのため

そのため 表示“因此”，用于引出结果。
```

之后再用一个全新的段落测试同一个连接表达。卡片帮助你记住句间关系，新语境则能检验你是否会用。

## 记录阅读错因，保留完整原文

阅读题考查对连贯文本的理解，不同级别的考查目标也不同。N5 使用简单的短篇、中篇文本和信息检索题；N3 增加长篇文本与逻辑展开。N1 和 N2 还包括比较或整合多篇文本，以及判断更广泛的主题或写作意图。

把整篇原文复制到卡片上，会失去原本让题目变难的作答条件，还可能不必要地复制受版权保护的内容。JLPT 主办方明确禁止未经授权复制试题（[JLPT 常见问题](https://www.jlpt.jp/e/faq/#anchor26)）。

先在原练习材料中完成整篇文章，再给错误分类：

- 不认识的单词或读音
- 语法关系
- `それ`、`この点` 等指代词
- 因果关系
- 对比关系或作者立场的变化
- 两篇文本之间的差异
- 忽略了通知、日程、广告或表格中的条件
- 问题出在时间压力，而非知识缺口

前七类问题都可以做成有用的卡片。时间不够需要通过限时阅读来解决，而不是制作一张写着“读快一点”的卡片。

假设你选错了作者反对某项提议的原因，可以制作这样的修正卡：

**正面**

```text
练习套题 4，阅读 2：
为什么费用示例不是作者反对该提议的主要原因？
```

**背面**

```text
费用只是佐证。作者明确提出的反对理由是
准备时间不足。

错因：我把费用示例当成了主要理由。
来源：[教材或官方练习册，页码]
```

这张卡片记录的是具体区别，以及当时把你带偏的陷阱，不会复制原文或答案选项。如果脱离原文后看不懂提示，就重写或删除卡片。接下来，再找一篇陌生文章练习同类推理任务。

针对信息检索题中的错误，可以记录筛选规则：

**正面**

```text
案内から条件に合う選択肢を探す前に、何を確認する？
```

**背面**

```text
要求的日期或时间、资格条件和排除条件。
```

这种官方题型从 N5 到 N1 都会出现。材料和复杂度随级别变化，但逐一检查所有条件的习惯始终有用。

[把练习题转成闪卡](/blog/how-to-turn-practice-questions-into-flashcards/)进一步介绍了如何把一道错题压缩成一条可重复使用的经验。别忘了在计划中安排下一篇陌生文章；[闪卡与模拟测试](/blog/flashcards-vs-practice-tests/)衡量的是备考状态的不同部分。

## 听力训练要从看文字稿之前开始

文字稿非常适合诊断问题，但如果先读文字稿再听音频，听力练习的效果会很差。

按以下顺序使用官方样题音频或其他获得授权的听力材料：

1. 只阅读说明，以及播放前题目提供的信息。
2. 不看文字稿，先听一遍。
3. 选择答案，并记录自己的把握程度。
4. 核对答案。
5. 重听音频进行诊断，定位出错的那一刻。
6. 打开文字稿，找出漏听的具体语音细节、单词、语法形式、意图或关系。
7. 只针对这个今后可能再次遇到的薄弱点制作卡片。
8. 关闭文字稿，再听一遍音频。

[JLPT 官方样题集](https://www.jlpt.jp/e/samples/sample09.html)提供 N1 至 N5 的音频、文字稿和答案。该资料原本用于说明 2010 年的考试修订；页面提醒，实际题量与样题不同，部分答题说明此后也有变化。请用当前的题型页面确认任务结构。

文字稿修正卡可以这样写：

**正面**

```text
「念のため、もう一度確認しておきます。」

「念のため」が示す話し手の判断は？
```

**背面**

```text
問題があると決めたのではなく、用心のために確認する。
说话者是出于谨慎再次确认。
```

然后在新的录音中辨认这个表达。文字复习可以保留你漏掉的含义，却无法证明你能在自然语速下听出这个短语。

练习内容要匹配所在级别的听力题型。N3 至 N5 有结合情景和插图的话语表达题。N1 和 N2 则有整合多项信息的综合理解题。N1 至 N3 考查概要理解，而每个级别都包含任务理解、要点理解和即时应答。

练习任务理解和综合理解时，记录当时没有听明白的关系：谁必须采取行动、哪个条件发生了变化、哪个选项满足全部限制，或两位说话者的观点有何不同。完整录音应继续作为先听音频的任务。卡片上的文字稿片段只是修正工具，不能代替完成听力任务本身。

## 根据报考级别分配学习时间

官方[2026 年考试日程与科目说明](https://www.jlpt.jp/e/guideline/testsections.html)列出的考试日期为 7 月 5 日（星期日）和 12 月 6 日（星期日）。日本以外的一些城市每年只举行一次考试，因此还要确认当地日程和报名信息。

各级别的科目时长也不同：

| 级别 | 语言知识与阅读 | 听力 |
| --- | --- | --- |
| N1 | 词汇、语法、阅读合并：110 分钟 | 55 分钟 |
| N2 | 词汇、语法、阅读合并：105 分钟 | 50 分钟 |
| N3 | 词汇：30 分钟；语法与阅读：70 分钟 | 40 分钟 |
| N4 | 词汇：25 分钟；语法与阅读：55 分钟 | 35 分钟 |
| N5 | 词汇：20 分钟；语法与阅读：40 分钟 | 30 分钟 |

官方页面指出，规定时长可能调整，听力时间也会随录音长度略有变化。N1 和 N2 把语言知识与阅读合并为一个考试科目。N3、N4 和 N5 则把词汇与语法、阅读分开。偶尔应按这一结构安排学习，包括科目转换和持续专注；这些都不是闪卡能训练的能力。

计分结构也是保持牌组平衡的另一个原因。N1 至 N3 分别报告语言知识、阅读和听力成绩。N4 和 N5 合并语言知识与阅读成绩，听力单独计分。根据官方[成绩科目说明](https://www.jlpt.jp/e/guideline/results.html)，通过考试既要达到总分合格线，也要达到每个计分科目的合格线。

N1 至 N3 的每个计分科目最低要求都是 60 分中的 19 分。N4 和 N5 的语言知识与阅读合并成绩最低要求为 120 分中的 38 分，听力最低要求为 60 分中的 19 分。即使总分很高，也无法弥补某个科目低于最低分。

这不代表每个科目都要制作同样数量的卡片。适合通过主动回忆来巩固的内容才做成卡片，其余部分则安排完整的阅读和听力练习。听力薄弱时，再增加一百张孤立的汉字卡也解决不了问题。

## CEFR 参考等级没有带来新考纲

从 2025 年 12 月起参加 JLPT 并通过考试的考生，成绩单会根据总分显示 A1 至 C1 的 CEFR 等级，作为参考信息。未通过考试则不会显示。官方说明明确指出，这项调整没有改变考试内容，也不要求考生采用不同的备考方式（[JLPT CEFR 通知](https://www.jlpt.jp/e/cefrlevel/cefrnews.html)）。

这项变化也没有把 JLPT 变成听、说、读、写四项考试。该参考等级只涵盖 JLPT 所测量的语言知识和接受性技能：语言知识、阅读与听力，不涵盖口语、写作等产出能力或互动能力（[CEFR 官方说明](https://www.jlpt.jp/e/about/cefr_reference.html)）。因此，也不存在可制成卡片的全新官方“2026 CEFR 词汇表”。

## 用小牌组配合真实日语

从正在学习的材料和自己实际犯过的错误开始。每周可以按以下节奏练习：

- 一节课后，为读音、语境词义、近义表达、词汇用法和语法判断添加几张已经核实的卡片。
- 阅读练习后，针对每个知识或推理缺口记录一个简短知识点。速度和耐力问题留在练习计划中解决。
- 听力练习后，查看文字稿，保存漏掉的线索，再关掉文字重听音频。
- 卡片到期时进行复习。
- 每周完成一次混合训练，题型与所在级别的官方题型一致。
- 定期在没有闪卡帮助的情况下，完成一段较长的阅读或听力练习。

FSRS 可以根据你的复习记录安排下一次复习：难卡更早出现，熟悉的卡片间隔更久。它无法判断句子是否自然、卡片是否属于 N2，也无法发现你复制了一段错误解释。[用 FSRS 备考的流程](/blog/how-to-study-for-an-exam-with-fsrs/)介绍了如何在固定考试日期前逐步减少新卡数量。

在 [Flashcards Open Source App](/features/) 中，本指南的示例只需使用普通正反面卡片。标签可以记录级别和题型，例如 `N3`、`kanji-reading`、`paraphrase`、`text-grammar` 或 `listening-miss`。图片或相关媒体能提供有效语境时，也可以加入卡片。你可以用 FSRS 复习到期卡片，在移动端离线学习，并在恢复网络后同步更改。导入和导出功能可让卡片、标签及相关媒体保持可迁移。

应用不提供预制 JLPT 牌组或 JLPT 模拟考试，也不能直接导入 Anki `.apkg` 文件。AI 可以协助起草或精简候选卡片，但不会核实日语、来源准确性、级别归属或考试相关性。保存前必须检查每张生成的卡片。[入门指南](/docs/getting-started/)介绍了托管版、移动端、Agent 和自托管选项。

## 根据学习材料和错题制作接下来的十张卡片

打开所在级别的官方题型页面，再准备一份你信任的学习材料。从当前课程或近期错题中选出十个知识点：

- 两个置于语境中的汉字读音
- 两个语境词义或近义表达
- 一个当前级别会考查的词汇用法或字形判断
- 两个语法判断
- 一张阅读错题修正卡
- 两张在先听音频练习后制作的听力错题修正卡

十张就足够开始。复习这些卡片，修改含糊的提示；只有当课程或练习暴露出真实需求时，再继续添加。

好用的 JLPT 牌组应当能够追溯来源。你清楚每张卡片对应的级别、题型、来源，以及背后的错误或判断。牌组以外的备考仍要覆盖更完整的任务：读完全文、听陌生音频、完成限时训练，并在真实交流中使用日语。

先制作这十张 JLPT 闪卡，再回到一篇新文章或一段新录音。牌组帮助你记住这些小知识点，下一次完整练习则检验你能否在考试前真正运用它们。
