[Flashcards](/) 托管版在 beta 期间费用为 $0，也不要求绑定信用卡。AI 和同步功能都包含在内，闪卡数量、文件数量和总存储空间均不设套餐配额。对于使用正反面闪卡学习的人来说，它是一款**免费的 Quizlet 替代方案**。不过，这里的“免费”有两个前提：技术限制依然存在，而且并非所有托管功能都承诺永久免费。

这款软件采用 MIT 许可证，因此自托管不收软件许可费，但运行生产环境仍然要花钱。如果你离不开 Quizlet 的 Learn 或 Test 模式、公共学习集、AI 学习工具套件或课堂工具，Flashcards 也没有一一对应的替代功能。

> **利益披露：** 我是 Kirill Markin，也是 Flashcards 的开发者。本文重点说明价格和免费范围，包括 Quizlet 提供、而 Flashcards 尚未提供的功能。

## 托管版 beta 中哪些功能免费？

目前，你可以免费注册并使用主要学习流程：

- 创建和编辑正反面闪卡
- 使用 FSRS-6 调度器复习
- 修改闪卡和完成复习时，数据会先写入本地，再同步到 Web、iOS 和 Android
- 为闪卡添加相关媒体
- 使用可添加文件附件的 AI 对话
- 通过 MCP 连接 AI 客户端
- 使用 Agent API
- 导入和导出 Flashcards 工作区数据包

beta 期间，AI 和跨设备同步都不需要付费解锁。[定价页](/pricing/)列出了托管版目前包含的服务，以及未来的承诺边界。

功能包含在内，不代表它能全程离线使用。修改闪卡和完成复习时，数据可以先写入本地，重新联网后再同步；AI 调用和同步本身仍然需要网络连接。

## 免费托管版也有技术限制

没有套餐配额，不等于没有技术限制。Flashcards 不会根据闪卡总数、文件总数或已用存储空间限制 beta 账号，但单次请求和传输仍有大小上限。

目前，`flashcards.zip` 数据包的限制如下：

| 单次数据包操作 | 限制 |
|---|---:|
| 单个数据包中的闪卡 | 5,000 张 |
| 单个数据包中的媒体文件 | 10,000 个 |
| 单个媒体文件 | 16 MiB |
| 单个数据包中的媒体总大小 | 64 MiB |
| 导入的 ZIP 文件 | 80 MiB |

这些数字限制的是单次导入或导出，并非整个账号的闪卡、文件或存储上限，也不是隐藏付费套餐的门槛。较大的工作区可能需要拆成多个数据包迁移。AI 请求和附件也有各自的单次请求限制和文件支持范围。

## 导入导出支持的格式很有限

Flashcards 只有一种原生传输格式：`flashcards.zip` 工作区数据包。

它可以导入由 Flashcards 导出的有效数据包，但不能导入 Quizlet 学习集、CSV、TSV 或其他通用分隔符文本。Quizlet 可以[通过导入分隔符文本创建学习集](https://help.quizlet.com/hc/en-us/articles/360029977151-Creating-sets-by-importing-content)；Flashcards 没有对应的文本导入界面。

数据包会带上 Flashcards 可以重建的学习内容：

- 闪卡
- 闪卡标签
- 闪卡引用的媒体

但不会带上与这些内容相关的状态：

- 复习历史
- FSRS 调度器状态
- 工作区设置
- 完整牌组结构
- 账号数据

因此，`flashcards.zip` 可以在托管版与自托管版 Flashcards 工作区之间迁移选定的学习材料，但不能完整复制账号，也无法接着原来的复习计划继续学习。它同样不能用作灾难恢复备份；负责自托管的人仍需备份数据库和媒体文件。

### 现有 Quizlet 学习集需要重新创建

Quizlet 允许创建者在网站上[导出自己拥有的学习集中的术语和定义](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets)，但不会导出复制的学习集或图片。

导出结果是文本，并非 Flashcards 可以接收的数据包。你可以手动重建选定的闪卡，也可以把文本作为源材料交给 Flashcards 的 AI 对话，让它起草正反面闪卡。无论采用哪种方法，都需要你检查并保存重建后的卡片，都不属于直接导入。

[Quizlet 导出指南](/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/)介绍了文本清理流程。这并非无损迁移：导出内容不含图片和学习状态，Flashcards 也无法把这些文本作为原生传输格式直接导入。

## 自托管不收许可费，但运行仍有成本

Flashcards 代码采用 MIT 许可证。你可以查看、修改和部署代码，无需购买软件许可证。生产服务器和相关运维则要另外付出成本。

项目支持的生产部署方式是仓库中的 AWS CDK 技术栈。Docker 和 PostgreSQL 配置只用于本地开发，并不是文档所支持的生产部署捷径。

生产环境运维者需要负责：

- AWS 数据库、存储、计算和网络服务
- 域名和 DNS 配置
- 邮件投递
- 监控和告警
- 可选 AI 服务商的用量费用和凭据
- 密钥管理
- 数据库和媒体备份，包括恢复测试
- 升级、迁移、安全维护和运维时间

这套技术栈会自动完成部分部署工作，但上述责任仍要由运维者承担。这里无法给出适用于所有人的月费估算：区域、流量、存储量、备份策略、邮件量、AI 用量和运维方式都会影响账单。[自托管指南](/docs/self-hosting/)说明了 AWS 架构，以及本地开发与生产部署之间的边界。

所以，自托管改变的是由谁付费、由谁运维，并不会让云基础设施变成免费服务。如果你并不需要掌控基础设施，那么在托管版 beta 免费期间，直接使用托管版可以省去这些运维工作。

## Quizlet 的几项重要功能还没有对应替代品

Flashcards 目前没有直接对应 Quizlet 以下四类功能，而对有些用户来说，它们比价格更重要：

- 独立的 Learn 和 Test 模式，包括自动生成的选择题流程
- 规模相当的公共学习集库
- Quizlet 的 AI Study Guides、Practice Tests 和 Ask Quizlet 工具套件
- 围绕 Quizlet Live、班级和学习进度报告建立的课堂与教师生态

Quizlet 的功能概览介绍了 [Learn、Test、Practice Tests、Study Guides 和 Quizlet Live](https://help.quizlet.com/hc/en-us/articles/360030841732-Studying-on-Quizlet)。Quizlet 免费版也有限制：非订阅用户只能完成有限轮次的 Learn，每个学习集也只能免费完成一次 Test。加入符合条件、由教师管理的班级后，学生可以针对班级学习集获得[不限次数、无广告的 Learn 和 Test 使用权](https://help.quizlet.com/hc/en-us/articles/34270983035149-Free-student-access-to-Learn-and-Test-modes)。

如果引导式学习模式、现成的公共学习材料或课堂工具是你日常学习的核心，那么 $0 的 Flashcards 账号也替代不了它们。免费 beta 覆盖的是另一套流程：正反面闪卡、FSRS-6 复习、离线优先的数据写入与同步、媒体、AI 对话和智能体访问。

## 免费 Quizlet 替代方案：坦诚的结论

beta 期间，如果你的学习方式以正反面闪卡、FSRS-6 复习、Web 和移动端离线优先使用、同步、媒体及 AI 辅助为主，Flashcards 是一款**免费的 Quizlet 替代方案**。它不要求绑定信用卡，闪卡数量、文件数量和总存储空间也不设套餐配额，但数据包和请求仍有技术限制。

它无法一一替代 Quizlet 的 Learn 或 Test 模式、公共学习集库、AI 学习功能或课堂系统。现有 Quizlet 材料也不能直接导入，只能根据允许导出的文本重新创建。

把几类成本分开看会更清楚：托管版 beta 目前费用为 $0；核心的闪卡创建和复习功能会一直免费；未来 AI 用量较高时，可能需要你提供自己的服务商密钥或选择付费方案。自托管不收软件许可费，但要承担基础设施、第三方服务、维护和运维时间成本。如果这些边界符合你的需求，可以[打开 Flashcards](https://app.flashcards-open-source-app.com/)试用托管版。
