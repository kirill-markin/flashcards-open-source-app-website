一台台式机拔掉电源后就记不住时间。一台笔记本电脑给自己分配了 `169.254.x.x` 地址。一名用户可以登录，却无法编辑共享文件。CompTIA A+ 要求技术人员根据这些细小线索作出判断，而两门考试各自最多有 90 道题。

好用的 **CompTIA A+ 闪卡**能让你更容易想起线索、判断及其理由。端口、连接器、命令、症状、安全概念和支持流程都适合做成卡片。但要练习安装硬盘、解读陌生的命令输出，或完成包含多个步骤的实操题（PBQ），闪卡就没那么有用了。这些内容依然要靠真机或实验环境。

## 备考当前的 CompTIA A+ V15 考试

截至 2026 年 8 月 1 日，当前有效的 A+ 考试系列是 V15：

- Core 1：`220-1201`
- Core 2：`220-1202`

CompTIA 于 2025 年 3 月 25 日推出这两门考试，目前预计在 2028 年退役。你必须两门都通过才能获得 A+ 认证。购买考试券前，到官方 [Core 1 页面](https://www.comptia.org/en-us/certifications/a/core-1-v15/)和 [Core 2 页面](https://www.comptia.org/en-us/certifications/a/core-2-v15/)再次核对考试代码最稳妥。

| 考试 | 最多题数 | 时长 | 合格分数 |
| --- | ---: | ---: | ---: |
| Core 1 (`220-1201`) | 90 | 90 分钟 | 100–900 分制中的 675 分 |
| Core 2 (`220-1202`) | 90 | 90 分钟 | 100–900 分制中的 700 分 |

考试页面逐项列出了单选题、多选题、拖放题和实操题。考试目标 PDF 则用更简短的“选择题和实操题”概括。两种描述指的都是同一套 V15 考试。

还有一个版本号很容易混淆。当前 [Core 1 考试目标 PDF](https://lecbyo.files.cmp.optimizely.com/download/34be017cb73211ef8985a6f347fbf652)和 [Core 2 考试目标 PDF](https://lecbyo.files.cmp.optimizely.com/download/cefedfb2b8a511ef809306d06d323538)均注明 **Exam Objectives Document Version 4.0**。这是可下载文档的修订版本；**V15** 才是考试系列。以后 PDF 修订号再次变化时，仍应以考试代码和 CompTIA 当前的考试页面为准。

已退役的 `220-1101` Core 1 和 `220-1102` Core 2 考试属于 V14。有些基础知识仍然通用，但旧考试目标已经不能作为当前考试的可靠检查清单。

## 按两门 Core 各自考查的工作拆分卡组

在真实的支持工单中，Core 1 与 Core 2 会有交集，但两份考试蓝图的重点不同。

| Core 1 (`220-1201`) | 权重 | Core 2 (`220-1202`) | 权重 |
| --- | ---: | --- | ---: |
| 移动设备 | 13% | 操作系统 | 28% |
| 网络 | 23% | 安全 | 28% |
| 硬件 | 25% | 软件故障排除 | 23% |
| 虚拟化与云计算 | 11% | 操作流程 | 21% |
| 硬件与网络故障排除 | 28% |  |  |

实际来看，Core 1 要求你把设备、组件、网络行为和物理症状联系起来。Core 2 更侧重操作系统工具、安全、软件故障、文档、变更控制和用户支持。

可以使用两个卡组，也可以给每张卡添加 `core-1` 或 `core-2` 标签。如果考试目标编号能方便你核对卡片，也把它加上，例如打印机故障排除可以标记为 `220-1201:5.6`。`lab-miss`、`practice-miss` 或 `objective-check` 这样的来源标签，则能说明这张卡为什么存在。

这些百分比用于检查覆盖范围，不是规定卡片数量。如果某个领域占考试的 28%，你的卡组却几乎没有涉及，就应该仔细检查。对于已经能熟练回忆和应用的内容，也不必硬凑几十张卡。

## 围绕一个技术判断来写 A+ 卡片

卡片应该容易判定对错：翻面前，你要么知道答案，要么不知道。清晰的 A+ 问题通常要求你完成以下四类任务之一。

### 区分两个相近概念

Core 1 会把接口、外形规格、线缆、网络服务和云模型等相近概念放在一起。卡片要问清那条能避免实际错误的分界线。

```text
正面：“M.2 SSD”能否说明硬盘使用 SATA 还是 PCIe/NVMe？

背面：不能。M.2 描述的是外形规格。需要查看硬盘和主板的规格，确认它们
支持的接口与协议。
```

```text
正面：Type 1 虚拟机监控程序与 Type 2 虚拟机监控程序有什么区别？

背面：Type 1 直接运行在主机硬件上。Type 2 运行在主机操作系统上。
```

这类卡片比照抄定义更有用，因为问题会要求你作出选择。

### 把症状与下一项检查联系起来

故障排除卡片的措辞必须谨慎。一个症状很少能证明只有一个原因。

```text
正面：一台 Windows 客户端获得了 169.254.x.x 地址，无法访问本地网络。
这个地址说明了什么？接下来应该检查什么？

背面：客户端未能取得 DHCP 租约，因此自行分配了 APIPA 地址。先检查
有线或无线链路，再检查它到 DHCP 的路径。
```

```text
正面：一台台式机通电时走时准确，但断开所有电源后会丢失日期和时间。
首先检查哪个组件比较合理？

背面：CMOS/RTC 电池，同时仍要继续排查其他固件或主板故障的可能性。
```

“由此可以初步判断什么？”通常比“这是什么造成的？”更合适。前一种问法给继续寻找证据留出了空间；后一种问法可能让人误以为已经确定了唯一原因。

### 把服务与线索一起记住

端口要从两个方向学习，再把它与支持场景联系起来。

```text
正面：技术人员需要通过加密的远程命令行访问一台主机。哪种标准服务和
端口符合这个需求？

背面：SSH，通常使用 TCP 端口 22。
```

```text
正面：一台服务器开放了 TCP 端口 22。应该优先调查哪项服务？

背面：标准关联是 SSH。还要确认实际监听的进程；仅凭端口号不能证明
正在运行哪项服务。
```

这样，端口卡组就不会变成单纯背数字。想更深入了解协议卡片，可以阅读 [Security+ 闪卡指南](/blog/how-to-use-flashcards-for-security-plus/)。A+ 卡组的范围仍应以 A+ 考试目标为界。

### 选择能提供所需证据的工具

Core 2 目标 1.4 和 1.5 涵盖 Windows 管理工具和命令行工具，并要求你在场景中使用合适的工具。写问题时，先写要完成的任务，让答案指向工具。

```text
正面：测试 DNS 或路由之前，哪条 Windows 命令可以显示客户端当前的
IP 配置？

背面：ipconfig
```

```text
正面：哪条 Windows 命令可以直接测试主机名能否解析为 IP 地址？

背面：nslookup
```

```text
正面：Windows 崩溃前后的应用程序和系统事件应该在哪里查看？

背面：Event Viewer (eventvwr.msc)
```

复习卡片后，实际运行一次命令或打开工具。卡片帮你想起第一步，真机则会教会你选项、输出、权限和各种失败状态。[终端命令闪卡指南](/blog/how-to-learn-terminal-commands-with-flashcards/)更详细地介绍了这个循环。

## Core 2 还会考查边界、顺序和判断

Core 2 看起来可能只是一串 Windows 工具与安全术语。更好的卡片会把这些知识放进技术支持中的具体判断里。

学习安全时，要对比解决不同问题的控制措施：

```text
正面：移除用户的管理员权限与启用多因素身份验证有何不同？

背面：移除管理员权限会限制用户登录后的授权范围。多因素身份验证会
加强登录时的身份验证。
```

学习操作流程时，要保留能够保护系统和客户的先后顺序：

```text
正面：实施一项已批准的工作站变更之前，为应对失败，必须明确哪两项计划？

背面：备份计划和回滚计划。变更记录还应包含范围、风险、批准情况、时间、
受影响的系统、实施过程和结果。
```

学习客户支持时，把场景写具体：

```text
正面：用户用含糊的语言描述问题。提出解决方案前，技术人员应该怎么做？

背面：提出有针对性的开放式问题，再复述问题，确认双方理解一致。
```

Core 2 目标 4.10 还包括基础 AI 概念：合理使用政策、抄袭、偏见、幻觉、准确性，以及公开数据与私有数据方面的注意事项。用几张范围明确的卡片就够了，不必再做一整套 AI 课程：

```text
正面：把客户的诊断日志粘贴到公共 AI 服务前，技术人员应该确认什么？

背面：组织的 AI 与数据处理政策、日志是否包含私有或受监管的数据，以及
该服务是否获准处理这类数据。
```

## 闪卡代替不了完整的 PBQ 练习

CompTIA 将[实操题](https://www.comptia.org/en-us/resources/test-policies/exam-development/performance-based-questions-explained/)描述为在模拟或虚拟环境中考查问题解决能力的题目，目前也把 A+ 列入包含模拟 PBQ 的认证。一个 PBQ 可能要求你在同一个技术情境中完成多项观察和操作。一张只有一行字的卡片无法还原这个完整情境。

在 PBQ 或实验练习前后使用卡片：

1. 练习前，回忆端口、连接器、命令用途、权限或故障线索等小知识点。
2. 练习时，在完整界面中操作并检查可用的证据。
3. 答错后，记下忽略的线索，以及把自己引向错误方向的假设。
4. 只有当某个具体知识点回忆失败导致了错误，才为它制作一张卡片。
5. 换一个场景，再次检验补上的知识。

假设你记得 DNS 的作用，却花了很久才判断问题是否出在名称解析。询问何时使用 `nslookup` 的卡片，可以补上这个回忆缺口。下一次实验应换一台主机和一种失败状态，这样你仍然必须推理。

如果真正的问题是界面导航、命令输出、组件安装、时间管理或证据收集不完整，就不要把这次错误压缩成卡片。这些问题需要更多 PBQ 练习、虚拟实验室、备用硬件或篇幅更长的故障排除练习。

考试目标文档还提醒考生，不要使用通常称为 brain dump 的未获授权第三方材料。应使用当前考试目标、获授权的培训与练习，以及自己的实验笔记。[把练习题变成闪卡](/blog/how-to-turn-practice-questions-into-flashcards/)介绍了如何在不复制题目的前提下，保留可以反复运用的知识点。

## 每次围绕一门 Core 建立学习循环

先选定准备参加的第一门考试，优先复习它的卡片。针对每个领域：

1. 使用当前有效、获得授权的资料学习一小组考试目标。
2. 完成一项动手任务或一组正规练习题。
3. 只把犹豫、险些答错和确实答错的内容做成卡片。
4. 继续动手练习，同时用 FSRS 复习到期卡片。

每周将卡组与领域表格对照一次。这样可以发现盲区，又不会让复习队列塞满照抄的考试目标条目。临近考试时，放慢制作新卡的速度，把更多时间用在限时题、PBQ 和新的故障排除场景上。

CompTIA 建议参加两门 V15 考试的考生具备 12 个月 IT 支持专员岗位的实践经验。这是建议，不是额外的认证要求，但它能提醒你：考试目标期待考生具备怎样的实际背景。

## Flashcards Open Source App 在哪里发挥作用

[Flashcards Open Source App](/features/)负责记忆这一层：普通正反面卡、卡组与标签、使用 FSRS 复习到期卡片、由 AI 辅助起草卡片（可选）、可同步的移动端离线学习，以及便于迁移的导出功能。当前 beta 测试期间可以免费使用托管版应用，项目也支持自托管。

一套清晰的 A+ 配置可以很简单：

- 为 `220-1201` 和 `220-1202` 各建一个卡组
- 在版本相关的卡片上添加考试目标标签与来源标签
- 每次实验和练习后写一份简短的失误记录
- 用 AI 润色卡片措辞，但保存前核对每一项技术答案

本应用不是 CompTIA 官方产品、A+ 课程、考试模拟器或 PBQ 环境。它适合存放那些你希望 FSRS 帮你重新想起的小知识点和判断。真机、完整场景和获授权的考试练习，应继续使用各自合适的工具。[入门指南](/docs/getting-started/)介绍了托管和自托管两种方式。

## CompTIA A+ 闪卡常见问题

### 2026 年应该备考哪两门 CompTIA A+ 考试？

备考 A+ V15 Core 1 `220-1201` 和 Core 2 `220-1202`。两门考试都于 2025 年 3 月 25 日推出，CompTIA 目前预计在 2028 年退役。预约考试前，请再次查看官方考试页面。

### 获得 A+ 认证需要同时通过 Core 1 和 Core 2 吗？

需要。CompTIA 要求通过两门 V15 考试才能获得 A+ 认证。Core 1 的合格分数是 675，Core 2 是 700，两门考试均采用 100–900 分制。

### CompTIA A+ 闪卡足以应对 PBQ 吗？

不够。卡片可以帮助你回忆命令、端口、组件之间的区别、权限概念和线索。A+ PBQ 仍要求你在模拟环境中逐步解决问题，因此卡组必须配合获授权的 PBQ 练习和动手实验。

### 应该为每一条考试目标制作一张闪卡吗？

把考试目标当作范围边界和覆盖地图。对于需要快速回忆、又反复答错的信息，再制作卡片。安装、配置、输出解读和多步骤故障排除应留在卡组之外练习。

## 从二十张卡片和一项真实任务开始

打开准备先考的那门 Core 的官方考试目标。选择一个领域，学习其中一小部分，然后实际操作：运行命令、检查硬件、配置设置，或排查一个新的故障场景。

只把让你犹豫的地方做成卡片，最多二十张。这个数量足以让你在建立庞大复习队列之前，看出问题是否清楚。实用的 **CompTIA A+ 闪卡**能让这些小知识点随时想得起来。真实任务则会检验你能否把它们组合起来。
