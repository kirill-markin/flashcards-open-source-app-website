L’Alaska s’abrège AK, l’Alabama AL et l’Arkansas AR. Les deux premières lettres du nom d’un État ne donnent pas toujours son abréviation postale. Un tableau de référence permet alors de retrouver rapidement le bon code.

Pour chercher un code, repérez l’État dans le tableau alphabétique ci-dessous. Pour réviser, masquez la colonne des codes et essayez de donner chaque réponse, puis faites l’exercice dans l’autre sens. Reconnaître une association sur la page et la retrouver de mémoire sont deux exercices différents.

Le [paquet gratuit sur les abréviations des États américains](/fr/catalog/packages/us-state-abbreviations-flashcards/) propose **100 cartes en anglais** pour vous exercer de l’État vers le code et dans l’autre sens. Essayez de retrouver chaque réponse avant de la vérifier, puis revenez régulièrement pour des révisions espacées qui aident à retenir les paires sur la durée. Le tableau complet et les réponses au quiz se trouvent plus bas.

L’abréviation d’un État est distincte du ZIP Code. Dans une adresse américaine, le code à deux lettres désigne l’État ; le ZIP Code est la partie numérique qui le suit. Si un formulaire prévoit des champs séparés pour l’État et le ZIP Code, saisissez chaque information dans le champ correspondant.

Washington, DC a pour abréviation **DC**, et Porto Rico (Puerto Rico), **PR**. Ces deux destinations ont une abréviation postale, mais aucune ne fait partie des 50 États du tableau. L’annexe de l’USPS comprend aussi des territoires et d’autres destinations postales ; consultez la [référence complète de l’USPS](https://pe.usps.com/text/pub28/28apb.htm) si c’est ce qu’il vous faut.

## Commencez par les codes que vous confondez

Une liste alphabétique est pratique pour trouver une réponse, mais les lignes voisines peuvent aussi servir d’indices. Commencez par comparer les noms que vous confondez, puis mélangez-les avec d’autres États pour vérifier que vous retrouvez chaque réponse sans aide.

![Des clés semblables triées dans les compartiments distincts d’un petit plateau](/blog/us-state-abbreviations.png)

### Alaska, Alabama, Arkansas, Arizona

Gardez ces quatre États ensemble pour une première comparaison. Tous les indices fondés sur les lettres dans cet article se rapportent à l’orthographe anglaise des noms :

- **Alaska → AK :** repérez le K dans Alaska.
- **Alabama → AL :** ici, les deux premières lettres conviennent.
- **Arkansas → AR :** là encore, ce sont les deux premières lettres.
- **Arizona → AZ :** repérez le Z dans Arizona.

Servez-vous de ces observations comme repères pour mémoriser les codes. Après avoir regardé ce groupe, masquez-le et répondez à la question « AK désigne quel État ? ». Essayez ensuite « Quel est le code de l’Arkansas ? ». Vérifiez aussi dans le sens inverse : de l’Alaska vers AK, et de AR vers l’Arkansas. Un sens vous semblera peut-être plus facile que l’autre.

### Les huit États commençant par M

Michigan, Minnesota, Mississippi et Missouri commencent tous par « Mi ». Seul le Michigan utilise MI. Apprenez chaque association complète plutôt que d’essayer d’abréger tous les noms selon la même règle.

| État | Code | Détail à repérer |
| --- | --- | --- |
| Michigan | MI | Reprend les deux premières lettres MI |
| Minnesota | MN | La deuxième lettre du code est N |
| Mississippi | MS | La deuxième lettre du code est S |
| Missouri | MO | La deuxième lettre du code est O |
| Massachusetts | MA | Reprend les deux premières lettres MA |
| Maryland | MD | Commence par M et finit par D |
| Maine | ME | Commence par M et finit par E |
| Montana | MT | Reprend le T de Montana |

Si vous répondez « Missouri » en voyant MS, notez précisément cette confusion : **MS = Mississippi ; MO = Missouri**. Revoir ces deux associations vous donne une différence concrète à travailler. Relire les huit noms peut vous faire perdre de vue celui qui posait problème.

### Iowa, Idaho, Illinois, Indiana

L’Idaho s’abrège ID, l’Illinois IL et l’Indiana IN. L’Iowa s’abrège **IA**, avec sa première et sa dernière lettre. Révisez IA séparément si vous proposez toujours IO, puis réintégrez-le au groupe.

### L’État de Washington et Washington, DC

**WA désigne l’État de Washington. DC désigne le district de Columbia (District of Columbia).** Sur le recto de vos propres cartes, écrivez « État de Washington » pour que la question soit sans ambiguïté. Une carte qui demande seulement « Abréviation de Washington ? » laisse inutilement place à plusieurs interprétations.

Pour les capitales des États, prévoyez aussi des questions distinctes, par exemple « Quelle est la capitale du Minnesota ? ». ## Transformez vos erreurs en révisions dans les deux sens

Pour chaque association oubliée ou incertaine, créez deux petites cartes de révision. Par exemple :

| Recto | Verso |
| --- | --- |
| Missouri — abréviation USPS ? | MO |
| Abréviation USPS MO — quel État ? | Missouri |

Si vous avez confondu MO et MS, ajoutez aussi les deux cartes du Mississippi. Gardez une seule réponse par carte et intercalez d’autres questions entre les cartes qui interrogent la même association en sens inverse pour ne pas répondre grâce à celle que vous venez de voir. Notre [guide pour créer de meilleures cartes de révision](/blog/how-to-make-better-flashcards/) explique comment formuler des questions précises.

Retrouver régulièrement les réponses de mémoire et les revoir à intervalles espacés aide à retenir les paires sur la durée. Lors de la prochaine révision, répondez avant de dévoiler le verso et notez vos erreurs honnêtement. Revenez sur ces cartes au cours d’une séance ultérieure pour vérifier si les réponses vous reviennent toujours en mémoire. Ajoutez d’autres États selon le temps dont vous disposez pour les réviser ; vous n’avez pas besoin de découvrir toutes les cartes en une seule séance.
