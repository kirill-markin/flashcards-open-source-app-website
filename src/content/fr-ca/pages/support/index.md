## Contact

Pour une question sur le produit, une aide sur votre compte ou une question sur l’examen de l’application par l’App Store, écrivez à [kirill+flashcards@kirill-markin.com](mailto:kirill+flashcards@kirill-markin.com).

## Suppression du compte

Pour supprimer votre compte Nibomo sans installer l'application, ouvrez la [page de suppression du compte](https://app.nibomo.com/settings/delete-account). Si nécessaire, connectez-vous avec la même adresse courriel que celle utilisée pour votre compte. Choisissez `Supprimer mon compte`, saisissez la phrase de confirmation affichée, puis confirmez la suppression. Vous pouvez aussi demander la suppression de votre compte par courriel à [kirill+flashcards@kirill-markin.com](mailto:kirill+flashcards@kirill-markin.com).

La suppression retire de la base de données active les données actuelles de votre compte, vos identifiants de connexion, vos adhésions et les espaces de travail dont vous êtes le seul membre. Le contenu des espaces partagés reste accessible aux autres membres. L'historique de facturation nécessaire est conservé pour la comptabilité, le rapprochement des transactions et les réclamations juridiques. Les données supprimées peuvent rester dans des sauvegardes de récupération chiffrées pendant 35 jours au maximum. Consultez notre [Politique de confidentialité](/privacy/) pour tous les détails de conservation.

La suppression de votre compte Nibomo ne résilie pas votre abonnement Google Play. [Gérez-le ou résiliez-le séparément dans Google Play](https://play.google.com/store/account/subscriptions).

## Code source ouvert et signalements techniques

Nibomo est à code source ouvert. Pour signaler un bogue, poser une question sur l'auto-hébergement ou lancer une discussion technique, vous pouvez aussi utiliser le [dépôt GitHub](https://github.com/kirill-markin/flashcards-open-source-app) et son suivi des tickets.

## Auto-hébergement

Si vous préférez ne pas utiliser la version bêta hébergée dans le nuage, vous pouvez auto-héberger la même solution à code source ouvert et faire tourner le service sur votre propre infrastructure.

## Délais de réponse

L'assistance est assurée au mieux pendant la période de bêta. Nous essayons de répondre le plus vite possible, mais les délais de réponse ne sont pas garantis.
