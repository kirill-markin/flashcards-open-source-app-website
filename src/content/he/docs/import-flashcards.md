פתחו את [Nibomo](https://app.nibomo.com), עברו למרחב העבודה שאליו תרצו להוסיף את הכרטיסיות ובחרו **ספרייה > ייבוא**. בקטע **מאפליקציה אחרת** בחרו את האפליקציה שבה השתמשתם. לכל אפליקציה יש אפשרות ייבוא משלה, גם כשכמה אפליקציות משתמשות באותו פורמט.

האפשרויות שלהלן זמינות באפליקציית הווב. אם התפריט או אפשרות הייבוא הרצויה לא מופיעים ב־iPhone, ב־iPad, ב־Mac או ב־Android, השתמשו באפליקציית הווב. אם אתם משתמשים ב־Nibomo כאורחים במכשיר, התחברו תחילה במכשיר עצמו. באפליקציית הווב התחברו לאותו חשבון Nibomo ובחרו את מרחב העבודה הרצוי לפני הייבוא. ב־iPhone, ב־iPad וב־Mac הכפתור **התחלת ייבוא** עשוי להופיע בשם **התחלת הייבוא**.

## בחירת מקור הייבוא

| מקור | מה להכין | איך מייבאים |
| --- | --- | --- |
| Quizlet | טקסט שהועתק מהייצוא | הדביקו במסך הייבוא של Quizlet |
| Anki | חפיסה בפורמט `.apkg` או אוסף בפורמט `.colpkg` | **בחירת קבצים** |
| Noji | `.csv` או `.ofc` | **בחירת קבצים** |
| Knowt | `.pdf` | **בחירת קבצים** |
| RemNote | `.apkg`, `.md` או `.txt` | **בחירת קבצים** |
| Brainscape | `.csv` | **בחירת קבצים** |
| StudySmarter | `.csv` | **בחירת קבצים** |
| Cram | `.csv` | **בחירת קבצים** |
| Mochi | `.mochi` | **בחירת קבצים** |
| SuperMemo | `.xml` | **בחירת קבצים** |
| AlgoApp (לשעבר AnkiApp) | `.zip` או `.xml` | **בחירת קבצים** |
| אפליקציה אחרת | `.csv`, `.txt`, `.xlsx`, `.pdf`, `.json`, `.xml`, `.md`, `.docx` או `.zip` | בחרו קבצים תחת **ייבוא מאפליקציה אחרת** |
| גיליון אלקטרוני | שורות שהועתקו, עם צד קדמי ואחורי לכל כרטיסייה | הדביקו תחת **ייבוא מגיליון אלקטרוני** |
| Nibomo | קובץ `flashcards.zip` שיוצא מ־Nibomo | בדקו את התצוגה המקדימה תחת **ייבוא מ־Nibomo** |

אם בתפריט הייבוא עדיין מופיע השם הקודם של AlgoApp, חפשו את **AnkiApp**. ל־Anki יש אפשרות נפרדת.

אם יש לכם קובץ Excel ישן בפורמט `.xls`, שמרו אותו כ־`.xlsx` או כ־`.csv` לפני הייבוא. אפשר גם להעתיק את עמודות הצד הקדמי והאחורי [ולהדביק אותן במסך הייבוא מגיליון אלקטרוני](#הדבקה-מגיליון-אלקטרוני).

## ייבוא מאפליקציית כרטיסיות אחרת

1. באפליקציית המקור, ייצאו את הכרטיסיות שתרצו להעביר. ב־Quizlet פתחו את ערכת הלימוד, בחרו **Export** והעתיקו את הטקסט. השתמשו בטאב בין המונח להגדרה ובשורה חדשה בין כרטיסיות.
2. ב־Nibomo בחרו **ספרייה > ייבוא** ופתחו את האפשרות המתאימה. עבור Quizlet, הדביקו את הטקסט שהעתקתם. עבור מקורות אחרים, בחרו את הקבצים שייצאתם. אם אין אפשרות ייעודית לאפליקציה שלכם אבל אפשר לייצא ממנה בפורמט נתמך, למשל PDF, בחרו **ייבוא מאפליקציה אחרת**.
3. בחרו **התחלת ייבוא**. Nibomo תפתח צ׳אט AI חדש ותשלח את בקשת הייבוא עם הקבצים או הטקסט שהדבקתם. הפעולה דורשת חיבור לאינטרנט. הגודל המרבי של כל קובץ שמייבאים באמצעות AI הוא **30 MiB**. אם הקובץ גדול יותר, נסו לייצא חפיסות או ערכות קטנות יותר בנפרד.
4. בדקו את התוצאה ב־**ספרייה**. צ׳אט ה־AI עשוי לשמור את הכרטיסיות בקבוצות במהלך הייבוא. אם הייבוא נעצר, בדקו אילו כרטיסיות כבר נוספו ל־Nibomo ובקשו מהצ׳אט להמשיך עם השאר לפני שתנסו לייבא שוב את כל הקובץ.

### בדקו תחילה ייבוא של כמה כרטיסיות

שמרו את הייצוא המקורי והתחילו מחפיסה או מערכה קטנה. השוו את מספר הכרטיסיות ובדקו את הצד הקדמי, הצד האחורי והתגיות בכמה מהן, לצד תמונות או עיצוב שחשובים לכם. כדי לראות דוגמה לפני השמירה, צרפו את הייצוא לצ׳אט AI חדש ובקשו תצוגה מקדימה של כמה כרטיסיות בלי לשמור אותן. בדרך זו תכתבו את הבקשה בעצמכם במקום לבחור **התחלת ייבוא**.

כרטיסיות שיובאו באמצעות AI נוצרות ככרטיסיות חדשות ב־Nibomo. היסטוריית החזרות ומועדי החזרות הקודמים נשארים באפליקציית המקור. מידת השימור של הארגון, העיצוב והמדיה תלויה בתוכן הייצוא ובמה שצ׳אט ה־AI יכול לקרוא ממנו. בדקו את התוצאה לפני שתשתמשו בכרטיסיות או תמחקו דבר באפליקציית המקור.

## הדבקה מגיליון אלקטרוני

בחרו **ספרייה > ייבוא > ייבוא מגיליון אלקטרוני** לכרטיסיות פשוטות עם צד קדמי ואחורי. העתיקו שתי עמודות מהגיליון, בלי שורת הכותרת, והדביקו אותן במסך הייבוא. כשמעתיקים תאים מגיליון, התחילו ב־**טאב** בין הצד הקדמי לאחורי וב־**שורה חדשה** בין כרטיסיות. אם הטקסט משתמש במפרידים אחרים, שנו את ההגדרות בהתאם.

בדקו את התצוגה המקדימה, תקנו שורות חלקיות ובחרו אילו תגיות להוסיף. לאחר מכן בחרו בכפתור **ייבוא** שמציג את מספר הכרטיסיות לשמירת הכרטיסיות. דרך זו אינה משתמשת בצ׳אט AI.

## ייבוא קובץ ZIP של Nibomo

בחרו **ספרייה > ייבוא > ייבוא מ־Nibomo** כדי לייבא קובץ `flashcards.zip` שיוצא בעבר מ־Nibomo. בחרו את קובץ ה־ZIP בלי לחלץ אותו, בדקו בתצוגה המקדימה את הכרטיסיות והמדיה המקושרת אליהן ואשרו את הייבוא. בדרך זו אפשר להעביר את הכרטיסיות, התגיות והמדיה שבחבילה בלי להשתמש בצ׳אט AI.
