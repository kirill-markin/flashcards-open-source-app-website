શરૂ કરવાની ઘણી રીતો છે, સૌથી લોકપ્રિય રીતથી શરૂ કરીને:

- **iPhone, iPad અને Mac ઍપ**: [App Store](https://apps.apple.com/app/apple-store/id6760538964?pt=128797295&ct=marketing_site&mt=8)
- **Android ઍપ**: [Google Play](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&utm_source=flashcards_website&utm_medium=referral&utm_campaign=marketing_site)
- **હોસ્ટ કરેલી વેબ ઍપ**: [app.nibomo.com](https://app.nibomo.com)
- **AI એજન્ટ**: [MCP કનેક્ટર](/docs/mcp-connector/) અથવા `https://api.nibomo.com/v1/` પરની API
- **સેલ્ફ-હોસ્ટિંગ**: [સેલ્ફ-હોસ્ટિંગ માર્ગદર્શિકા](/docs/self-hosting/)

## મોબાઇલ અને ડેસ્કટૉપ ઍપ

તમારા ઉપકરણ માટે નેટિવ ઍપ ઇન્સ્ટોલ કરો:

- iPhone, iPad અને Mac: [App Store](https://apps.apple.com/app/apple-store/id6760538964?pt=128797295&ct=marketing_site&mt=8)
- Android: [Google Play](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&utm_source=flashcards_website&utm_medium=referral&utm_campaign=marketing_site)

ઍપ તમારાં કાર્ડ ઉપકરણ પર જ રાખે છે, એટલે તમે ઑફલાઇન પણ પુનરાવર્તન કરી શકો છો, અને ફરી ઑનલાઇન થાઓ ત્યારે તે સિંક થઈ જાય છે. તમે અતિથિ તરીકે શરૂ કરી શકો છો અને પછીથી સાઇન ઇન કરી શકો છો.

### હોમ સ્ક્રીન વિજેટ

Nibomo ઍપ iPhone, iPad, Mac અને Android પર પુનરાવર્તન વિજેટ ઉમેરે છે. તે ત્રણ કદમાં મળે છે:

- **નાનું**: કેટલાં કાર્ડ બાકી છે અને તમારા સળંગ અભ્યાસનો ક્રમ
- **મધ્યમ**: કેટલાં કાર્ડ બાકી છે અને તમારા આગળના કાર્ડનો પ્રશ્ન
- **મોટું**: કેટલાં કાર્ડ બાકી છે, તમારો આગળનો પ્રશ્ન અને સળંગ અભ્યાસનો ક્રમ

જ્યારે કંઈ બાકી ન હોય, ત્યારે વિજેટ “બધું પૂર્ણ” અને આગળનું કાર્ડ ક્યારે પુનરાવર્તન માટે આવશે તે બતાવે છે. તે ક્યારેય જવાબ બતાવતું નથી. પુનરાવર્તન ખોલવા માટે વિજેટ પર ટૅપ કરો; મધ્યમ કે મોટું વિજેટ તેમાં દેખાતા કાર્ડ પર જ પુનરાવર્તન ખોલે છે. વિજેટ દરેક માટે મફત છે, અતિથિઓ માટે પણ.

iPhone, iPad અથવા Mac પર વિજેટ ઉમેરવા માટે, વિજેટ ગૅલેરી ખોલો, Nibomo પસંદ કરો અને પછી કદ પસંદ કરો. Android પર, વિજેટની સૂચિમાંથી Nibomo વિજેટ ઉમેરો, પછી તેનું કદ બદલો; લેઆઉટ કદ મુજબ બદલાય છે.

## હોસ્ટ કરેલી વેબ ઍપ

શરૂ કરવાનો સૌથી ઝડપી રસ્તો હોસ્ટ કરેલી વેબ ઍપ છે:

1. [app.nibomo.com](https://app.nibomo.com) ખોલો
2. પાસવર્ડ વગરના OTP વડે તમારા ઈમેલથી સાઇન ઇન કરો
3. કાર્ડ બનાવો, બાકી કાર્ડનું પુનરાવર્તન કરો, અને કાર્યક્ષેત્રના ડેટા તથા જોડેલી ફાઇલો સાથે AI ચૅટ વાપરો

હોસ્ટ કરેલી ઍપ માટે કંઈ ઇન્સ્ટોલ કરવાની કે સર્વર ગોઠવવાની જરૂર નથી.

## એજન્ટ સેટઅપ

Claude, ChatGPT અને Cursor જેવા MCP ક્લાયન્ટ [MCP કનેક્ટર માર્ગદર્શિકા](/docs/mcp-connector/) દ્વારા જોડાઈ શકે છે.

જો તમે Claude Code, Codex કે OpenClaw ને સીધું જોડવા માંગતા હો, તો અહીંથી શરૂ કરો:

```text
GET https://api.nibomo.com/v1/
```

આ ડિસ્કવરી જવાબ એજન્ટને ઈમેલ OTP લૉગિન, લાંબા સમય સુધી માન્ય રહેતી API કી બનાવવી, ખાતું લોડ કરવું, કાર્યક્ષેત્રની પ્રારંભિક ગોઠવણી અને પ્રકાશિત SQL ઇન્ટરફેસ સુધીનાં બધાં પગલાં સમજાવે છે.

આ જ પેલોડ `GET /v1/agent` પર પણ ઉપલબ્ધ છે, પણ `/v1/` જ સત્તાવાર જાહેર પ્રવેશબિંદુ છે.

## સેલ્ફ-હોસ્ટેડ

જો તમે તમારું પોતાનું ઇન્સ્ટન્સ ચલાવવાનું પસંદ કરો, તો [સેલ્ફ-હોસ્ટિંગ માર્ગદર્શિકા](/docs/self-hosting/) જુઓ.

## આજે તમને શું મળે છે

- કાર્ડ, પુનરાવર્તન અને AI ચૅટ માટે હોસ્ટ કરેલી વેબ ઍપ
- લોકલ SQLite સ્ટોરેજ અને ઑફલાઇન-ફર્સ્ટ સિંક સાથેની નેટિવ iPhone, iPad, Mac અને Android ઍપ
- અલગ `api` અને `auth` ડોમેન પર સહિયારી બૅકએન્ડ અને પ્રમાણીકરણ સેવાઓ
- ડિસ્કવરી, OTP અને ApiKey પ્રમાણીકરણ દ્વારા બાહ્ય એજન્ટનું ઓનબોર્ડિંગ
- AWS પર ઓપન-સોર્સ ડિપ્લોયમેન્ટનો માર્ગ, જેમાં Postgres પ્રમાણભૂત ડેટા સ્રોત છે

## રિપોઝિટરીની દિશા

આ પ્રોજેક્ટ ઑફલાઇન-ફર્સ્ટ છે.

આજે રિપોઝિટરીમાં વેબ ઍપ, iOS ઍપ, પ્રમાણીકરણ સેવા, બૅકએન્ડ API, બાહ્ય એજન્ટ ફ્લો અને Google Play પર પ્રકાશિત Android ઍપ સામેલ છે.
