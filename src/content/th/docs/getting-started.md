## แอปบนมือถือและเดสก์ท็อป

ติดตั้งแอปเนทีฟสำหรับอุปกรณ์ของคุณ:

- iPhone, iPad และ Mac: [App Store](https://apps.apple.com/app/apple-store/id6760538964?pt=128797295&ct=marketing_site&mt=8)
- Android: [Google Play](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&utm_source=flashcards_website&utm_medium=referral&utm_campaign=marketing_site)

แอปจะเก็บการ์ดของคุณไว้ในอุปกรณ์ คุณจึงทบทวนได้แม้ออฟไลน์ และแอปจะซิงค์เมื่อกลับมาออนไลน์ คุณเริ่มใช้งานแบบผู้เยี่ยมชมได้ แล้วค่อยลงชื่อเข้าใช้ภายหลัง

### วิดเจ็ตบนหน้าจอโฮม

แอป Nibomo มีวิดเจ็ตทบทวนสำหรับ iPhone, iPad, Mac และ Android โดยมีให้เลือก 3 ขนาด:

- **เล็ก**: จำนวนการ์ดที่ถึงกำหนดทบทวนและสถิติการเรียนต่อเนื่องของคุณ
- **กลาง**: จำนวนการ์ดที่ถึงกำหนดทบทวนและคำถามบนการ์ดใบถัดไป
- **ใหญ่**: จำนวนการ์ดที่ถึงกำหนดทบทวน คำถามถัดไป และสถิติการเรียนต่อเนื่องของคุณ

เมื่อไม่มีการ์ดที่ถึงกำหนด วิดเจ็ตจะแสดง “ทบทวนครบแล้ว” และเวลาที่การ์ดใบถัดไปจะถึงกำหนด วิดเจ็ตจะไม่แสดงคำตอบเลย แตะวิดเจ็ตเพื่อเปิดหน้าทบทวน วิดเจ็ตขนาดกลางหรือใหญ่จะเปิดหน้าทบทวนไปที่การ์ดที่แสดงอยู่บนวิดเจ็ต วิดเจ็ตใช้ได้ฟรีสำหรับทุกคน รวมถึงผู้ใช้แบบผู้เยี่ยมชม

วิดเจ็ตอีก 8 แบบแสดงความคืบหน้าในการเรียนของคุณ ได้แก่ “กิจกรรม” “รายปี” “วันนี้” “การทบทวน” “สถิติต่อเนื่อง” “ปฏิทิน” “ที่กำลังจะถึง” และ “แดชบอร์ด” บน iPhone และ iPad คุณยังวางวิดเจ็ต “การ์ดที่ถึงกำหนด” บนหน้าจอล็อคได้ด้วย และดูวิดเจ็ตแต่ละแบบได้ใน[คู่มือวิดเจ็ต](/blog/flashcard-widget/)

หากต้องการเพิ่มวิดเจ็ตบน iPhone, iPad หรือ Mac ให้เปิดแกลเลอรีวิดเจ็ต เลือก Nibomo แล้วเลือกขนาด บน Android ให้เพิ่มวิดเจ็ต Nibomo ที่ต้องการจากรายการวิดเจ็ต แล้วปรับขนาด เลย์เอาต์จะเปลี่ยนตามขนาด

## เว็บแอปที่โฮสต์ให้

วิธีที่เร็วที่สุดในการเริ่มต้นคือใช้เว็บแอปที่โฮสต์ให้:

1. เปิด [app.nibomo.com](https://app.nibomo.com)
2. ลงชื่อเข้าใช้ด้วยอีเมลผ่าน OTP โดยไม่ต้องใช้รหัสผ่าน
3. สร้างการ์ด ทบทวนการ์ดที่ถึงกำหนด และใช้แชต AI กับข้อมูลในพื้นที่ทำงานและไฟล์แนบ

การใช้แบบโฮสต์ให้ไม่ต้องติดตั้งอะไรและไม่ต้องตั้งค่าเซิร์ฟเวอร์

## ย้ายการ์ดที่มีอยู่มาใช้

มีการ์ดใน Quizlet, Anki หรือแอปอื่นอยู่แล้วใช่ไหม? เปิด **คลัง > นำเข้า** แล้วดู[คู่มือนำเข้าการ์ด](/th/docs/import-flashcards/) เพื่อเลือกรูปแบบไฟล์และตรวจว่าข้อมูลใดจะย้ายมาด้วย

## การตั้งค่าเอเจนต์

ไคลเอ็นต์ MCP อย่าง Claude, ChatGPT และ Cursor เชื่อมต่อได้ตาม[คู่มือตัวเชื่อมต่อ MCP](/docs/mcp-connector/)

หากต้องการให้ Claude Code, Codex หรือ OpenClaw เชื่อมต่อโดยตรง ให้เริ่มจาก:

```text
GET https://api.nibomo.com/v1/
```

การตอบกลับสำหรับค้นหาบริการ (discovery) นี้จะพาเอเจนต์ผ่านขั้นตอนการเข้าสู่ระบบด้วย OTP ทางอีเมล การสร้างคีย์ API แบบใช้งานได้ระยะยาว การโหลดบัญชี การตั้งค่าเริ่มต้นของพื้นที่ทำงาน และส่วนติดต่อ SQL ที่เผยแพร่ไว้

ข้อมูลชุดเดียวกันนี้เรียกได้ที่ `GET /v1/agent` แต่ `/v1/` คือจุดเริ่มต้นสาธารณะหลัก

## โฮสต์เอง

หากต้องการรันอินสแตนซ์ของคุณเอง โปรดดู[คู่มือการโฮสต์เอง](/docs/self-hosting/)

## สิ่งที่ใช้ได้ในวันนี้

- เว็บแอปที่โฮสต์ให้สำหรับการ์ด การทบทวน และแชต AI
- แอปเนทีฟสำหรับ iPhone, iPad, Mac และ Android พร้อมพื้นที่จัดเก็บ SQLite ในเครื่องและการซิงค์แบบออฟไลน์เป็นหลัก
- บริการแบ็กเอนด์และการยืนยันตัวตนที่ใช้ร่วมกัน บนโดเมน `api` และ `auth` ที่แยกกัน
- การเริ่มต้นใช้งานสำหรับเอเจนต์ภายนอกผ่าน discovery, OTP และการยืนยันตัวตนแบบ ApiKey
- เส้นทางการดีพลอยแบบโอเพนซอร์สบน AWS โดยมี Postgres เป็นแหล่งข้อมูลหลัก

## ทิศทางของรีโพซิทอรี

โปรเจกต์นี้ออกแบบให้ทำงานแบบออฟไลน์เป็นหลัก

ปัจจุบันรีโพซิทอรีประกอบด้วยเว็บแอป แอป iOS บริการยืนยันตัวตน API แบ็กเอนด์ โฟลว์สำหรับเอเจนต์ภายนอก และแอป Android ที่เผยแพร่บน Google Play
