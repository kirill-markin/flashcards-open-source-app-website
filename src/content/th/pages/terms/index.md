## บริการและผู้ให้บริการ

Nibomo เป็นเครื่องมือการ์ดคำถามคำตอบและการทบทวนเว้นระยะแบบโอเพนซอร์ส ข้อกำหนดนี้ใช้บังคับเฉพาะกับเว็บไซต์ แอป API และบริการ MCP แบบโฮสต์ให้ ที่ให้บริการโดย SAMO DANNI EOOD เลขทะเบียนบริษัท 207395566 เลขประจำตัวผู้เสียภาษีมูลค่าเพิ่ม (VAT) BG207395566 ที่อยู่จดทะเบียน bulv. Maritza 154, entrance D, floor 6 #14, 4018, Plovdiv, Bulgaria ผู้สร้าง Nibomo คือ Kirill Markin

ในช่วงเบต้า บริการแบบโฮสต์ให้มีให้ใช้ตามสภาพที่เป็นอยู่ (as-is) และตามที่พร้อมให้บริการ (as-available)

## อายุ

คุณต้องมีอายุอย่างน้อย 13 ปีจึงจะใช้บริการแบบโฮสต์ให้ได้ หากกฎหมายในประเทศที่คุณอาศัยอยู่กำหนดอายุขั้นต่ำที่สูงกว่านี้ ให้ใช้อายุที่สูงกว่านั้น หากคุณมีอายุต่ำกว่า 18 ปี คุณต้องได้รับอนุญาตจากบิดามารดาหรือผู้ปกครองตามกฎหมายก่อนใช้บริการ

## บัญชีของคุณ

คุณมีหน้าที่รับผิดชอบต่อการเข้าถึงบัญชีอีเมล รหัสยืนยันตัวตน เซสชัน และข้อมูลรับรอง API ของคุณ รวมถึงกิจกรรมที่ดำเนินการผ่านสิ่งเหล่านี้ โปรดให้ข้อมูลที่ถูกต้อง เก็บข้อมูลรับรองเป็นความลับ และแจ้งให้เราทราบหากคุณเชื่อว่าบัญชีของคุณถูกบุกรุก

## เนื้อหาและข้อมูลของคุณ

ในระหว่างคุณกับเรา คุณยังคงมีสิทธิ์ที่คุณมีอยู่ในการ์ด ไฟล์ ความคิดเห็น และเนื้อหาอื่นที่คุณส่งเข้ามา คุณให้สิทธิ์แบบจำกัดแก่เราเท่าที่จำเป็นในการโฮสต์ ประมวลผล ส่งต่อ สำรอง และแสดงเนื้อหานั้นแก่คุณและผู้ที่คุณแชร์พื้นที่ทำงานด้วย เพื่อให้เราดำเนินการให้บริการได้

การประมวลผลข้อมูลส่วนบุคคลของเราอธิบายไว้ในนโยบายความเป็นส่วนตัว เมื่อคุณลบบัญชี เนื้อหาในพื้นที่ทำงานที่แชร์ร่วมกันอาจยังคงเข้าถึงได้สำหรับสมาชิกคนอื่นของพื้นที่ทำงานนั้น

## การใช้งานที่ยอมรับได้

ห้ามใช้บริการเพื่อกิจกรรมที่ผิดกฎหมาย ละเมิดสิทธิ์ของผู้อื่น พยายามเข้าถึงบัญชีหรือข้อมูลของผู้ใช้อื่น รบกวน สำรวจหาช่องโหว่ หรือทำให้บริการทำงานเกินกำลัง หลบเลี่ยงการจำกัดอัตราการใช้งานหรือมาตรการควบคุมความปลอดภัย เผยแพร่มัลแวร์ หรือส่งเนื้อหาที่ผิดกฎหมาย เป็นอันตราย หรือมีลักษณะล่วงละเมิดผ่านฟีเจอร์ AI หรือฟีเจอร์การแชร์

เราอาจระงับหรือยุติการเข้าถึงเมื่อจำเป็นตามสมควรเพื่อปกป้องผู้ใช้หรือบริการ ตรวจสอบการละเมิด หรือปฏิบัติตามกฎหมาย

## ฟีเจอร์ AI

ฟีเจอร์ AI แบบโฮสต์ให้เป็นตัวเลือกที่ไม่บังคับและใช้ OpenAI ข้อมูลเทเลเมทรี (telemetry) ของ AI ที่เกี่ยวข้องจะถูกประมวลผลผ่าน Langfuse เพื่อการแก้ไขข้อบกพร่องและการวิเคราะห์คุณภาพบริการ ผลลัพธ์จาก AI อาจไม่ถูกต้อง ไม่ครบถ้วน หรือไม่เหมาะสม คุณมีหน้าที่ตรวจสอบผลลัพธ์ก่อนนำไปใช้อ้างอิง แชร์ หรือนำการเปลี่ยนแปลงไปใช้

เมื่อคุณอนุญาตให้ไคลเอ็นต์ AI ภายนอกใช้บริการ MCP หรือ Agent API ไคลเอ็นต์นั้นและผู้ให้บริการโมเดลของไคลเอ็นต์จะประมวลผลข้อมูลที่คุณร้องขอภายใต้ข้อกำหนดของตนเอง เราไม่รับผิดชอบต่อการทำงานหรือผลลัพธ์ของไคลเอ็นต์ภายนอก

## ความพร้อมใช้งานและการเปลี่ยนแปลง

บริการเบต้าแบบโฮสต์ให้มีให้ใช้เท่าที่เราทำได้ (best effort) และอาจเปลี่ยนแปลง หยุดชั่วคราว หรือยุติได้โดยไม่ต้องแจ้งให้ทราบล่วงหน้า เราไม่รับประกันว่าบริการจะพร้อมใช้งานอย่างต่อเนื่องโดยไม่หยุดชะงัก ว่าสำเนาทุกชุดในเครื่องหรือบนระบบที่โฮสต์จะถูกเก็บรักษาไว้ หรือว่าทุกฟีเจอร์จะยังคงมีให้ใช้งาน โปรดเก็บสำเนาของเนื้อหาที่คุณไม่อาจยอมให้สูญหายไว้แยกต่างหาก

## การเลิกใช้งาน

คุณสามารถเลิกใช้บริการแบบโฮสต์ให้และลบบัญชีของคุณได้ทุกเมื่อ บทบัญญัติที่โดยสภาพแล้วควรมีผลต่อไปหลังการสิ้นสุดการใช้งาน รวมถึงบทบัญญัติเกี่ยวกับสิทธิ์ ความรับผิดชอบ และการปฏิบัติตามกฎหมาย จะยังคงมีผลใช้บังคับต่อไป

## อินสแตนซ์ที่โฮสต์เอง

ซอร์สโค้ดเผยแพร่ภายใต้สัญญาอนุญาต MIT การดีพลอยที่โฮสต์เองอยู่ภายใต้การควบคุมของผู้ดำเนินการระบบนั้น ไม่ใช่ SAMO DANNI EOOD และไม่อยู่ภายใต้ข้อกำหนดนี้ ผู้ดำเนินการการดีพลอยนั้นมีหน้าที่รับผิดชอบต่อความพร้อมใช้งาน ความปลอดภัย การจัดการข้อมูล และข้อกำหนดที่ใช้บังคับของระบบดังกล่าว
