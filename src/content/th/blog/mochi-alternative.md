Mochi เริ่มจากเอกสาร Markdown แทนแบบฟอร์มด้านหน้าและด้านหลังที่คุ้นเคย เพียงเพิ่มบรรทัดที่มีขีดกลางสามตัว เอกสารก็จะมีด้านต่าง ๆ สำหรับทบทวน คุณจะเก็บไว้เป็นโน้ต เชื่อมลิงก์ไปยังการ์ดอีกใบ หรือเก็บเข้าคลังเพื่อให้ยังค้นหาได้โดยไม่เข้าสู่คิวทบทวนก็ได้

ตัวคั่นเล็ก ๆ นี้ช่วยให้เห็นว่า **แฟลชการ์ด Mochi** เหมาะกับใคร Mochi เหมาะมากกับคนที่ต้องการโน้ตและการทบทวนแบบเว้นระยะในแอปเดียวที่เก็บข้อมูลในเครื่องเป็นหลัก โดยเฉพาะคนที่คุ้นกับ Markdown ลิงก์ย้อนกลับ และการทบทวนแบบง่าย ๆ ที่เลือกว่าจำได้หรือลืม แต่สำหรับผู้ใช้ Anki มานานซึ่งคลังการ์ดพึ่งพาการสร้างการ์ดหลายรูปแบบจากโน้ตเดียว การปรับ HTML/CSS, JavaScript ส่วนเสริม หรือการควบคุมตัวจัดตารางอย่างละเอียด เหตุผลที่จะย้ายมา Mochi ยังมีน้ำหนักน้อยกว่า

ถ้าใช้เพียงอุปกรณ์เดียว แผนฟรีให้อะไรมากกว่าการทดลองใช้: ไม่ต้องสมัครบัญชี และเอกสารของ Mochi ระบุว่าใช้ออฟไลน์ได้ไม่จำกัด ข้อจำกัดคือการซิงค์ข้ามอุปกรณ์อยู่ใน **แผน Pro ราคา US$5 ต่อเดือน** สำหรับผู้ใช้ Anki ต้นทุนที่สำคัญกว่าคือข้อมูลและความสามารถที่อาจสูญเสียระหว่างย้าย Mochi นำเข้าแพ็กเกจ Anki พร้อมประวัติการทบทวนได้ แต่เก็บเทมเพลต รูปแบบการแสดงผล สคริปต์ การตั้งค่าตัวจัดตาราง หรือการทำงานของส่วนเสริมทุกอย่างไว้ไม่ได้

> **ข้อมูลเกี่ยวกับผู้เขียน:** ผมคือ Kirill Markin ผู้พัฒนา [Nibomo](/th/) บทความนี้เป็นรีวิวลักษณะการใช้งานโดยตรวจสอบกับแหล่งข้อมูล ไม่ใช่การอ้างว่าผมได้ทดลองผลิตภัณฑ์ด้วยตัวเอง ไม่มีลิงก์รับค่าคอมมิชชัน Mochi กับ Anki เป็นคู่เปรียบเทียบหลัก ส่วนผลิตภัณฑ์ของผมปรากฏเฉพาะช่วงท้าย โดยระบุชัดเจนว่าเป็นอีกทางเลือกหนึ่ง

**ตรวจสอบข้อมูลเมื่อ:** 7 กันยายน 2026 ณ วันนั้น [Mochi รุ่นล่าสุด](https://mochi.cards/changelog/) ที่ปรากฏคือเวอร์ชัน 26.8.2 ลงวันที่ 10 สิงหาคม 2026 ราคาและรายละเอียดในร้านแอปอาจเปลี่ยนแปลงได้

## รีวิวแบบสั้น

- **เลือก Mochi** หากต้องการโน้ต Markdown กับการ์ดอยู่ด้วยกัน ใช้ออฟไลน์บนอุปกรณ์เดียวโดยไม่ต้องมีบัญชี มีลิงก์ย้อนกลับ และเลือกผลการทบทวนเพียงสองแบบ
- **เลือก Anki** หากต้องการประเภทโน้ตที่พัฒนามานาน เทมเพลต HTML/CSS ส่วนเสริม การซิงค์ฟรีผ่านเซิร์ฟเวอร์ของผู้ให้บริการ ระดับผลการทบทวนสี่ระดับ หรือการควบคุม FSRS ที่ละเอียดกว่า
- **ยังไม่ต้องย้าย** หากคุณทบทวนได้สม่ำเสมออยู่แล้วและยังบอกไม่ได้ว่า Mochi จะแก้ปัญหาอะไรในวิธีใช้งานของคุณ หน้าตาใหม่เพียงอย่างเดียวไม่ใช่เหตุผลที่ดีพอจะเสี่ยงกับข้อมูลตารางทบทวนหลายปีและการ์ดที่ปรับแต่งไว้
- **ทดสอบก่อนย้าย** หาก Anki เป็นคลังการ์ดระยะยาวของคุณอยู่แล้ว Mochi รับไฟล์ `.apkg` และนำประวัติการทบทวนเข้ามาได้ แต่จะแปลง HTML เป็น Markdown และลบ CSS กับ JavaScript

## เปรียบเทียบ Mochi กับ Anki แบบรวดเร็ว

| ประเด็นในการเลือก | Mochi | Anki |
|---|---|---|
| เหมาะกับใครที่สุด | ผู้ใช้โน้ตที่เชื่อมโยงกันและ Markdown ซึ่งอยากเก็บโน้ตไว้คู่กับการ์ดทบทวน | ผู้เรียนที่ต้องการระบบแฟลชการ์ดที่พัฒนามานานและปรับแต่งได้ |
| การสร้างการ์ด | เอกสาร Markdown มีหลายด้านได้เมื่อเพิ่ม `---`; มีฟิลด์และเทมเพลตให้ใช้ด้วย | โน้ตมีฟิลด์ต่าง ๆ; เทมเพลต HTML/CSS สร้างการ์ดหนึ่งใบหรือหลายใบ |
| ขั้นตอนทบทวน | การ์ดใหม่เข้าสู่ช่วงเรียนรู้ก่อน; การ์ดที่เรียนแล้วใช้ Forgot (ลืม) / Remembered (จำได้) | การ์ดใช้ Again (อีกครั้ง) / Hard (ยาก) / Good (ดี) / Easy (ง่าย) |
| การจัดตาราง | ใช้อัลกอริทึมของ Mochi เองเป็นค่าเริ่มต้น; เลือกใช้ FSRS ได้ | FSRS หรือ SM-2 แบบเดิม พร้อมเครื่องมือปรับ FSRS ที่ครอบคลุมกว่า |
| การใช้ฟรี | ไม่ต้องสมัครบัญชีและใช้ออฟไลน์ได้ไม่จำกัด | แอปเดสก์ท็อปฟรีและซิงค์ AnkiWeb ฟรี; แอป iOS อย่างเป็นทางการต้องซื้อ |
| การซิงค์ข้ามอุปกรณ์ | Pro ราคา US$5 ต่อเดือน | ฟรีผ่าน AnkiWeb |
| แพลตฟอร์ม | เว็บ, macOS, Windows, Linux, iOS, Android | Windows, macOS, Linux, AnkiWeb, AnkiMobile อย่างเป็นทางการ และ AnkiDroid ที่พัฒนาโดยอิสระ |
| รูปแบบไฟล์สำหรับย้ายข้อมูล | ส่งออกเป็นรูปแบบเฉพาะ `.mochi`, Markdown และ CSV | รูปแบบเฉพาะ `.colpkg` และ `.apkg` รวมถึงข้อความคั่นด้วยแท็บ |
| ขอบเขตการควบคุมข้อมูลและการโฮสต์ | เก็บข้อมูลในเครื่องเป็นหลัก; ไม่ได้นำเสนอตัวแอปหลักว่าเป็นโอเพนซอร์ส และไม่มีเอกสารระบุวิธีโฮสต์บริการซิงค์เองที่ผู้พัฒนารองรับ | คลังซอร์สโค้ดหลักใช้สัญญาอนุญาต AGPL; มีเอกสารทางการสำหรับเซิร์ฟเวอร์ซิงค์ที่โฮสต์เอง |

ความต่างที่ช่วยตัดสินใจได้คือ **ความเรียบง่ายที่เริ่มจากโน้ต เทียบกับการควบคุมคลังการ์ดทั้งระบบ**

## อินเทอร์เฟซของ Mochi ออกแบบโดยยึดอะไรเป็นหลัก

จะเข้าใจอินเทอร์เฟซของ Mochi ได้ง่ายขึ้นเมื่อลองไล่ดูการใช้งานการ์ดหนึ่งใบ

การ์ดทุกใบอยู่ในชุดการ์ด เมื่อคลิก **New Card (การ์ดใหม่)** คุณจะได้พื้นที่เขียน Markdown แทนช่องคำถามและคำตอบแบบตายตัว การ์ดใบเดียวใส่หัวข้อ รายการ โค้ด รูปภาพ ฟิลด์ที่มีโครงสร้าง และลิงก์ได้ เพิ่ม `---` ระหว่างบล็อกเพื่อสร้างด้านสำหรับทบทวนตั้งแต่สองด้านขึ้นไป เพิ่ม `[[double brackets]]` หรือวงเล็บเหลี่ยมซ้อนสองชั้นเพื่ออ้างอิงการ์ดอีกใบ แล้ว Mochi จะสร้างลิงก์ย้อนกลับให้โดยอัตโนมัติ [ภาพรวมเรื่องการ์ด](https://mochi.cards/docs/cards/) ในเอกสารทางการยังอธิบายเทมเพลตที่ใช้ตัวแทนค่าเพื่อแสดงค่าจากฟิลด์ที่มีโครงสร้างด้วย

การ์ดทำหน้าที่ได้สองอย่างโดยไม่ต้องแยกไปอยู่คนละระบบ:

- การ์ดทบทวนใช้ด้านต่าง ๆ และเข้าสู่การทบทวนแบบเว้นระยะ
- โน้ตอ้างอิงอยู่ในชุดเดียวกันและเก็บเข้าคลังได้ การเก็บเข้าคลังจะนำโน้ตออกจากคิวการ์ดใหม่และการ์ดที่ถึงกำหนด โดยไม่ลบเนื้อหา แท็ก ลิงก์ หรือประวัติ

[มุมมองชุดการ์ด](https://mochi.cards/docs/decks/custom-views/) คือชุดตัวกรอง ลำดับการเรียง และรูปแบบการแสดงผลที่บันทึกไว้ใช้ร่วมกัน คุณอาจใช้มุมมองตารางกริดสำหรับเปิดดูตามปกติ แล้วสร้างอีกมุมมองตามแท็ก สถานะถึงกำหนด อัตราการจำได้ต่ำ หรือการทบทวนล่าสุด Mochi ยังให้เปลี่ยนมุมมองเป็นรอบติวเร่งรัดได้โดยไม่กระทบตารางปกติหรือประวัติการทบทวน นี่อธิบายได้ชัดกว่าคำว่าอินเทอร์เฟซ “เรียบง่าย”: ชุดการ์ดเดียวทำหน้าที่เป็นได้ทั้งสมุดโน้ต ฐานข้อมูลที่กรองได้ และคิวเรียน

[การทบทวนประจำวัน](https://mochi.cards/docs/getting-started/reviewing-cards/) มีสองช่วง ใน **New cards (การ์ดใหม่)** คุณจะเพิ่มการ์ดเข้าตารางทบทวน หรือเลือก Again เพื่อกลับมาดูอีกในไม่ช้า เมื่อเรียนแล้ว การ์ดที่ถึงกำหนดจะแสดงด้านถัดไปและให้เลือก **Forgot (ลืม)** หรือ **Remembered (จำได้)** หากลืม Mochi จะใช้คิวทบทวนซ้ำก่อนรีเซ็ตความคืบหน้า จึงตั้งใจจำกัดตัวเลือกให้ตัดสินใจได้ง่ายระหว่างทบทวน

## Mochi ฟรีไหม และอะไรใช้ออฟไลน์ได้บ้าง?

Mochi ใช้ฟรีได้ แต่ความหมายของ “ฟรี” และ “ออฟไลน์” ต่างกันตามช่องทางที่คุณใช้ [หน้าราคาของ Mochi](https://mochi.cards/) ระบุไว้ดังนี้:

- **แผนฟรี (Free):** US$0 ตลอดไป ไม่ต้องสมัครบัญชี ใช้ออฟไลน์ได้ไม่จำกัด
- **แผน Pro:** US$5 ต่อเดือน เพิ่มการซิงค์ข้ามอุปกรณ์ การเผยแพร่ชุดการ์ด ฟิลด์แบบไดนามิก การเชื่อมต่อ AI และความช่วยเหลือทางอีเมล

Mochi ใช้ได้บน macOS, Windows, Linux, iOS, Android และเว็บ [คู่มือดาวน์โหลดและติดตั้ง](https://mochi.cards/docs/getting-started/download-and-install/) ระบุขอบเขตการใช้งานจริงไว้ดังนี้:

| ช่องทางใช้งาน | ความหมายของฟรีและออฟไลน์ |
|---|---|
| แอปที่ติดตั้งบนเดสก์ท็อปหรือมือถือ | ใช้ Mochi ออฟไลน์ได้โดยไม่ต้องมีบัญชี ข้อมูลเก็บอยู่บนอุปกรณ์ ดังนั้นแอปที่ติดตั้งไว้เครื่องเดียวก็รองรับการใช้งานฟรีได้ครบกระบวนการ |
| เว็บแอปที่ไม่ได้ใช้ Pro | เนื้อหาเก็บอยู่ในพื้นที่จัดเก็บออฟไลน์ของเบราว์เซอร์ Mochi เตือนว่าเบราว์เซอร์อาจล้างข้อมูลนี้โดยไม่แจ้งล่วงหน้า |
| คลังการ์ดเดียวกันบนหลายอุปกรณ์ | การซิงค์ข้ามอุปกรณ์อัตโนมัติเป็นฟีเจอร์ Pro แม้แอปที่ติดตั้งแต่ละเครื่องจะใช้ออฟไลน์ได้ก็ตาม |

การใช้ออฟไลน์กับการซิงค์เป็นคนละเรื่อง คุณไม่ต้องมี Pro เพียงเพื่อสร้างหรือทบทวนการ์ดในแอปที่ดาวน์โหลดมา แต่ต้องมีหากต้องการให้คลังการ์ดชุดเดียวกันอัปเดตตรงกันโดยอัตโนมัติทั้งบนแล็ปท็อปและโทรศัพท์ สำหรับข้อมูลสำคัญในแผนฟรี ให้เก็บสำเนาสำรองในรูปแบบเฉพาะของแอปด้วย อย่าให้ข้อมูลบนอุปกรณ์ โดยเฉพาะพื้นที่จัดเก็บของเบราว์เซอร์ เป็นสำเนาเดียวที่มี

หากการใช้ออฟไลน์เป็นปัจจัยตัดสิน ลองเทียบขั้นตอนใช้งานบนอุปกรณ์ที่ต้องการใน [Anki ใช้ออฟไลน์ได้ไหม?](/blog/does-anki-work-offline/) และภาพรวมที่กว้างขึ้นใน [คู่มือแอปแฟลชการ์ดออฟไลน์](/blog/best-offline-flashcards-app/)

## แฟลชการ์ด Markdown คือเหตุผลหลักที่ควรเลือก Mochi

จุดเด่นของ Mochi อยู่ที่การใช้ Markdown เป็นรูปแบบต้นฉบับของเนื้อหาที่คุณเขียนและดูแล

การ์ด Mochi ยังคงอ่านได้ในรูปแบบข้อความ เอกสารเดียวมีได้ทั้งคำอธิบายสั้น ๆ บล็อกโค้ด ลิงก์ไปยังแนวคิดที่เกี่ยวข้อง และตัวคั่นด้านสำหรับทบทวน การ์ดยังใช้ฟิลด์และเทมเพลตได้เมื่อต้องการโครงสร้างที่ใช้ซ้ำ เมื่อนำเทมเพลตมาใช้ Mochi จะแสดง Markdown ของเทมเพลตโดยแทนค่าจากฟิลด์ และจะไม่ใช้ Markdown ของตัวการ์ดในการแสดงผล แต่ไม่ได้ลบเนื้อหานั้น

Anki เริ่มจากโมเดลที่ต่างออกไป โน้ตเก็บข้อมูลในฟิลด์ ส่วน[เทมเพลตการ์ด](https://docs.ankiweb.net/templates/intro.html)กำหนดว่าจะแสดงฟิลด์ไหนและสร้างการ์ดอะไรบ้าง เทมเพลตใช้ HTML และจัดรูปแบบด้วย CSS โน้ตคำศัพท์หนึ่งรายการจึงสร้างได้ทั้งการ์ดฝึกจำเมื่อเห็นคำและการ์ดฝึกนึกคำขึ้นมาเอง โดยเก็บข้อมูลต้นทางไว้ที่เดียว

โครงสร้างนี้ทำให้ Anki รองรับการจัดวางแบบมีเงื่อนไข การสร้างการ์ดหลายรูปแบบ การพิมพ์คำตอบ การปรับหน้าตา และการต่อยอดวิธีใช้งานด้วยส่วนเสริมได้มากกว่า แต่ก็หมายความว่า Anki ไม่ใช่แอปแฟลชการ์ดที่รองรับ Markdown โดยตรง การใช้ Markdown กับ Anki ต้องมีขั้นตอนแปลงหรือส่วนเสริมเพิ่มเข้ามา

คำถามในการเลือกจึงเรียบง่าย: คุณอยากได้โน้ตที่เปลี่ยนเป็นการ์ดได้ หรือประเภทโน้ตที่มีโครงสร้างและสร้างการ์ดได้หลายใบ? Mochi เน้นแบบแรก ส่วน Anki เน้นแบบที่สอง

## การทบทวนแบบเว้นระยะของ Mochi รองรับ FSRS แล้ว

บทเปรียบเทียบที่บอกว่า Mochi ไม่มี FSRS ล้าสมัยแล้ว Mochi เพิ่ม FSRS รุ่นพรีวิวในปี 2025 และออกอัปเดตแก้ปัญหาของตัวจัดตารางมาอย่างต่อเนื่อง อย่างไรก็ตาม [อัลกอริทึมของ Mochi เองยังเป็นค่าเริ่มต้น](https://mochi.cards/docs/reviewing/fsrs/)

อัลกอริทึมเริ่มต้นปรับช่วงห่างด้วยตัวคูณคงที่หลังการทบทวนแต่ละครั้งที่จำได้หรือลืม เมื่อเปลี่ยนเป็น FSRS ใน Review Settings (การตั้งค่าการทบทวน) การ์ดเดิมที่เรียนแล้วจะย้ายไปใช้ FSRS โดยไม่สูญเสียประวัติ คุณตั้งอัตราการจำได้เป้าหมาย ใส่พารามิเตอร์ที่กำหนดเอง และเปลี่ยนกลับภายหลังได้

Mochi ยังคงใช้ผลการทบทวนสองแบบ ไม่ว่าจะเลือกตัวจัดตารางใด:

- **Forgot (ลืม)** ตรงกับ Again ของ FSRS
- **Remembered (จำได้)** ตรงกับ Good ของ FSRS

เอกสารของ Mochi ระบุว่าการประเมินผลสองแบบใช้กับ FSRS ได้ แม้จะขาดข้อมูลบางส่วนที่ Hard และ Easy ให้ได้ ระบบรับพารามิเตอร์ที่ปรับให้เหมาะแล้วได้ แต่ไม่มีตัวปรับพารามิเตอร์อัตโนมัติในตัว การสร้างพารามิเตอร์เฉพาะบุคคลต้องใช้เครื่องมือปรับ FSRS ภายนอกกับประวัติการทบทวนของ Mochi

[การตั้งค่า FSRS ของ Anki](https://docs.ankiweb.net/deck-options.html#fsrs) ทำได้มากกว่า อัตราการจำได้ที่ต้องการและพารามิเตอร์ผูกกับชุดค่าที่ตั้งไว้ได้ เครื่องมือปรับพารามิเตอร์ในตัวหาค่าที่เหมาะกับประวัติการทบทวนได้ และเครื่องมือจำลองประเมินจำนวนครั้งที่ต้องทบทวนหรือเวลาเรียนเป็นนาทีภายใต้การตั้งค่าต่าง ๆ ได้ Anki ยังบันทึกผลสี่แบบ ได้แก่ Again, Hard, Good และ Easy

ปุ่มที่เพิ่มมาจะช่วยก็ต่อเมื่อคุณใช้แต่ละปุ่มตามความหมายเดียวกันทุกครั้ง คู่มือ Anki ถือว่า Hard หมายถึงนึกคำตอบได้สำเร็จ การกด Hard ทั้งที่ลืมคำตอบจะส่งข้อมูลผิดให้ FSRS และอาจทำให้ช่วงห่างยาวเกินไป

เลือกการทบทวนสองแบบของ Mochi หากการเลือกเพียงว่าผ่านหรือไม่ผ่านช่วยให้ทบทวนได้ง่ายขึ้น เลือก Anki หากต้องการข้อมูลจากระดับผลที่ละเอียดขึ้นและจะใช้ตัวปรับพารามิเตอร์ การควบคุมอัตราการจำได้ ชุดค่าที่ตั้งไว้ หรือตัวจำลองภาระการเรียน หากต้องการเทียบตัวจัดตารางแทนตัวแอป อ่าน [FSRS เทียบกับ SM-2](/blog/fsrs-vs-sm-2/)

## ราคา Mochi กับ Anki คิดค่าใช้จ่ายคนละส่วน

ถ้าเรียนบนคอมพิวเตอร์เครื่องเดียว ทั้งสองแอปอาจไม่มีค่าใช้จ่ายเลย เมื่อเพิ่มอุปกรณ์ ค่าใช้จ่ายจะเกิดขึ้นคนละจุด

Mochi คิด **US$5 ต่อเดือน** สำหรับการซิงค์ Pro โดยรวมการเผยแพร่ ฟิลด์แบบไดนามิก การเชื่อมต่อ AI และความช่วยเหลือไว้ด้วย แอปเดสก์ท็อปของ Anki ฟรี และ[เว็บไซต์ Anki อย่างเป็นทางการ](https://apps.ankiweb.net/)ระบุว่าการซิงค์ผ่าน AnkiWeb ฟรี AnkiMobile เป็นแอป iPhone และ iPad อย่างเป็นทางการที่ต้องซื้อ ส่วน AnkiDroid เป็นแอป Android ฟรีที่พัฒนาโดยอิสระ

คำถามว่า “อะไรถูกกว่า?” จึงขึ้นอยู่กับอุปกรณ์ของคุณ:

- คอมพิวเตอร์หนึ่งเครื่อง: ทั้งคู่ใช้ฟรีได้
- เดสก์ท็อปหรือ Android หลายเครื่อง: การซิงค์ฟรีผ่านเซิร์ฟเวอร์ของผู้ให้บริการของ Anki ช่วยให้ไม่ต้องจ่ายค่าสมาชิก
- iPhone หรือ iPad: Anki มีค่าซื้อแอปครั้งเดียว ส่วน Mochi ต้องสมัครแผน Pro และจ่ายต่อเนื่องเพื่อซิงค์ข้ามอุปกรณ์
- ผู้ใช้ Mochi ที่ต้องการการเผยแพร่ ฟิลด์แบบไดนามิก หรือการเชื่อมต่อ AI อยู่แล้ว อาจมองการซิงค์เป็นเพียงส่วนหนึ่งของแพ็กเกจ ไม่ใช่สิ่งเดียวที่จ่ายเงินเพื่อให้ได้มา

ตรวจราคาใน App Store ของภูมิภาคคุณก่อนเทียบค่าใช้จ่าย iOS แบบเจาะจง รีวิวนี้ไม่ยึดราคาจากร้านแอปเป็นตัวเลขตายตัว เพราะอาจต่างกันตามตลาด

## การโฮสต์ Mochi ต่างจากการเก็บข้อมูลในเครื่องเป็นหลัก

คำสามคำนี้มักถูกนำมาปนกัน:

- **เก็บข้อมูลในเครื่องเป็นหลัก (Local-first)** หมายถึงสำเนาที่ใช้ทำงานอยู่บนอุปกรณ์ของคุณ และแอปยังทำงานต่อได้โดยไม่พึ่งบริการคลาวด์ของแอป
- **โอเพนซอร์ส (Open source)** หมายถึงเปิดให้เข้าถึงซอร์สโค้ดภายใต้สัญญาอนุญาตที่ยอมให้ตรวจสอบและแก้ไขได้
- **โฮสต์เอง (Self-hosted)** หมายถึงผลิตภัณฑ์มีเอกสารอธิบายวิธีรันบริการที่เกี่ยวข้องซึ่งผู้พัฒนารองรับบนโครงสร้างพื้นฐานของคุณเอง

Mochi อธิบายการเก็บข้อมูลในเครื่องเป็นหลักไว้อย่างชัดเจน แต่ไม่ได้นำเสนอตัวแอปหลักว่าเป็นโอเพนซอร์ส: ลิงก์ “Open source” ในส่วนท้ายเว็บไซต์สาธารณะนำไปยัง[ชุดเครื่องมือเชื่อมต่อ](https://github.com/mochi-cards/open-source) ไม่ใช่ตัวแอปหลัก เว็บไซต์ทางการยังไม่มีเอกสารระบุวิธีโฮสต์บริการซิงค์เองที่ผู้พัฒนารองรับเพื่อใช้แทนการซิงค์ Pro

หากค้นหา **การโฮสต์ Mochi** เพราะอยากใช้เซิร์ฟเวอร์ของตัวเอง ขอบเขตคือคุณเก็บข้อมูลในเครื่องและสำรองในรูปแบบเฉพาะของแอปได้ แต่ช่องทางข้ามอุปกรณ์ที่มีเอกสารรองรับคือ Mochi Pro การเก็บข้อมูลในเครื่องเป็นหลักช่วยให้ควบคุมข้อมูลได้ แต่ไม่ใช่การโฮสต์เอง

คลังซอร์สโค้ดหลักของ Anki [ใช้สัญญาอนุญาต AGPL เวอร์ชัน 3 หรือใหม่กว่า](https://github.com/ankitects/anki/blob/main/LICENSE) โดยระบุข้อยกเว้นสำหรับบางองค์ประกอบ คู่มือทางการยังอธิบาย[เซิร์ฟเวอร์ซิงค์ที่โฮสต์เอง](https://docs.ankiweb.net/sync-server.html)สำหรับผู้ใช้ขั้นสูง เซิร์ฟเวอร์นี้แทนที่การซิงค์ AnkiWeb สำหรับแอปที่เข้ากันได้ ไม่ใช่เว็บไซต์ AnkiWeb ฉบับโฮสต์เอง และ Anki คาดหวังให้ผู้ดูแลจัดการเรื่องบรรทัดคำสั่ง เครือข่าย ไฟร์วอลล์ โปรโตคอล และการอัปเดตได้เอง

## การนำเข้าจาก Anki เก็บอะไรไว้และเปลี่ยนอะไรบ้าง

[เอกสารการนำเข้าของ Mochi](https://mochi.cards/docs/import-and-export/importing/) ระบุว่ารองรับไฟล์ Anki `.apkg` รวมถึงประวัติการทบทวน แต่การ “นำเข้าสำเร็จ” กับการ “ทำงานได้เหมือนเดิม” เป็นคนละผลลัพธ์

ระหว่างนำเข้า Mochi จะแปลง HTML เป็น Markdown และลบ CSS กับ JavaScript นี่คือการแปลงรูปแบบระหว่างโมเดลการ์ดสองแบบที่ต่างกัน เนื้อหาด้านหน้าและด้านหลังแบบธรรมดาย้ายได้ง่ายที่สุด การ์ดที่พึ่งพาการจัดรูปแบบ ตรรกะของเทมเพลต การโต้ตอบที่ใช้การพิมพ์คำตอบ หรือ JavaScript ต้องตรวจหลังนำเข้า

หากต้องการย้ายประวัติการทบทวนมาด้วย ต้องเลือกให้รวมประวัติไว้ตอนส่งออก [คู่มือการส่งออกของ Anki](https://docs.ankiweb.net/exporting.html) ระบุว่า **Include Scheduling Information (รวมข้อมูลการจัดตาราง)** เป็นตัวกำหนดว่าจะใส่ประวัติการทบทวนลงในแพ็กเกจหรือไม่ หากไม่เปิดตัวเลือกนี้ Mochi ก็เรียกคืนประวัติที่ไม่เคยอยู่ใน `.apkg` ไม่ได้

แม้ประวัติจะย้ายมาครบ ก็อย่าคาดหวังว่าวันครบกำหนดในอนาคตจะเหมือนเดิม ทั้งสองแอปอาจใช้ตัวจัดตาราง ระดับผลการทบทวน อัตราการจำได้เป้าหมาย พารามิเตอร์ ขั้นตอนการเรียนรู้ และการตั้งค่าชุดการ์ดต่างกัน ประวัติเหตุการณ์ที่เก็บไว้เป็นข้อมูลให้ตัวจัดตารางใหม่ใช้คำนวณ แต่ไม่ได้ทำให้สองระบบเหมือนกัน

## ไฟล์สำรองในรูปแบบของแอปกับไฟล์ข้อความสำหรับย้ายข้อมูลทำหน้าที่ต่างกัน

ก่อนย้ายสิ่งใด ให้เก็บสำเนาสำรองที่กู้คืนระบบเดิมได้ ไฟล์ส่งออกที่อ่านได้มีประโยชน์ แต่ไม่ได้หมายความว่าจะใช้กู้คืนระบบเดิมได้เสมอไป

[คู่มือสำรองข้อมูลของ Mochi](https://mochi.cards/docs/getting-started/backing-up/) อธิบายวิธีสำรองข้อมูลในรูปแบบของแอปไว้สองวิธี:

- การคัดลอกไดเรกทอรีผู้ใช้ทั้งชุดเก็บเนื้อหา ประวัติการทบทวน ไฟล์แนบ การตั้งค่าแอป และสถานะการเข้าสู่ระบบไว้
- การส่งออก `.mochi` เก็บชุดการ์ด การ์ด เทมเพลตและฟิลด์ ไฟล์แนบ แท็กและข้อมูลกำกับ ประวัติการทบทวน ลำดับการ์ด และโครงสร้างชุดการ์ดไว้

[การส่งออก Markdown และ CSV ของ Mochi](https://mochi.cards/docs/import-and-export/exporting/) เป็นรูปแบบสำหรับนำข้อมูลไปใช้ที่อื่น Markdown สร้างหนึ่งไฟล์ต่อการ์ดและโฟลเดอร์สำหรับชุดการ์ดย่อย แต่ไม่เก็บประวัติการทบทวน ลำดับการ์ด หรือเทมเพลต และไม่เก็บแท็กในข้อมูลกำกับ เว้นแต่แท็กจะอยู่ใน Markdown ส่วน CSV ส่งออกฟิลด์ของเทมเพลตหรือเนื้อหาด้านหน้าและด้านหลังที่แสดงผลแล้วได้ แต่ไม่เก็บประวัติการทบทวนหรือเทมเพลต และไม่เก็บแท็กในข้อมูลกำกับ เว้นแต่ฝังแท็กไว้ในเนื้อหา

Anki แบ่งรูปแบบคล้ายกัน:

- `.colpkg` ส่งออกคลังการ์ดทั้งหมดพร้อมข้อมูลการจัดตาราง และรวมสื่อได้ การนำเข้าไฟล์นี้จะแทนที่การ์ดในคลัง Anki ปลายทาง
- `.apkg` ส่งออกหนึ่งชุดการ์ดและชุดย่อย พร้อมตัวเลือกสำหรับข้อมูลการจัดตาราง ชุดค่าที่ตั้งไว้ และสื่อ
- โน้ตในรูปแบบข้อความล้วนใช้ฟิลด์คั่นด้วยแท็บและฝังการจัดรูปแบบ HTML ไว้ รูปแบบนี้เก็บเนื้อหาที่แก้ไขได้ ไม่ได้เก็บการทำงานทั้งหมดของคลังการ์ด

การย้ายจาก Mochi กลับไป Anki โดยทั่วไปใช้ CSV Anki [จับคู่คอลัมน์ข้อความกับฟิลด์ของโน้ต](https://docs.ankiweb.net/importing/text-files.html)ได้ แต่ลิงก์ของ Mochi การทำงานแบบหลายด้าน เทมเพลต และประวัติการทบทวนไม่ได้กลายเป็นองค์ประกอบ Anki ที่เทียบเท่ากันผ่านไฟล์นี้ เก็บไฟล์ส่งออก `.mochi` ไว้แม้สำเนาใน Anki จะดูถูกต้องแล้วก็ตาม

## ทดสอบด้วยชุดการ์ดตัวแทนโดยยังย้อนกลับได้

หน้าต่างแจ้งผลการย้ายพิสูจน์ได้เพียงว่าระบบรับไฟล์แล้ว ไม่ได้พิสูจน์ว่าคลังการ์ดจริงของคุณยังทำงานได้ หรือคุณจะนำเนื้อหากลับมาใช้งานได้ ทดสอบทั้งสองทิศทางโดยไม่แตะโปรไฟล์ Anki ที่ใช้ตามปกติ

1. **สำรอง Anki ทั้งหมด** ส่งออก `.colpkg` พร้อมสื่อและเก็บไว้นอกโปรไฟล์ที่ใช้งาน
2. **ตรวจว่าสำเนาสำรองเปิดได้จริง** สร้างโปรไฟล์ Anki ชั่วคราวที่ว่างแล้วนำเข้า `.colpkg` ที่นั่น การนำเข้าแพ็กเกจคลังการ์ดจะแทนที่คลังปลายทาง นี่คือเหตุผลที่ต้องใช้โปรไฟล์ชั่วคราว
3. **สร้างชุดการ์ดตัวแทนในโปรไฟล์ชั่วคราวนั้น** ให้เล็กพอที่จะตรวจทีละใบ แต่รวมการทำงานที่คุณพึ่งพาไว้: การ์ดพื้นฐานและแบบกลับด้าน การ์ดเติมคำในช่องว่าง เทมเพลตที่ปรับแต่ง CSS, JavaScript รูปภาพ เสียง สมการ แท็ก ชุดการ์ดที่ซ้อนเป็นลำดับชั้น และประวัติการทบทวน
4. **ส่งออกชุดนั้นเป็น `.apkg`** รวมข้อมูลการจัดตาราง ชุดค่าที่ตั้งไว้ และสื่อเมื่อจำเป็น ตัวเลือกเหล่านี้ใส่ข้อมูลลงในแพ็กเกจ Anki แต่ไม่ได้รับประกันว่า Mochi จะทำตามการตั้งค่าทุกอย่างได้
5. **นำเข้าเป็นชุดการ์ดใหม่ใน Mochi** เก็บโปรไฟล์ Anki ที่ใช้ทุกวันและคิวการ์ดถึงกำหนดไว้ตามเดิม
6. **ตรวจก่อนทบทวน** เปรียบเทียบเนื้อหา การจัดรูปแบบ ฟิลด์ สื่อ แท็ก โครงสร้างชุดการ์ด และประวัติ ตรวจสิ่งที่พึ่งพา HTML, CSS, JavaScript หรือการสร้างการ์ดหลายรูปแบบเป็นพิเศษ
7. **เลือกตัวจัดตารางให้ตรงกับที่ตั้งใจ** Mochi เริ่มด้วยอัลกอริทึมของตัวเอง เปิด FSRS เฉพาะเมื่อคุณตั้งใจจะใช้มันหลังทดลอง
8. **ทบทวนสำเนานี้เป็นเวลาหนึ่งสัปดาห์ตามปกติ** ประเมินขั้นตอนแก้ไข Markdown ช่วง New cards การเลือก Remembered/Forgot การใช้ออฟไลน์ และหากจ่ายเงินแล้ว ให้ดูการซิงค์บนอุปกรณ์ที่คุณพกจริงด้วย
9. **ทดสอบการย้ายกลับ** ส่งออกชุดทดลองของ Mochi เป็น `.mochi` เพื่อสำรองในรูปแบบเฉพาะ และเป็น CSV สำหรับ Anki ใช้ CSV ที่เก็บค่าฟิลด์เมื่อฟิลด์ที่ใช้ซ้ำมีความสำคัญ ใช้ CSV ของด้านที่แสดงผลแล้วเมื่อสิ่งที่ต้องการหลัก ๆ คือเนื้อหาด้านหน้าและด้านหลังที่มองเห็น นำเข้า CSV นั้นในโปรไฟล์ Anki ว่างอีกโปรไฟล์หนึ่ง แล้วจับคู่คอลัมน์กับประเภทโน้ตที่เหมาะสม
10. **จดทุกสิ่งที่ยอมรับได้ว่าจะสูญเสีย** ตรวจเส้นทางไปและกลับแยกกัน ความตรงกันของรูปแบบการแสดงผล การทำงานแบบหลายด้าน การทำงานของส่วนเสริม รูปแบบการ์ดที่สร้างขึ้น ระดับผลการทบทวน ประวัติ หรือวันครบกำหนดในอนาคต อาจสำคัญในการใช้ทุกวันมากกว่าตอนอ่านตารางเปรียบเทียบ

การย้ายกลับผ่าน CSV คือการย้ายเนื้อหา ไม่ใช่การกู้คืน Mochi ทั้งระบบ: ไฟล์ไม่เก็บประวัติการทบทวนหรือเทมเพลต และไม่เก็บแท็กในข้อมูลกำกับ เว้นแต่แท็กเหล่านั้นฝังอยู่ในเนื้อหา หาก Mochi ไม่ได้แก้ปัญหาที่คุณระบุไว้ ให้ลบชุดทดลองแล้วใช้โปรไฟล์ Anki เดิมต่อ หากแก้ได้ ให้ย้ายชุดจริงทีละชุด และเก็บสำเนาสำรอง Anki `.colpkg` กับ Mochi `.mochi` ไว้จนผ่านการทบทวนตามปกติไปหลายรอบ

## ใครควรใช้แฟลชการ์ด Mochi?

Mochi เหมาะเมื่อ:

- คุณใช้ Markdown ในการเขียนและจัดระเบียบความคิดอยู่แล้ว
- โน้ตกับการ์ดทบทวนควรอยู่ในพื้นที่ทำงานเดียวที่เชื่อมโยงถึงกัน
- คุณอยากเลือกเพียง Remembered/Forgot แทนระดับผลการทบทวนสี่ระดับ
- การใช้ออฟไลน์บนอุปกรณ์เดียวครอบคลุมสิ่งที่ต้องการจากแผนฟรี หรือการซิงค์ Pro คุ้มกับ US$5 ต่อเดือน
- คลังการ์ดของคุณเพิ่งเริ่มหรือเรียบง่ายพอที่การแปลงจาก Anki มีความเสี่ยงต่ำ

ใช้ Anki ต่อเมื่อ:

- ประเภทโน้ตของคุณสร้างการ์ดหลายรูปแบบที่จำเป็นต่อการเรียน
- เทมเพลต HTML/CSS, JavaScript ส่วนเสริม หรือชุดการ์ดที่แบ่งปันกันเป็นส่วนหนึ่งของระบบ
- การซิงค์ข้ามอุปกรณ์ฟรีสำคัญกว่าการเขียนด้วย Markdown
- คุณต้องการตัวปรับพารามิเตอร์ FSRS ของ Anki การควบคุมชุดค่าที่ตั้งไว้ ระดับผลการทบทวนสี่ระดับ และตัวจำลองภาระการเรียน
- ข้อมูลการทบทวนหลายปีและการทำงานที่ปรับแต่งไว้ใช้งานได้ดีอยู่แล้ว

แอปที่เหมาะจะใช้แทน Mochi ขึ้นอยู่กับว่าทำไมทั้งสองตัวเลือกจึงไม่ตอบโจทย์ สำหรับคลังการ์ดใหม่ที่เรียบง่ายกว่า [ฟีเจอร์ของ Nibomo](/th/features/) มีการทบทวนด้วย FSRS การเรียนออฟไลน์และการซิงค์ การถ่ายโอนการ์ด แท็ก และสื่อในรูปแบบที่นำไปใช้ต่อได้ การเข้าถึงผ่านเอเจนต์ และแนวทางโฮสต์เองที่มีเอกสารอธิบาย ผมเป็นผู้พัฒนาแอปนี้ และมีข้อจำกัดที่ควรใช้ประกอบการตัดสินใจ: แอปนี้ไม่ได้แทนที่สมุดโน้ต Markdown ที่เชื่อมโยงกันของ Mochi หรือระบบเทมเพลตและส่วนเสริมที่พัฒนามานานของ Anki [คู่มือเริ่มต้นใช้งาน](/docs/getting-started/) อธิบายวิธีใช้งานที่มีอยู่ผ่านบริการโฮสต์ แอปมือถือ เอเจนต์ และการโฮสต์เอง

## ควรเลือกอย่างไร

Mochi มีมากกว่าแค่อินเทอร์เฟซ Anki ที่สวยขึ้น แนวคิดหลักคือโน้ต Markdown บันทึกความรู้ที่เชื่อมโยงกัน และการ์ดทบทวนแบบเว้นระยะเป็นสิ่งเดียวกันได้ แผนฟรีครอบคลุมการใช้ออฟไลน์โดยไม่ต้องมีบัญชี ส่วน Pro เพิ่มฟีเจอร์ผ่านบริการโฮสต์ รวมถึงการซิงค์ข้ามอุปกรณ์

นี่เป็นข้อแลกเปลี่ยนที่ดีสำหรับผู้เรียนที่เริ่มคลังการ์ดใหม่โดยใช้ Markdown เป็นหลัก การย้ายจาก Anki ก็อาจคุ้ม หากการทดสอบชุดการ์ดตัวแทนพิสูจน์ว่าการรองรับ Markdown โดยตรงและการเลือกผลทบทวนสองแบบช่วยลดความยุ่งยากจริง

สำหรับคนที่ใช้ Anki มานาน ควรให้ Mochi พิสูจน์ก่อนว่าคุ้มที่จะย้าย สำรองคลังการ์ด ทดสอบการ์ดที่มีการทำงานปรับแต่งมากที่สุด และใช้ Anki ต่อ เว้นแต่ Mochi จะช่วยให้การใช้งานในแต่ละสัปดาห์ดีขึ้นมากพอที่จะคุ้มกับฟีเจอร์ด้านการจัดรูปแบบ เทมเพลต ตัวจัดตาราง และเครื่องมือในระบบนิเวศของ Anki ที่คุณต้องสละไป
