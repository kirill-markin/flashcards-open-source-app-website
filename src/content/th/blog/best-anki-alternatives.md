การนำเข้าข้อมูลจาก Anki อาจเสร็จโดยไม่แจ้งข้อผิดพลาด ทั้งที่องค์ประกอบสำคัญของสำรับหายไปแล้ว ข้อความมาครบ เปิดการ์ดได้ แล้วคุณก็เริ่มสังเกตว่า CSS หายไป ช่องข้อมูลเสียงว่างเปล่า การ์ดทุกใบกลายเป็นการ์ดใหม่ หรือโน้ตหนึ่งรายการไม่สร้างการ์ดแบบถามไป–ตอบกลับอย่างที่คาดไว้อีกแล้ว

นี่คือต้นทุนก้อนใหญ่ของการเปรียบเทียบแอปทางเลือกแทน Anki หน้าจอแก้ไขที่ดูเรียบง่ายขึ้นหรือแพ็กเกจที่ถูกลงนั้นเห็นได้ง่ายก่อนย้าย แต่พฤติกรรมของเทมเพลต ประวัติการทบทวน วันครบกำหนด ส่วนเสริม สื่อที่ใช้แบบออฟไลน์ และทางส่งข้อมูลกลับออกมา มักจะเพิ่งเห็นปัญหาหลังเกิดความเสียหายไปแล้ว

บทเปรียบเทียบนี้เริ่มจากข้อจำกัดตรงนั้น โดยดูแอปคล้าย Anki ทั้งเจ็ดตัวว่าแต่ละตัวรับอะไรจากคอลเลกชันเดิมได้บ้าง อะไรเปลี่ยนไปหลังนำเข้า และเมื่อไรการใช้ Anki ต่อจึงเป็นทางเลือกที่ปลอดภัยกว่า

> **เปิดเผยความเกี่ยวข้อง:** ผมชื่อ Kirill Markin และเป็นผู้พัฒนา [Nibomo](https://nibomo.com/) ซึ่งเป็นหนึ่งในผลิตภัณฑ์ด้านล่าง ผมรวมแอปนี้ไว้เพราะเป็นโอเพนซอร์ส โฮสต์เองได้ และมีเวิร์กโฟลว์สำหรับเอเจนต์ แต่ไม่ได้ยกให้เป็นผู้ชนะโดยอัตโนมัติ: แอปไม่มีตัวนำเข้า `.apkg` โดยตรง การย้ายจาก Anki ทำให้ข้อมูลบางส่วนสูญหาย และการดูแลระบบที่โฮสต์เองก็เป็นงานโครงสร้างพื้นฐานจริงจัง

**ตรวจสอบข้อเท็จจริงเมื่อ:** 28 สิงหาคม 2026 ราคาเป็นราคาสาธารณะในสหรัฐฯ หรือราคาท้องถิ่นที่ระบุไว้ ณ วันนั้น ภาษี ภูมิภาค ข้อเสนอสำหรับการศึกษา และการเรียกเก็บเงินผ่านแอปสโตร์อาจทำให้ยอดเปลี่ยนไป

## คำตอบสั้น ๆ ก่อนเริ่มย้ายอะไร

ให้ใช้ Anki ต่อเป็นหลัก ย้ายก็ต่อเมื่อแอปอื่นแก้ปัญหาที่เจอซ้ำ ๆ ได้คุ้มกับต้นทุนการย้าย

มีสามผลิตภัณฑ์ที่รับแพ็กเกจ Anki พร้อมข้อมูลการเรียนรู้ แต่ขอบเขตที่แต่ละตัวระบุว่ารองรับนั้นต่างกัน:

- **Mnemosyne** ระบุในเอกสารว่ารองรับการนำเข้า Anki แบบครบถ้วน รวมถึงประเภทการ์ดที่กำหนดเองและข้อมูลการเรียนรู้ ในกลุ่มนี้ แอปนี้ใกล้เคียงกับการใช้โปรแกรมเดสก์ท็อปโอเพนซอร์สที่เก็บข้อมูลในเครื่องแบบดั้งเดิมมากที่สุด แม้จะไม่มีแอปเนทีฟบน iOS
- **Mochi** นำเข้าไฟล์ `.apkg` พร้อมประวัติการทบทวนได้ โดยแปลง HTML เป็น Markdown ตัด CSS และ JavaScript ออก และเปลี่ยนปุ่มให้คะแนนสี่ปุ่มของ Anki เป็น Remembered หรือ Forgot
- **RemNote** นำเข้าไฟล์ `.apkg` ประเภทโน้ตส่วนใหญ่ และประวัติการทบทวนได้ แต่คู่มือปัจจุบันยังระบุว่าการ์ดที่นำเข้าจะไปอยู่ในคิว **Need to Learn** แยกต่างหาก ดังนั้นอย่าเข้าใจว่า “นำเข้าประวัติการทบทวนได้” หมายถึง “คัดลอกคิว Anki ของวันนี้มาได้ตรงกันทุกอย่าง”

อีกสี่ตัวเป็นการสร้างเนื้อหาขึ้นใหม่ ไม่ใช่การย้ายทั้งคอลเลกชัน:

- **Quizlet** เหมาะกับชุดการเรียนสาธารณะ ชั้นเรียน เกม และแบบฝึกที่มีแนวทางให้
- **Brainscape** ให้กลุ่มผู้เรียนใช้วิธีทบทวนที่เรียบง่ายขึ้น โดยให้คะแนนความมั่นใจ 1–5
- **SuperMemo** คือการย้ายไปใช้วิธีการของผู้พัฒนาและคลังหลักสูตรของบริการนั้น
- **Nibomo** ให้คุณเข้าถึงแอปเว็บและแอปเนทีฟภายใต้สัญญาอนุญาต MIT แบ็กเอนด์ที่โฮสต์เองได้ API และ MCP กระบวนการย้ายผ่าน TXT หรือ CSV ที่ให้ AI ช่วยร่างแล้วตรวจทานไม่เก็บสถานะการเรียนรู้จาก Anki ไว้

หากการ์ดของคุณต้องแสดงผลตรงตามเดิม ใช้ส่วนเสริม หรืออาศัยคิวทบทวนปัจจุบัน การใช้ Anki ต่อก็เป็นคำตอบ ไม่ใช่ความลังเล

## เริ่มจากนับว่าคอลเลกชัน Anki ของคุณมีอะไรอยู่จริง ๆ

“สำรับ” ไม่ใช่ข้อมูลก้อนเดียวที่ย้ายไปใช้ที่ไหนก็ได้ ก่อนเปรียบเทียบผลิตภัณฑ์ ให้แยกองค์ประกอบที่คุณอาจต้องย้ายออกมาก่อน

| ส่วนของคอลเลกชัน | สิ่งที่ Anki ใส่ไว้ในแพ็กเกจได้ | สิ่งที่แอปปลายทางต้องระบุว่ารองรับ |
| --- | --- | --- |
| **เนื้อหาโน้ต** | ช่องข้อความและ HTML ที่จัดเก็บไว้ | การจับคู่ช่องข้อมูล การ์ดเติมคำ (cloze) ข้อความที่ไม่ใช่อักษรละติน โค้ด และการขึ้นบรรทัดใหม่ |
| **การสร้างการ์ด** | ประเภทโน้ตและเทมเพลตการ์ด | การ์ดแบบปกติ/กลับด้าน ช่องข้อมูลที่กำหนดเอง CSS และพฤติกรรมของ JavaScript |
| **สื่อ** | รูปภาพ เสียง และไฟล์อื่นในเครื่อง เมื่อเปิด **Include media** | การแยกไฟล์ออกจากแพ็กเกจ การอ้างอิงไฟล์ รูปแบบที่รองรับ และการซิงค์ระหว่างอุปกรณ์ |
| **การจัดระเบียบ** | สำรับ สำรับย่อย แท็ก และชุดการตั้งค่าสำรับหากเลือกไว้ | ลำดับชั้น ความหมายของแท็ก ชุดการตั้งค่า และขอบเขตเนื้อหาที่จะเรียน |
| **สถานะการเรียนรู้** | ข้อมูลตารางทบทวนและประวัติการทบทวนเมื่อเลือกรวมไว้ | วันครบกำหนด ช่วงห่างการทบทวน การลืมการ์ดที่เคยเรียนแล้ว และการแปลงข้อมูลให้เข้ากับระบบจัดตารางปลายทาง |
| **โค้ดที่ใช้ในเวิร์กโฟลว์** | ส่วนเสริมไม่ได้ถูกรวมเป็นส่วนหนึ่งของแพ็กเกจสำรับ | สิ่งทดแทนเครื่องมือในหน้าจัดการการ์ด การแก้ไขเป็นชุด การสร้างโน้ต และพฤติกรรมอื่นของส่วนเสริม |

[คู่มือการส่งออกของ Anki](https://docs.ankiweb.net/exporting.html) อธิบายตัวเลือกแพ็กเกจทั้งหมดเหล่านี้ ตัวนำเข้าข้อความเห็นเพียงแถวแรก และอาจเห็นแท็กด้วย ตัวนำเข้า `.apkg` โดยตรงเห็นได้มากกว่า แต่แต่ละผลิตภัณฑ์เป็นผู้ตัดสินใจว่าจะแปลงอะไรและทิ้งอะไร

นี่จึงเป็นเหตุผลที่คำว่า “นำเข้าจาก Anki ได้” กว้างเกินไปสำหรับใช้ตัดสินใจย้าย ให้ถามแยกเป็นสามข้อ:

1. **การ์ดยังสื่อความหมายเดิมหรือไม่?** ตรวจช่องข้อมูล รูปแบบการถามไป–ตอบกลับของการ์ดที่สร้างขึ้น การ์ดเติมคำ สื่อ และการแสดงผล
2. **แอปปลายทางรู้หรือไม่ว่าฉันเรียนอะไรไปแล้ว?** ตรวจบันทึกการทบทวนแต่ละครั้ง สถานะปัจจุบัน วันครบกำหนด และคิวใช้งานจริงคิวแรก
3. **ฉันจะย้ายออกอีกครั้งได้หรือไม่?** ส่งออกจากแอปปลายทาง แล้วตรวจว่ารูปแบบไฟล์ส่งออกมีอะไรอยู่จริง

ตัวนำเข้าอาจผ่านข้อแรก แต่ไม่ผ่านอีกสองข้อ

## RemNote: ย้ายการ์ดเข้าไปอยู่กับโน้ตที่เชื่อมโยงกัน

RemNote เปลี่ยนวิธีสร้างการ์ด แทนที่จะดูแลสำรับแยกจากโน้ตจากการบรรยาย คุณสร้างการ์ดอยู่ในโครงร่าง เอกสาร หรือเวิร์กโฟลว์ PDF ได้เลย นี่เป็นเหตุผลที่มีน้ำหนักสำหรับการออกจาก Anki หากการคัดลอกเนื้อหาระหว่างแอปจดโน้ตกับแอปแฟลชการ์ดกลายเป็นงานที่กินแรงที่สุด

RemNote รองรับการย้ายข้อมูลหลายส่วน แต่ต้องอ่านรายละเอียดเรื่องคิวให้ดี [คู่มือนำเข้าจาก Anki ฉบับปัจจุบัน](https://help.remnote.com/en/articles/6751471-importing-from-anki) ของ RemNote ให้ส่งออก `.apkg` พร้อมข้อมูลตารางทบทวน ชุดการตั้งค่าสำรับ และสื่อ โดยนำเข้าประวัติการทบทวนและประเภทโน้ตส่วนใหญ่ได้ รวมถึงแบบพื้นฐาน แบบเติมคำ และแบบปิดบังภาพที่ใช้กันทั่วไป

คู่มือเดียวกันระบุว่าการ์ดที่เพิ่งนำเข้าจะถูกส่งไปยังคิว **Need to Learn** แยกต่างหาก กล่าวคือ RemNote มีประวัติให้ใช้ แต่เอกสารไม่ได้รับประกันว่าคิวการ์ดที่ถึงกำหนดใน Anki ปัจจุบันจะกลับมาเหมือนเดิมทุกอย่าง นอกจากนี้ CSS ที่ซับซ้อนจะถูกตัดออก ไม่รองรับ JavaScript ที่กำหนดเอง การแปลงข้อความเป็นเสียงขณะใช้งานบางแบบทำงานไม่ได้ และการนำเข้าการ์ดปิดบังภาพต้องอาศัยชื่อประเภทโน้ตและช่องข้อมูลตามที่ระบบคาดไว้

ลองนำเข้าสำรับที่เป็นตัวแทนการใช้งานจริง แล้วตรวจทั้งการ์ดและคิวแรก การนำเข้าที่หน้าตาดูเรียบร้อยเป็นเพียงครึ่งหนึ่งของการทดสอบ

แอปเดสก์ท็อปและมือถือใช้แบบออฟไลน์ได้หลังติดตั้งและเข้าสู่ระบบ [คู่มือออฟไลน์](https://help.remnote.com/en/articles/6752029-offline-mode) ระบุข้อจำกัดเรื่องสื่อที่สำคัญ: เดสก์ท็อปเก็บรูปภาพและ PDF ทั้งหมดในฐานความรู้ แต่มือถือแคชเพียงภาพล่าสุดบางส่วน เว็บแอปใช้งานต่อในแท็บที่เปิดอยู่แล้วได้ แต่เปิดขึ้นมาใหม่ขณะออฟไลน์ไม่ได้

ใช้ RemNote เมื่อการเชื่อมโน้ตเข้าด้วยกันคุ้มค่ากับการเปลี่ยนรูปแบบคอลเลกชัน ใช้ Anki ต่อหากเทมเพลตและส่วนเสริมเป็นแกนหลักของระบบคุณ ไม่ใช่แค่ของตกแต่ง

## Mochi: Markdown ในเครื่อง พร้อมส่งออกข้อมูลครบในรูปแบบของแอปเอง

Mochi เป็นทางเลือกที่เรียบง่ายกว่าสำหรับคนที่ต้องการข้อมูลในเครื่อง การ์ดแบบ Markdown และปุ่มควบคุมบนหน้าจอน้อยลง แอปที่ติดตั้งรองรับแพลตฟอร์มเดสก์ท็อปและมือถือหลักทุกตัว และใช้[แบบออฟไลน์ทั้งหมดได้โดยไม่ต้องมีบัญชี](https://mochi.cards/docs/getting-started/download-and-install/) ส่วนที่ต้องจ่ายคือการซิงค์ ราคา $5 ต่อเดือน

ตัวนำเข้าจาก Anki โดยตรงย้ายประวัติการทบทวนมาด้วย ทำให้ Mochi ไปได้ไกลกว่าตัวเลือกที่รับแต่ข้อความมาก วิธีแปลงก็ระบุไว้ชัดเจนกว่าที่พบทั่วไป: Mochi ตัด CSS และ JavaScript ออก แล้วแปลง HTML เป็น Markdown วิธีนี้ใช้ได้เมื่อความหมายอยู่ในข้อความและไฟล์แนบทั่วไป แต่ต้องระวังหากเทมเพลตเป็นตัวสื่อความหมาย

ปัจจุบัน Mochi มีระบบจัดตารางสองแบบ อัลกอริทึมของตัวเองยังเป็นค่าเริ่มต้น และ[เปิดใช้ FSRS ได้](https://mochi.cards/docs/reviewing/fsrs/)โดยไม่ต้องรีเซ็ตความคืบหน้าเดิมใน Mochi ระบบ FSRS คำนวณสถานะการ์ดจากประวัติการทบทวนที่ Mochi มี การให้คะแนนยังมีสองตัวเลือกคือ Remembered หรือ Forgot แม้จะใช้ FSRS ดังนั้นผู้ใช้ Anki ที่ใช้ Hard และ Easy เป็นสัญญาณแยกกันควรเผื่อใจว่ารูปแบบการทบทวนในแต่ละวันจะเปลี่ยนไป

การส่งข้อมูลกลับออกมาชัดเจนกว่าแอปกรรมสิทธิ์ส่วนใหญ่ ไฟล์[ส่งออก `.mochi`](https://mochi.cards/docs/import-and-export/exporting/) ซึ่งเป็นรูปแบบของแอปเองมีการ์ด เทมเพลต ไฟล์แนบ แท็ก โครงสร้างสำรับ และประวัติการทบทวน ส่วน Markdown และ CSV เปิดตรวจที่อื่นได้ง่ายกว่า แต่ไม่มีประวัติการทบทวนและเมทาดาทาอื่น ๆ

รีโพซิทอรี GitHub สาธารณะของ Mochi มี[ส่วนเชื่อมต่อและเครื่องมือที่เกี่ยวข้อง](https://github.com/mochi-cards/open-source) ไม่มีตัวแอปหลักหรือเซิร์ฟเวอร์ซิงค์ที่รองรับให้ใช้งาน เหตุผลที่ควรเลือกแอปนี้คือการใช้ออฟไลน์และความสะดวกในการย้ายข้อมูล ส่วนการควบคุมซอร์สโค้ดไม่ใช่จุดเด่นของแอป

## Mnemosyne: ทางเลือกเดสก์ท็อปโอเพนซอร์ส

Mnemosyne ใกล้เคียงรูปแบบดั้งเดิมที่เป็น “โปรแกรมกับฐานข้อมูลในเครื่อง” มากที่สุด รุ่นปัจจุบันรองรับ Windows, macOS และ Linux พร้อมแอป Android สำหรับทบทวนออฟไลน์ หน้าฟีเจอร์ระบุว่ารองรับการ์ดที่ใส่เนื้อหาได้หลากหลาย แท็กแบบลำดับชั้น ปลั๊กอิน คะแนนทบทวน 0–5 และการนำเข้า Anki แบบครบถ้วนพร้อมประเภทการ์ดที่กำหนดเองและข้อมูลการเรียนรู้

นี่เป็นทางเลือกโอเพนซอร์สที่ย้ายจาก Anki ได้โดยตรงที่สุดในกลุ่มนี้ หากคุณอยากออกจาก Anki โดยไม่ย้ายไปอยู่ในระบบจดโน้ตขนาดใหญ่หรือบริการคลาวด์ นอกจากนี้ยังมี[เซิร์ฟเวอร์ซิงค์ในตัว](https://mnemosyne-proj.org/help/syncing)ที่รันบนเดสก์ท็อปหรือเครื่องที่ทำงานโดยไม่ใช้ส่วนติดต่อกราฟิกได้ และรวมข้อมูลการเรียนรู้จากหลายไคลเอ็นต์เข้าด้วยกัน

ข้อจำกัดก็เป็นส่วนหนึ่งของการตัดสินใจ แอป Android [แก้ไขการ์ดไม่ได้](https://mnemosyne-proj.org/help/android-client) ผู้ใช้ iOS ต้องทบทวนผ่านเบราว์เซอร์ที่เชื่อมกับเซิร์ฟเวอร์ซึ่งรันอยู่บนอีกเครื่อง และหน้าฟีเจอร์ทางการของเซิร์ฟเวอร์นั้นเตือนว่าไม่มีฟีเจอร์ความปลอดภัย การรันระบบซิงค์เองยังหมายถึงการดูแลให้เข้าถึงเซิร์ฟเวอร์ได้ ตั้งค่าเครือข่าย และสำรองไดเรกทอรีข้อมูลด้วย

เรื่องสัญญาอนุญาตละเอียดกว่าการติดป้ายว่า “GPL” เฉย ๆ: [ไฟล์สัญญาอนุญาตของโครงการ](https://raw.githubusercontent.com/mnemosyne-proj/mnemosyne/master/LICENSE) ชี้ไปยังเงื่อนไขที่ต่างกันตามส่วนประกอบ [สัญญาอนุญาตของส่วนหลัก](https://raw.githubusercontent.com/mnemosyne-proj/mnemosyne/master/mnemosyne/LICENSE) ใช้ AGPL v3 พร้อมข้อกำหนดเพิ่มเรื่องชื่อและการระบุที่มา ส่วน [openSM2sync](https://raw.githubusercontent.com/mnemosyne-proj/mnemosyne/master/openSM2sync/LICENSE) ใช้ LGPL v3 หากคุณวางแผนแก้ไขหรือแจกจ่ายต่อ ให้อ่านไฟล์เหล่านี้

## Quizlet: ย้ายเพื่อชั้นเรียน ไม่ใช่เพื่อรักษาคอลเลกชันให้เหมือนเดิม

Quizlet เด่นในงานอีกประเภทหนึ่ง ชุดการเรียนสาธารณะ ชั้นเรียนของครู การแชร์ Match, Test, Learn และกิจกรรมกลุ่ม ส่งต่อให้ทั้งชั้นใช้ได้ง่ายกว่าโปรไฟล์ Anki ที่ปรับแต่งไว้เฉพาะตัว

การย้ายทำได้แค่ข้อความล้วน Quizlet เปลี่ยนแถวที่วางลงไปเป็นคำศัพท์และคำจำกัดความได้ แต่ไม่ได้อ่าน `.apkg` แล้วสร้างประเภทโน้ต เทมเพลต ตารางทบทวน หรือประวัติการทบทวนกลับมา ผู้สร้างสามารถ[ส่งออกชุดของตนเองเป็นข้อความที่คัดลอกได้](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets)โดยไม่มีรูปภาพ ส่วนชุดที่คัดลอกมาจากผู้ใช้อื่นส่งออกไม่ได้ นี่คือการย้ายเนื้อหา ไม่ใช่การย้ายทั้งคอลเลกชัน

ระบบจัดตารางของ Quizlet กำลังเปลี่ยนไป ฟีเจอร์ [Spaced Repetition](https://quizlet.com/features/spaced-repetition) ใหม่เปิดใช้อัตโนมัติบนเว็บสำหรับชุดที่มีอย่างน้อย 100 คำ และใช้คะแนน Repeat, Hard, Okay และ Easy โดย Quizlet ยังระบุว่าการรองรับบนมือถือจะมาเร็ว ๆ นี้ ส่วน Learn ยังคงเป็นแบบฝึกปรับตามผู้เรียนที่แยกต่างหาก และมีขีดจำกัดการใช้งานตามแพ็กเกจที่ชำระเงิน

ออฟไลน์ในที่นี้หมายถึงแอปมือถือ ไม่ใช่เว็บไซต์ Quizlet บันทึกแปดชุดล่าสุดให้อัตโนมัติและให้ดาวน์โหลดเพิ่มได้ โดย [Flashcards และ Match ใช้แบบออฟไลน์ได้](https://help.quizlet.com/hc/en-us/articles/360030565412-Studying-offline-with-Quizlet-mobile-apps) แล้วซิงค์ความคืบหน้าเมื่อเชื่อมต่ออีกครั้ง

ย้ายมาที่นี่เมื่อเป้าหมายคือการแจกจ่ายเนื้อหาและกิจกรรมในชั้นเรียน การสร้างตารางทบทวนส่วนตัวที่สะสมมานานขึ้นใหม่เพียงเพื่อให้ได้ฟีเจอร์เหล่านั้นมักไม่คุ้ม

## Brainscape: ตัดสินใจเรื่องตารางน้อยลง แต่ย้ายข้อมูลมาได้น้อยลงด้วย

Brainscape ให้คุณประเมินความมั่นใจตั้งแต่ 1 ถึง 5 แล้วใช้คะแนนนั้นนำการ์ดที่ยังไม่แม่นกลับมาเร็วขึ้น สูตรทั้งหมดไม่ได้เผยแพร่ แต่วิธีใช้นั้นสอนให้ผู้เรียนในชั้นเดียวกันทำตามได้ง่าย

แอปรับไฟล์ CSV, TXT, XLSX และ ODS ซึ่งสะดวกสำหรับการ์ดหน้าคำถาม–หลังคำตอบ แต่ก็หมายความว่าเทมเพลต ส่วนเสริม กฎการใช้สื่อ และข้อมูลการเรียนรู้ของ Anki ไม่ได้ตามมาด้วย การส่งออกข้อมูลสำรองส่วนตัวเป็นฟีเจอร์ Pro และได้ไฟล์ที่เปิดในโปรแกรมสเปรดชีตและนำกลับเข้าในภายหลังได้

ศูนย์ช่วยเหลือปัจจุบันของ Brainscape ระบุว่าเว็บไซต์และแอปมือถือมีฟีเจอร์หลักในการค้นหา สร้าง แชร์ และเรียนเหมือนกันแล้ว นอกจากนี้ยังอธิบายการใช้งานมือถือขณะออฟไลน์ การสั่งซิงค์ใหม่ด้วยตนเอง และการอัปเดตชั้นเรียนที่ดาวน์โหลดลงอุปกรณ์ไว้แล้ว จึงมีวิธีซิงค์งานเมื่อกลับมาออนไลน์ แต่ไม่ได้หมายความว่าจะมีเนื้อหาทั้งบัญชีเก็บอยู่ในเครื่องอย่างครบถ้วน

การส่งออกสำรับส่วนตัวยังคงเป็น[ฟีเจอร์ Pro](https://brainscape.zendesk.com/hc/en-us/articles/115002383872-How-can-I-export-a-backup-of-my-flashcards) ไม่มีการเผยแพร่ซอร์สโค้ดอย่างเป็นทางการหรือวิธีโฮสต์เอง

Brainscape น่าพิจารณาเมื่อ Anki มีสิ่งที่ต้องตั้งค่ามากเกินไปสำหรับคนที่จะเรียน แต่ไม่ใช่ทางออกที่ดีสำหรับคนที่ใช้ประโยชน์จากการตั้งค่าเหล่านั้นได้ดีอยู่แล้ว

## SuperMemo: เลือกวิธีของแอป และยอมเริ่มใหม่

บริการ SuperMemo.com ปัจจุบันเป็นแพลตฟอร์มเรียนภาษาบนเว็บ iOS และ Android ที่ใช้วิธีจัดตารางเฉพาะของ SuperMemo เป็นหลัก โดยแยกจากผลิตภัณฑ์ Windows รุ่นเก่าที่ผู้ใช้ SuperMemo มานานอาจคุ้นเคย

นี่คือการเลือกวิธีเรียนและคลังหลักสูตร ไม่ใช่การย้ายจาก Anki ได้ครบถ้วน SuperMemo รองรับ[การสร้างการ์ดจำนวนมากด้วยการวางข้อมูลคำถาม–คำตอบทีละแถว โดยใช้ตัวคั่นระหว่างช่องข้อมูล](https://www.supermemo.com/en/blog/how-to-create-flashcards-for-learning) จำกัดครั้งละ 100 ใบ ผมไม่พบตัวนำเข้า `.apkg` อย่างเป็นทางการหรือช่องทางให้ผู้ใช้ส่งออกข้อมูลจากบริการที่โฮสต์ให้ในปัจจุบัน ดังนั้นเทมเพลต ส่วนเสริม โครงสร้างสื่อ และประวัติการทบทวนจึงไม่ย้ายผ่านวิธีที่มีเอกสารระบุไว้นี้

หลักสูตรที่ดาวน์โหลดแล้วเรียนออฟไลน์ในแอปมือถือได้ แต่[คู่มือออฟไลน์](https://www.supermemo.com/en/faq/can-i-use-supermemo-offline) ระบุว่าใช้ฟีเจอร์ AI เพิ่ม MemoCards ค้นหา ใช้ฟีเจอร์บันทึกเสียง ดูสถิติ และใช้ตัวแก้ไขหลักสูตรไม่ได้ จึงควรเตรียมเนื้อหาและซิงค์ก่อนตัดการเชื่อมต่อ

เลือก SuperMemo เพราะคุณต้องการวิธีเฉพาะหรือคลังหลักสูตรของมันมากพอที่จะเริ่มตารางทบทวนใหม่ หากสิ่งสำคัญที่สุดคือการรักษาตารางเดิม แอปนี้แก้ปัญหาคนละเรื่อง

## Nibomo: เข้าถึงซอร์สโค้ดทั้งระบบ แต่ย้ายจาก Anki ได้น้อยที่สุด

Nibomo ให้คุณเข้าถึงซอร์สโค้ดและควบคุมได้หลายส่วนของระบบ [รีโพซิทอรีภายใต้สัญญาอนุญาต MIT](https://github.com/kirill-markin/flashcards-open-source-app) มีทั้งเว็บแอป ไคลเอ็นต์ iOS และ Android แบ็กเอนด์ ระบบซิงค์ออฟไลน์ โครงสร้างพื้นฐาน [API สาธารณะ](/docs/api/) และ[เซิร์ฟเวอร์ MCP](/docs/mcp-connector/) การทบทวนใช้ [FSRS](/docs/architecture/#scheduling) เว็บ iOS และ Android เขียนข้อมูลลงเครื่องก่อน เพิ่มรายการเปลี่ยนแปลงลงในคิวขาออก แล้วซิงค์เมื่อกลับมาเชื่อมต่อ

แต่นั่นไม่ได้ทำให้ใช้งานร่วมกับ Anki ได้ Nibomo อ่าน `.apkg` หรือ `.colpkg` ไม่ได้ วิธี[ย้ายจาก Anki ผ่าน TXT](/blog/migrate-from-anki-txt-export-open-source-flashcards/) ที่รองรับเป็นเวิร์กโฟลว์ให้ AI ช่วยร่างแล้วตรวจทาน เหมาะกับการ์ดที่ส่วนใหญ่เป็นข้อความ โดยไม่เก็บเทมเพลต ส่วนเสริม ลำดับชั้นสำรับ วันครบกำหนด ช่วงห่างการทบทวน หรือบันทึกการทบทวนแต่ละครั้งไว้ การอ้างอิงสื่อในไฟล์ TXT ไม่ใช่ตัวไฟล์สื่อ ดังนั้นสำรับที่ใช้สื่อมากต้องสร้างใหม่และตรวจสอบแยกต่างหาก

แพ็กเกจ `flashcards.zip` ของ Nibomo เองก็เก็บข้อมูลได้น้อยกว่าข้อมูลสำรองเต็มรูปแบบ โดยย้ายการ์ด แท็ก และสื่อที่เกี่ยวข้องระหว่างเวิร์กสเปซ Nibomo ได้ แต่ไม่ย้ายประวัติการทบทวน สถานะ FSRS โครงสร้างสำรับทั้งหมด การตั้งค่าเวิร์กสเปซ หรือบัญชี

บริการหลักที่โฮสต์ให้[ใช้ฟรีในช่วงเบต้า](/th/pricing/) การโฮสต์ระบบสำหรับใช้งานจริงด้วยตนเองไม่ใช่การติดตั้ง Docker ด้วยคำสั่งเดียว: [คู่มือโฮสต์เอง](/docs/self-hosting/) ใช้ AWS CDK และต้องมีบริการ AWS รวมถึง Cloudflare, Resend, Sentry ข้อมูลลับ การย้ายโครงสร้างข้อมูล การสำรอง การกู้คืน และการอัปเกรด ส่วน Docker Compose เป็นวิธีสำหรับพัฒนา ไม่ใช่วิธีติดตั้งใช้งานจริงที่รองรับ

ใช้ Nibomo เมื่อเหตุผลที่ย้ายคือการได้ซอร์สโค้ดครบและแบ็กเอนด์ที่ผู้ดูแลควบคุมเองได้ และการ์ดของคุณเรียบง่ายพอจะสร้างใหม่ได้อย่างปลอดภัย [เปิดแอปที่โฮสต์ให้](https://app.nibomo.com/)เพื่อลองกับสำรับชั่วคราวเล็ก ๆ ใช้ Anki ต่อ หรือลอง RemNote, Mochi หรือ Mnemosyne หากการรักษาสถานะการเรียนรู้ให้ใกล้เคียงเดิมสำคัญที่สุด

## แอปแทน Anki ตัวไหนใช้บน iOS ได้โดยไม่เจอปัญหาย้ายข้อมูลแบบไม่คาดคิด?

“แอปแทน Anki สำหรับ iOS” อาจหมายถึงสองเรื่อง: แอปเนทีฟบน iPhone หรือทางเลือกแทน[การซื้อ AnkiMobile ครั้งเดียวราคา $24.99](https://apps.apple.com/us/app/ankimobile-flashcards/id373493387)

RemNote, Mochi, Quizlet, Brainscape, SuperMemo และ Nibomo มีแอป iOS ทั้งหมด ส่วน Mnemosyne ไม่มี แต่ยังเหลือคำถามเรื่องการย้ายข้อมูล:

- **Mochi** เก็บข้อมูลได้มากกว่าตัวเลือก iOS ที่รับแต่ข้อความ โดยนำเข้าประวัติการทบทวนจาก `.apkg` ได้ แต่แปลงเป็น Markdown และใช้การให้คะแนนสองตัวเลือก
- **RemNote** นำเข้าประวัติการทบทวนจาก `.apkg` ได้เช่นกัน แต่ต้องทดสอบคิว **Need to Learn** แทนการสมมติว่าตาราง Anki ของวันนี้ยังอยู่ครบ
- **Quizlet** เหมาะกับการแจกจ่ายเนื้อหาในชั้นเรียน แต่ย้ายจาก Anki ได้แค่ข้อความ และระบบทบทวนเว้นระยะใหม่ยังไม่มาบนมือถือ
- **Nibomo** เป็นตัวเลือกที่เปิดซอร์สโค้ดและมีไคลเอ็นต์เนทีฟบน iOS แต่การย้ายจาก Anki จะรีเซ็ตสถานะการเรียนรู้
- **Brainscape** และ **SuperMemo** เหมาะก็ต่อเมื่อวิธีทบทวนของแอปคุ้มกับการสร้างการ์ดและตารางขึ้นใหม่

ก่อนเลิกใช้ AnkiMobile เพราะราคา ให้เทียบกับค่าสมาชิกและจำนวนชั่วโมงที่ต้องใช้แก้ปัญหาจากการย้าย การซื้อแอปครั้งเดียวอาจถูกกว่าแอปฟรีที่ทำให้คอลเลกชันซึ่งสะสมมานานกลายเป็นงานที่ต้องไล่แก้ด้วยมือ

## เมื่อไรใช้ Anki ต่อจึงปลอดภัยกว่า

การใช้แอปเดิมต่อเป็นการตัดสินใจอย่างหนึ่ง ไม่ได้แปลว่าคุณเลือกแอปใหม่ไม่ได้ ใช้ Anki ต่อเมื่อมีข้อใดข้อหนึ่งตรงกับคุณ:

- คอลเลกชันของคุณอาศัยเทมเพลตที่กำหนดเอง CSS, JavaScript หรือส่วนเสริม
- การ์ดปิดบังภาพ (Image Occlusion) เสียง หรือสื่ออื่นเป็นส่วนสำคัญที่สื่อความหมาย
- โน้ตหนึ่งรายการสร้างการ์ดที่สลับด้านคำถาม–คำตอบหลายแบบ และการ์ดเหล่านั้นต้องยังเชื่อมโยงกัน
- ประวัติการทบทวนหลายปีและวันครบกำหนดปัจจุบันมีค่ามากกว่าหน้าจอแก้ไขแบบใหม่
- คุณอาศัยเวิร์กโฟลว์เดสก์ท็อปหรือการใช้งานข้ามแพลตฟอร์มที่แอปทางเลือกรองรับได้ไม่เหมือนเดิม
- โหมดออฟไลน์ของแอปใหม่ใช้ได้เฉพาะบนช่องทางที่คุณไม่ได้ใช้
- คุณชอบแนวคิดการโฮสต์เอง แต่ไม่อยากดูแลการทำงาน ความปลอดภัย การสำรองข้อมูล และการอัปเกรดเซิร์ฟเวอร์
- แอปทางเลือกไม่ได้แก้ปัญหาที่เกิดซ้ำ นอกเหนือจากหน้าตาที่ดูสะอาดขึ้น

Anki ยังมีระบบนิเวศส่วนเสริมที่พัฒนามานาน เทมเพลตโน้ตและการ์ดที่ยืดหยุ่น การตั้งค่าตารางทบทวนทั้งแบบ FSRS และอัลกอริทึมเดิม แอปติดตั้งที่ทำงานในเครื่อง และรูปแบบแพ็กเกจที่ขนย้ายคอลเลกชันได้ ไม่มีผลิตภัณฑ์ข้างต้นตัวไหนทำทั้งหมดนี้ได้เหมือนกัน

หากต้องการเปรียบเทียบเฉพาะขอบเขตการควบคุมระบบ อ่าน[คู่มือแอปแฟลชการ์ดโอเพนซอร์ส](/blog/best-open-source-flashcard-apps-2026/) หากการใช้ออฟไลน์เป็นตัวตัดสิน [บทเปรียบเทียบแฟลชการ์ดออฟไลน์](/blog/best-offline-flashcards-app/) จะแยกให้เห็นความต่างระหว่างแอปที่ติดตั้ง เนื้อหาในแคช และแท็บเบราว์เซอร์

## เช็กลิสต์ย้ายข้อมูลที่ยังลงท้ายว่า “ไม่ย้าย” ได้

อย่าเริ่มจากทั้งคอลเลกชัน ออกแบบการทดสอบที่ยอมให้ผลออกมาว่าไม่ผ่านได้

1. **สร้างแพ็กเกจสำหรับกู้คืน** ส่งออก `.colpkg` พร้อมสื่อ เก็บไว้นอกโปรไฟล์ Anki และเก็บสำเนาที่สองไว้อีกแห่ง
2. **เลือกสำรับที่ยุ่งยาก** ให้มีการ์ดเติมคำ ช่องข้อมูลที่กำหนดเอง การ์ดปกติและกลับด้าน สำรับซ้อนกัน แท็ก รูปภาพ เสียง และประวัติการทบทวนมากพอให้เห็นผลจากการแปลงตาราง
3. **ส่งออกรูปแบบที่ปลายทางรองรับจริง** ใช้ `.apkg` พร้อมตารางทบทวน ชุดการตั้งค่า และสื่อสำหรับตัวนำเข้าโดยตรง ใช้ Notes in Plain Text เฉพาะเมื่อยอมรับการสร้างใหม่จากเนื้อหาอย่างเดียวได้
4. **บันทึกข้อมูลตั้งต้นไว้เปรียบเทียบ** จดจำนวนโน้ต จำนวนการ์ด ชื่อแท็กและสำรับ จำนวนไฟล์สื่อ ตัวอย่างวันครบกำหนดและช่วงห่างการทบทวน รวมถึงจำนวนการ์ดที่คาดว่าจะสร้างได้จากโน้ตแต่ละประเภท
5. **นำเข้าในพื้นที่ชั่วคราว** อย่าเขียนทับโปรไฟล์ต้นทางหรือรวมการทดสอบครั้งแรกเข้ากับคลังถาวรของแอปปลายทาง
6. **ตรวจเนื้อหาและสถานะการเรียนรู้แยกกัน** ด้านหน้าและด้านหลังที่ถูกต้องไม่ได้พิสูจน์ว่าการ์ดเติมคำ สื่อ การ์ดอื่นที่สร้างจากโน้ตเดียวกัน ประวัติการทบทวน หรือวันครบกำหนดครั้งถัดไปยังอยู่ครบ
7. **ลองเปิดแอปใหม่แบบออฟไลน์บนทุกอุปกรณ์ที่ใช้จริง** ทบทวน แก้ไข ปิดแอปให้สนิท เปิดใหม่โดยไม่มีการเชื่อมต่อ แล้วเชื่อมต่ออีกครั้งและตรวจบนอีกอุปกรณ์
8. **ดูคิวก่อนทำให้ตารางเริ่มต่างกัน** เปรียบเทียบการ์ดที่ถึงกำหนดชุดแรกและตัวอย่างช่วงห่าง ก่อนให้คะแนนการ์ดที่ใช้งานจริงใบเดียวกันในทั้งสองแอป หลังทบทวนครั้งแรกในแอปอื่น ตารางทั้งสองจะเป็นอิสระจากกัน
9. **ทดสอบทางย้ายออกก่อนตัดสินใจใช้จริง** ส่งออกจากปลายทางและตรวจว่าคุณจะกู้ข้อมูลอะไรกลับมาได้บ้างหากเลิกใช้ในปีหน้า
10. **เก็บ Anki และข้อมูลสำรองต้นฉบับที่ยังไม่ถูกแตะต้องไว้** อย่าลบทั้งสองอย่างจนกว่าแอปใหม่จะผ่านการใช้งานปกติ และคุณได้พิจารณายอมรับทุกอย่างที่สูญเสียไปแล้ว

หากปลายทางรับเฉพาะข้อความ ให้ทำตาม[ขั้นตอนส่งออก TXT อย่างปลอดภัยฉบับเต็ม](/blog/migrate-from-anki-txt-export-open-source-flashcards/) ซึ่งแยก `.colpkg` สำหรับกู้คืนออกจากไฟล์ทำงานที่ใช้ย้าย และระบุให้ชัดว่าข้อมูลการเรียนรู้จะถูกรีเซ็ต

## ตัดสินใจตามลำดับนี้

เริ่มจากสิ่งที่คุณยอมเสียไม่ได้:

1. หากเทมเพลตที่ตรงตามเดิม ส่วนเสริม หรือคิวปัจจุบันจำเป็น ให้ใช้ Anki ต่อ เว้นแต่การทดสอบ `.apkg` ที่เป็นตัวแทนการใช้งานจริงจะพิสูจน์ว่าย้ายได้
2. หากโน้ตกับการ์ดควรเป็นระบบเดียวกัน ให้ลอง RemNote ตรวจคิว **Need to Learn** ด้วย ไม่ใช่ดูเฉพาะหน้าที่นำเข้า
3. หาก Markdown ในเครื่องและไฟล์ส่งออกที่เปิดตรวจได้สำคัญกว่าการแสดงผลแบบ Anki ให้ลอง Mochi
4. หากต้องการแอปเดสก์ท็อปโอเพนซอร์สที่เน้นงานนี้และนำเข้า Anki โดยตรงได้ ให้ลอง Mnemosyne และยืนยันว่าข้อจำกัดบนมือถือเข้ากับกิจวัตรของคุณ
5. หากปัญหาจริงคือการแจกจ่ายเนื้อหาในชั้นเรียนหรือการทบทวนร่วมกันที่ควรเรียบง่ายขึ้น ให้สร้างชุดเล็ก ๆ ใหม่ใน Quizlet หรือ Brainscape
6. หากต้องการวิธีของ SuperMemo โดยเฉพาะ ให้ยอมรับการเริ่มตารางทบทวนใหม่ หากต้องการซอร์สโค้ดทั้งระบบ การโฮสต์เอง API และ MCP โดยเฉพาะ ให้ยอมรับการสร้างเนื้อหาใหม่ใน Nibomo ที่สูญเสียข้อมูลบางส่วน และงานดูแลระบบที่ตามมา

หากต้องการดูทีละฟีเจอร์ของสามรูปแบบที่ต่างกันมาก อ่าน [Anki vs Quizlet vs Nibomo](/blog/anki-vs-quizlet-vs-open-source-flashcards-app/)

หลักที่ใช้ได้จริงนั้นเรียบง่าย: ย้ายเมื่อสิ่งที่จะได้ชัดเจน และคุณได้ทดสอบจริงแล้วว่ายอมรับสิ่งที่เสียไปได้ หากสำรับตัวแทนของคุณย้ายข้ามไปได้ไม่ครบถ้วน การใช้ Anki ต่อไม่ใช่แค่แผนสำรองที่เลือกไว้เพื่อความปลอดภัย แต่เป็นผลลัพธ์ของการเปรียบเทียบ
