ณ วันที่ 18 สิงหาคม 2026 Quizlet ยังไม่มีเอกสาร API สาธารณะที่นักพัฒนาสมัครใช้งานเองได้ และไม่มีพอร์ทัลนักพัฒนาสาธารณะ นักพัฒนาอิสระจึงยังไม่มีช่องทางอย่างเป็นทางการในปัจจุบันสำหรับลงทะเบียนแอป รับ Quizlet API key และใช้เอนด์พอยต์ที่มีเอกสารกำกับเพื่ออ่านหรือเขียนข้อมูลบัตรคำ

ข้อค้นพบนี้มาจากเอกสารสาธารณะของ Quizlet ไม่ใช่ข้อสรุปเกี่ยวกับระบบภายในของบริษัท Quizlet มีการเชื่อมต่อกับผลิตภัณฑ์และพันธมิตรอยู่แล้ว แอปใน ChatGPT และส่วนเสริม Google Classroom เป็นสองตัวอย่างในปัจจุบัน แต่ทั้งสองอย่างไม่ได้เปิด API ของ Quizlet ให้นักพัฒนาแอปพลิเคชันอื่นนำไปใช้งานทั่วไปได้

**ตรวจสอบข้อเท็จจริง:** 18 สิงหาคม 2026

> **หมายเหตุจากผู้เขียน:** ผมคือ Kirill Markin และเป็นผู้พัฒนา Nibomo ซึ่งมี Agent API และเซิร์ฟเวอร์ MCP ที่กล่าวถึงเป็นทางเลือกด้านล่าง Nibomo ไม่ได้รองรับการทำงานร่วมกับ Quizlet และไม่ได้นำเข้าชุดบัตรคำ Quizlet โดยอัตโนมัติ

## คำตอบสั้น ๆ: ไม่มีเอกสาร Quizlet API ที่นักพัฒนาสมัครใช้งานเองได้

หากคุณค้นหาว่า “Quizlet มี API หรือไม่?” เพราะต้องการทำงานอัตโนมัติกับ Quizlet โดยตรง คำตอบที่ใช้ตัดสินใจได้ในปัจจุบันคือ **ยังไม่มีเอกสาร API สาธารณะที่สมัครใช้งานเองได้**

ฟีเจอร์อย่างเป็นทางการหลายอย่างอาจดูคล้าย API เมื่อมองจากภายนอก แต่แต่ละอย่างรองรับงานที่จำกัดกว่า:

| สิ่งที่ต้องการ | ช่องทางที่รองรับ | เหมาะสำหรับ | สิ่งที่ไม่รองรับ |
|---|---|---|---|
| ย้ายข้อความจากชุดที่คุณสร้างเอง | [การส่งออกผ่านเว็บไซต์ Quizlet](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets) | คัดลอกคำศัพท์และคำจำกัดความครั้งเดียว | รูปภาพ การส่งออกชุดที่คัดลอกมา ประวัติการเรียน หรือสิทธิ์ใช้ API |
| แสดงชุดสาธารณะบนเว็บไซต์หรือหน้า LMS | [การฝังชุดบัตรคำของ Quizlet](https://help.quizlet.com/hc/en-us/articles/360032935851-Embedding-sets) | กิจกรรมการเรียนที่มีแบรนด์ Quizlet อยู่ภายในหน้าของคุณ | ข้อมูลบัตรแบบมีโครงสร้าง หรือสิทธิ์อ่านและเขียนข้อมูล |
| เปลี่ยนบทสนทนาใน ChatGPT เป็นชุด Quizlet | [แอป Quizlet ใน ChatGPT](https://quizlet.com/blog/quizlet-comes-to-chat-gpt) | สร้างและดูตัวอย่างชุดผ่าน `@Quizlet` | ข้อมูลยืนยันสิทธิ์หรือเอนด์พอยต์สำหรับแอปของคุณเอง |
| มอบหมายงาน Quizlet ใน Google Classroom | [ส่วนเสริม Quizlet สำหรับ Google Classroom](https://quizlet.com/blog/quizlet-google-classroom-add-on) | ค้นหา มอบหมาย และติดตามกิจกรรมใน Classroom | API ทั่วไปสำหรับซอฟต์แวร์การศึกษาที่พัฒนาเอง |
| สร้างการเชื่อมต่อกับ Quizlet ของคุณเอง | ปัจจุบันยังไม่มีเอกสารช่องทางที่สมัครใช้งานเองได้ | อาจมีข้อตกลงเฉพาะกับพันธมิตร | การเปิดรับสมัครทั่วไป API key หรือเอกสารข้อกำหนดการเข้าถึงข้อมูลบัตรคำ |
| ทำงานอัตโนมัติในเวิร์กสเปซบัตรคำของคุณเอง | [Nibomo Agent API](/th/docs/api/) หรือ [ตัวเชื่อมต่อ MCP](/th/docs/mcp-connector/) | อ่านและเขียนบัตรคำและชุดบัตรคำซ้ำ ๆ ภายในเวิร์กสเปซที่เลือก | การรองรับ Quizlet หรือการนำเข้า Quizlet อัตโนมัติ |

แยกประเภทงานให้ชัดก็พอ: การคัดลอกข้อความบัตรของคุณเองครั้งเดียวเป็นงานส่งออก การแสดง Quizlet บนหน้าอื่นเป็นงานฝังเนื้อหา การเชื่อมต่อเฉพาะผลิตภัณฑ์ใช้ได้เฉพาะในขั้นตอนการใช้งานของผลิตภัณฑ์นั้น ส่วนซอฟต์แวร์ที่ต้องสร้าง อ่าน และแก้ไขบัตรซ้ำ ๆ จำเป็นต้องมี API สำหรับอ่านและเขียนที่มีเอกสารกำกับ

## การส่งออก การฝังเนื้อหา และสิทธิ์ของพันธมิตรไม่ใช่ API สาธารณะ

API สาธารณะมีข้อกำหนดที่ชัดเจนสำหรับนักพัฒนาภายนอก ได้แก่ เอกสาร วิธียืนยันตัวตน การทำงานที่รองรับ กฎการใช้งาน และวิธีรับข้อมูลยืนยันสิทธิ์ ช่องทางสาธารณะของ Quizlet ในปัจจุบันยังไม่มีช่องทางใดที่ให้นักพัฒนาดำเนินการทั้งหมดนี้ได้ด้วยตนเอง

**การส่งออก**ของ Quizlet เป็นการย้ายข้อมูลด้วยตนเอง ผู้สร้างชุดสามารถใช้เว็บไซต์จัดรูปแบบคำศัพท์และคำจำกัดความ เลือกคัดลอกข้อความ (**Copy text**) แล้วนำผลลัพธ์ไปวางที่อื่น Quizlet ระบุว่าไม่สามารถส่งออกรูปภาพหรือชุดที่คัดลอกมาได้ และฟีเจอร์นี้ใช้ได้บนเว็บไซต์เท่านั้น วิธีนี้เหมาะกับการย้ายข้อมูลครั้งเดียวอย่างระมัดระวัง แต่ไม่เปิดทางให้ซอฟต์แวร์ซิงก์ข้อมูลระหว่างสองระบบอย่างต่อเนื่อง

**การฝังเนื้อหา**เป็นการแสดงผล ไม่ใช่สิทธิ์เข้าถึงข้อมูล Quizlet ให้คุณคัดลอก HTML ของชุดสาธารณะในโหมด Match, Learn, Test, Flashcards หรือ Spell กิจกรรมที่ฝังยังคงมีโลโก้ Quizlet และผู้เรียนโต้ตอบผ่านอินเทอร์เฟซของ Quizlet แอปพลิเคชันของคุณไม่ได้รับข้อมูลชุดนั้นเป็นรายการบัตรที่สามารถแก้ไขได้

**การเชื่อมต่อเฉพาะผลิตภัณฑ์**มีขั้นตอนการใช้งานที่ตกลงกันไว้ Quizlet สามารถทำงานร่วมกับ ChatGPT หรือ Google Classroom ได้โดยไม่ต้องเปิดอินเทอร์เฟซเดียวกันให้นักพัฒนาทุกคน การเปิดตัวเหล่านี้ยืนยันว่าการเชื่อมต่อดังกล่าวมีอยู่จริง แต่ไม่ได้ยืนยันว่ามี Quizlet API สาธารณะอยู่เบื้องหลังให้ใช้งานทั่วไป

ด้วยเหตุนี้ ไลบรารี wrapper เก่าหรือคำขอที่มองเห็นในเครื่องมือนักพัฒนาของเบราว์เซอร์จึงไม่ใช่ Quizlet API ที่รองรับอย่างเป็นทางการ สิ่งที่ยังขาดคือเอกสารสาธารณะและข้อกำหนดที่นักพัฒนาใช้เป็นหลักในการพัฒนาซอฟต์แวร์ได้อย่างต่อเนื่อง

## เลือกช่องทางให้ตรงกับงาน

### ใช้การส่งออกสำหรับสำรองข้อมูลหรือย้ายข้อมูลครั้งเดียว

ใช้ขั้นตอนส่งออกอย่างเป็นทางการของ Quizlet กับชุดที่คุณสร้างเอง เมื่อเลือกคัดลอกข้อความ (**Copy text**) แล้ว ให้เก็บสำเนาแรกที่วางออกมาไว้โดยไม่แก้ไข ก่อนปรับตัวคั่นหรือจับคู่ฟิลด์ วิธีนี้เก็บได้เฉพาะคำศัพท์และคำจำกัดความ ไม่ได้ดาวน์โหลดแพ็กเกจชุดบัตรที่นำกลับมากู้คืนได้ รูปภาพและประวัติการเรียนจะไม่ได้ย้ายมาด้วย

ดูรายการตรวจสอบขั้นตอนได้ใน [วิธีส่งออกชุดบัตรคำ Quizlet ในปี 2026](/th/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/) ซึ่งครอบคลุมสำเนาต้นฉบับและสำเนาที่ใช้แก้ไข UTF-8 แท็บ คำจำกัดความหลายบรรทัด และความแตกต่างระหว่างการย้ายเนื้อหาบัตรกับการย้ายสถานะการจัดตารางทบทวน

การส่งออกเหมาะกับการย้ายข้อมูลให้เสร็จในครั้งเดียว แต่ไม่เหมาะกับการสร้างข้อมูลทุกวัน การซิงก์ หรือการแก้ไขซ้ำ ๆ ผ่านซอฟต์แวร์

### ใช้การฝังเนื้อหาอย่างเป็นทางการเพื่อแสดงกิจกรรม

หากต้องการให้ผู้เรียนศึกษาชุด Quizlet สาธารณะจากเว็บไซต์ของชั้นเรียนหรือหน้า LMS ให้ใช้โค้ดฝังเนื้อหาที่ Quizlet ให้ไว้บนเว็บไซต์ เลือกกิจกรรม เลือกคัดลอก HTML (**Copy HTML**) แล้วเพิ่มผลลัพธ์ลงในหน้า ผู้เรียนจะได้กิจกรรม Quizlet ที่โต้ตอบได้ แต่เว็บไซต์ที่ฝังไม่ได้รับข้อมูลบัตรคำดิบ

บ่อยครั้งครูก็ต้องการเพียงเท่านี้ การเรียกสิ่งนี้ว่า API จะทำให้ความต้องการดูซับซ้อนเกินจริง

### ใช้การเชื่อมต่อที่รองรับสำหรับ ChatGPT หรือ Google Classroom

ประกาศเรื่อง ChatGPT ของ Quizlet เมื่อวันที่ 10 มีนาคม 2026 อธิบายขั้นตอนเฉพาะไว้ดังนี้: เชื่อมต่อแอป Quizlet เริ่มพรอมป์ต์ด้วย `@Quizlet` ดูตัวอย่างชุดที่สร้างขึ้นใน ChatGPT แล้วเปิดใน Quizlet เพื่อปรับให้เหมาะกับตัวเองและเริ่มเรียน นี่เป็นช่องทางที่รองรับสำหรับสร้างชุด Quizlet จากบทสนทนานั้น แต่ไม่ได้ให้ข้อมูลยืนยันสิทธิ์สำหรับ Quizlet API ที่คุณนำไปใช้กับบอต สคริปต์ หรือเว็บไซต์ของตัวเองได้

ประกาศเรื่อง Google Classroom ของ Quizlet เมื่อวันที่ 30 มิถุนายน 2026 ก็ระบุขั้นตอนไว้เฉพาะเช่นกัน ส่วนเสริมช่วยให้นักการศึกษาค้นหาและมอบหมายกิจกรรม ทั้งโจทย์ฝึก บัตรคำ และเกม แล้วติดตามการมีส่วนร่วมและความคืบหน้าในขั้นตอนการทำงานของ Classroom Quizlet ระบุว่าต้องใช้ Google Workspace for Education Plus และนักการศึกษาอาจต้องให้ผู้ดูแลระบบ IT อนุญาตการใช้งานหรือจัดเตรียมส่วนเสริมให้

หากขั้นตอนใดตรงกับเป้าหมายของคุณอยู่แล้ว ก็ใช้ช่องทางนั้น แต่หากต้องพัฒนาแอปพลิเคชันเอง การเชื่อมต่อทั้งสองนี้ไม่สามารถทดแทนช่องทางสาธารณะสำหรับนักพัฒนาได้

### เลือกอินเทอร์เฟซสำหรับอ่านและเขียนที่มีเอกสารกำกับ เมื่อต้องทำงานอัตโนมัติเป็นประจำ

การทำงานอัตโนมัติอย่างต่อเนื่องหมายความว่าซอฟต์แวร์ของคุณต้องทำงานเดิมซ้ำได้อย่างเชื่อถือได้ เช่น สร้างบัตรจากโน้ต แสดงรายการชุดบัตร อัปเดตคำตอบ หรือจัดการเวิร์กสเปซในระยะยาว การส่งออกผ่านคลิปบอร์ดไม่มีข้อกำหนดการทำงานที่รองรับการใช้งานแบบนี้

ช่องทางที่ปลอดภัยคือระบบบัตรคำที่เผยแพร่อย่างชัดเจนว่าซอฟต์แวร์ภายนอกยืนยันตัวตนอย่างไร และรองรับการอ่านและเขียนแบบใดบ้าง คุณอาจต้องเลือกทางเลือกแทน Quizlet API สำหรับงานอัตโนมัติ ขณะที่ยังใช้ Quizlet เรียนด้วยฟีเจอร์ที่เปิดให้ใช้งานทั่วไป

## ทางเลือก API ของ Nibomo ให้อะไรบ้าง

Nibomo เปิดให้เข้าถึงข้อมูลชุดเดียวกันได้สองช่องทาง โดยจำกัดขอบเขตข้อมูลและแยกข้อมูลตามผู้ใช้:

- [Agent API สำหรับซอฟต์แวร์ภายนอก](/th/docs/api/) เริ่มที่ `GET https://api.nibomo.com/v1/` ข้อมูลตอบกลับจะบอกวิธีใช้งานให้เอเจนต์ ตั้งแต่เข้าสู่ระบบด้วย OTP ทางอีเมล สร้าง API key ไปจนถึงเลือกเวิร์กสเปซ การอ่านใช้เส้นทาง query ในรูปแบบ SQL ส่วนการเขียนใช้เส้นทาง execute แยกต่างหาก
- [เซิร์ฟเวอร์ MCP ระยะไกล](/th/docs/mcp-connector/) อยู่ที่ `https://mcp.nibomo.com/mcp` ไคลเอนต์ MCP มีเครื่องมือแปดรายการ ได้แก่ `list_workspaces`, `sql_query`, `sql_execute`, `get_guide` และเครื่องมือทบทวน `next_review_card`, `reveal_answer`, `submit_review`

`get_usage_limits` — ใช้อ่านแพ็กเกจบัญชี ขีดจำกัด และปริมาณการใช้ AI ในเดือนปัจจุบันเท่านั้น ไม่อ่านหรือเปลี่ยนแปลงบัตรคำ

ทั้งสองช่องทางจำกัดการทำงานอยู่ภายในเวิร์กสเปซที่เลือก ทรัพยากรที่เผยแพร่คือ `workspace`, `cards`, `decks` และ `review_events` โดยผลลัพธ์จำกัดที่ 100 แถวต่อคำสั่ง อินเทอร์เฟซรูปแบบ SQL รองรับภาษาย่อยที่จำกัด ไม่ใช่ PostgreSQL โดยตรง ไม่มีสคีมา OpenAPI ดังนั้นขั้นตอนที่ต้องพึ่งไคลเอนต์ซึ่งสร้างจาก OpenAPI จะต้องใช้อินเทอร์เฟซอื่น

ช่องทางนี้ช่วยให้นักพัฒนาหรือเอเจนต์ AI ทำงานอัตโนมัติกับบัตรคำที่ตนเป็นเจ้าของได้ แต่ไม่สามารถอ่าน URL ของ Quizlet ทำสำเนาข้อมูลทั้งบัญชี Quizlet ให้ตรงกัน หรือทำหน้าที่เป็นไคลเอนต์ Quizlet ผ่านช่องทางที่ไม่มีเอกสารรองรับได้ ไม่มีเครื่องมือนำเข้า Quizlet อัตโนมัติ หากต้องการย้ายข้อมูล ให้ส่งออกคำศัพท์และคำจำกัดความจากชุดของคุณเองก่อน ตรวจสอบข้อความ แล้วจับคู่กับฟิลด์บัตรของระบบปลายทาง ระบบปลายทางจะสร้างสถานะการเรียนของตัวเอง ประวัติจาก Quizlet จะไม่ย้ายตามมา

หากต้องการเปรียบเทียบผลิตภัณฑ์ในด้านอื่นนอกเหนือจากการเข้าถึง API ดู [บทเปรียบเทียบทางเลือกโอเพนซอร์สแทน Quizlet](/blog/quizlet-alternative/)

## คำขอภายในเบราว์เซอร์ไม่ใช่ทางลัดที่ปลอดภัย

อินเทอร์เฟซเว็บของ Quizlet ส่งคำขอผ่านเครือข่าย เช่นเดียวกับเว็บแอปพลิเคชันสมัยใหม่ทั่วไป การพบคำขอเหล่านั้นไม่ได้ทำให้มันกลายเป็นเอนด์พอยต์ที่รองรับสำหรับโปรแกรมของคุณ

เอนด์พอยต์ภายในที่เบราว์เซอร์ใช้อาจขึ้นอยู่กับคุกกี้เซสชัน รูปแบบข้อมูลภายใน มาตรการป้องกันการใช้งานที่ไม่เหมาะสม และเงื่อนไขที่ผูกกับอินเทอร์เฟซปัจจุบัน สิ่งเหล่านี้เปลี่ยนได้โดยไม่มีการกำหนดเวอร์ชันสาธารณะหรือคำแนะนำสำหรับย้ายไปใช้เวอร์ชันใหม่ ข้อจำกัดที่ชัดเจนกว่านั้นอยู่ใน [ข้อกำหนดการให้บริการของ Quizlet](https://quizlet.com/tos) ซึ่งอัปเดตล่าสุดเมื่อวันที่ 28 พฤษภาคม 2026 โดยห้าม scraping และการดึงข้อมูลอัตโนมัติรูปแบบอื่น รวมถึงการใช้งานบริการแบบอัตโนมัติโดยไม่ได้รับอนุญาต

นี่เป็นพื้นฐานที่เปราะบางและมีความเสี่ยงแม้สำหรับสคริปต์ส่วนตัว ยิ่งไม่เหมาะกับการสร้างผลิตภัณฑ์ ผมจึงไม่ให้เอนด์พอยต์ที่คาดเดาขึ้นหรือขั้นตอนวิศวกรรมย้อนกลับในบทความนี้

สำหรับชุดของคุณเอง ให้ส่งออกเมื่อต้องการย้ายข้อมูลครั้งเดียว ฝังชุดสาธารณะเมื่อผู้เรียนต้องใช้บนหน้าอื่น ใช้การเชื่อมต่อกับ ChatGPT หรือ Google Classroom สำหรับขั้นตอนการใช้งานที่รองรับโดยเฉพาะ หากต้องอ่านและเขียนซ้ำ ๆ ให้เลือกซอฟต์แวร์ที่มีเอกสารข้อกำหนดการทำงานอัตโนมัติ หรือทำส่วนที่เกี่ยวกับ Quizlet ด้วยตนเองไปก่อนจนกว่า Quizlet จะเผยแพร่ช่องทางดังกล่าว

## จะรู้ได้อย่างไรว่าสถานะเปลี่ยนไปแล้ว

Quizlet อาจเปิดโครงการสำหรับนักพัฒนาหลังวันที่ตรวจสอบข้อเท็จจริงของบทความนี้ สิ่งที่ควรมองหาคือพอร์ทัลนักพัฒนาอย่างเป็นทางการ หรือเอกสารที่อธิบายว่าใครลงทะเบียนได้ วิธียืนยันตัวตนเป็นอย่างไร รองรับการทำงานใดกับบัตรคำ และมีกฎการใช้งานอะไรบ้าง

ไลบรารี wrapper จากบุคคลที่สามตัวใหม่ไม่ทำให้คำตอบเปลี่ยนไป การประกาศความร่วมมือกับพันธมิตรรายใหม่ก็เช่นกัน จนกว่า Quizlet จะมีเอกสารช่องทางที่นักพัฒนาสมัครใช้งานเองได้ ให้พิจารณาคำกล่าวอ้างเรื่อง Quizlet API ในปัจจุบันอย่างรอบคอบ และเลือกช่องทางที่รองรับให้ตรงกับงานที่ต้องทำจริง
