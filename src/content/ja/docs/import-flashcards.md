---
title: Nibomoにフラッシュカードをインポートする
description: QuizletやAnkiなどのアプリからカードを移す方法を紹介します。対応するエクスポート形式と、大量にインポートする前の確認手順がわかります。
---

[Nibomo](https://app.nibomo.com)を開き、カードの移動先のワークスペースに切り替えてから、**ライブラリ > インポート**を開きます。**ほかのアプリから**で、使っていたアプリを選びます。ファイル形式が同じでも、アプリごとに項目が分かれています。

以下の方法はWebアプリで利用できます。iPhone、iPad、Mac、Androidでメニューや目的の項目が見つからない場合は、Webアプリを使ってください。端末でゲストとして使っている場合は、先に端末でログインします。Webアプリでも同じNibomoアカウントでログインし、カードの移動先のワークスペースを選んでからインポートします。

## 移動元と対応形式

| 移動元 | 用意するもの | インポート方法 |
| --- | --- | --- |
| Quizlet | コピーしたエクスポートテキスト | Quizletのインポート画面に貼り付ける |
| Anki | `.apkg`のデッキまたは`.colpkg`のコレクション | **ファイルを選択** |
| Noji | `.csv`または`.ofc` | **ファイルを選択** |
| Knowt | `.pdf` | **ファイルを選択** |
| RemNote | `.apkg`、`.md`、`.txt`のいずれか | **ファイルを選択** |
| Brainscape | `.csv` | **ファイルを選択** |
| StudySmarter | `.csv` | **ファイルを選択** |
| Cram | `.csv` | **ファイルを選択** |
| Mochi | `.mochi` | **ファイルを選択** |
| SuperMemo | `.xml` | **ファイルを選択** |
| AlgoApp（旧AnkiApp） | `.zip`または`.xml` | **ファイルを選択** |
| その他のアプリ | `.csv`、`.txt`、`.xlsx`、`.pdf`、`.json`、`.xml`、`.md`、`.docx`、`.zip`のいずれか | **ほかのアプリからインポート**でファイルを選ぶ |
| スプレッドシート | カードの表面と裏面を並べた行をコピー | **スプレッドシートからインポート**で貼り付ける |
| Nibomo | Nibomoからエクスポートした`flashcards.zip` | **Nibomoからインポート**でプレビューを確認 |

メニューで旧名称が使われている場合、AlgoAppの項目は**AnkiApp**と表示されます。Ankiは別の項目です。

古いExcelファイル（`.xls`）は、`.xlsx`か`.csv`として保存し直してください。表面と裏面の列をコピーして[スプレッドシート用のインポート画面に貼り付ける](#スプレッドシートから貼り付ける)方法もあります。

## ほかのフラッシュカードアプリからインポートする

1. 元のアプリで移したいカードをエクスポートします。Quizletでは学習セットを開き、**Export**（エクスポート）を選んでテキストをコピーします。用語と定義はタブで、カード同士は改行で区切ると扱いやすくなります。
2. Nibomoの**ライブラリ > インポート**で、元のアプリの項目を開きます。Quizletの場合はコピーしたテキストを貼り付け、それ以外の場合はエクスポートしたファイルを選びます。元のアプリの項目がなくても、PDFなどの対応形式でエクスポートできる場合は、**ほかのアプリからインポート**を使えます。
3. **インポートを開始**を選びます。新しいAIチャットが開き、ファイルや貼り付けたテキストと一緒にインポートの依頼が送信されます。インターネット接続が必要です。AIインポートのファイルは1件につき最大**30 MiB**です。上限を超える場合は、小さなデッキや学習セットに分けてエクスポートしてください。
4. **ライブラリ**で結果を確認します。AIチャットは処理の途中でもカードをまとめて保存することがあります。途中で止まったら、保存済みのカードを確認し、エクスポート全体をやり直す前に、残りから続けるようAIに頼みます。

### まず少量で試す

元のエクスポートは保管し、まずは小さなデッキや学習セットを1つ試します。枚数を比べ、何枚かの表面と裏面、タグ、必要な画像や書式を確認します。保存前に見本を確認したいときは、**インポートを開始**を使わず、新しいAIチャットにファイルを添付し、少数のカードを保存せずにプレビューするよう頼んでください。

AIでインポートしたカードは、Nibomoで新規カードとして扱われます。これまでの復習履歴や次の復習予定日は引き継がれません。元のデッキ構成や書式、メディアの再現度は、エクスポート内容とAIチャットが読み取れる情報に左右されます。移行先で学習を始めたり、元のアプリからデータを削除したりする前に、結果を確認してください。

## スプレッドシートから貼り付ける

表面と裏面の組み合わせだけなら、**ライブラリ > インポート > スプレッドシートからインポート**を使います。見出し行を除いて2列をコピーし、インポート画面に貼り付けます。通常は表面と裏面の区切りに**タブ**、カードの区切りに**改行**を選びます。テキストが別の区切り文字を使っている場合は設定を変えてください。

プレビューでカードを確認し、不完全な行を直して、必要なタグを選びます。その後、インポートボタンを押して保存します。この方法ではAIチャットは使いません。

## NibomoのZIPをインポートする

Nibomoからエクスポートした`flashcards.zip`には、**ライブラリ > インポート > Nibomoからインポート**を使います。ZIPを解凍せずに選び、プレビューでカードと参照メディアを確認してからインポートを確定します。パッケージに含まれるカード、タグ、メディアを移せます。この方法ではAIチャットは使いません。
