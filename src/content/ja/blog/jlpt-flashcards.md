2025年に実施された2回のJLPTには、92の国・地域から1,940,852人が受験を申し込みました。2024年より12.9%多い数字です（[公式の過去の試験データ](https://www.jlpt.jp/e/statistics/archive.html)）。その一方で、主催者は語彙・漢字・文法の固定リストを含む「出題基準」を現在は公開していません。

役に立つ **JLPTフラッシュカード** は、公式の問題形式で求められる判断から作ります。単語の中で漢字を読む、文脈から言い換えを選ぶ、語句を文法的に正しい順番に並べる、読解や聴解の練習で見落とした手がかりをそのまま残す、といった判断です。文章全体、時間を計るセクション練習、スクリプトを見ずに音声から始める聴解練習はデッキの外に置き、問題本来の形で練習できるようにします。

## 公式の問題形式を軸にデッキを作る

JLPTの主催者は、すべてのレベルについて[試験科目と問題の構成](https://www.jlpt.jp/e/guideline/testsections.html)を公開しています。また、[各問題形式の例題を1問ずつ](https://www.jlpt.jp/e/samples/forlearners.html)確認できるほか、より多くの問題を収録した[日本語能力試験公式問題集](https://www.jlpt.jp/e/samples/sampleindex.html)も2冊あります。

「JLPTの全単語」と銘打ったダウンロード教材より、こうした公式ページのほうがデッキの設計図として信頼できます。

公式FAQでは、2010年の改定後に「出題基準」が公開されなくなった理由を説明しています。JLPTが測るのは、言語知識と、その知識をコミュニケーション上の課題に使う力です。そのため、語彙・漢字・文法項目を一覧にした出題基準を公開するのは適切ではないと主催者は判断しました（[JLPT FAQ](https://www.jlpt.jp/e/faq/#anchor28)）。

だからといって、市販の教材やリストが役に立たないわけではありません。実用的な学習カリキュラムにはなります。ただし、位置づけは正確にしましょう。出版社が作ったN3語彙リストは、その出版社による解釈であり、JLPTの完全な公式リストではありません。

問題形式を並べると、信頼できる全体像が見えてきます。

| 公式の問題形式グループ | 出題されるレベル |
| --- | --- |
| 漢字読み、文脈規定、言い換え類義 | N1–N5 |
| 表記 | N2–N5 |
| 用法 | N1–N4 |
| 語形成 | N2のみ |
| 文の文法1（文法形式の判断）、文の文法2（文の組み立て）、文章の文法 | N1–N5 |
| 内容理解（短文・中文）、情報検索 | N1–N5 |
| 内容理解（長文） | N1とN3 |
| 統合理解、主張理解（長文） | N1とN2 |
| 課題理解・ポイント理解・即時応答の聴解 | N1–N5 |
| 概要理解 | N1–N3 |
| 発話表現 | N3–N5 |
| 統合理解 | N1とN2 |

この表から、受験レベルが変わればデッキの一部も変える必要があると分かります。N5には用法問題がありません。語形成が出るのはN2だけです。N1とN2では、複数の文章や音声情報を比較・統合する問題も出ます。一般的な日本語デッキでも日本語力は伸ばせますが、自分のJLPTレベルで問われる判断を自動的にすべてカバーできるわけではありません。

文字をまだ学び始めた段階なら、[基本ひらがな46文字とローマ字のフラッシュカードデッキ](/catalog/packages/basic-hiragana-romaji/)で、現代の基本ひらがな46文字を「かな→学習者向けヘボン式ローマ字」と「ローマ字→かな」の両方向、合計92枚で練習できます。これは文字の基礎練習用であり、JLPTの公式リストでも、レベル別の語彙・文法・読解・聴解練習の代わりでもありません。

## 漢字・語彙カードでは一度に1つだけ問う

最初は `提出 = 提出すること` というカードでも役立つかもしれません。しかし、公式の問題構成で求められるのは訳語だけではありません。レベルによっては、漢字を読む、表記を選ぶ、文脈から意味を理解する、近い言い換えを見つける、用法を判断する、語形成を見抜く、といった力も語彙問題に含まれます。

カード1枚につき、役割を1つに絞りましょう。

### 実際の単語の中で漢字を読む

短いオリジナル文を使い、単語と文脈を含めて読みを覚えます。

**表**

```text
申込書を提出してください。

「提出」の読み方は？
```

**裏**

```text
ていしゅつ
提出する、差し出す
```

裏面を辞書の1ページのようにしないでください。よく使われる読みや意味が複数ある場合は、この文で使われているものだけを問い、別の用法も必要になったときにもう1枚作ります。

N2からN5では、表記を逆向きのカードとして分けて作る価値があります。文中で読みを見せ、対応する漢字を思い出します。N5では、ひらがなで示された語のカタカナ表記を選ぶ問題も出ます。選択肢から見分ける力と、答えを自分で思い出す力は別々に崩れることがあります。

### 文脈上の意味や言い換えを問う

どのレベルにも、文脈規定と言い換え類義の問題があります。判断に必要な文脈を十分に残したプロンプトが役立ちます。

**表**

```text
会議は来週に延期になった。

「延期」に近い意味は？
```

**裏**

```text
予定していた日を後に変えること
延期。予定日を後ろにずらすこと
```

2行目の短い説明は答えを補うものであって、答えそのものではありません。レベルが上がるにつれ、日本語の説明や、より近い日本語の類義表現を増やしましょう。

### 文を判断させて用法を確かめる

N1からN4では、見れば分かる単語と、自然に使える単語を区別するカードも加えます。

**表**

```text
「支障」の使い方として自然なのはどちら？

A. 電車が少し遅れたが、仕事に支障はなかった。
B. 電車が少し遅れたが、仕事を支障しなかった。
```

**裏**

```text
A

「支障がある／ない」または「支障を来す」の形で使う。
```

この例文はオリジナルです。カードとして保存する前に、信頼できる辞書、教師、資料で意味と自然さを確かめてください。AIは候補を出せますが、自然に見える日本語だからといって正しいとは限りません。

答えが本当に視覚的なものなら、画像などのメディアも役立ちます。標識や物、似た形の違いなどです。すべての単語に飾りの画像を付ける必要はありません。答えを隠したときに、きちんと思い出す必要があるカードにします。

## 文法カードでは選ぶか並べる

どのJLPTレベルにも、文法形式の判断、文の組み立て、文章の流れに合う文法の判断という3種類の問題があります。文法項目の名前だけを積み上げるより、この3つに対応するカードを作るほうが実践的です。

文法形式を選ぶカードでは、判断に必要な部分を隠します。

**表**

```text
この資料は初心者___分かりやすい。

選択肢：に / にも / には
「初心者にとっても」という意味になるものを選ぶ。
```

**裏**

```text
にも

この資料は初心者にも分かりやすい。

にもはここで「初心者にとっても」を表す。
```

迷いやすい別の選択肢と区別するのに役立つ場合だけ、短い説明を加えます。妥当な答えが複数あるカードには、文脈を足すか、問い方を明確にする必要があります。

文の組み立てでは、表面に文節を置きます。

**表**

```text
並べ替える：
駅 / まで / 歩いて / どのくらい / かかりますか
```

**裏**

```text
駅まで歩いてどのくらいかかりますか。
```

答えを見る前に、文全体を声に出すか書いてください。黙って正解を見分けるだけでは、並べ替えカードが実際より簡単に感じられます。すべての文節を使い、自然な語順が複数できるならプロンプトを直しましょう。

文章の文法には、つながりのある文が少なくとも2つ必要です。

**表**

```text
電車が止まっていた。___、約束の時間に間に合わなかった。

選択肢：しかし / そのため / たとえば
原因を受けて結果を表すものを選ぶ。
```

**裏**

```text
そのため

そのためは原因を受けて結果を示す。
```

後日、同じ接続表現を新しい段落でも問いましょう。カードには文同士の関係を残し、新しい文脈でも判断できるかを確かめます。

## 読解のミスだけを残し、文章全体はそのまま使う

読解問題が測るのは、つながりのある文章を理解する力です。測る内容はレベルによって変わります。N5では易しい短文・中文と情報検索が中心ですが、N3では長文と論理展開も加わります。N1とN2では、複数の文章を比較・統合したり、より広いテーマや筆者の意図を見抜いたりする問題もあります。

文章全体をカードにコピーすると、難しさを生んだ条件が失われます。また、著作物を不必要に複製することにもなります。JLPTの主催者は、試験問題の無断転載を明確に禁止しています（[JLPT FAQ](https://www.jlpt.jp/e/faq/#anchor26)）。

まず、元の問題集で文章を最後まで解きます。その後、ミスを分類します。

- 知らない単語や読み
- 文法上の関係
- `それ` や `この点` などの指示語
- 原因と結果
- 対比、または筆者の立場の変化
- 2つの文章の違い
- お知らせ、予定表、広告、フォームで見落とした条件
- 知識不足ではなく時間不足

最初の7種類からは、役に立つカードを作れます。時間切れに必要なのは、「速く読め」と書いたカードではなく、時間を計った読解練習です。

たとえば、筆者が反対する理由を間違えて選んだとします。ミス対策カードは次のように作れます。

**表**

```text
演習セット4、読解2：
費用の例が、筆者が提案に反対する主な理由ではなかったのはなぜか。
```

**裏**

```text
費用は補足的な根拠だった。明示された反対理由は、
準備時間が足りないことだった。

ミス：費用の例を主な理由として扱った。
出典：[書籍名または公式問題集、ページ]
```

このカードに残すのは、正確な違いと、自分が引っかかったポイントです。文章や選択肢は転載しません。カードの表面だけで意味が通じないなら、書き直すか削除してください。その後、同じ推論が必要な初見の文章を解きます。

情報検索のミスでは、選ぶための条件をカードに残します。

**表**

```text
案内から条件に合う選択肢を探す前に、何を確認する？
```

**裏**

```text
必要な日付や時間、対象となる条件、除外条件。
```

この問題形式はN5からN1まで出題されます。使われる資料と複雑さは変わりますが、すべての条件を確認する習慣はどのレベルでも役立ちます。

[演習問題をフラッシュカードに変える方法](/blog/how-to-turn-practice-questions-into-flashcards/)では、間違えた問題を、再利用できる1つの学びに絞る流れを詳しく説明しています。次の初見の文章も必ず学習計画に入れてください。[フラッシュカードと模擬試験](/blog/flashcards-vs-practice-tests/)では、試験への準備の別々の側面を測ります。

## 聴解はスクリプトを見る前に始める

スクリプトは原因分析にとても役立ちます。しかし、先に読んでしまうと聴解練習にはなりません。

公式例題の音声など、使用許可のある聴解教材を次の順番で使います。

1. 再生前は、指示と問題に示された情報だけを読む。
2. スクリプトを見ずに1回聞く。
3. 答えを選び、確信度も記録する。
4. 正解を確認する。
5. 原因を調べるために音声をもう一度再生し、ミスにつながった箇所を探す。
6. スクリプトを開き、聞き逃した音、単語、文法形式、意図、関係を正確に特定する。
7. ほかの場面でも必要になる、聞き取れなかった点だけをカードにする。
8. スクリプトを閉じ、もう一度音声を再生する。

[JLPT公式例題集](https://www.jlpt.jp/e/samples/sample09.html)には、N1からN5までの音声、スクリプト、正答があります。これは2010年の改定内容を説明するために公開されたもので、掲載されている問題数は実際の試験とは異なり、一部の指示もその後変更されたとページに明記されています。現在の問題構成は、最新の公式ページで確認してください。

スクリプトから作るミス対策カードは、次のようになります。

**表**

```text
「念のため、もう一度確認しておきます。」

「念のため」が示す話し手の判断は？
```

**裏**

```text
問題があると決めたのではなく、用心のために確認する。
話し手は念を入れて確認している。
```

次に、新しい音声の中でこの表現を聞き取ります。テキストでの復習は、聞き逃した意味を記憶に残す助けにはなります。しかし、自然な速さでその表現を聞き取れる証明にはなりません。

自分のレベルの聴解問題に合わせて練習しましょう。N3からN5には、状況やイラストに合う発話を選ぶ問題があります。一方、N1とN2には複数の情報を統合して理解する問題があります。N1からN3には概要理解があり、すべてのレベルに課題理解、ポイント理解、即時応答が含まれます。

課題理解や統合理解では、取り違えた関係をカードに残します。誰が行動する必要があるか、どの条件が変わったか、すべての条件を満たす選択肢はどれか、2人の話者の意見はどう違うか、といった点です。音声全体は、まず音声だけで解く課題として残します。カード上のスクリプト抜粋はミスの修正用であり、音声を聞いて解く練習の代わりではありません。

## レベルに合わせて学習配分を決める

公式の[2026年試験日程と試験科目の案内](https://www.jlpt.jp/e/guideline/testsections.html)には、7月5日（日）と12月6日（日）の日程が掲載されています。日本国外では年1回しか実施しない都市もあるため、現地の日程と申込情報を確認してください。

試験時間もレベルによって異なります。

| レベル | 言語知識・読解 | 聴解 |
| --- | --- | --- |
| N1 | 言語知識（文字・語彙・文法）・読解：110分 | 55分 |
| N2 | 言語知識（文字・語彙・文法）・読解：105分 | 50分 |
| N3 | 言語知識（文字・語彙）：30分、言語知識（文法）・読解：70分 | 40分 |
| N4 | 言語知識（文字・語彙）：25分、言語知識（文法）・読解：55分 | 35分 |
| N5 | 言語知識（文字・語彙）：20分、言語知識（文法）・読解：40分 | 30分 |

公式ページには、試験時間が変更される場合があり、聴解の時間も録音の長さによって多少変わると記載されています。N1とN2では、言語知識と読解を1つの試験科目として実施します。N3、N4、N5では、文字・語彙と言語知識（文法）・読解が分かれています。学習セッションでも、ときどきこの構成を再現しましょう。カードだけでは身につかない、科目間の切り替えや集中力の維持も含めて練習します。

デッキのバランスが必要な理由は、得点区分にもあります。N1からN3では、「言語知識」「読解」「聴解」の得点が別々に示されます。N4とN5では「言語知識・読解」が合算され、「聴解」は別です。公式の[得点区分の案内](https://www.jlpt.jp/e/guideline/results.html)によると、合格には総合得点の合格点と、すべての得点区分の基準点を満たす必要があります。

N1からN3では、各得点区分の基準点は60点中19点です。N4とN5では、「言語知識・読解」が120点中38点、「聴解」が60点中19点です。総合得点が高くても、1つの区分が基準点を下回れば補えません。

これは、各区分で同じ枚数のカードを作るという意味ではありません。思い出す練習が役立つ部分にはカードを使い、それ以外には読解と聴解の通し練習を予定します。聴解の弱さは、単独の漢字カードをさらに100枚追加しても解消できません。

## CEFRの参考表示で新しい出題範囲ができたわけではない

2025年第2回（12月）試験以降のJLPT合格者には、総合得点に基づき、A1からC1までのCEFRレベルが参考情報として成績書類に表示されます。不合格の場合は表示されません。公式案内によると、この追加によって試験内容が変わったり、別の対策が必要になったりしたわけではありません（[JLPTのCEFRレベル参考表示に関する案内](https://www.jlpt.jp/e/cefrlevel/cefrnews.html)）。

これによってJLPTが4技能試験になったわけでもありません。参考表示の対象は、JLPTが測る言語知識と受容能力、つまり言語知識・読解・聴解です。話す・書くという産出能力や、やり取りする力は対象外です（[公式のCEFR参考表示の説明](https://www.jlpt.jp/e/about/cefr_reference.html)）。カードにするための新しい公式「2026年CEFR語彙リスト」も存在しません。

## 実際の日本語に触れながら、小さなデッキを回す

今まさに勉強している教材と、実際にしたミスから始めます。実用的な1週間の流れは次のとおりです。

- 授業の後に、読み、文脈上の意味、近い言い換え、用法、文法判断について、確認済みのカードを数枚追加する。
- 読解練習の後に、知識や推論の不足1つにつき、小さな学びを1つ記録する。時間と持久力の問題は練習計画に残す。
- 聴解練習の後にスクリプトを確認し、聞き逃した手がかりを保存して、文字を見ずに音声をもう一度聞く。
- 復習時期が来たカードを復習する。
- 週に1回、自分のレベルの公式問題形式を混ぜた問題セットを解く。
- 定期的に、デッキの助けを借りず、まとまった長さの読解または聴解問題を解く。

FSRSは履歴をもとに次の復習時期を決め、難しいカードを早めに、覚えているカードを間隔を空けて表示できます。ただし、文が自然か、そのカードがN2に合うか、間違った説明をコピーしていないかまでは分かりません。[FSRSを使った試験勉強の流れ](/blog/how-to-study-for-an-exam-with-fsrs/)では、試験日が決まっている場合に、新規カードの追加をいつ減らすかも説明しています。

[Flashcards Open Source App](/features/)では、このガイドの例ならシンプルな表裏カードだけで十分です。`N3`、`kanji-reading`、`paraphrase`、`text-grammar`、`listening-miss` のようなタグで、レベルと問題形式を残せます。意味のある文脈を伝えられる場所には画像や関連メディアを追加でき、期限が来たカードをFSRSで復習し、モバイルではオフラインで学習して、接続が戻ったときに変更を同期できます。インポートとエクスポートにより、カード、タグ、関連メディアを持ち運べます。

このアプリには、作成済みのJLPTデッキやJLPT模擬試験機能はありません。また、Ankiの `.apkg` ファイルを直接インポートすることもできません。AIはカード候補の下書きや短縮を手伝えますが、日本語、出典の正確さ、レベル分け、試験との関連性を検証するものではありません。生成されたカードは、保存前に必ず1枚ずつ確認してください。[スタートガイド](/docs/getting-started/)では、ホスト版、モバイル、AIエージェント、セルフホストの各利用方法を説明しています。

## 次の10枚を根拠のある情報から作る

自分のレベルの公式問題構成ページと、信頼できる教材を1つずつ開きます。今の授業や最近のミスから、次の10項目を選びましょう。

- 文脈に入れた漢字の読みを2つ
- 文脈上の意味または言い換えを2つ
- 自分のレベルに出る用法または表記の判断を1つ
- 文法判断を2つ
- 読解のミス対策カードを1枚
- 音声を先に聞く練習の後に作った聴解のミス対策カードを2枚

始めるにはこれで十分です。カードを復習し、分かりにくいプロンプトを直し、授業や問題演習で本当に必要だと分かったときだけ追加します。

質の高いJLPTデッキは、根拠をたどれます。各カードのレベル、問題形式、出典、そのカードにつながったミスや判断が分かる状態です。デッキだけで試験対策を完結させないでください。文章全体、初見の音声、時間を計るセクション練習、実際のコミュニケーションで使う日本語も必要です。

まず10枚のJLPTフラッシュカードを作り、その後で新しい文章や音声に戻りましょう。デッキは、小さな学びを忘れないために使えます。次の通し問題で、本番までにそれを使いこなせるか確かめましょう。
