役立つ**CompTIA A+フラッシュカード**は、手がかりと判断、その理由をすぐに思い出せるようにします。ポート、コネクター、コマンド、症状、セキュリティの概念、サポート手順を覚えるのに向いています。一方、ドライブの取り付け、初めて見るコマンド出力の読み取り、複数の手順を伴うパフォーマンスベース問題には、あまり向きません。こうした練習には実機やラボが必要です。

## 現行のCompTIA A+ V15試験に備える

2026年8月1日現在、現行のA+試験シリーズはV15です。

- Core 1: `220-1201`
- Core 2: `220-1202`

CompTIAは両試験を2025年3月25日に開始し、現時点では2028年に終了する見込みとしています。A+認定を取得するには、両方に合格する必要があります。バウチャーを購入する前に試験コードを確かめるなら、公式の[Core 1ページ](https://www.comptia.org/en-us/certifications/a/core-1-v15/)と[Core 2ページ](https://www.comptia.org/en-us/certifications/a/core-2-v15/)が最も確実です。

| 試験 | 最大問題数 | 試験時間 | 合格スコア |
| --- | ---: | ---: | ---: |
| Core 1 (`220-1201`) | 90 | 90分 | 100～900点満点中675点 |
| Core 2 (`220-1202`) | 90 | 90分 | 100～900点満点中700点 |

試験ページには、単一回答式と複数回答式、ドラッグ＆ドロップ、パフォーマンスベース問題が試験形式として挙げられています。試験範囲PDFでは、より簡潔に「選択式問題とパフォーマンスベース問題」と説明されています。表現は異なりますが、どちらも同じV15試験を指しています。

もう1つ、混同しやすいバージョン番号があります。現在の[Core 1試験範囲PDF](https://lecbyo.files.cmp.optimizely.com/download/34be017cb73211ef8985a6f347fbf652)と[Core 2試験範囲PDF](https://lecbyo.files.cmp.optimizely.com/download/cefedfb2b8a511ef809306d06d323538)には、**Exam Objectives Document Version 4.0**と記載されています。これはダウンロード版の文書そのものの改訂番号です。**V15**は試験シリーズを指します。今後PDFが改訂されても、試験コードと現在のCompTIA公式リンクを基準にしてください。

廃止された`220-1101` Core 1と`220-1102` Core 2の試験はV14に属します。共通する基礎知識もありますが、古い試験範囲は現行試験の信頼できるチェックリストにはなりません。

## 各Coreで問われる仕事に合わせてデッキを分ける

実際のサポートチケットではCore 1とCore 2の内容が重なりますが、試験範囲の重点は異なります。

| Core 1 (`220-1201`) | 比率 | Core 2 (`220-1202`) | 比率 |
| --- | ---: | --- | ---: |
| モバイルデバイス | 13% | オペレーティングシステム | 28% |
| ネットワーク | 23% | セキュリティ | 28% |
| ハードウェア | 25% | ソフトウェアのトラブルシューティング | 23% |
| 仮想化とクラウドコンピューティング | 11% | 運用手順 | 21% |
| ハードウェアとネットワークのトラブルシューティング | 28% |  |  |

実際のところ、Core 1ではデバイス、コンポーネント、ネットワークの動作、物理的な症状を関連付ける力が問われます。Core 2では、オペレーティングシステムのツール、セキュリティ、ソフトウェア障害、文書化、変更管理、ユーザーサポートが重視されます。

デッキを2つに分けるか、すべてのカードに `core-1` または `core-2` を付けましょう。試験範囲と照合しやすくなるなら、項目コードも追加します。たとえば、プリンターのトラブルシューティングなら `220-1201:5.6` です。`lab-miss`、`practice-miss`、`objective-check` のような出典タグを使えば、そのカードを作った理由も分かります。

比率は学習範囲を確認する目安であり、カード枚数の割り当てではありません。試験の28%を占める分野なのにデッキではほとんど扱っていなければ、詳しく確認しましょう。すでにすぐ思い出して応用できる内容について、カードを何十枚も無理に作る必要はありません。

## A+カードには技術者としての判断を1つだけ入れる

カードは自己採点しやすい形にします。裏面を見る前に答えられたかどうかが、はっきり分かる形です。A+で使いやすいプロンプトは、主に次の4種類です。

### よく似た2つの概念を区別する

Core 1では、インターフェース、フォームファクター、ケーブル、ネットワークサービス、クラウドモデルなど、混同しやすい項目が並びます。実務上のミスを防ぐ違いを問いましょう。

```text
表: 「M.2 SSD」と分かれば、そのドライブがSATAとPCIe/NVMeのどちらを
使うか判断できますか？

裏: いいえ。M.2はフォームファクターを表します。対応するインターフェースと
プロトコルは、ドライブとマザーボードの仕様で確認します。
```

```text
表: Type 1ハイパーバイザーとType 2ハイパーバイザーの違いは？

裏: Type 1はホストのハードウェア上で直接動作します。Type 2はホストの
オペレーティングシステム上で動作します。
```

定義をコピーするより、このように選択を求めるプロンプトのほうが役立ちます。

### 症状を次に確認すべき項目につなげる

トラブルシューティングカードでは、問いの書き方に注意が必要です。1つの症状だけで原因を断定できることは、ほとんどありません。

```text
表: Windowsクライアントに169.254.x.xのアドレスが設定され、ローカル
ネットワークに接続できません。このアドレスから何が分かり、次に何を確認しますか？

裏: DHCPリースを受け取れなかったため、クライアントがAPIPAアドレスを
自己割り当てしています。有線または無線の接続を確認し、次にDHCPサーバーまで
到達できるかを確認します。
```

```text
表: デスクトップPCは電源が入っている間は正確な時刻を保ちますが、すべての
電源を切ると日付と時刻が失われます。最初に確認するのが妥当な部品は？

裏: CMOS/RTCバッテリーです。ただし、ファームウェアや
マザーボードに別の障害がある可能性も残します。
```

多くの場合、「これは何を示唆しますか？」と問うほうが、「原因は何ですか？」より適切です。前者なら証拠を検討する余地が残ります。後者は誤った断定を覚えさせるおそれがあります。

### サービスと手がかりをセットで思い出す

ポートは双方向で覚え、サポート場面にも結び付けます。

```text
表: 技術者がホストへ暗号化されたリモートコマンドライン接続を行う必要があります。
該当する標準サービスとポートは？

裏: SSH。通常はTCPポート22を使います。
```

```text
表: サーバーでTCPポート22が開いています。どのサービスを調べますか？

裏: 標準的にはSSHです。実際に待ち受けているプロセスを確認してください。
ポート番号だけでは、動作中のサービスを断定できません。
```

こうすれば、ポートのデッキが単なる数字の暗唱になりません。プロトコルカードについてさらに詳しく知りたい場合は、[Security+フラッシュカードガイド](/blog/how-to-use-flashcards-for-security-plus/)を参照してください。A+デッキはA+の試験範囲内に収めましょう。

### 必要な証拠を得られるツールを選ぶ

Core 2の試験範囲1.4と1.5では、Windowsの管理ツールとコマンドラインツールを扱い、シナリオに応じて適切なツールを使うことが求められます。作業内容からツールを思い出すプロンプトにしましょう。

```text
表: DNSや経路をテストする前に、クライアントの現在のIP設定を表示する
Windowsコマンドは？

裏: ipconfig
```

```text
表: ホスト名がIPアドレスに名前解決されるか直接テストするWindowsコマンドは？

裏: nslookup
```

```text
表: Windowsのクラッシュ前後に発生したアプリケーションイベントと
システムイベントは、どこで確認しますか？

裏: Event Viewer (eventvwr.msc)
```

カードを復習したら、そのコマンドを実行するかツールを開きます。カードで最初の一手を思い出し、実機でオプション、出力、権限、失敗時の挙動を学びます。この流れは[ターミナルコマンドのフラッシュカードガイド](/blog/how-to-learn-terminal-commands-with-flashcards/)で詳しく説明しています。

## Core 2では境界、順序、判断力も問われる

Core 2は、Windowsツールとセキュリティ用語の一覧に見えるかもしれません。よいカードは、こうした知識を具体的なサポート判断の中で問います。

セキュリティでは、異なる問題を解決する対策を比べます。

```text
表: ユーザーの管理者権限を削除することと、多要素認証を有効にすることは
なぜ異なるのですか？

裏: 管理者権限を削除すると、サインイン後の認可が制限されます。
多要素認証は、サインイン時の本人確認を強化します。
```

運用手順では、システムと顧客を守るため、手順の順序もカードに残します。

```text
表: 承認済みのワークステーション変更を実施する前に、失敗に備えて
明確にしておくべき2つの計画は？

裏: バックアップ計画とロールバック計画です。変更記録には、範囲、リスク、
承認、実施時期、影響を受けるシステム、実施内容、結果も残します。
```

カスタマーサポートでは、状況を具体的にします。

```text
表: ユーザーが問題を曖昧な言葉で説明しています。解決策を提案する前に、
技術者は何をすべきですか？

裏: 要点を絞りつつ自由に答えられる質問をし、問題を言い換えて、双方の認識が
一致していることを確認します。
```

Core 2の試験範囲4.10には、AIの基礎概念も含まれます。適正利用ポリシー、盗用、バイアス、ハルシネーション、正確性、公開データと非公開データの扱いです。別のAI講座を作るのではなく、焦点を絞ったカードを数枚用意すれば十分です。

```text
表: 顧客の診断ログを公開AIサービスに貼り付ける前に、技術者は何を
確認すべきですか？

裏: 組織のAIおよびデータ取扱ポリシー、ログに非公開データや規制対象データが
含まれるか、そのデータに対してサービスの利用が承認されているかを確認します。
```

## PBQの練習はフラッシュカードより大きな単位で行う

CompTIAは[パフォーマンスベース問題](https://www.comptia.org/en-us/resources/test-policies/exam-development/performance-based-questions-explained/)を、シミュレーションまたは仮想環境で出題される問題解決型の設問と説明しています。現在、シミュレーション形式のPBQがある認定資格の1つとしてA+も掲載されています。1つの技術的な状況の中で、複数の観察と操作が必要になることもあります。1行のカードでは、そうした状況を再現できません。

PBQやラボの練習前後にカードを使います。

1. 練習前に、ポート、コネクター、コマンドの目的、権限、トラブルシューティングの手がかりなど、小さな前提知識を思い出す。
2. 練習中は、実際のインターフェースで作業し、利用できる証拠を確認する。
3. 間違えたら、見落とした手がかりと、判断を誤らせた思い込みを書き留める。
4. 小さな知識を思い出せなかったことが間違いにつながった場合だけ、カードを1枚作る。
5. 修正した知識を別のシナリオで試す。

DNSの役割は覚えていたものの、名前解決に問題があるかを判断するのに時間がかかったとします。`nslookup` をいつ使うか問うカードなら、その記憶の抜けを補えます。次のラボでは別のホストと障害状態を使い、引き続き自分で考える必要がある形にします。

本当の原因が画面操作、コマンド出力、コンポーネントの取り付け、時間管理、証拠収集の不足だった場合は、その間違いを無理にカード1枚へ落とし込まないでください。必要なのは、PBQ練習、仮想ラボ、予備のハードウェア、より長いトラブルシューティング演習です。

試験範囲文書では、一般にbrain dumpと呼ばれる、許可されていない第三者教材を使わないよう受験者に警告しています。現行の試験範囲、正規のトレーニングや演習、自分のラボノートを使ってください。[演習問題をフラッシュカードに変える方法](/blog/how-to-turn-practice-questions-into-flashcards/)では、問題をコピーせず、別の場面でも使える学びを残す方法を説明しています。

## 一度に1つのCoreに絞って学習サイクルを作る

先に受験するCoreを決め、そのカードを優先して学びます。各分野は、次のように進めましょう。

1. 現行の正規教材を使い、試験範囲の小さなまとまりを学ぶ。
2. ハンズオン作業または正規の演習問題に取り組む。
3. 迷った箇所、正解できたものの確信を持てなかった箇所、間違えた箇所だけをカードにする。
4. 実践練習を続けながら、FSRSで復習期限を迎えたカードに取り組む。

週に1回、デッキと分野別の表を比べます。試験範囲の箇条書きをコピーして復習キューを埋めなくても、学習の抜けを見つけられます。試験が近づいたら新しいカードの作成を減らし、時間を計った問題演習、PBQ、初見のトラブルシューティングシナリオに多くの時間を使います。

CompTIAは両方のV15試験について、ITサポートスペシャリストとして12か月の実務経験を推奨しています。これは追加の認定要件ではありませんが、試験範囲が想定する実務経験の目安として役立ちます。

## Flashcards Open Source Appの役割

[Flashcards Open Source App](/features/)は、記憶の定着を支える部分を担います。シンプルな表裏カード、デッキとタグ、FSRSによる期限ベースの復習、必要に応じたAIによるカードの下書き支援、同期機能のあるモバイルでのオフライン学習、持ち運びやすい形式でのエクスポートを利用できます。ホスト版アプリは現在のベータ期間中は無料で、プロジェクトをセルフホストすることもできます。

A+向けの構成はシンプルに保てます。

- `220-1201` 用と `220-1202` 用にデッキを1つずつ作る
- バージョンに左右されるカードには試験範囲の項目と出典を示すタグを付ける
- ラボや演習の後に短いミス記録を残す
- AIはカードの文面編集に使い、技術的な答えはすべて保存前に確認する

このアプリはCompTIAの公式製品でも、A+コース、試験シミュレーター、PBQ環境でもありません。FSRSを使って繰り返し思い出したい、小さな知識と判断を保存する場所です。実機、総合シナリオ、正規の試験演習には、それぞれ適切なツールを使ってください。[スタートガイド](/docs/getting-started/)では、ホスト版とセルフホスト版の始め方を説明しています。

## CompTIA A+フラッシュカード FAQ

### 2026年はどのCompTIA A+試験に向けて学習すればよいですか？

A+ V15のCore 1 `220-1201` とCore 2 `220-1202` に向けて学習してください。両方とも2025年3月25日に開始され、CompTIAは現時点で2028年に終了する見込みとしています。受験を予約する前に、公式試験ページを再確認してください。

### A+認定にはCore 1とCore 2の両方が必要ですか？

はい。CompTIAのA+認定を取得するには、V15試験の両方に合格する必要があります。Core 1の合格スコアは675点、Core 2は700点です。どちらも100～900点で採点されます。

### CompTIA A+フラッシュカードだけでPBQに対応できますか？

いいえ。カードは、コマンド、ポート、コンポーネントの違い、権限の概念、手がかりを思い出すのに役立ちます。A+のPBQでは実際にシミュレーションを進める必要があるため、正規のPBQ演習やハンズオンラボと組み合わせてください。

### 試験範囲の全項目をフラッシュカードにすべきですか？

試験範囲は学ぶ内容の線引きと、抜けを確認する地図として使います。すぐ思い出す必要があり、何度も間違える情報をカードにしてください。取り付け、設定、出力の解釈、複数手順のトラブルシューティングは、デッキの外で練習します。

## まず20枚のカードと1つの実作業から始める

先に受験するCoreの公式試験範囲を開きましょう。分野を1つ選び、小さなセクションを学んだら、実際に手を動かします。コマンドを実行する、ハードウェアを確認する、設定を変更する、初見のシナリオをトラブルシューティングするといった作業です。

迷った箇所から作るカードは20枚以内にします。大きな復習キューを作る前に、プロンプトが明確か確かめるには十分な枚数です。役立つ**CompTIA A+フラッシュカード**は、小さな知識をすぐ取り出せる状態に保ちます。実作業では、それらを組み合わせられるかを確かめられます。
