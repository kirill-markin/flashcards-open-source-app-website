## ഹോസ്റ്റ് ചെയ്ത വെബ് ആപ്പ്

തുടങ്ങാനുള്ള ഏറ്റവും വേഗമേറിയ വഴി ഹോസ്റ്റ് ചെയ്ത വെബ് ആപ്പാണ്:

1. [app.nibomo.com](https://app.nibomo.com) തുറക്കുക
2. പാസ്‌വേഡ് ഇല്ലാത്ത OTP ഉപയോഗിച്ച് ഇമെയിൽ വഴി സൈൻ ഇൻ ചെയ്യുക
3. കാർഡുകൾ ഉണ്ടാക്കുക, ആവർത്തിക്കേണ്ടവ ആവർത്തിക്കുക, വർക്ക്‌സ്‌പേസ് ഡാറ്റയും ഫയൽ അറ്റാച്ച്മെന്റുകളും ഉപയോഗിച്ച് AI ചാറ്റ് പ്രയോജനപ്പെടുത്തുക

ഹോസ്റ്റ് ചെയ്ത ആപ്പ് ഉപയോഗിക്കുമ്പോൾ ഇൻസ്റ്റാളേഷനോ സെർവർ സജ്ജീകരണമോ ആവശ്യമില്ല.

## ഏജന്റ് സജ്ജീകരണം

Claude Code, Codex അല്ലെങ്കിൽ OpenClaw നേരിട്ട് ബന്ധിപ്പിക്കണമെങ്കിൽ, ഇവിടെ നിന്ന് തുടങ്ങുക:

```text
GET https://api.nibomo.com/v1/
```

ഇമെയിൽ OTP ലോഗിൻ, ദീർഘകാല API കീ സൃഷ്ടിക്കൽ, അക്കൗണ്ട് ലോഡ് ചെയ്യൽ, വർക്ക്‌സ്‌പേസ് ബൂട്ട്സ്ട്രാപ്പ്, പ്രസിദ്ധീകരിച്ച SQL സർഫേസ് എന്നിവയിലൂടെ ഈ ഡിസ്കവറി പ്രതികരണം ഏജന്റിനെ പടിപടിയായി നയിക്കുന്നു.

ഇതേ പേലോഡ് `GET /v1/agent` ലും ലഭ്യമാണ്, പക്ഷേ ഔദ്യോഗിക പൊതു പ്രവേശന കവാടം `/v1/` ആണ്.

## സ്വന്തം ഹോസ്റ്റിംഗ്

സ്വന്തം ഇൻസ്റ്റൻസ് പ്രവർത്തിപ്പിക്കാനാണ് താൽപ്പര്യമെങ്കിൽ, [സ്വന്തം ഹോസ്റ്റിംഗ് വഴികാട്ടി](/docs/self-hosting/) കാണുക.

## ഇന്ന് നിങ്ങൾക്ക് ലഭിക്കുന്നത്

- കാർഡുകൾക്കും ആവർത്തനത്തിനും AI ചാറ്റിനുമുള്ള ഹോസ്റ്റ് ചെയ്ത വെബ് ആപ്പ്
- പ്രധാന റിപ്പോസിറ്ററിയിൽ, ലോക്കൽ SQLite ഉം ഓഫ്‌ലൈൻ-ഫസ്റ്റ് സമന്വയവുമുള്ള iOS ക്ലയന്റ്
- വേറിട്ട `api`, `auth` ഡൊമെയ്‌നുകളിൽ പങ്കിട്ട ബാക്കെൻഡ്, ഓതന്റിക്കേഷൻ സേവനങ്ങൾ
- ഡിസ്കവറി, OTP, ApiKey ഓതന്റിക്കേഷൻ എന്നിവ വഴി ബാഹ്യ ഏജന്റുകളുടെ ഓൺബോർഡിംഗ്
- Postgres ആധികാരിക ഡാറ്റാ ഉറവിടമായി ഉപയോഗിക്കുന്ന, AWS ലെ ഓപ്പൺ സോഴ്സ് ഡിപ്ലോയ്മെന്റ് മാർഗം

## റിപ്പോസിറ്ററിയുടെ ദിശ

ഈ പ്രോജക്റ്റ് ഓഫ്‌ലൈൻ-ഫസ്റ്റ് ആണ്.

ഇന്ന് റിപ്പോസിറ്ററിയിൽ വെബ് ആപ്പ്, iOS ആപ്പ്, ഓതന്റിക്കേഷൻ സേവനം, ബാക്കെൻഡ് API, ബാഹ്യ ഏജന്റ് ഫ്ലോ, Google Play ൽ പ്രസിദ്ധീകരിച്ച Android ആപ്പ് എന്നിവ ഉൾപ്പെടുന്നു.
