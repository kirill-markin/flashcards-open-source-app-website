- **Android செயலி**: [Google Play](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&utm_source=flashcards_website&utm_medium=referral&utm_campaign=marketing_site)

- **AI முகவர்கள்**: [MCP இணைப்பான்](/docs/mcp-connector/) அல்லது `https://api.nibomo.com/v1/` இல் உள்ள API
- **சொந்தமாக இயக்குதல்**: [சொந்த இயக்க வழிகாட்டி](/docs/self-hosting/)

## மொபைல், டெஸ்க்டாப் செயலிகள்

உங்கள் சாதனத்துக்கென உருவாக்கப்பட்ட செயலியை நிறுவுங்கள்:

- iPhone, iPad, Mac: [App Store](https://apps.apple.com/app/apple-store/id6760538964?pt=128797295&ct=marketing_site&mt=8)
- Android: [Google Play](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&utm_source=flashcards_website&utm_medium=referral&utm_campaign=marketing_site)

செயலிகள் உங்கள் அட்டைகளைச் சாதனத்திலேயே வைத்திருக்கின்றன; அதனால் இணையம் இல்லாதபோதும் மீள்பயிற்சி செய்யலாம், மீண்டும் இணையம் கிடைத்ததும் அவை ஒத்திசைகின்றன. விருந்தினராகத் தொடங்கி, பின்னர் உள்நுழையலாம்.

### முகப்புத் திரை விட்ஜெட்டுகள்

Nibomo செயலி iPhone, iPad, Mac, Android ஆகியவற்றில் மீள்பயிற்சி விட்ஜெட்டைச் சேர்க்கிறது. இது மூன்று அளவுகளில் கிடைக்கிறது:

- **சிறியது**: மீள்பயிற்சிக்கு உரிய அட்டைகளின் எண்ணிக்கையும் உங்கள் தொடர் படிப்பு நாட்களும்
- **நடுத்தரம்**: மீள்பயிற்சிக்கு உரிய அட்டைகளின் எண்ணிக்கையும் உங்கள் அடுத்த அட்டையின் கேள்வியும்
- **பெரியது**: மீள்பயிற்சிக்கு உரிய அட்டைகளின் எண்ணிக்கை, உங்கள் அடுத்த கேள்வி, தொடர் நாட்கள்

மீள்பயிற்சிக்கு எதுவும் இல்லாதபோது, விட்ஜெட் “அனைத்தும் முடிந்தது” என்பதையும் அடுத்த அட்டை எப்போது வரும் என்பதையும் காட்டும். அது ஒருபோதும் பதிலைக் காட்டாது. மீள்பயிற்சியைத் திறக்க விட்ஜெட்டைத் தட்டுங்கள்; நடுத்தர அல்லது பெரிய விட்ஜெட், தான் காட்டும் அட்டையிலேயே மீள்பயிற்சியைத் திறக்கும். விருந்தினர்கள் உட்பட அனைவருக்கும் விட்ஜெட்டுகள் இலவசம்.

iPhone, iPad அல்லது Mac-இல் விட்ஜெட்டைச் சேர்க்க, விட்ஜெட் தொகுப்பைத் திறந்து, Nibomo-வைத் தேர்ந்தெடுத்து, ஒரு அளவைத் தேர்வு செய்யுங்கள். Android-இல், விட்ஜெட் பட்டியலிலிருந்து Nibomo விட்ஜெட்டைச் சேர்த்து, பிறகு அதன் அளவை மாற்றுங்கள்; அளவுக்கு ஏற்ப தளவமைப்பு மாறும்.

## தளத்தில் இயங்கும் வலைச் செயலி

தொடங்குவதற்கான மிக விரைவான வழி, தளத்தில் இயங்கும் வலைச் செயலிதான்:

1. [app.nibomo.com](https://app.nibomo.com) ஐத் திறங்கள்
2. கடவுச்சொல் இல்லாத OTP மூலம் உங்கள் மின்னஞ்சலுடன் உள்நுழையுங்கள்
3. அட்டைகளை உருவாக்குங்கள், நிலுவையில் உள்ள அட்டைகளை மீள்பயிற்சி செய்யுங்கள், பணியிடத் தரவுடனும் இணைப்புக் கோப்புகளுடனும் AI அரட்டையைப் பயன்படுத்துங்கள்

தளத்தில் இயங்கும் இந்த வழிக்கு எதையும் நிறுவவோ சேவையகத்தை அமைக்கவோ தேவையில்லை.

## முகவர் அமைப்பு

Claude, ChatGPT, Cursor போன்ற MCP கிளையண்டுகள் [MCP இணைப்பான் வழிகாட்டி](/docs/mcp-connector/) மூலம் இணையலாம்.

Claude Code, Codex அல்லது OpenClaw நேரடியாக இணைய வேண்டுமென்றால், இங்கிருந்து தொடங்குங்கள்:

```text
GET https://api.nibomo.com/v1/
```

அந்தக் கண்டறிதல் பதில், மின்னஞ்சல் OTP உள்நுழைவு, நீண்ட காலம் செல்லுபடியாகும் API விசை உருவாக்கம், கணக்கை ஏற்றுதல், பணியிடத் தொடக்க அமைப்பு, வெளியிடப்பட்ட SQL இடைமுகம் ஆகியவற்றின் வழியாக முகவரை வழிநடத்துகிறது.

இதே உள்ளடக்கம் `GET /v1/agent` இலும் கிடைக்கிறது, ஆனால் அதிகாரப்பூர்வ பொது நுழைவுப் புள்ளி `/v1/` தான்.

## சொந்தமாக இயக்குதல்

உங்கள் சொந்த நிறுவலை இயக்க விரும்பினால், [சொந்த இயக்க வழிகாட்டி](/docs/self-hosting/) ஐப் பாருங்கள்.

## இன்று உங்களுக்குக் கிடைப்பவை

- அட்டைகள், மீள்பயிற்சி, AI அரட்டை ஆகியவற்றுக்கான தளத்தில் இயங்கும் வலைச் செயலி
- உள்ளூர் SQLite சேமிப்புடனும், இணையம் இல்லாமல் இயங்குவதை முதன்மையாகக் கொண்ட ஒத்திசைவுடனும் iPhone, iPad, Mac, Android சாதனங்களுக்கென உருவாக்கப்பட்ட செயலிகள்
- தனித்தனி `api`, `auth` டொமைன்களில் பகிரப்பட்ட பின்தள, அங்கீகாரச் சேவைகள்
- கண்டறிதல், OTP, ApiKey அங்கீகாரம் வழியாக வெளிப்புற முகவர்களை இணைத்தல்
- Postgres ஐ அதிகாரப்பூர்வத் தரவு மூலமாகக் கொண்டு AWS இல் திறந்த மூலப் பயன்படுத்தல் வழி

## களஞ்சியத்தின் திசை

இந்தத் திட்டம் இணையம் இல்லாமல் இயங்குவதை முதன்மையாகக் கொண்டது.

இன்று களஞ்சியத்தில் வலைச் செயலி, iOS செயலி, அங்கீகாரச் சேவை, பின்தள API, வெளிப்புற முகவர் ஓட்டம், Google Play இல் வெளியிடப்பட்ட Android செயலி ஆகியவை உள்ளன.
