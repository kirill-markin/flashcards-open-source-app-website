## தளத்தில் இயங்கும் வலைச் செயலி

தொடங்குவதற்கான மிக விரைவான வழி, தளத்தில் இயங்கும் வலைச் செயலிதான்:

1. [app.nibomo.com](https://app.nibomo.com) ஐத் திறங்கள்
2. கடவுச்சொல் இல்லாத OTP மூலம் உங்கள் மின்னஞ்சலுடன் உள்நுழையுங்கள்
3. அட்டைகளை உருவாக்குங்கள், நிலுவையில் உள்ள அட்டைகளை மீள்பயிற்சி செய்யுங்கள், பணியிடத் தரவுடனும் இணைப்புக் கோப்புகளுடனும் AI அரட்டையைப் பயன்படுத்துங்கள்

தளத்தில் இயங்கும் இந்த வழிக்கு எதையும் நிறுவவோ சேவையகத்தை அமைக்கவோ தேவையில்லை.

## முகவர் அமைப்பு

Claude Code, Codex அல்லது OpenClaw நேரடியாக இணைய வேண்டுமென்றால், இங்கிருந்து தொடங்குங்கள்:

```text
GET https://api.nibomo.com/v1/
```

அந்தக் கண்டறிதல் பதில், மின்னஞ்சல் OTP உள்நுழைவு, நீண்ட காலம் செல்லுபடியாகும் API விசை உருவாக்கம், கணக்கை ஏற்றுதல், பணியிடத் தொடக்க அமைப்பு, வெளியிடப்பட்ட SQL இடைமுகம் ஆகியவற்றின் வழியாக முகவரை வழிநடத்துகிறது.

இதே உள்ளடக்கம் `GET /v1/agent` இலும் கிடைக்கிறது, ஆனால் அதிகாரப்பூர்வ பொது நுழைவுப் புள்ளி `/v1/` தான்.

## சொந்தமாக இயக்குதல்

உங்கள் சொந்த நிறுவலை இயக்க விரும்பினால், [சொந்த இயக்க வழிகாட்டி](/docs/self-hosting/) ஐப் பாருங்கள்.

## இன்று உங்களுக்குக் கிடைப்பவை

- அட்டைகள், மீள்பயிற்சி, AI அரட்டை ஆகியவற்றுக்கான தளத்தில் இயங்கும் வலைச் செயலி
- உள்ளூர் SQLite உடனும், இணையம் இல்லாமல் இயங்குவதை முதன்மையாகக் கொண்ட ஒத்திசைவுடனும் பிரதான களஞ்சியத்தில் உள்ள iOS கிளையண்ட்
- தனித்தனி `api`, `auth` டொமைன்களில் பகிரப்பட்ட பின்தள, அங்கீகாரச் சேவைகள்
- கண்டறிதல், OTP, ApiKey அங்கீகாரம் வழியாக வெளிப்புற முகவர்களை இணைத்தல்
- Postgres ஐ அதிகாரப்பூர்வத் தரவு மூலமாகக் கொண்டு AWS இல் திறந்த மூலப் பயன்படுத்தல் வழி

## களஞ்சியத்தின் திசை

இந்தத் திட்டம் இணையம் இல்லாமல் இயங்குவதை முதன்மையாகக் கொண்டது.

இன்று களஞ்சியத்தில் வலைச் செயலி, iOS செயலி, அங்கீகாரச் சேவை, பின்தள API, வெளிப்புற முகவர் ஓட்டம், Google Play இல் வெளியிடப்பட்ட Android செயலி ஆகியவை உள்ளன.
