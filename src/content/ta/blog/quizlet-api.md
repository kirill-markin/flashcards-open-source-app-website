இது Quizlet-இன் பொது ஆவணங்களைப் பற்றிய முடிவு; அதன் உள் அமைப்புகளைப் பற்றிய கூற்று அல்ல. Quizlet-க்கு தயாரிப்புகள் மற்றும் கூட்டாளர்களுடனான ஒருங்கிணைப்புகள் உள்ளன. அதன் ChatGPT செயலியும் Google Classroom துணை நிரலும் தற்போதைய இரு எடுத்துக்காட்டுகள். இவற்றில் எதுவும் பிற செயலிகளுக்குப் பொதுப் பயன்பாட்டுக்கான Quizlet உருவாக்குநர் API-ஐ வழங்குவதில்லை.

## ஏற்றுமதி, உட்பொதித்தல், கூட்டாளர் அணுகல் ஆகியவை பொது API-கள் அல்ல

ஒரு பொது API, வெளிப்புற மென்பொருள் உருவாக்குநர்கள் அதைப் பயன்படுத்துவதற்கான தெளிவான வரையறையை வழங்கும். ஆவணங்கள், அடையாளச் சரிபார்ப்பு, ஆதரிக்கப்படும் செயல்கள், பயன்பாட்டு விதிகள், அணுகல் சான்றுகளைப் பெறும் வழி ஆகியவை அதில் அடங்கும். Quizlet தற்போது பொதுவில் வழங்கும் எந்த வசதியிலும், இவை அனைத்தையும் உருவாக்குநர்களே மேற்கொள்ளும் முழுமையான வழி இல்லை.

Quizlet-இன் **ஏற்றுமதி** என்பது கையால் செய்யும் தரவு இடமாற்றம். தொகுப்பை உருவாக்கியவர் இணையதளத்தில் அதன் சொற்களையும் விளக்கங்களையும் தேவையான வடிவில் அமைத்து, **உரையை நகலெடு (Copy text)** என்பதைத் தேர்ந்தெடுத்து, கிடைத்த உரையை வேறொரு இடத்தில் ஒட்டலாம். படங்களையும் நகலெடுத்த தொகுப்புகளையும் ஏற்றுமதி செய்ய முடியாது என்றும், இந்த வசதி இணையதளத்தில் மட்டுமே கிடைக்கும் என்றும் Quizlet கூறுகிறது. கவனமாகச் செய்யும் ஒருமுறை இடமாற்றத்திற்கு இது உதவும். மென்பொருள் மூலம் இரண்டு அமைப்புகளைத் தொடர்ந்து ஒத்திசைக்க இது வழி தராது.

**உட்பொதித்தல்** உள்ளடக்கத்தைக் காட்டுவதற்கான வசதி; தரவை அணுகுவதற்கான வழி அல்ல. பொதுவில் கிடைக்கும் தொகுப்பை பொருத்துதல் (Match), கற்றல் (Learn), தேர்வு (Test), ஃபிளாஷ்கார்டுகள் (Flashcards) அல்லது எழுத்துக்கூட்டல் (Spell) முறையில் காட்டுவதற்கான HTML-ஐ Quizlet-இல் நகலெடுக்கலாம். உட்பொதிக்கப்பட்ட செயல்பாட்டில் Quizlet இலச்சினை இருக்கும்; கற்பவர்கள் Quizlet-இன் இடைமுகத்தையே பயன்படுத்துவார்கள். உங்கள் செயலிக்குத் திருத்தக்கூடிய அட்டைப் பதிவுகளாக அந்தத் தொகுப்பு கிடைக்காது.

**ஒரு குறிப்பிட்ட தயாரிப்புடனான ஒருங்கிணைப்பு**, அதற்காக ஒப்புக்கொள்ளப்பட்ட செயல்முறையைப் பின்பற்றும். எல்லா மென்பொருள் உருவாக்குநர்களுக்கும் ஒரே இடைமுகத்தை வழங்காமலேயே Quizlet, ChatGPT அல்லது Google Classroom-உடன் இணைந்து இயங்க முடியும். அந்த அறிவிப்புகள், குறிப்பிட்ட ஒருங்கிணைப்புகள் இருப்பதை உறுதிப்படுத்துகின்றன. அவற்றுக்குப் பின்னால் பொதுப் பயன்பாட்டுக்கான Quizlet API இருப்பதை அவை உறுதிப்படுத்துவதில்லை.

இதனால்தான் பழைய API ரேப்பரோ, உலாவியின் உருவாக்குநர் கருவிகளில் தெரியும் கோரிக்கையோ ஆதரிக்கப்படும் Quizlet API ஆகாது. பொது ஆவணங்களும் உருவாக்குநர்கள் நம்பிப் பயன்படுத்தக்கூடிய நிலையான இடைமுக வரையறையும் அங்கு இல்லை.

நீங்கள் உருவாக்கிய தொகுப்பிற்கு Quizlet-இன் அதிகாரப்பூர்வ ஏற்றுமதி முறையைப் பயன்படுத்துங்கள். இந்தச் செயல்முறை **உரையை நகலெடு (Copy text)** என்பதுடன் முடிவதால், பிரிப்பான்களைச் சீரமைப்பதற்கும் தரவுப் புலங்களைப் பொருத்துவதற்கும் முன், முதலில் ஒட்டிய உரையை மாற்றாமல் சேமித்துவையுங்கள். நீங்கள் பாதுகாப்பது சொற்களையும் விளக்கங்களையும்தான்; முழு அட்டைத் தொகுப்பையும் மீட்டமைக்க உதவும் கோப்புத் தொகுப்பைப் பதிவிறக்கவில்லை. படங்களும் கற்றல் வரலாறும் இடமாற்றம் ஆகாது.

நடைமுறைச் சரிபார்ப்புப் பட்டியலை [2026-இல் Quizlet தொகுப்புகளை ஏற்றுமதி செய்வது எப்படி](/ta/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/) என்ற வழிகாட்டியில் பார்க்கலாம். அசல் நகலையும் திருத்துவதற்கான நகலையும் வைத்திருப்பது, UTF-8, டேப் பிரிப்பான்கள், பல வரிகளில் அமைந்த விளக்கங்கள் ஆகியவற்றை அது விளக்குகிறது. அட்டைகளின் உள்ளடக்கத்தை இடமாற்றுவதற்கும், அவற்றின் மறுபயிற்சி அட்டவணைத் தரவை இடமாற்றுவதற்கும் உள்ள வேறுபாட்டையும் எடுத்துரைக்கிறது.

ஒருமுறை செய்து முடிக்கும் இடமாற்றத்திற்கு ஏற்றுமதி பொருத்தமானது. தினமும் அட்டைகளை உருவாக்கவோ, ஒத்திசைக்கவோ, மென்பொருள் வழியாகத் தொடர்ந்து திருத்தவோ அது பொருந்தாது.

### பக்கத்தில் காட்டுவதற்கு அதிகாரப்பூர்வ உட்பொதித்தலைப் பயன்படுத்துங்கள்

வகுப்புக்கான இணையதளத்திலோ LMS பக்கத்திலோ பொதுவில் கிடைக்கும் Quizlet தொகுப்பைக் கற்பவர்கள் படிக்க வேண்டுமெனில், Quizlet இணையதளம் வழங்கும் உட்பொதிக்கும் குறியீட்டைப் பயன்படுத்துங்கள். செயல்பாட்டைத் தேர்ந்தெடுத்து, **HTML-ஐ நகலெடு (Copy HTML)** என்பதை அழுத்தி, கிடைக்கும் குறியீட்டைப் பக்கத்தில் சேருங்கள். கற்பவர்கள் Quizlet செயல்பாட்டைப் பயன்படுத்திப் படிக்கலாம்; அதை உட்பொதித்த இணையதளத்திற்கு அட்டைகளின் மூலத் தரவு கிடைக்காது.

பல நேரங்களில் ஓர் ஆசிரியருக்கு இது மட்டுமே தேவைப்படும். இதை API என்று அழைப்பது, தேவையை இருப்பதைவிடச் சிக்கலானதாகக் காட்டும்.

### ChatGPT அல்லது Google Classroom-க்கு அதற்குரிய ஒருங்கிணைப்பைப் பயன்படுத்துங்கள்

மார்ச் 10, 2026 அன்று வெளியான Quizlet-இன் ChatGPT அறிவிப்பு ஒரு குறிப்பிட்ட செயல்முறையை விளக்குகிறது: Quizlet செயலியை இணைக்கவும், கோரிக்கையை `@Quizlet` எனத் தொடங்கவும், உருவாக்கப்பட்ட தொகுப்பை ChatGPT-இல் முன்னோட்டமாகப் பார்க்கவும், பின்னர் அதை Quizlet-இல் திறந்து உங்கள் தேவைக்கேற்ப மாற்றிப் படிக்கவும். அந்த உரையாடலிலிருந்து Quizlet தொகுப்பை உருவாக்குவதற்கான ஆதரிக்கப்படும் வழி இது. உங்கள் பாட், ஸ்கிரிப்ட் அல்லது இணையதளம் மீண்டும் பயன்படுத்தக்கூடிய Quizlet API அணுகல் சான்றை இது வழங்குவதில்லை.

ஜூன் 30, 2026 அன்று வெளியான Quizlet-இன் Google Classroom அறிவிப்பும் இதேபோலக் குறிப்பிட்ட வரம்பைக் கொண்டது. பயிற்சிக் கேள்விகள், ஃபிளாஷ்கார்டுகள், விளையாட்டுகள் உள்ளிட்ட செயல்பாடுகளைக் கண்டறிந்து மாணவர்களுக்கு வழங்கவும், பின்னர் Classroom செயல்முறைக்குள் அவர்களின் பங்கேற்பையும் முன்னேற்றத்தையும் கண்காணிக்கவும் இந்தத் துணை நிரல் ஆசிரியர்களை அனுமதிக்கிறது. இதற்கு Google Workspace for Education Plus தேவை என்று Quizlet கூறுகிறது. அனுமதி வழங்கவோ துணை நிரலைக் கிடைக்கச் செய்யவோ ஆசிரியர்கள் தங்கள் தகவல் தொழில்நுட்ப நிர்வாகியை அணுக வேண்டியிருக்கலாம்.

இந்த இரு செயல்முறைகளில் ஏதேனும் ஒன்று உங்கள் தேவையை நிறைவேற்றினால், அதைப் பயன்படுத்துங்கள். தனிப்பயன் செயலி தேவைப்பட்டால், இந்த ஒருங்கிணைப்புகள் எதுவும் பொது உருவாக்குநர் அணுகலுக்கு மாற்றாகாது.

### தொடர்ச்சியான தானியக்கத்திற்கு, தரவைப் படிக்கவும் எழுதவும் ஆவணப்படுத்தப்பட்ட வழியைத் தேர்ந்தெடுங்கள்

தொடர்ச்சியான தானியக்கத்தில், உங்கள் மென்பொருள் ஒரே வகையான பணிகளை மீண்டும் மீண்டும் நம்பகமாகச் செய்ய வேண்டும்: குறிப்புகளிலிருந்து அட்டைகளை உருவாக்குதல், தொகுப்புகளைப் பட்டியலிடுதல், பதில்களைப் புதுப்பித்தல் அல்லது காலப்போக்கில் ஒரு பணியிடத்தை நிர்வகித்தல் போன்றவை. கிளிப்போர்டுக்கு உரையை ஏற்றுமதி செய்வதால் இதற்கான நிலையான வழிமுறை கிடைக்காது.

வெளிப்புற மென்பொருள் எவ்வாறு அடையாளச் சரிபார்ப்பைச் செய்வது, தரவைப் படிக்கவும் எழுதவும் எந்தச் செயல்கள் ஆதரிக்கப்படுகின்றன என்பதைத் தெளிவாக வெளியிடும் ஃபிளாஷ்கார்டு அமைப்பைப் பயன்படுத்துவது பாதுகாப்பான வழி. தானியக்கப் பணிக்கு Quizlet API-க்கு மாற்றான ஒன்றைத் தேர்ந்தெடுத்து, Quizlet-இன் பொது வசதிகள் ஆதரிக்கும் படிப்புப் பணிகளுக்கு Quizlet-ஐத் தொடர்ந்து பயன்படுத்தலாம்.

## Nibomo வழங்கும் மாற்று API-இல் என்ன கிடைக்கும்?

ஒவ்வொரு பயனருக்கும் உரிய தரவின் ஒரு குறிப்பிட்ட பகுதியை அணுக Nibomo இரண்டு வழிகளை வழங்குகிறது. இரண்டிலும் கிடைப்பது அதே தரவுதான்:

- [வெளிப்புற Agent API](/ta/docs/api/) `GET https://api.nibomo.com/v1/` என்பதில் தொடங்குகிறது. இந்தக் கோரிக்கைக்குக் கிடைக்கும் பதில், மின்னஞ்சல் OTP மூலம் உள்நுழையவும், API விசையை உருவாக்கவும், பணியிடத்தைத் தேர்ந்தெடுக்கவும் ஓர் ஏஜென்ட்டுக்கு வழிகாட்டுகிறது. தரவைப் படிக்க SQL போன்ற வினவல்களை அனுப்பும் வழியும், எழுதுவதற்குத் தனியாகக் கட்டளைகளை இயக்கும் வழியும் உள்ளன.
- [தொலைநிலை MCP சேவையகம்](/ta/docs/mcp-connector/) `https://mcp.nibomo.com/mcp` என்ற முகவரியில் கிடைக்கிறது. MCP கிளையன்ட்களுக்கு எட்டுக் கருவிகள் கிடைக்கின்றன: `list_workspaces`, `sql_query`, `sql_execute`, `get_guide`, மறுபயிற்சிக் கருவிகளான `next_review_card`, `reveal_answer`, `submit_review` ஆகியவை.

எட்டாவது கருவியான `get_usage_limits`, கணக்கின் சந்தாத் திட்டம், வரம்புகள், நடப்பு மாத AI பயன்பாடு ஆகியவற்றைப் படிக்க மட்டுமே உதவும்; இது அட்டைகளைப் படிக்கவோ மாற்றவோ செய்யாது.

இரண்டு வழிகளிலும் அணுகல் தேர்ந்தெடுக்கப்பட்ட பணியிடத்திற்குள் மட்டுமே இருக்கும். கிடைக்கும் தரவு வளங்கள் `workspace`, `cards`, `decks`, `review_events` ஆகியவை. ஒவ்வொரு SQL கட்டளையும் அதிகபட்சம் 100 வரிகளையே திருப்பித் தரும். இந்த இடைமுகம் SQL-இன் வரம்புக்குட்பட்ட ஒரு வடிவத்தைப் பயன்படுத்துகிறது; நேரடி PostgreSQL அணுகலை வழங்குவதில்லை. OpenAPI ஸ்கீமா இல்லை. எனவே OpenAPI-இலிருந்து உருவாக்கப்படும் கிளையன்ட்களைச் சார்ந்த செயல்முறைகளுக்கு வேறொரு இடைமுகம் தேவைப்படும்.

மென்பொருள் உருவாக்குநரோ AI ஏஜென்ட்டோ தங்களுக்குச் சொந்தமான ஃபிளாஷ்கார்டுகளில் செயல்களைத் தானியக்கமாக்க இது உதவும். Quizlet URL-ஐப் படிக்கவோ, Quizlet கணக்கின் பிரதியைப் பராமரிக்கவோ, ஆவணப்படுத்தப்படாத Quizlet கிளையன்ட்டாக இயங்கவோ இதனால் முடியாது. தானியங்கி Quizlet இறக்குமதி வசதி இல்லை. இடமாற்றம் செய்ய, முதலில் உங்கள் சொந்தத் தொகுப்பிலுள்ள சொற்களையும் விளக்கங்களையும் ஏற்றுமதி செய்து, உரையைச் சரிபார்த்து, பின்னர் அதை புதிய அமைப்பின் அட்டைப் புலங்களுக்குப் பொருத்துங்கள். புதிய அமைப்பு தனது சொந்தக் கற்றல் நிலையை உருவாக்கும்; Quizlet வரலாறு அதற்கு மாற்றப்படாது.

API அணுகலைத் தாண்டி இந்தத் தயாரிப்புகள் எவ்வாறு வேறுபடுகின்றன என்பதை அறிய, [Quizlet-க்கு மாற்றான திறந்த மூலச் செயலியின் ஒப்பீட்டைப்](/blog/quizlet-alternative/) பாருங்கள்.
