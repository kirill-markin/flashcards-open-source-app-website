---
title: Как импортировать карточки в Nibomo
description: Перенесите карточки из Quizlet, Anki или другого приложения. Выберите подходящий формат экспорта и проверьте результат перед большим импортом.
---

Откройте [Nibomo](https://app.nibomo.com/?locale=ru), выберите рабочее пространство для карточек и перейдите в **Библиотека > Импорт**. В разделе **Из другого приложения** выберите приложение, из которого переносите карточки. У каждого приложения свой пункт меню, даже если несколько приложений используют один формат.

Перечисленные ниже способы доступны в веб-приложении. Воспользуйтесь им, если на iPhone, iPad, Mac или Android нет нужного меню или пункта. Если вы пользуетесь Nibomo на устройстве как гость, сначала войдите в аккаунт на этом устройстве. Затем войдите в тот же аккаунт Nibomo в веб-приложении и выберите рабочее пространство, в котором должны появиться карточки.

## Выберите источник

| Источник | Что подготовить | Как импортировать |
| --- | --- | --- |
| Quizlet | Скопированный текст экспорта | Вставьте на экране импорта из Quizlet |
| Anki | Колода `.apkg` или коллекция `.colpkg` | Выбрать файлы |
| Noji | `.csv` или `.ofc` | Выбрать файлы |
| Knowt | `.pdf` | Выбрать файлы |
| RemNote | `.apkg`, `.md` или `.txt` | Выбрать файлы |
| Brainscape | `.csv` | Выбрать файлы |
| StudySmarter | `.csv` | Выбрать файлы |
| Cram | `.csv` | Выбрать файлы |
| Mochi | `.mochi` | Выбрать файлы |
| SuperMemo | `.xml` | Выбрать файлы |
| AlgoApp (раньше AnkiApp) | `.zip` или `.xml` | Выбрать файлы |
| Gizmo | `.pdf` | Выберите файл в разделе **Импорт из Gizmo** |
| Другое приложение | `.csv`, `.txt`, `.xlsx`, `.pdf`, `.json`, `.xml`, `.md`, `.docx` или `.zip` | Выберите файлы в разделе **Импорт из другого приложения** |
| Электронная таблица | Скопированные строки с лицевой и обратной стороной каждой карточки | Вставьте строки в разделе **Импорт из таблицы** |
| Nibomo | Файл `flashcards.zip`, экспортированный из Nibomo | Откройте предпросмотр в разделе **Импорт из Nibomo** |

Если в меню отображается прежнее название AlgoApp, ищите **AnkiApp**. Для Anki предусмотрен отдельный пункт.

Старый файл Excel в формате `.xls` сначала сохраните как `.xlsx` или `.csv`. Можно также скопировать столбцы с лицевой и обратной сторонами и [вставить их на экране импорта из таблицы](#вставка-из-таблицы).

## Импорт из другого приложения с карточками

1. Экспортируйте нужные карточки из исходного приложения. В Quizlet откройте свой набор, выберите **Экспорт** и скопируйте текст. Между термином и определением удобно ставить табуляцию, а каждую карточку начинать с новой строки. Экспорт доступен только на сайте Quizlet и только для оригинальных наборов, которые вы создали сами.
2. В Nibomo откройте **Библиотека > Импорт** и выберите пункт нужного приложения. Для Quizlet вставьте скопированный текст. Для остальных источников выберите экспортированные файлы. Если приложения нет в списке, но оно экспортирует файл в поддерживаемом формате, например PDF, выберите **Импорт из другого приложения**.
3. Нажмите **Начать импорт**. Nibomo откроет новый ИИ-чат и отправит запрос на импорт вместе с файлами или вставленным текстом. Для этого нужен интернет. Размер одного файла для импорта через ИИ — до **30 МиБ**. Если файл больше, попробуйте экспортировать небольшие колоды или наборы по отдельности.
4. Проверьте результат в разделе **Библиотека**. ИИ-чат может сохранять карточки партиями. Если он остановится, проверьте, какие карточки уже появились в Nibomo, и попросите чат продолжить с оставшимися, прежде чем повторять импорт целиком.

В Gizmo откройте меню колоды с тремя точками и выберите **Print**, затем в окне печати браузера выберите **Save as PDF**. В Nibomo перейдите в **Библиотека > Импорт** и выберите **Импорт из Gizmo**. Выберите PDF-файл и нажмите **Начать импорт**. Сверьте сохранённые в разделе **Библиотека** карточки с PDF. Проверьте, совпадает ли количество карточек и правильно ли сопоставлены лицевые и обратные стороны.

### Сначала проверьте импорт на небольшом наборе

Сохраните исходный экспорт и начните с небольшой колоды или набора. Сверьте количество карточек, обе стороны нескольких карточек, теги и нужные вам изображения и форматирование. Чтобы увидеть образец до сохранения, прикрепите экспорт в новом ИИ-чате и попросите показать несколько карточек, ничего не сохраняя. Напишите запрос сами вместо нажатия кнопки **Начать импорт**.

Карточки, импортированные через ИИ, появляются в Nibomo как новые. История повторений и запланированные даты остаются в исходном приложении. Перенос структуры, форматирования и медиа зависит от содержимого экспорта и от того, что сможет прочитать ИИ-чат. Проверьте результат, прежде чем пользоваться карточками или удалять что-либо в исходном приложении.

## Вставка из таблицы

Сначала войдите в аккаунт Nibomo. Для простых пар с лицевой и обратной стороной откройте **Библиотека > Импорт > Импорт из таблицы**. Скопируйте два столбца без строки заголовков и вставьте их на экране импорта. Установите **Табуляция** между сторонами карточки и **Новая строка** между карточками. Если в тексте используются другие разделители, измените настройки.

Проверьте предпросмотр, исправьте неполные строки и при необходимости выберите теги. Затем нажмите кнопку импорта, чтобы сохранить карточки. Этот способ работает без ИИ-чата.

## Импорт ZIP из Nibomo

Сначала войдите в аккаунт Nibomo. Чтобы загрузить ранее экспортированный из Nibomo файл `flashcards.zip`, откройте **Библиотека > Импорт > Импорт из Nibomo**. Выберите ZIP-файл без распаковки. В предпросмотре проверьте количество карточек и медиафайлов и обратите внимание на предупреждения, если они есть. Затем подтвердите импорт и проверьте отдельные карточки и медиа в разделе **Библиотека**. Так можно перенести карточки, теги и медиа из пакета. Этот способ работает без ИИ-чата.
