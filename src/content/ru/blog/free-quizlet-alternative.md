Облачная версия [Flashcards](/) во время бета-тестирования стоит $0, а банковская карта для регистрации не нужна. ИИ и синхронизация уже включены. Тариф не устанавливает квот ни на количество карточек и файлов, ни на общий объём хранилища. Поэтому Flashcards можно считать **бесплатной альтернативой Quizlet** для работы с двусторонними карточками. Правда, у слова «бесплатной» здесь есть две оговорки: технические лимиты всё равно действуют, и никто не обещает навсегда оставить бесплатными все функции облачной версии.

Код распространяется по лицензии MIT, поэтому за самостоятельное развёртывание не нужно платить лицензионный сбор. Но работающая продакшен-система всё равно обойдётся в деньги. А если вы пользуетесь режимами Learn и Test, публичными наборами, ИИ-инструментами Quizlet для учёбы или функциями для классов, равноценной замены этим возможностям в Flashcards нет.

## Что бесплатно в облачной бета-версии?

Сейчас можно зарегистрироваться и бесплатно пользоваться основными возможностями для учёбы:

- создавать и редактировать карточки с лицевой и обратной сторонами
- повторять карточки по расписанию планировщика FSRS-6
- сохранять изменения карточек и результаты повторений локально, а затем синхронизировать их между веб-версией, iOS и Android
- прикреплять к карточкам связанные медиафайлы
- пользоваться ИИ-чатом с вложениями файлов
- подключать ИИ-клиенты через MCP
- пользоваться Agent API
- импортировать и экспортировать пакеты рабочих пространств Flashcards

Во время бета-тестирования не нужно переходить на отдельный платный тариф, чтобы разблокировать ИИ или синхронизацию между устройствами. Актуальные условия облачной версии и будущие условия доступа опубликованы на [странице с ценами](/pricing/).

При этом «включено в тариф» не означает «работает без интернета». Изменения карточек и результаты повторений сохраняются локально, а после восстановления подключения синхронизируются. Для запросов к ИИ и самой синхронизации сеть по-прежнему нужна.

## У бесплатного облачного приложения есть технические ограничения

Отсутствие тарифных квот не означает, что технических ограничений нет. У бета-аккаунтов Flashcards нет общего лимита на количество карточек и файлов или занятый объём хранилища. Однако размеры отдельных запросов и операций переноса ограничены.

Текущие ограничения пакета `flashcards.zip`:

| Операция с пакетом | Ограничение |
|---|---:|
| Карточки в одном пакете | 5 000 |
| Медиафайлы в одном пакете | 10 000 |
| Один медиафайл | 16 МиБ |
| Все медиафайлы в одном пакете | 64 МиБ |
| Импортируемый ZIP-файл | 80 МиБ |

Эти лимиты относятся к одной операции импорта или экспорта. Они не ограничивают общее количество карточек и файлов или объём хранилища аккаунта и не скрывают за собой платный тариф. Большое рабочее пространство, возможно, придётся переносить несколькими пакетами. У запросов к ИИ и вложений тоже есть отдельные ограничения на размер запроса и поддерживаемые типы файлов.

## Импорт и экспорт работают не так широко, как может показаться

У Flashcards есть только один собственный формат переноса данных: пакет рабочего пространства `flashcards.zip`.

Приложение умеет импортировать корректный пакет, ранее экспортированный из Flashcards. Наборы Quizlet, CSV, TSV и обычный текст с разделителями оно не принимает. В Quizlet можно [создавать наборы, импортируя текст с разделителями](https://help.quizlet.com/hc/en-us/articles/360029977151-Creating-sets-by-importing-content), а в Flashcards похожего экрана для импорта текста нет.

В пакет входят учебные материалы, которые Flashcards умеет восстановить:

- карточки
- теги карточек
- связанные с карточками медиафайлы

Но связанное с ними состояние не переносится:

- история повторений
- состояние планировщика FSRS
- настройки рабочего пространства
- полная структура колод
- данные учётной записи

`flashcards.zip` позволяет переносить выбранные учебные материалы между облачными и самостоятельно развёрнутыми рабочими пространствами Flashcards. Пакет не воссоздаёт учётную запись и не продолжает прежнее расписание повторений. Для аварийного восстановления он тоже не подходит: при самостоятельном размещении всё равно нужны резервные копии базы данных и медиафайлов.

### Существующие наборы Quizlet придётся собирать заново

На сайте Quizlet авторы могут [экспортировать термины и определения из собственных наборов](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets). Скопированные наборы и изображения экспортировать нельзя.

На выходе получается текст, а не пакет, который принимает Flashcards. Нужные карточки можно воссоздать вручную или передать текст ИИ-чату Flashcards как исходный материал для черновиков двусторонних карточек. В обоих случаях новые карточки придётся проверить и сохранить. Прямого импорта ни один из этих способов не даёт.

В [руководстве по экспорту из Quizlet](/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/) описано, как очистить экспортированные данные. Перенести всё без потерь не получится: экспорт не содержит изображений и состояния обучения, а Flashcards не принимает такой текст в качестве собственного формата переноса.

## Лицензия для самостоятельного развёртывания бесплатна, инфраструктура — нет

Код Flashcards распространяется по лицензии MIT. Его можно изучать, менять и развёртывать без покупки лицензии на программу. Но серверы для продакшена и работа по их обслуживанию оплачиваются отдельно.

Поддерживаемый способ продакшен-развёртывания — стек AWS CDK из репозитория. Конфигурация с Docker и PostgreSQL предназначена для локальной разработки и не является коротким документированным путём к запуску в продакшене.

При самостоятельном размещении нужно оплачивать и обслуживать:

- базу данных, хранилище, вычислительные и сетевые сервисы AWS
- домен и настройку DNS
- доставку электронной почты
- мониторинг и оповещения
- использование ИИ-провайдера при необходимости и учётные данные для доступа к нему
- управление секретами
- резервные копии базы данных и медиафайлов, включая проверку восстановления
- обновления, миграции, безопасность и время специалиста, который обслуживает систему

Стек автоматизирует часть развёртывания, но не избавляет от этих задач. Одной полезной для всех оценки ежемесячных расходов не существует: итоговая сумма зависит от региона, трафика, объёма хранилища, политики резервного копирования, объёма почтовых отправлений, использования ИИ и решений владельца системы. В [руководстве по самостоятельному развёртыванию](/docs/self-hosting/) описаны архитектура AWS и назначение варианта для локальной разработки.

Самостоятельное развёртывание просто переносит оплату и обслуживание стека на вас. Облачная инфраструктура от этого не становится бесплатной. Если контроль над ней вам не нужен, бесплатная облачная бета-версия избавляет от забот об эксплуатации.

## Важные функции Quizlet, у которых нет аналогов

Сейчас во Flashcards нет прямых аналогов четырёх возможностей Quizlet, которые могут оказаться важнее цены:

- отдельные режимы Learn и Test, включая автоматически создаваемые задания с вариантами ответа
- сопоставимая библиотека публичных учебных наборов
- ИИ-инструменты Quizlet для учёбы: Study Guides, Practice Tests и Ask Quizlet
- экосистема для преподавателей и классов: Quizlet Live, классы и отчёты об успеваемости

В обзоре Quizlet описаны [Learn, Test, Practice Tests, Study Guides и Quizlet Live](https://help.quizlet.com/hc/en-us/articles/360030841732-Studying-on-Quizlet). У бесплатного доступа к Quizlet тоже есть ограничения: без подписки доступно ограниченное число раундов Learn и один пробный тест в режиме Test для каждого набора. Ученики классов, отвечающих требованиям Quizlet и управляемых преподавателем, могут получить [неограниченный доступ без рекламы к режимам Learn и Test для наборов класса](https://help.quizlet.com/hc/en-us/articles/34270983035149-Free-student-access-to-Learn-and-Test-modes).

Если ваш учебный процесс строится вокруг готовых режимов, публичных материалов или функций для классов, аккаунт Flashcards за $0 их не заменит. Бесплатная бета-версия рассчитана на другой сценарий: двусторонние карточки, повторения по FSRS-6, локальное сохранение с последующей синхронизацией, медиафайлы, ИИ-чат и доступ для агентов.

## Честный ответ о бесплатной альтернативе Quizlet

Во время бета-тестирования Flashcards — **бесплатная альтернатива Quizlet** для двусторонних карточек, повторений по FSRS-6, офлайн-работы в веб-версии и мобильных приложениях, синхронизации, медиафайлов и помощи ИИ. Банковская карта не нужна, а тариф не ограничивает количество карточек и файлов или общий объём хранилища. При этом лимиты на отдельные пакеты и запросы всё равно действуют.

Flashcards не заменяет один в один режимы Learn и Test, библиотеку публичных наборов, учебные форматы с ИИ или систему Quizlet для классов. Существующие материалы Quizlet тоже придётся воссоздавать из доступного для экспорта текста: прямого импорта нет.

Эти расходы лучше не смешивать. Сегодня облачная бета-версия стоит $0. Основные функции создания и повторения карточек останутся бесплатными, а для более интенсивного использования ИИ в будущем может понадобиться собственный API-ключ провайдера или платная опция. При самостоятельном развёртывании нет лицензионного сбора за программу, зато вы платите за инфраструктуру, сторонние сервисы, обслуживание и время специалиста. Если такие условия вам подходят, [откройте Flashcards](https://app.flashcards-open-source-app.com/) и попробуйте облачную версию.
