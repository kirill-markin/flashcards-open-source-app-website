По состоянию на 18 августа 2026 года Quizlet не документирует публичный API для разработчиков с открытой регистрацией и не предоставляет публичный портал для разработчиков. Сейчас независимый разработчик не может официально зарегистрировать приложение, получить ключ API Quizlet и использовать документированные эндпоинты для чтения или записи данных карточек.

Это вывод только о публичной документации Quizlet, а не утверждение о внутренних системах компании. У Quizlet явно есть продуктовые и партнёрские интеграции — например, приложение для ChatGPT и дополнение для Google Classroom. Но ни одна из них не открывает другим приложениям доступ к универсальному API Quizlet для разработчиков.

**Факты проверены:** 18 августа 2026 года.

> **Раскрытие интересов:** меня зовут Кирилл Маркин, и я разрабатываю Flashcards Open Source App. Ниже его Agent API и MCP-сервер представлены как альтернативы. Flashcards не совместим с Quizlet и не импортирует наборы Quizlet автоматически.

## Короткий ответ: документированного публичного API Quizlet нет

Если вы искали «есть ли у Quizlet API?», потому что хотите автоматизировать работу самого Quizlet, практический ответ сейчас такой: **публичного API с открытой регистрацией в документации нет**.

Некоторые официальные функции со стороны похожи на API, но решают гораздо более узкие задачи:

| Что вам нужно | Поддерживаемый способ | Для чего подходит | Чего этот способ не даёт |
|---|---|---|---|
| Перенести текст из созданного вами набора | [Экспорт на сайте Quizlet](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets) | Однократно скопировать термины и определения | Изображения, экспорт скопированного набора, историю занятий или доступ к API |
| Разместить публичный набор на сайте или странице LMS | [Встраивание Quizlet](https://help.quizlet.com/hc/en-us/articles/360032935851-Embedding-sets) | Добавить на свою страницу учебное задание с брендом Quizlet | Структурированные данные карточек или доступ на чтение и запись |
| Превратить разговор в ChatGPT в набор Quizlet | [Приложение Quizlet в ChatGPT](https://quizlet.com/blog/quizlet-comes-to-chat-gpt) | Создать и предварительно просмотреть набор через `@Quizlet` | Учётные данные или эндпоинты для вашего приложения |
| Назначить работу в Quizlet через Google Classroom | [Дополнение Quizlet для Google Classroom](https://quizlet.com/blog/quizlet-google-classroom-add-on) | Находить, назначать и отслеживать задания в Classroom | Универсальный API для собственного образовательного ПО |
| Создать собственную интеграцию с Quizlet | Открытый способ получить доступ сейчас не документирован | Возможно, существует договорённость с конкретным партнёром | Публичную регистрацию, ключи API или документированный контракт для работы с карточками |
| Автоматизировать собственное рабочее пространство с карточками | [Flashcards Agent API](/docs/api/) или [MCP-коннектор](/docs/mcp-connector/) | Многократно читать и записывать карточки и колоды в пределах рабочего пространства | Совместимость с Quizlet или автоматический импорт из Quizlet |

Разница простая. Один раз скопировать текст собственных карточек — задача для экспорта. Показать Quizlet на другой странице — задача для встраивания. Именованная интеграция работает только внутри предусмотренного для неё сценария. А программе, которая регулярно создаёт, читает и редактирует карточки, нужен документированный API с доступом на чтение и запись.

## Экспорт, встраивание и партнёрский доступ — не публичные API

Публичный API даёт сторонним разработчикам понятный контракт: документацию, аутентификацию, список поддерживаемых операций, правила использования и способ получить учётные данные. Ни один из нынешних публичных интерфейсов Quizlet не предлагает весь этот путь через открытую регистрацию.

**Экспорт** Quizlet — это ручной перенос. Автор набора может открыть его на сайте, настроить расположение терминов и определений, выбрать **Copy text** и вставить результат в другое место. Quizlet сообщает, что изображения экспортировать нельзя, скопированные наборы не подлежат экспорту, а сама функция доступна только на сайте. Такой способ подходит для аккуратного разового переноса. Он не позволяет программе поддерживать синхронизацию между двумя системами.

**Встраивание** показывает материал, но не даёт доступа к данным. Quizlet позволяет скопировать HTML публичного набора в режиме Match, Learn, Test, Flashcards или Spell. Во встроенном задании сохраняется логотип Quizlet, а учащиеся работают с интерфейсом Quizlet. Ваше приложение при этом не получает набор в виде отдельных записей карточек, которые можно редактировать.

**Именованная интеграция** работает по отдельно согласованному продуктовому сценарию. Quizlet может интегрироваться с ChatGPT или Google Classroom, не предоставляя тот же интерфейс каждому разработчику. Эти примеры подтверждают существование конкретных интеграций, но не публичного API Quizlet для общего использования.

По той же причине старая библиотека-обёртка или запрос из инструментов разработчика в браузере не становятся поддерживаемым API Quizlet. Для этого нужны публичная документация и стабильный контракт для разработчиков.

## Выберите способ под свою задачу

### Для разовой резервной копии или миграции используйте экспорт

Используйте официальный экспорт Quizlet для созданного вами набора. Поскольку в конце этого процесса нужно выбрать **Copy text**, сохраните первую вставленную копию без изменений и только потом очищайте разделители или сопоставляйте поля. Так вы сохраняете термины и определения, а не скачиваете пакет колоды, пригодный для восстановления. Изображения и история занятий остаются в Quizlet.

Практический чек-лист есть в статье [Как экспортировать наборы Quizlet в 2026 году](/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/). В ней разобраны исходная и рабочая копии, UTF-8, табуляция, многострочные определения и разница между переносом содержимого карточек и переносом состояния планировщика.

Экспорт подходит для конечного разового переноса. Для ежедневного создания, синхронизации или регулярного редактирования из программы он не подходит.

### Для показа материала используйте официальное встраивание

Если учащиеся должны заниматься с публичным набором Quizlet на сайте класса или странице LMS, используйте код встраивания, который Quizlet предоставляет на своём сайте. Выберите задание, нажмите **Copy HTML** и добавьте результат на страницу. Учащиеся получат интерактивное задание Quizlet, а сайт, на котором оно размещено, не получит необработанный поток данных карточек.

Часто преподавателю нужно именно это. Если называть такое решение API, требование лишь звучит сложнее, чем оно есть на самом деле.

### Для ChatGPT или Google Classroom используйте отдельную интеграцию

В объявлении Quizlet от 10 марта 2026 года о ChatGPT описан конкретный сценарий: подключите приложение Quizlet, начните промпт с `@Quizlet`, просмотрите созданный набор в ChatGPT, а затем откройте его в Quizlet, чтобы персонализировать и изучать. Это поддерживаемый способ создать набор Quizlet из этого разговора. Он не выдаёт вашему боту, скрипту или сайту многократно используемые учётные данные Quizlet API.

Объявление Quizlet от 30 июня 2026 года о Google Classroom настолько же конкретно. Дополнение позволяет преподавателям находить и назначать задания, включая тренировочные вопросы, карточки и игры, а затем отслеживать вовлечённость и прогресс в процессе работы с Classroom. По информации Quizlet, для него требуется Google Workspace for Education Plus; преподавателям может понадобиться разрешение IT-администратора или его помощь в предоставлении дополнения.

Если один из этих отдельных сценариев уже соответствует вашей цели, используйте его. Если вам нужно собственное приложение, ни одна из интеграций не заменяет публичный доступ для разработчиков.

### Для регулярной автоматизации выберите документированный интерфейс на чтение и запись

Регулярная автоматизация означает, что программа должна надёжно выполнять одну и ту же работу больше одного раза: создавать карточки из заметок, выводить список колод, обновлять ответы или со временем управлять рабочим пространством. Экспорт через буфер обмена не может дать такой контракт.

Безопасный путь — выбрать систему карточек, которая прямо документирует, как внешние программы проходят аутентификацию и какие операции чтения и записи она поддерживает. Для автоматизированного процесса это может означать переход на альтернативу API Quizlet, при этом Quizlet можно оставить для учебных задач, которые поддерживает его общедоступный продукт.

## Что на самом деле предлагает Flashcards как альтернатива API Quizlet

Flashcards Open Source App публикует два способа доступа к одному и тому же ограниченному набору пользовательских данных:

- [Внешний Agent API](/docs/api/) начинается с `GET https://api.flashcards-open-source-app.com/v1/`. Его discovery-ответ проводит агента через вход по email с одноразовым кодом (OTP), создание API-ключа и выбор рабочего пространства. Для чтения используется маршрут запросов в стиле SQL, для записи — отдельный маршрут выполнения.
- [Удалённый MCP-сервер](/docs/mcp-connector/) доступен по адресу `https://mcp.flashcards-open-source-app.com/mcp`. MCP-клиенты получают три инструмента: `list_workspaces`, `sql_query` и `sql_execute`.

Оба способа ограничены рабочим пространством. Опубликованные ресурсы — `workspace`, `cards`, `decks` и `review_events`, а результат каждого SQL-выражения ограничен 100 строками. Интерфейс в стиле SQL использует ограниченный диалект, а не даёт прямой доступ к PostgreSQL. Схемы OpenAPI нет, поэтому для процессов, которым нужны сгенерированные OpenAPI-клиенты, потребуется другой интерфейс.

Так разработчик или ИИ-агент может автоматизировать собственные карточки. Этот интерфейс не умеет читать URL Quizlet, зеркалировать аккаунт Quizlet или работать как недокументированный клиент Quizlet. Автоматического импортера из Quizlet нет. Для миграции сначала экспортируйте термины и определения из собственного набора, проверьте текст, а затем сопоставьте его с полями карточек в целевой системе. В целевой системе будет создано собственное состояние обучения; история из Quizlet не переносится.

О различиях между продуктами помимо доступа к API читайте в [сравнении альтернативы Quizlet с открытым исходным кодом](/blog/quizlet-alternative/).

## Внутренние запросы браузера — небезопасный обходной путь

Веб-интерфейс Quizlet отправляет сетевые запросы, как и любое современное веб-приложение. Но запрос, найденный в инструментах разработчика, не становится от этого поддерживаемым эндпоинтом для вашей программы.

Приватные браузерные эндпоинты могут зависеть от сессионных cookie, внутренних форматов, механизмов защиты от злоупотреблений и предположений, привязанных к текущему интерфейсу. Они могут измениться без публичного версионирования или инструкций по миграции. Более того, [Условия использования Quizlet](https://quizlet.com/tos), последнее обновление которых датировано 28 мая 2026 года, запрещают скрейпинг и другие способы автоматизированного извлечения данных, а также неразрешённое автоматизированное использование сервиса.

Это хрупкая и рискованная основа даже для личного скрипта, не говоря уже о продукте. Я не буду приводить здесь предполагаемые эндпоинты или инструкции по обратному проектированию.

Для разового переноса собственного набора используйте экспорт. Встройте публичный набор, если он нужен учащимся на другой странице. Для конкретных сценариев ChatGPT или Google Classroom используйте соответствующую отдельную интеграцию. Для регулярного чтения и записи выберите программу, которая документирует контракт автоматизации, — или оставьте работу с Quizlet ручной, пока сам Quizlet не опубликует такой контракт.

## Как понять, что статус изменился

Quizlet может запустить программу для разработчиков после даты проверки фактов для этой статьи. Ищите официальный портал для разработчиков или документацию, где объясняется, кто может зарегистрироваться, как работает аутентификация, какие операции с карточками поддерживаются и какие действуют правила использования.

Ещё одна сторонняя обёртка ответа не изменит. Новая интеграция с конкретным партнёром — тоже. Пока Quizlet не документирует открытый доступ для разработчиков, осторожно относитесь к заявлениям о существовании актуального Quizlet API и выбирайте официально поддерживаемый способ под свою задачу.
