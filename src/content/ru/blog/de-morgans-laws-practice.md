Число 3 входит в промежуток `3 ≤ x < 8`, а число 8 уже за его пределами. В отрицании всё наоборот. **Отрицание `3 ≤ x < 8` записывается как `x < 3 ∨ x ≥ 8`.** На самих границах удобно проверить знаки сравнения. Чтобы проверить связку «или», пригодится ещё одно число.

## Что меняют законы де Моргана

Когда знак отрицания `¬` стоит перед скобками, найдите главную связку внутри них. Поменяйте «и» на «или» или «или» на «и» и отрицайте каждую часть целиком. [Законы де Моргана в учебнике OpenStax](https://openstax.org/books/contemporary-mathematics/pages/2-6-de-morgans-laws).

| Что отрицаем | Равносильная запись | Когда отрицание истинно |
| --- | --- | --- |
| Конъюнкцию («и») | `¬(p ∧ q) ≡ ¬p ∨ ¬q` | Хотя бы одна из исходных частей ложна |
| Дизъюнкцию («или») | `¬(p ∨ q) ≡ ¬p ∧ ¬q` | Обе исходные части ложны |

Знак `≡` означает, что формулы слева и справа дают одинаковый результат при любых значениях истинности `p` и `q`. Символ `∨` означает нестрогое «или». Подходит и случай, когда обе части истинны. Например, «6 делится на 2 или на 3» истинно, потому что 6 делится на оба числа. [Таблицы истинности для И, ИЛИ и НЕ](/ru/blog/truth-values-conjunction-disjunction/).

## Как отрицать условие `3 ≤ x < 8`

Пусть `x` — действительное число. Запись `3 ≤ x < 8` означает, что **одновременно** выполнены условия `x ≥ 3` и `x < 8`. Чтобы число оказалось вне промежутка, достаточно нарушения одного из этих условий. Отсюда по закону де Моргана получаем `¬(x ≥ 3) ∨ ¬(x < 8)`.

Осталось отрицать сами сравнения. Каждое новое сравнение должно быть истинно ровно для тех чисел, при которых исходное ложно. Когда `x ≥ 3` ложно, верно `x < 3`. Когда `x < 8` ложно, верно `x ≥ 8`. Получается `x < 3 ∨ x ≥ 8`.

## Какие числа подставить для проверки

Подставьте одно и то же число в исходное условие и в предполагаемое отрицание. Если оба дают истину или оба дают ложь, вы нашли контрпример. Для проверки `3 ≤ x < 8` возьмём три числа.

1. **Левая граница, `x = 3`.** Если получилось `x ≤ 3 ∨ x ≥ 8`, правая часть ложна и всё решает левая. Сравнение `3 ≤ 3` истинно. Исходное условие при этом тоже истинно, поэтому в ответе нужен строгий знак `<`.
2. **Правая граница, `x = 8`.** В записи `x < 3 ∨ x > 8` оба сравнения ложны. Исходное условие при 8 тоже ложно, поэтому правое сравнение должно включать равенство, `x ≥ 8`.
3. **Вне промежутка, `x = 2`.** Запись `x < 3 ∧ x ≥ 8` при 2 ложна, как и исходное условие. Сравнение `2 < 3` истинно, а `2 ≥ 8` ложно. Для «или» одной истинной части достаточно, а «и» требует обеих.

Если сомневаетесь в связке, ищите число, при котором одно сравнение истинно, а другое ложно. Если сомневаетесь, включать ли равенство, берите саму границу. Для «или» выбирайте границу, на которой второе сравнение ложно. Для «и» нужна граница, на которой второе сравнение истинно. Тогда результат определяет сравнение, которое вы проверяете.

## Когда в условии есть и «и», и «или»

Добавим к двойному неравенству ещё одну часть. Возьмём условие `(x > 10) ∨ ((x ≥ 3) ∧ (x < 8))`. Две части соединяет внешняя связка «или». В правой части сравнения соединены связкой «и». Применяем законы по очереди, начиная с внешней связки.

1. Отрицаем обе части внешнего «или» и получаем `¬(x > 10) ∧ ¬((x ≥ 3) ∧ (x < 8))`.
2. Раскрываем оставшееся отрицание и записываем сравнения. Получается `(x ≤ 10) ∧ ((x < 3) ∨ (x ≥ 8))`.

При `x = 11` исходное условие истинно за счёт `x > 10`. В правильном отрицании условие `x ≤ 10` ложно, поэтому весь результат ложен. Если убрать внутренние скобки, по обычному приоритету `∧` перед `∨` получится `((x ≤ 10) ∧ (x < 3)) ∨ (x ≥ 8)`. Правая часть `x ≥ 8` уже сама даёт истину. Число 11 выявляет ошибку в скобках.

## Задача на связку и границу

Для действительного `x` дано условие `(x ≤ −2) ∨ (x > 4)`.

1. Запишите отрицание, оставив в нём только сравнения и одну связку.
2. Проверьте запись `x > −2 ∨ x ≤ 4`. Подберите число, отличное от `−2` и `4`, которое выявит ошибку в связке.
3. Какое число покажет ошибку в записи `x ≥ −2 ∧ x ≤ 4`?

### Ответы

1. `(x > −2) ∧ (x ≤ 4)`. Отрицание дизъюнкции истинно, когда обе исходные части ложны.
2. Подходит `x = 5`. Исходное условие истинно, потому что `5 > 4`. Ошибочное отрицание тоже истинно, потому что `5 > −2`. В правильной записи сравнение `5 ≤ 4` ложно, поэтому «и» даёт ложь.
3. Подходит `x = −2`. Исходное условие и оба сравнения в ошибочной записи истинны. В правильной записи сравнение `−2 > −2` ложно, поэтому всё отрицание ложно.

## Задача на завтра

Попробуйте решить обратную задачу по памяти. Восстановите исходное двойное неравенство по его отрицанию `x ≤ 1 ∨ x > 6` и проверьте ответ при `x = 1` и `x = 6`.

Ответ для самопроверки — `1 < x ≤ 6`. При `x = 1` исходное условие ложно, а при `x = 6` истинно.
