Alaska is AK, Alabama is AL en Arkansas is AR. De eerste twee letters van de naam van een staat leveren niet altijd de postale afkorting op. Even opzoeken kan dus handig zijn.

Wil je iets opzoeken, zoek de staat dan in de alfabetische tabel hieronder. Wil je oefenen, dek dan de kolom met codes af en probeer zelf elk antwoord te geven. Wissel daarna van kolom. Een combinatie op de pagina herkennen en die uit je geheugen ophalen zijn verschillende vaardigheden.

De volledige tabel en de antwoorden op de quiz staan hieronder.

Schrijf elke code met twee hoofdletters, zonder punten. De tabel volgt de alfabetische volgorde van de Engelse namen van de staten. Een afkorting van een staat staat los van een ZIP Code, de Amerikaanse postcode. In een adres geeft de tweelettercode de staat aan; de ZIP Code is het cijfergedeelte dat erop volgt. Heeft een formulier aparte velden voor de staat en de ZIP Code, vul ze dan elk in het juiste veld in.

Washington, DC gebruikt **DC** en Puerto Rico gebruikt **PR**. Ze hebben postale afkortingen, maar horen geen van beide thuis in een tabel met de 50 staten. De bijlage van USPS bevat ook territoria en andere postbestemmingen. Gebruik de [volledige USPS-lijst](https://pe.usps.com/text/pub28/28apb.htm) als je die nodig hebt.

## Begin met de codes die je door elkaar haalt

Een alfabetische lijst is handig om een antwoord te vinden, maar de omliggende rijen geven ook aanwijzingen. Vergelijk eerst de namen die je verwart. Meng ze daarna met andere staten om te controleren of je elk antwoord ook zonder die aanwijzingen kunt oproepen.

![Op elkaar lijkende sleutels worden over aparte vakjes van een klein bakje verdeeld](/blog/us-state-abbreviations.png)

### Alaska, Alabama, Arkansas, Arizona

Bekijk deze vier eerst samen:

- **Alaska → AK:** let op de K in Alaska.
- **Alabama → AL:** hier werken de eerste twee letters.
- **Arkansas → AR:** ook hier de eerste twee letters.
- **Arizona → AZ:** let op de Z in Arizona.

Gebruik deze observaties als geheugensteuntjes. Dek de groep na het bekijken af en beantwoord de vraag: “Bij welke staat hoort AK?” Probeer daarna: “Wat is de code van Arkansas?” Controleer ook de omgekeerde vragen: van Alaska naar AK en van AR naar Arkansas. Misschien gaat de ene richting je makkelijker af.

### De acht staten die met een M beginnen

Michigan, Minnesota, Mississippi en Missouri beginnen allemaal met “Mi”. Alleen Michigan gebruikt MI. Leer de volledige combinaties in plaats van elke naam volgens dezelfde regel te proberen af te korten.

| Staat | Code | Waar je op kunt letten |
| --- | --- | --- |
| Michigan | MI | Gebruikt de eerste twee letters, MI |
| Minnesota | MN | De tweede letter van de code is N |
| Mississippi | MS | De tweede letter van de code is S |
| Missouri | MO | De tweede letter van de code is O |
| Massachusetts | MA | Gebruikt de eerste twee letters, MA |
| Maryland | MD | Begint met M en eindigt op D |
| Maine | ME | Begint met M en eindigt op E |
| Montana | MT | Bevat de T uit Montana |

Antwoord je “Missouri” als je MS ziet, noteer dan precies die verwarring: **MS = Mississippi; MO = Missouri**. Door die twee combinaties te herhalen, oefen je een concreet onderscheid. Als je alle acht namen opnieuw leest, kan het onduidelijk blijven welke naam het probleem veroorzaakte.

### Iowa, Idaho, Illinois, Indiana

Idaho is ID, Illinois is IL en Indiana is IN. Iowa is **IA**, met de eerste en de laatste letter van de naam. Oefen IA apart als je steeds IO gokt en voeg die combinatie daarna weer aan de groep toe.

### De staat Washington en Washington, DC

**WA staat voor de staat Washington. DC staat voor het District of Columbia.** Zet op je eigen kaarten “de staat Washington”, zodat de vraag eenduidig is. Een kaart met alleen “Afkorting Washington?” laat onnodig veel ruimte voor interpretatie.

## Bepaal wat je uit je hoofd moet kennen

Bij een aardrijkskundeopdracht kunnen verschillende vaardigheden aan bod komen. Stem je oefeningen af op de vragen die je daadwerkelijk krijgt.

| Taak | Voorbeeldvraag | Verwacht antwoord |
| --- | --- | --- |
| Van staat naar code | Wat is de USPS-afkorting van Minnesota? | MN |
| Van code naar staat | Welke staat gebruikt MN? | Minnesota |
| Locatie op de kaart | Benoem een gemarkeerde staat op een blinde kaart | De naam van de staat |

De tabel geeft de antwoorden voor de eerste twee taken. Gebruik voor een kaarttoets een blinde kaart met een antwoordenblad en oefen het herkennen van staten aan hun ligging. Hoofdsteden hebben ook eigen vragen nodig, zoals “Wat is de hoofdstad van Minnesota?” Houd die kaarten gescheiden van vragen over afkortingen, zodat elk antwoord laat zien welk feit je hebt onthouden. De aparte [kaartenset met Amerikaanse staten en hun hoofdsteden](/nl/catalog/packages/us-states-and-capitals/) bevat daarvoor Engelstalige kaarten.

## Een korte quiz over de afkortingen

Zorg dat je de tabel niet kunt zien. Schrijf alle 12 antwoorden op voordat je naar de antwoorden scrolt. Er zijn geen antwoordopties die je op weg helpen: geef precies de gevraagde tweelettercode of de volledige naam van de staat.

1. Wat is de code van Alaska?
2. Welke staat gebruikt MO?
3. Wat is de code van Iowa?
4. Welke staat gebruikt MD?
5. Wat is de code van Arkansas?
6. Welke staat gebruikt MN?
7. Wat is de code van de staat Washington?
8. Welke staat gebruikt ME?
9. Wat is de code van Mississippi?
10. Welke staat gebruikt AZ?
11. Wat is de code van Michigan?
12. Welke staat gebruikt AL?

Markeer voordat je nakijkt elk antwoord dat je hebt gegokt of waarover je lang moest nadenken. Laat die markeringen staan, ook als de antwoorden goed blijken te zijn. Ze helpen je kiezen wat je hierna gaat oefenen.

### Antwoorden

Tel één punt per exact goed antwoord, met een maximum van 12 punten. Bekijk daarna de fouten: haalde je twee staten door elkaar, bedacht je een code zoals IO, of kende je een combinatie maar in één richting? Dat laat zien wat je moet oefenen. Zelfs 12 van de 12 zegt alleen iets over deze selectie. Voor een volledige controle heb je alle 50 staten nodig, in beide richtingen als je die voor je opdracht allebei moet kennen.

Maak voor elke combinatie die je fout had of waarover je twijfelde twee korte leerkaarten. Bijvoorbeeld:

Haalde je MO en MS door elkaar, voeg dan ook twee kaarten voor Mississippi toe. Houd het bij één antwoord per kaart en zet andere vragen tussen de twee richtingen.
