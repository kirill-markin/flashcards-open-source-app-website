18 ऑगस्ट 2026 पर्यंत Quizlet ने स्वतः नोंदणी करून वापरता येणाऱ्या सार्वजनिक डेव्हलपर API चे दस्तऐवज किंवा सार्वजनिक डेव्हलपर पोर्टल उपलब्ध केलेले नाही. स्वतंत्र डेव्हलपरला ॲपची नोंदणी करून Quizlet API की मिळवणे आणि अधिकृत दस्तऐवजांत दिलेल्या एंडपॉइंट्सद्वारे फ्लॅशकार्ड्सचा डेटा वाचणे किंवा लिहिणे यासाठी सध्या अधिकृत मार्ग नाही.

हा निष्कर्ष Quizlet च्या सार्वजनिक दस्तऐवजांपुरता आहे; त्याच्या अंतर्गत प्रणालींबद्दलचा दावा नाही. इतर उत्पादने आणि भागीदारांसोबत Quizlet ची जोडणी उपलब्ध आहे. त्याचे ChatGPT ॲप आणि Google Classroom ॲड-ऑन ही सध्याची दोन उदाहरणे आहेत. मात्र या जोडण्यांमुळे इतर ॲप्लिकेशन्सना सर्वसाधारण वापरासाठी Quizlet डेव्हलपर API मिळत नाही.

**तथ्यांची पडताळणी:** 18 ऑगस्ट 2026.

> **हितसंबंधांची नोंद:** मी Kirill Markin आहे आणि Nibomo विकसित करतो. त्याचे Agent API आणि MCP सर्व्हर खाली पर्याय म्हणून दिले आहेत. Nibomo हे Quizlet-सुसंगत नाही आणि ते Quizlet संच आपोआप इम्पोर्ट करत नाही.

## थोडक्यात: स्वतः नोंदणी करून वापरता येणाऱ्या Quizlet API चे दस्तऐवज नाहीत

Quizlet मध्येच कामे स्वयंचलित करायची म्हणून तुम्ही “Quizlet चे API आहे का?” असा शोध घेतला असेल, तर सध्याचे व्यावहारिक उत्तर असे आहे: **स्वतः नोंदणी करून वापरता येणाऱ्या सार्वजनिक API चे अधिकृत दस्तऐवज उपलब्ध नाहीत**.

काही अधिकृत सुविधा पाहून API उपलब्ध असल्याचा भास होऊ शकतो. प्रत्यक्षात त्या ठरावीक कामांपुरत्या मर्यादित आहेत:

|---|---|---|---|
| तुम्ही तयार केलेल्या संचातील मजकूर दुसरीकडे न्यायचा आहे | [Quizlet वेबसाइटवरील एक्सपोर्ट](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets) | संज्ञा आणि व्याख्यांची एकदाच प्रत काढणे | प्रतिमा, कॉपी केलेल्या संचाचा एक्सपोर्ट, अभ्यासाचा इतिहास किंवा API प्रवेश |

| स्वतःची Quizlet जोडणी तयार करायची आहे | स्वतः नोंदणी करून प्रवेश मिळवण्याचा मार्ग सध्या अधिकृत दस्तऐवजांत दिलेला नाही | एखाद्या विशिष्ट भागीदाराशी करार असू शकतो | सार्वजनिक नोंदणी, API की किंवा कार्डांसाठी अधिकृत दस्तऐवजांत निश्चित केलेला इंटरफेस |
| स्वतःच्या फ्लॅशकार्ड वर्कस्पेसमधील कामे स्वयंचलित करायची आहेत | [Nibomo Agent API](/mr/docs/api/) किंवा [MCP कनेक्टर](/mr/docs/mcp-connector/) | ठरावीक वर्कस्पेसमधील कार्डे आणि डेक वारंवार वाचणे आणि बदलणे | Quizlet शी सुसंगतता किंवा Quizlet संचांचे स्वयंचलित इम्पोर्ट |

फरक सोपा आहे: स्वतःच्या कार्डांवरील मजकूर एकदाच कॉपी करणे हे एक्सपोर्टचे काम आहे. दुसऱ्या पानावर Quizlet दाखवणे हे एम्बेडचे काम आहे. एखाद्या विशिष्ट उत्पादनाशी असलेली जोडणी फक्त त्याच उत्पादनाच्या प्रक्रियेत चालते. कार्डे वारंवार तयार करणाऱ्या, वाचणाऱ्या आणि बदलणाऱ्या सॉफ्टवेअरला अधिकृत दस्तऐवज असलेले वाचन आणि लेखन API हवे असते.

## एक्सपोर्ट, एम्बेड आणि भागीदारांचा प्रवेश म्हणजे सार्वजनिक API नाही

सार्वजनिक API बाहेरील डेव्हलपर्ससाठी वापराची स्पष्ट चौकट देते: दस्तऐवज, प्रमाणीकरण, उपलब्ध क्रिया, वापराचे नियम आणि प्रवेशाची क्रेडेन्शियल्स मिळवण्याचा मार्ग. Quizlet च्या सध्या सार्वजनिकपणे उपलब्ध असलेल्या कोणत्याही सुविधेत स्वतः नोंदणी करून वापर सुरू करण्याची ही संपूर्ण प्रक्रिया मिळत नाही.

Quizlet चा **एक्सपोर्ट** वापरताना मजकूर स्वतः कॉपी करून दुसरीकडे न्यावा लागतो. संच तयार करणारी व्यक्ती वेबसाइटवर त्यातील संज्ञा आणि व्याख्यांची मांडणी ठरवू शकते, **मजकूर कॉपी करा (Copy text)** निवडू शकते आणि मिळालेला मजकूर दुसरीकडे पेस्ट करू शकते. Quizlet नुसार प्रतिमा एक्सपोर्ट करता येत नाहीत, कॉपी केलेले संच एक्सपोर्ट करता येत नाहीत आणि ही सुविधा फक्त वेबसाइटवर उपलब्ध आहे. एकदाच काळजीपूर्वक डेटा हलवायचा असेल, तर हा मार्ग उपयोगी पडतो. मात्र याच्या मदतीने सॉफ्टवेअरला दोन प्रणालींमधील डेटा सतत जुळता ठेवता येत नाही.

**एम्बेड** म्हणजे सामग्री दाखवण्याची सोय; त्यातून मूळ डेटा मिळत नाही. Quizlet सार्वजनिक संचासाठी जोड्या जुळवणे (Match), शिकणे (Learn), चाचणी (Test), फ्लॅशकार्ड्स (Flashcards) किंवा स्पेलिंग (Spell) मोडमधील HTML कॉपी करू देते. एम्बेड केलेल्या उपक्रमात Quizlet चा लोगो कायम राहतो आणि विद्यार्थी Quizlet चाच इंटरफेस वापरतात. तुमच्या ॲप्लिकेशनला त्या संचातील कार्डे संपादित करता येतील अशा डेटा नोंदी म्हणून मिळत नाहीत.

**विशिष्ट उत्पादनाशी केलेली जोडणी** परस्पर संमतीने ठरवलेल्या प्रक्रियेनुसार चालते. प्रत्येक डेव्हलपरला तोच इंटरफेस न देताही Quizlet हे ChatGPT किंवा Google Classroom सोबत काम करू शकते. या सुविधा उपलब्ध आहेत, एवढेच त्यांच्या घोषणांवरून स्पष्ट होते. सर्वांना वापरता येईल असे सार्वजनिक Quizlet API त्यामागे आहे, असा निष्कर्ष काढता येत नाही.

याच कारणामुळे जुना रॅपर किंवा ब्राउझरच्या डेव्हलपर टूल्समध्ये दिसणारी रिक्वेस्ट म्हणजे अधिकृत पाठबळ असलेले Quizlet API नाही. सार्वजनिक दस्तऐवज आणि डेव्हलपरसाठी स्थिर, स्पष्ट चौकट यांचा अभाव आहे.

## कामाला योग्य असा मार्ग निवडा

### एकदाच बॅकअप घ्यायचा किंवा स्थलांतर करायचे असेल, तर एक्सपोर्ट वापरा

तुम्ही तयार केलेल्या संचासाठी Quizlet ची अधिकृत एक्सपोर्ट प्रक्रिया वापरा. प्रक्रिया **मजकूर कॉपी करा (Copy text)** येथे संपत असल्याने, विभाजक दुरुस्त करण्याआधी किंवा फील्ड्सची जुळवणी करण्याआधी पहिली पेस्ट केलेली प्रत जसाची तशी जपून ठेवा. तुम्ही संज्ञा आणि व्याख्या जतन करत आहात; मूळ डेक पुन्हा संपूर्णपणे तयार करता येईल असे पॅकेज डाउनलोड करत नाही. प्रतिमा आणि अभ्यासाचा इतिहास सोबत येत नाहीत.

यासाठीची तपासणी यादी [2026 मध्ये Quizlet संच एक्सपोर्ट कसे करायचे](/mr/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/) या लेखात आहे. त्यात मूळ प्रत आणि बदल करण्यासाठीची प्रत, UTF-8, टॅब आणि अनेक ओळींच्या व्याख्या यांची माहिती आहे. कार्डांवरील मजकूर हलवणे आणि उजळणीच्या वेळापत्रकाचा डेटा हलवणे यांतील फरकही समजावला आहे.

एकदाच पूर्ण करायच्या स्थलांतरासाठी एक्सपोर्ट योग्य आहे. रोज कार्डे तयार करणे, प्रणालींमधील डेटा जुळता ठेवणे किंवा सॉफ्टवेअरमधून वारंवार बदल करणे यासाठी तो योग्य नाही.

### सामग्री दाखवण्यासाठी अधिकृत एम्बेड वापरा

वर्गाच्या वेबसाइटवरून किंवा LMS पानावरून विद्यार्थ्यांना सार्वजनिक Quizlet संचाचा अभ्यास करू द्यायचा असेल, तर Quizlet च्या वेबसाइटवर दिलेला एम्बेड कोड वापरा. अभ्यासाचा उपक्रम निवडा, **HTML कॉपी करा (Copy HTML)** निवडा आणि मिळालेला कोड पानात जोडा. विद्यार्थी त्या पानावर Quizlet चा परस्परसंवादी उपक्रम वापरू शकतात; तो दाखवणाऱ्या वेबसाइटला मात्र कार्डांचा मूळ डेटा मिळत नाही.

शिक्षकाला बऱ्याचदा एवढेच हवे असते. त्याला API म्हटल्याने साधी गरज अनावश्यकपणे गुंतागुंतीची वाटते.

### ChatGPT किंवा Google Classroom साठी त्यांची विशिष्ट जोडणी वापरा

10 मार्च 2026 रोजी केलेल्या ChatGPT घोषणेत Quizlet ने एक विशिष्ट प्रक्रिया दिली आहे: Quizlet ॲप जोडा, प्रॉम्प्टची सुरुवात `@Quizlet` ने करा, तयार झालेल्या संचाचा प्रीव्ह्यू ChatGPT मध्ये पाहा आणि मग बदल करून अभ्यास करण्यासाठी तो Quizlet मध्ये उघडा. त्या संभाषणातून Quizlet संच तयार करण्याचा हा अधिकृत पाठबळ असलेला मार्ग आहे. यात तुमच्या बॉट, स्क्रिप्ट किंवा वेबसाइटला पुन्हा वापरता येणारे Quizlet API क्रेडेन्शियल मिळत नाही.

30 जून 2026 रोजी केलेली Quizlet ची Google Classroom घोषणाही अशाच ठरावीक कामांबद्दल आहे. या ॲड-ऑनमधून शिक्षक सराव प्रश्न, फ्लॅशकार्ड्स आणि खेळ असे अभ्यासाचे उपक्रम शोधून विद्यार्थ्यांना नेमून देऊ शकतात. त्यानंतर Classroom मध्येच विद्यार्थ्यांचा सहभाग आणि प्रगती पाहू शकतात. Quizlet नुसार यासाठी Google Workspace for Education Plus आवश्यक आहे. शिक्षकांना IT प्रशासकाची परवानगी घ्यावी लागू शकते किंवा त्यांच्याकडून ॲड-ऑन उपलब्ध करून घ्यावा लागू शकतो.

यापैकी एखादी प्रक्रिया तुमच्या उद्देशाला आधीच जुळत असेल, तर ती वापरा. स्वतःचे ॲप्लिकेशन हवे असेल, तर यांपैकी कोणतीही जोडणी सार्वजनिक डेव्हलपर प्रवेशाची जागा घेत नाही.

### वारंवार कामे स्वयंचलित करायची असतील, तर दस्तऐवज असलेला वाचन आणि लेखन इंटरफेस निवडा

कामे नियमितपणे स्वयंचलित करायची असतील, तर तुमच्या सॉफ्टवेअरला ती प्रत्येक वेळी विश्वासार्हपणे करता आली पाहिजेत: नोट्समधून कार्डे तयार करणे, डेकची यादी मिळवणे, उत्तरे बदलणे किंवा दीर्घकाळ वर्कस्पेस सांभाळणे. क्लिपबोर्डवर मजकूर एक्सपोर्ट करण्याची सोय यासाठी पुरेशी नाही.

बाहेरील सॉफ्टवेअरने प्रमाणीकरण कसे करायचे आणि कोणत्या वाचन व लेखन क्रिया उपलब्ध आहेत हे स्पष्टपणे प्रकाशित करणारी फ्लॅशकार्ड प्रणाली निवडणे हा सुरक्षित मार्ग आहे. स्वयंचलित कामासाठी Quizlet API चा पर्याय निवडून, Quizlet च्या सार्वजनिक उत्पादनात उपलब्ध असलेल्या अभ्यासाच्या कामांसाठी Quizlet वापरत राहावे लागू शकते.

## Nibomo चा API पर्याय प्रत्यक्षात काय देतो

Nibomo मध्ये प्रत्येक वापरकर्त्याच्या ठरावीक डेटापुरता प्रवेश मिळतो. त्याच डेटासाठी दोन मार्गांचे दस्तऐवज उपलब्ध आहेत:

- [बाह्य Agent API](/mr/docs/api/) ची सुरुवात `GET https://api.nibomo.com/v1/` येथे होते. सुरुवातीच्या प्रतिसादातून एजंटला ईमेल OTP ने लॉगिन करणे, API की तयार करणे आणि वर्कस्पेस निवडणे याबद्दल मार्गदर्शन मिळते. वाचनासाठी SQL-सदृश क्वेरी मार्ग आणि लेखनासाठी स्वतंत्र execute मार्ग आहे.
- [रिमोट MCP सर्व्हर](/mr/docs/mcp-connector/) `https://mcp.nibomo.com/mcp` येथे उपलब्ध आहे. MCP क्लायंट्सना आठ टूल्स मिळतात: `list_workspaces`, `sql_query`, `sql_execute`, `get_guide` आणि उजळणीची टूल्स `next_review_card`, `reveal_answer` व `submit_review`.

`get_usage_limits` — खात्याचा प्लॅन, मर्यादा आणि चालू महिन्यातील AI वापर फक्त वाचण्यासाठी; हे टूल कार्डे वाचत किंवा बदलत नाही.

दोन्ही मार्गांचा प्रवेश निवडलेल्या वर्कस्पेसपुरता मर्यादित असतो. दस्तऐवजांत दिलेली संसाधने `workspace`, `cards`, `decks` आणि `review_events` आहेत. प्रत्येक स्टेटमेंटच्या निकालात जास्तीत जास्त 100 ओळी मिळतात. SQL-सदृश इंटरफेसमध्ये SQL च्या मर्यादित रूपाला पाठबळ आहे; तो थेट PostgreSQL वापरण्याची सोय देत नाही. OpenAPI स्कीमा उपलब्ध नाही, त्यामुळे आपोआप तयार केलेल्या OpenAPI क्लायंट्सवर अवलंबून असलेल्या प्रक्रियांना वेगळा इंटरफेस लागेल.

यामुळे डेव्हलपर किंवा AI एजंटला स्वतःच्या फ्लॅशकार्ड्सवरील कामे स्वयंचलित करता येतात. त्यातून Quizlet URL वाचता येत नाही, Quizlet खात्याची समांतर प्रत ठेवता येत नाही किंवा अधिकृत दस्तऐवज नसलेला Quizlet क्लायंट म्हणून काम करता येत नाही. स्वयंचलित Quizlet इम्पोर्टर उपलब्ध नाही. स्थलांतरासाठी आधी स्वतःच्या संचातील संज्ञा आणि व्याख्या एक्सपोर्ट करा, मजकूर तपासा आणि मग तो लक्ष्य प्रणालीतील कार्ड फील्ड्सशी जुळवा. लक्ष्य प्रणाली अभ्यासाची स्वतःची स्थिती नव्याने तयार करते; Quizlet चा इतिहास सोबत येत नाही.

API प्रवेशाव्यतिरिक्त उत्पादनांमध्ये काय फरक आहेत, हे जाणून घेण्यासाठी [Quizlet आणि त्याचा ओपन सोर्स पर्याय यांची तुलना](/blog/quizlet-alternative/) पाहा.

## ब्राउझरमधील खाजगी रिक्वेस्ट हा सुरक्षित शॉर्टकट नाही

प्रत्येक आधुनिक वेब ॲप्लिकेशनप्रमाणे Quizlet चा वेब इंटरफेसही नेटवर्क रिक्वेस्ट करतो. त्यातील एखादी रिक्वेस्ट सापडली म्हणून ती तुमच्या प्रोग्रामसाठी अधिकृत पाठबळ असलेला एंडपॉइंट होत नाही.

ब्राउझरमधील खाजगी एंडपॉइंट्स सेशन कुकीज, अंतर्गत डेटा स्वरूप, गैरवापर रोखणारी नियंत्रणे आणि सध्याच्या इंटरफेसशी निगडित गृहीतकांवर अवलंबून असू शकतात. सार्वजनिक आवृत्ती क्रमांक किंवा बदलांशी जुळवून घेण्याच्या मार्गदर्शनाशिवाय ते बदलू शकतात. त्याहून स्पष्ट बाब म्हणजे, 28 मे 2026 रोजी शेवटचा बदल केलेल्या [Quizlet च्या सेवा अटी](https://quizlet.com/tos) स्क्रॅपिंग आणि इतर स्वयंचलित डेटा काढण्याच्या पद्धतींना, तसेच सेवेच्या अनधिकृत स्वयंचलित वापराला मनाई करतात.

स्वतःच्या स्क्रिप्टसाठीही हा अस्थिर आणि जोखमीचा आधार आहे; उत्पादनासाठी तर अधिकच. येथे मी अंदाजाने ठरवलेले एंडपॉइंट्स किंवा रिव्हर्स इंजिनिअरिंगच्या पायऱ्या देणार नाही.

स्वतःचा संच एकदाच दुसरीकडे न्यायचा असेल, तर एक्सपोर्ट करा. विद्यार्थ्यांना सार्वजनिक संच दुसऱ्या पानावर हवा असेल, तर एम्बेड करा. ChatGPT किंवा Google Classroom मधील नेमक्या त्या प्रक्रियांसाठी त्यांची विशिष्ट जोडणी वापरा. वारंवार वाचन आणि लेखनासाठी स्वयंचलित वापराची स्पष्ट चौकट दस्तऐवजांत देणारे सॉफ्टवेअर निवडा—किंवा Quizlet अशी चौकट प्रकाशित करेपर्यंत Quizlet मधील भाग स्वतः हाताने करा.

## स्थिती बदलली आहे हे कसे ओळखायचे

या लेखातील तथ्यांच्या पडताळणीच्या तारखेनंतर Quizlet डेव्हलपर कार्यक्रम सुरू करू शकते. कोणाला नोंदणी करता येते, प्रमाणीकरण कसे होते, कार्डांवर कोणत्या क्रिया उपलब्ध आहेत आणि वापराचे कोणते नियम लागू आहेत हे स्पष्ट करणारे अधिकृत डेव्हलपर पोर्टल किंवा दस्तऐवज हा त्याचा संकेत असेल.

एखादा नवा तृतीय-पक्ष रॅपर किंवा विशिष्ट भागीदारासोबतची नवी जोडणी यामुळे हे उत्तर बदलणार नाही. डेव्हलपरला स्वतः नोंदणी करून प्रवेश मिळवण्याचा मार्ग Quizlet अधिकृत दस्तऐवजांत देईपर्यंत, सध्याच्या Quizlet API बद्दलचे दावे काळजीपूर्वक तपासा. तुमच्या कामासाठी योग्य आणि अधिकृत पाठबळ असलेला मार्ग निवडा.
