## ಹೋಸ್ಟ್ ಮಾಡಿದ ವೆಬ್ ಆ್ಯಪ್

ಆರಂಭಿಸಲು ಅತ್ಯಂತ ವೇಗದ ಮಾರ್ಗವೆಂದರೆ ಹೋಸ್ಟ್ ಮಾಡಿದ ವೆಬ್ ಆ್ಯಪ್:

1. [app.nibomo.com](https://app.nibomo.com) ತೆರೆಯಿರಿ
2. ಪಾಸ್‌ವರ್ಡ್ ಇಲ್ಲದ OTP ಬಳಸಿ ನಿಮ್ಮ ಇಮೇಲ್ ಮೂಲಕ ಸೈನ್ ಇನ್ ಮಾಡಿ
3. ಕಾರ್ಡ್‌ಗಳನ್ನು ರಚಿಸಿ, ಬಾಕಿ ಇರುವ ಕಾರ್ಡ್‌ಗಳನ್ನು ಪುನರಾವರ್ತಿಸಿ, ಮತ್ತು ಕಾರ್ಯಸ್ಥಳದ ಡೇಟಾ ಹಾಗೂ ಫೈಲ್ ಲಗತ್ತುಗಳೊಂದಿಗೆ AI ಚಾಟ್ ಬಳಸಿ

ಹೋಸ್ಟ್ ಮಾಡಿದ ಮಾರ್ಗಕ್ಕೆ ಯಾವುದೇ ಇನ್‌ಸ್ಟಾಲೇಶನ್ ಅಥವಾ ಸರ್ವರ್ ಸೆಟಪ್ ಬೇಕಿಲ್ಲ.

## ಏಜೆಂಟ್ ಸೆಟಪ್

Claude Code, Codex ಅಥವಾ OpenClaw ನೇರವಾಗಿ ಸಂಪರ್ಕಗೊಳ್ಳಬೇಕೆಂದು ಬಯಸಿದರೆ, ಇಲ್ಲಿಂದ ಆರಂಭಿಸಿ:

```text
GET https://api.nibomo.com/v1/
```

ಆ ಡಿಸ್ಕವರಿ ಪ್ರತಿಕ್ರಿಯೆ ಏಜೆಂಟ್‌ಗೆ ಇಮೇಲ್ OTP ಲಾಗಿನ್, ದೀರ್ಘಾವಧಿಯ API ಕೀ ರಚನೆ, ಖಾತೆ ಲೋಡ್ ಮಾಡುವುದು, ಕಾರ್ಯಸ್ಥಳದ ಆರಂಭಿಕ ಸಿದ್ಧತೆ ಮತ್ತು ಪ್ರಕಟಿತ SQL ಇಂಟರ್ಫೇಸ್ ಮೂಲಕ ಹಂತ ಹಂತವಾಗಿ ಮಾರ್ಗದರ್ಶನ ನೀಡುತ್ತದೆ.

ಇದೇ ಪೇಲೋಡ್ `GET /v1/agent` ನಲ್ಲಿಯೂ ಲಭ್ಯವಿದೆ, ಆದರೆ ಅಧಿಕೃತ ಸಾರ್ವಜನಿಕ ಪ್ರವೇಶ ಬಿಂದು `/v1/` ಆಗಿದೆ.

## ಸ್ವಂತ ಹೋಸ್ಟಿಂಗ್

ನಿಮ್ಮದೇ ಇನ್‌ಸ್ಟೆನ್ಸ್ ಚಲಾಯಿಸಲು ಬಯಸಿದರೆ, [ಸ್ವಂತ ಹೋಸ್ಟಿಂಗ್ ಮಾರ್ಗದರ್ಶಿ](/docs/self-hosting/) ನೋಡಿ.

## ಇಂದು ನಿಮಗೆ ಏನು ಸಿಗುತ್ತದೆ

- ಕಾರ್ಡ್‌ಗಳು, ಪುನರಾವರ್ತನೆ ಮತ್ತು AI ಚಾಟ್‌ಗಾಗಿ ಹೋಸ್ಟ್ ಮಾಡಿದ ವೆಬ್ ಆ್ಯಪ್
- ಮುಖ್ಯ ರೆಪೊಸಿಟರಿಯಲ್ಲಿ ಲೋಕಲ್ SQLite ಮತ್ತು ಆಫ್‌ಲೈನ್-ಫಸ್ಟ್ ಸಿಂಕ್ ಇರುವ iOS ಕ್ಲೈಂಟ್
- ಪ್ರತ್ಯೇಕ `api` ಮತ್ತು `auth` ಡೊಮೇನ್‌ಗಳಲ್ಲಿ ಹಂಚಿಕೆಯ ಬ್ಯಾಕೆಂಡ್ ಮತ್ತು ದೃಢೀಕರಣ ಸೇವೆಗಳು
- ಡಿಸ್ಕವರಿ, OTP ಮತ್ತು ApiKey ದೃಢೀಕರಣದ ಮೂಲಕ ಬಾಹ್ಯ ಏಜೆಂಟ್‌ಗಳ ಆನ್‌ಬೋರ್ಡಿಂಗ್
- Postgres ಅನ್ನು ಡೇಟಾದ ಅಧಿಕೃತ ಮೂಲವಾಗಿ ಹೊಂದಿರುವ, AWS ಮೇಲಿನ ಓಪನ್ ಸೋರ್ಸ್ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್ ಮಾರ್ಗ

## ರೆಪೊಸಿಟರಿಯ ದಿಕ್ಕು

ಈ ಪ್ರಾಜೆಕ್ಟ್ ಆಫ್‌ಲೈನ್-ಫಸ್ಟ್ ಆಗಿದೆ.

ಇಂದು ರೆಪೊಸಿಟರಿಯಲ್ಲಿ ವೆಬ್ ಆ್ಯಪ್, iOS ಆ್ಯಪ್, ದೃಢೀಕರಣ ಸೇವೆ, ಬ್ಯಾಕೆಂಡ್ API, ಬಾಹ್ಯ ಏಜೆಂಟ್ ಫ್ಲೋ ಮತ್ತು Google Play ನಲ್ಲಿ ಪ್ರಕಟವಾದ Android ಆ್ಯಪ್ ಸೇರಿವೆ.
