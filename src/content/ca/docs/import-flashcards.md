---
title: Importa targetes a Nibomo
description: Porta les teves targetes de Quizlet, Anki o una altra app. Tria el format adequat i comprova el resultat abans de fer una importació gran.
---

Obre [Nibomo](https://app.nibomo.com/?locale=ca), tria l’espai de treball on vols desar les targetes i ves a **Biblioteca > Importa** (a l’app d’Apple, **Importar**). A **D’una altra app**, selecciona l’app que feies servir. Cadascuna té la seva pròpia opció, encara que el format dels fitxers sigui el mateix.

Les opcions següents són disponibles a l’app web. Si no trobes el menú o l’opció que necessites a l’iPhone, l’iPad, el Mac o Android, fes servir l’app web. Si fas servir Nibomo com a convidat al dispositiu, inicia-hi la sessió primer. Després inicia la sessió al web amb el mateix compte de Nibomo i selecciona l’espai de treball on vols importar les targetes.

## Tria l’origen de les targetes

| Origen | Què necessites | Com importar-ho |
| --- | --- | --- |
| Quizlet | El text copiat de l’exportació | Enganxa’l a la pantalla d’importació de Quizlet |
| Anki | Una baralla `.apkg` o una col·lecció `.colpkg` | Tria fitxers |
| Noji | `.csv` o `.ofc` | Tria fitxers |
| Knowt | `.pdf` | Tria fitxers |
| RemNote | `.apkg`, `.md` o `.txt` | Tria fitxers |
| Brainscape | `.csv` | Tria fitxers |
| StudySmarter | `.csv` | Tria fitxers |
| Cram | `.csv` | Tria fitxers |
| Mochi | `.mochi` | Tria fitxers |
| SuperMemo | `.xml` | Tria fitxers |
| AlgoApp (abans AnkiApp) | `.zip` o `.xml` | Tria fitxers |
| Una altra app | `.csv`, `.txt`, `.xlsx`, `.pdf`, `.json`, `.xml`, `.md`, `.docx` o `.zip` | Tria els fitxers a **Importa des d’una altra app** |
| Full de càlcul | Files copiades amb l’anvers i el revers de cada targeta | Enganxa-les a **Importa des d’un full de càlcul** |
| Nibomo | Un fitxer `flashcards.zip` exportat des de Nibomo | Comprova’n la vista prèvia a **Importa des de Nibomo** |

Si al menú d’importació hi surt el nom anterior d’AlgoApp, cerca **AnkiApp**. Anki té una opció pròpia.

Si tens un fitxer antic d’Excel amb extensió `.xls`, desa’l com a `.xlsx` o `.csv` abans d’importar-lo. També pots copiar les columnes de l’anvers i el revers i [enganxar-les a la pantalla d’importació de fulls de càlcul](#enganxa-targetes-des-dun-full-de-càlcul).

## Importa targetes d’una altra app

1. Exporta les targetes que vulguis traslladar des de l’app d’origen. A Quizlet, obre el conjunt, tria **Export** (Exporta) i copia el text. Fes servir una tabulació entre el terme i la definició i un salt de línia entre targetes.
2. A Nibomo, ves a **Biblioteca > Importa** i tria l’opció corresponent. Si vens de Quizlet, enganxa el text copiat. Per a la resta, tria el fitxer o els fitxers exportats. Si la teva app no té una opció pròpia però permet exportar en un format compatible, com ara PDF, fes servir **Importa des d’una altra app**.
3. Selecciona **Inicia la importació**. Nibomo obre un xat amb IA nou i hi envia la petició d’importació amb els fitxers o el text enganxat. Cal una connexió a internet. Cada fitxer que importis amb IA pot ocupar fins a **30 MiB**. Si el teu fitxer supera el límit, prova d’exportar baralles o conjunts més petits per separat.
4. Comprova el resultat a **Biblioteca**. El xat amb IA pot desar les targetes per tandes. Si s’atura a mitges, mira quines targetes ja s’han desat i demana-li que continuï amb les que falten abans de repetir tota la importació.

### Comença amb poques targetes

Conserva l’exportació original i comença amb una baralla o un conjunt petit. Compara el nombre de targetes i comprova l’anvers i el revers d’unes quantes, les etiquetes i les imatges o el format especial que vulguis conservar. Si vols que el xat et mostri una mostra abans de desar-la, adjunta l’exportació en un xat amb IA nou i demana-li que et mostri unes quantes targetes sense desar-les, en lloc de seleccionar **Inicia la importació**.

Les targetes importades amb IA s’afegeixen com a targetes noves a Nibomo. L’historial i les dates de repàs no es transfereixen. L’organització, el format i els fitxers multimèdia que es conserven depenen del contingut exportat i del que en pugui llegir el xat amb IA. Comprova el resultat abans de fer-lo servir o d’esborrar res de l’app d’origen.

## Enganxa targetes des d’un full de càlcul

Si només tens parells d’anvers i revers, fes servir **Biblioteca > Importa > Importa des d’un full de càlcul**. Copia dues columnes del full sense incloure la fila de capçalera i enganxa-les a la pantalla d’importació. Per a les cel·les d’un full de càlcul, comença amb **Tabulació** entre l’anvers i el revers i **Salt de línia** entre targetes. Si el text fa servir altres separadors, canvia’ls.

Comprova la vista prèvia de les targetes, corregeix les files incompletes i tria les etiquetes que hi vulguis aplicar. Després, selecciona el botó d’importació per desar les targetes. Aquest mètode no fa servir el xat amb IA.

## Importa un ZIP de Nibomo

Ves a **Biblioteca > Importa > Importa des de Nibomo** per importar un fitxer `flashcards.zip` que hagis exportat abans des de Nibomo. Tria el fitxer ZIP sense descomprimir-lo, comprova a la vista prèvia les targetes i els fitxers multimèdia associats i confirma la importació. Així pots traslladar les targetes, les etiquetes i els fitxers multimèdia inclosos en el paquet, sense fer servir el xat amb IA.
