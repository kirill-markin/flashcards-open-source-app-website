Vula [i-Nibomo](https://app.nibomo.com/?locale=zu), uye endaweni yokusebenza ofuna ukufaka kuyo amakhadi, bese ukhetha **Umtapo wolwazi > Ngenisa**. Ngaphansi kokuthi **Kusuka kolunye uhlelo lokusebenza**, khetha uhlelo obulusebenzisa. Uhlelo ngalunye lunenketho yalo, ngisho noma lisebenzisa ifomethi yefayela efanayo neyolunye uhlelo.

Izinketho ezingezansi ziyatholakala ohlelweni lwewebhu. Uma ungayiboni imenyu noma inketho oyidingayo ku-iPhone, i-iPad, i-Mac noma i-Android, sebenzisa uhlelo lwewebhu. Uma usebenzisa i-Nibomo njengesivakashi kudivayisi yakho, qala ngokungena ngemvume kuleyo divayisi. Ohlelweni lwewebhu, ngena ngemvume ku-akhawunti efanayo ye-Nibomo bese ukhetha indawo yokusebenza ofuna ukufaka kuyo amakhadi ngaphambi kokuwangenisa.

## Khetha umthombo

| Umthombo | Okudingekayo | Indlela yokungenisa |
| --- | --- | --- |
| Quizlet | Umbhalo okhishiwe wakopishwa | Namathisela esikrinini sokungenisa kusuka ku-Quizlet |
| Anki | Idekhi ye-`.apkg` noma iqoqo le-`.colpkg` | Khetha amafayela |
| Noji | `.csv` noma `.ofc` | Khetha amafayela |
| Knowt | `.pdf` | Khetha amafayela |

| Brainscape | `.csv` | Khetha amafayela |
| StudySmarter | `.csv` | Khetha amafayela |
| Cram | `.csv` | Khetha amafayela |
| Mochi | `.mochi` | Khetha amafayela |
| SuperMemo | `.xml` | Khetha amafayela |
| AlgoApp (eyayibizwa nge-AnkiApp) | `.zip` noma `.xml` | Khetha amafayela |
| Olunye uhlelo lokusebenza | `.csv`, `.txt`, `.xlsx`, `.pdf`, `.json`, `.xml`, `.md`, `.docx` noma `.zip` | Khetha amafayela ngaphansi kokuthi **Ngenisa kusuka kolunye uhlelo lokusebenza** |

Uma imenyu isasebenzisa igama elidala le-AlgoApp, funa u-**AnkiApp**. I-Anki inenketho yayo.

Uma unefayela elidala le-Excel elithi `.xls`, ligcine njengefayela le-`.xlsx` noma le-`.csv` ngaphambi kokulingenisa. Ungakopisha namakholomu angaphambili nangemuva [uwanamathisele esikrinini sokungenisa kusuka kuspredishithi](#namathisela-okuvela-kuspredishithi).

## Ngenisa usuka kolunye uhlelo lwamakhadi okufunda

1. Khipha amakhadi ofuna ukuwahambisa ohlelweni obuwasebenzisa. Ku-Quizlet, vula isethi yakho, khetha u-**Export** bese ukopisha umbhalo. Ungasebenzisa ithebhu phakathi kwetemu nencazelo, nomugqa omusha phakathi kwamakhadi. Ungakhipha isethi kuwebhusayithi ye-Quizlet kuphela, futhi ungakhipha kuphela amasethi oqobo owazenzele wona.
2. Ku-Nibomo, iya kokuthi **Umtapo wolwazi > Ngenisa**, bese uvula inketho yohlelo lwakho. Uma usebenzisa i-Quizlet, namathisela umbhalo owukopishile. Kweminye imithombo, khetha amafayela owakhiphile. Uma uhlelo lwakho lungekho ohlwini kodwa lukwazi ukukhipha ifayela ngefomethi esekelwayo njenge-PDF, sebenzisa **Ngenisa kusuka kolunye uhlelo lokusebenza**.
3. Khetha **Qala ukungenisa**. I-Nibomo ivula ingxoxo entsha ye-AI bese ithumela isicelo sokungenisa namafayela akho noma umbhalo owunamathisele. Lokhu kudinga i-inthanethi. Ifayela ngalinye elingeniswa nge-AI lingaba usayizi ongafika ku-**30 MiB**. Uma lilikhulu kunalokho, zama ukukhipha amadekhi noma amasethi amancane ngokwehlukana.
4. Hlola umphumela ku-**Umtapo wolwazi**. Ingxoxo ye-AI ingagcina amakhadi ngamaqoqo njengoba iqhubeka. Uma ima phakathi nendlela, hlola ukuthi yimaphi amakhadi aseku-Nibomo, bese uyicela iqhubeke nalawo asele ngaphambi kokuzama ukungenisa yonke into futhi.

### Qala ngokuhlola amakhadi ambalwa

Gcina ikhophi yokuqala oyikhiphile bese uqala ngedekhi noma isethi encane. Qhathanisa inani lamakhadi, uhlole izinhlangothi zamakhadi ambalwa, amathegi nezithombe noma ukufometha okudingayo. Uma ufuna ukubona isampula ngaphambi kokugcina, cela ingxoxo ye-AI ikubonise amakhadi ambalwa ingawagcini. Ukuze wenze lokhu, namathisela ifayela engxoxweni entsha ye-AI bese ubhala esakho isicelo esikhundleni sokukhetha **Qala ukungenisa**.

Amakhadi angeniswe nge-AI aqala njengamakhadi amasha ku-Nibomo. Umlando wokubuyekeza nezinsuku zokubuyekeza azidluliselwa. Ukuthi ukuhleleka, ukufometha nemidiya kugcineka kangakanani kuncike kulokho okukhishiwe nakulokho ingxoxo ye-AI engakwazi ukukufunda. Hlola umphumela ngaphambi kokuthembela kuwo noma ukususa okuthile ohlelweni lokuqala.

## Namathisela okuvela kuspredishithi

Qala ngokungena ngemvume ku-akhawunti yakho ye-Nibomo. Uma ikhadi ngalinye linombhalo olula ezinhlangothini ezimbili, khetha **Umtapo wolwazi > Ngenisa > Ngenisa kusuka kuspredishithi**. Kopisha amakholomu amabili, ushiye umugqa wezihloko, bese uwanamathisela esikrinini sokungenisa. Kumangqamuzana esipredishithi, qala ngo-**Ithebhu** phakathi kwengaphambili nengemuva, nangokuthi **Umugqa omusha** phakathi kwamakhadi. Uma umbhalo wakho usebenzisa ezinye izihlukanisi, zishintshe.

Buka amakhadi kuqala, ulungise imigqa engaphelele bese ukhetha amathegi ofuna ukuwafaka. Bese ucindezela inkinobho yokungenisa ukuze ugcine amakhadi. Le ndlela ayisebenzisi ingxoxo ye-AI.

## Ngenisa ifayela le-ZIP le-Nibomo

Qala ngokungena ngemvume ku-akhawunti yakho ye-Nibomo. Uma unefayela elithi `flashcards.zip` elake lakhishwa ku-Nibomo, khetha **Umtapo wolwazi > Ngenisa > Ngenisa kusuka ku-Nibomo**. Khetha ifayela le-ZIP njengoba linjalo, ungakhiphi okuqukethwe kulo. Ekubukeni kuqala, hlola inani lamakhadi nelamafayela emidiya, ufunde nezixwayiso uma zikhona. Bese uqinisekisa ukungenisa, uhlole amakhadi namafayela emidiya ngakunye ku-**Umtapo wolwazi**. Le ndlela ingadlulisela amakhadi, amathegi nemidiya okukuphakheji. Ayisebenzisi ingxoxo ye-AI.
