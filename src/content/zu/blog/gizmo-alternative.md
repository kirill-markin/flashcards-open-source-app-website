## Ingabe i-Gizmo imahhala?

Yebo. I-Gizmo inohlelo lwamahhala. Imikhawulo yamanje engase iphazamise ukufunda kwakho yile:

- I-[Magic Import](https://help.gizmo.ai/en/articles/15647624-what-is-magic-import) idinga ukuthi abasebenzisi bamahhala balinde imizuzu engu-20 phakathi kokungenisa ngakunye. I-Unlimited isusa lokhu kulinda.
- I-[AI Tutor](https://help.gizmo.ai/en/articles/15869958-how-many-ai-tutor-sessions-can-i-have-for-free) ivumela izikhathi ezinhlanu zamahhala zokufunda ngosuku lwekhalenda. Isibalo siqala kabusha usuku ngalunye, kanti i-Unlimited isusa umkhawulo wansuku zonke.
- Ama-[Hearts](https://help.gizmo.ai/en/articles/15623061-what-are-hearts) asetshenziswa ku-Memorise: uqala unama-Hearts angu-15, ulahlekelwe elilodwa ngemva kwempendulo engalungile, futhi kufanele ulinde imizuzu engu-10 ngaphambi kokuphinda uphendule imibuzo uma esephelile. I-Gizmo ithi uhlobo lwayo lwemibuzo oluthi Flashcards kuphela alusebenzisi ama-Hearts.
- Ama-[Hints](https://help.gizmo.ai/en/articles/15504721-what-are-hints) aveza uhlamvu lokuqala lwempendulo noma asuse impendulo engalungile ezinkethweni zombuzo. Abasebenzisi bamahhala bawathenga ngama-Coins abawathola ngokuphendula imibuzo; i-Unlimited ihlanganisa ama-Hints nama-Hearts angenamkhawulo.

Ngakho ungasebenzisa i-Magic Import kangaki ohlelweni lwamahhala lwe-Gizmo? Impendulo esemthethweni iyisikhathi sokulinda, hhayi inani. Imibhalo ithembisa isikhathi sokulinda semizuzu engu-20; ayithembisi inani elithile lokungenisa okuphumelelayo ngosuku.

## Lokho amakhadi okufunda e-Gizmo akwenzayo

I-Gizmo iqala ngezinto zokufunda osuvele unazo. I-Magic Import iziguqula zibe amakhadi, i-Memorise ikubuza imibuzo esekelwe emakhadini, kanti i-AI Tutor ingakufundisa isebenzisa umthombo. I-XP, i-Levels, i-Leagues ne-Streaks zengeza indlela yokulandelela inqubekela phambili kulo mjikelezo wokufunda, ngokwe-[ncazelo esemthethweni yomkhiqizo ye-Gizmo](https://help.gizmo.ai/en/articles/14472668-how-does-gizmo-work).

Umhlahlandlela we-Magic Import ubala imithombo eyisishiyagalolunye yokwakha amakhadi:

- i-PDF;
- inkulumo noma isifundo esiqoshwe ngaphakathi kohlelo;
- amanothi anamathiselwe njengombhalo;
- izithombe zamanothi noma zebhodi lokubhalela;
- i-PowerPoint;
- i-Quizlet;
- i-Anki;
- ispredishithi noma i-CSV; kanye
- ne-URL yewebhusayithi.

I-Gizmo ikhiqiza amakhadi futhi igqamise amagama ehlose ukukubuza ngawo. Umhlahlandlela wayo utshela abafundi ukuthi bahlole iqoqo bese bengeza noma yini engafakwanga ngesikhathi sokungenisa. Mina ngingakwenza lokho kube yingxenye evamile yokusebenza: qhathanisa amakhadi nomthombo, susa imibuzo engasizi, ulungise amaphutha ngaphambi kokuthi uqale ukubuyekeza iqoqo njalo. [Indlela yokulungisa amakhadi okufunda akhiqizwe yi-AI](/blog/how-to-fix-ai-flashcards/) inohlu oluwusizo lokuhlola nokulungisa.

I-AI Tutor inendlela yokungenisa ehlobene nalena. [Umhlahlandlela osemthethweni wokungenisa izifundo](https://help.gizmo.ai/en/articles/15935404-how-do-i-use-magic-import-to-start-an-ai-tutor-lesson) ubala i-PDF, i-PowerPoint, i-YouTube, amanothi, izithombe, izinkulumo eziqoshiwe, amaqoqo e-Quizlet neqoqo le-Gizmo osuvele unalo. I-Tutor ibe isikufundisa ngalezo zinto futhi ikubuze imibuzo njengoba uqhubeka.

Lezi zinhlu ezimbili zemithombo ezisemibhalweni azifani. I-Anki, amaspredishithi namawebhusayithi kuvela emhlahlandleleni wokwakha amakhadi; i-YouTube namaqoqo e-Gizmo asevele ekhona kuvela emhlahlandleleni wezifundo ze-Tutor. Hlola indlela oyidingayo kunokuba ucabange ukuthi yonke imithombo iyatholakala kuwo womabili amamenyu.

## I-Gizmo inezinhlobo ezinhlanu zamakhadi

[Imibhalo yamanje ye-Gizmo yezinhlobo zamakhadi](https://help.gizmo.ai/en/articles/16527223-what-types-of-flashcards-can-i-make) ibala amafomethi amahlanu:

| Uhlobo lwekhadi | Lokho olukuhlolayo | Indlela olungakhiwa ngayo |
| --- | --- | --- |
| **Card text** | Umbhalo noma i-LaTeX enamagama agqanyisiwe okubuzwa ngawo, noma inketho yokubonisa ingaphambili nengemuva | Ngesandla noma nge-Magic Import |
| **Multiple choice** | Umbuzo onezinketho zezimpendulo ezikhiqiziwe; ungangeza izinketho ezingalungile lapho uhlela | Ngesandla noma nge-Magic Import |
| **Matching** | Amapheya i-Gizmo ewaxubayo ukuze uwahlanganise futhi | Nge-Magic Import kuphela |
| **Ordering** | Izinto i-Gizmo ezixubayo ukuze uzibuyisele ekulandelaneni kwazo | Nge-Magic Import kuphela |
| **True/False** | Isitatimende okufanele unqume ukuthi siyiqiniso noma singamanga | Ngesandla noma nge-Magic Import |

Lokhu kubanzi kuneqoqo eliyisisekelo lamakhadi anengaphambili nengemuva, kanti i-Magic Import yenza okungaphezu kokusheshisa ukwakha: i-Matching ne-Ordering okwamanje kutholakala nge-Magic Import kuphela.

Kukhona ukungavumelani okukodwa emibhalweni okufanele ukwazi. Ikhasi lezinhlobo zamakhadi lithi i-Card text ingaba nezithombe ngaphambili nangemuva. [Umhlahlandlela we-Gizmo wokuphatha amakhadi](https://help.gizmo.ai/en/articles/13761411-how-do-i-edit-or-manage-my-cards) uthi izithombe zingangezwa ngaphambili kuphela. Uma izithombe ezingemuva zibalulekile kuwe, hlola umhleli wamanje ngaphambi kokwakha iqoqo. Lawa makhasi amabili asemthethweni awanikezi isisekelo sempendulo eqiniseke kakhudlwana.

I-Gizmo iphinde ithi izilungiselelo zokuphendula imibuzo zithinta ukuthi yiziphi izindlela zemibuzo ozibonayo. Ifomethi egciniwe yekhadi nendlela okubuzwa ngayo imibuzo ngalo kuyahlobana, kodwa akufani.

## Umjikelezo wokufunda wenza okungaphezu kokubuyekeza amakhadi

I-Memorise iyindlela eyinhloko yokubuyekeza amakhadi. I-Gizmo igqamisa amagama abalulekile, ikubuze ngawo, bese isebenzisa i-spaced repetition ukuze ibuyise amakhadi ngokuhamba kwesikhathi. I-Magic Import ikhetha ngokuzenzakalela amagama azogqanyiswa, kodwa ungawashintsha.

I-AI Tutor yenza umsebenzi ohlukile. Ingakuchazela izinto zokufunda isinyathelo ngesinyathelo, ikhiqize amanothi futhi ibuze imibuzo esekelwe emthonjeni. Lokhu kuyasiza uma unenkulumo noma idokhumenti kodwa ungakanqumi ukuthi yini okufanele ibe sekhadini lokufunda ozoligcina isikhathi eside.

Kuzo zombili lezi zindlela, i-Gizmo yenza inqubekela phambili ifane nomdlalo. Ukuphendula imibuzo kwengeza ku-XP, ku-Levels, ku-Leagues naku-Streaks, kanti ama-Hearts, ama-Hints nama-Coins athinta indlela ukufunda mahhala okuqhubeka ngayo. Uma lokhu kwenza kube lula ukubuya nsuku zonke, kuyisici esibalulekile lapho ukhetha umkhiqizo.

Noma kunjalo, lezi zinhlobo zemibuzo zifeza izinhloso ezihlukene: umbuzo omfushane wokukhumbula impendulo nombuzo wokuzilolonga onezinyathelo eziningi. [Ukuqhathanisa amakhadi okufunda nezivivinyo zokuzilolonga](/blog/flashcards-vs-practice-tests/) kuchaza ukuthi kungani ukuhlanganisa lezi zindlela kuvame ukusiza kakhulu kunokuphoqelela zonke izihloko ekhadini.

## Imikhawulo emine okufanele uyihlole ngaphambi kokufaka isifundo sonke ku-Gizmo

### Amakhadi akhiqiziwe asadinga ukuhlolwa

I-Gizmo incoma ngokucacile ukuhlola iqoqo ngemva kokusebenzisa i-Magic Import, futhi iphakamisa ukuhlukanisa amadokhumenti amakhulu abe yizingxenye ezincane. Indlela esebenzayo ilula: ngenisa ingxenye eyodwa enomkhawulo ocacile, qhathanisa umphumela nomthombo, lungisa noma ususe amakhadi angasizi, bese uqala ukubuyekeza. Ukukhiqiza konga ukuthayipha; akususi isinyathelo sokuhlela.

### Ukushintsha amakhadi kulula uma uphumile ku-Memorise

[Umhlahlandlela we-Gizmo wokuphatha amakhadi](https://help.gizmo.ai/en/articles/13761411-how-do-i-edit-or-manage-my-cards) uthi ungahlela umbhalo ongaphambili nongemuva, ufake ukufometha, ungeze izithombe ngaphambili, ushintshe izinketho zezimpendulo, uhambise amakhadi futhi uwasuse.

Umkhawulo uvela ku-Memorise: ungakwazi ukususa ikhadi lapho, kodwa okwamanje awukwazi ukulihlela usaphakathi kokuphendula imibuzo. Uma ubona impendulo engalungile lapho ufunda, kufanele uphume kuleyo ndlela ukuze uyilungise.

### Ukukhipha idatha ku-Gizmo akutholakali

Umhlahlandlela ofanayo osemthethweni uthi ukukhipha amakhadi akukatholakali. [Umhlahlandlela we-Gizmo wokuphatha amaqoqo](https://help.gizmo.ai/en/articles/12995587-how-do-i-make-changes-to-my-decks) uthi ukukhipha amaqoqo nakho akutholakali.

Lona ngumkhawulo ocace kakhulu wokulawula idatha endleleni yamanje yokusebenza. I-Gizmo yamukela izinto zokufunda ezivela kwezinye izinhlelo eziningana, kodwa okwamanje ayinayo indlela echazwe emibhalweni yokukhipha amakhadi akhiwe ngalezo zinto. Uma ukuthutha esikhathini esizayo kubalulekile, hlulela umkhiqizo ngalo mkhawulo wamanje kunokuthembela ekutheni kungase kwengezwe ukukhipha idatha kamuva.

### Ukusebenza ngaphandle kwe-inthanethi akuchazwanga ngokucacile ngokwanele ukuba kuthembiswe

Angitholanga sihloko sosizo esisemthethweni se-Gizmo esithembisa indlela yokusebenza ngaphandle kwe-inthanethi, ukugcina izinguquko kudivayisi kuqala, noma inqubo ethile yokuvumelanisa ngemva kokubuya koxhumano. Amakhasi omkhiqizo nokusesha esikhungweni sosizo okuhloliwe kulokhu kubuyekezwa akuwuchazi lowo mngcele.

Lokho **akufakazeli** ukuthi i-Gizmo ayikwazi ukusebenza ngaphandle kwe-inthanethi. Kusho ukuthi ubufakazi obusemthethweni obuhlolwe lapha abanele ukuthembisa ukuthi izosebenza. Uma ukufunda ngaphandle kwe-inthanethi kubalulekile, hlola uhlelo nedivayisi ozoyisebenzisa, uvule imodi yendiza: vala uhlelo uphinde uluvule, ubuyekeze ikhadi, wenze ushintsho, uxhumeke futhi, bese uqinisekisa ukuthi ushintsho nomlando wokubuyekeza kugciniwe.

Lo mehluko ubalulekile ngoba ukuthi “isikrini esesilayishiwe sisaphendula” nokuthi “umlando wami wokubuyekeza ugcinwe ngokuphepha futhi uyavumelaniswa kamuva” kuyizimangalo ezihlukene. [Umhlahlandlela wezinhlelo zamakhadi okufunda ngaphandle kwe-inthanethi](/blog/best-offline-flashcards-app/) usebenzisa lokho kuhlola okuqinile emikhiqizweni eminingana.

## Lapho i-Nibomo ikufanele kangcono

Khetha i-Nibomo uma into ofuna ukuyigcina kuyikhadi elihloliwe elinengaphambili nengemuva. Ungalakha ngesandla noma ucele i-AI ukuthi ikusize ukulibhala nokulithuthukisa, bese unquma ukuthi yini egcinwayo. Ukubuyekeza kusebenzisa i-FSRS; [i-FSRS uma iqhathaniswa ne-SM-2](/blog/fsrs-vs-sm-2/) ichaza kabanzi indlela yokuhlela izikhathi zokubuyekeza.

Izimangalo zayo zokusebenza ngaphandle kwe-inthanethi nezokukhipha idatha zicace kakhudlwana. I-Nibomo ichaza ukufunda ngeselula ngaphandle kwe-inthanethi nokuvumelanisa ngokuzenzakalela, kanti [umhlahlandlela wayo wokuqalisa](/zu/docs/getting-started/) uthi uhlelo lwe-iOS lusebenzisa i-SQLite kudivayisi, nokuvumelanisa okuklanyelwe ukuqala ngokugcina idatha lapho ngaphandle kwe-inthanethi. Amafayela akhishiwe ongawathutha ahlanganisa amakhadi, amathegi nemidiya ehambisanayo, kuhlanganise nokuthutha phakathi kohlelo olusingathiwe noluzisingathele wena.

Okufanele ukucabangele ububanzi bezici. Amakhasi amanje e-Nibomo awachazi imenyu yokungenisa ye-Gizmo, izinhlobo ezinhlanu zamakhadi, izifundo eziholwa yi-Tutor noma uhlelo lwemivuzo. Uma lezo zici zixazulula inkinga ekulethe lapha, cishe i-Gizmo ikufanele kangcono.

## Ungathutha usuke ku-Gizmo uye kolunye uhlelo?

Okwamanje akukho ndlela eqondile yokukwenza. Njengoba ukukhipha idatha ku-Gizmo kungatholakali, ayikho indlela evamile yokuthutha ngamafayela usuka ku-Gizmo uye ku-Nibomo noma kolunye uhlelo.

Indlela ephephile yokudlula lo mkhawulo ukwenza ngesandla, ukhethe okubalulekile:

1. Gcina inkulumo, amanothi, amaslayidi noma omunye umthombo wokuqala eduze kwakho.
2. Yakha kabusha kuphela amakhadi asenembile nasawusizo.
3. Bhala kabusha imibuzo engacacile kunokukopisha wonke amakhadi akhiqiziwe.
4. Lindela ukushiya ku-Gizmo amagama agqanyisiwe, imininingwane yezifundo ze-Tutor, umlando wezikhathi zokubuyekeza, i-XP nenye inqubekela phambili.

Lokhu kuthatha isikhathi eside kunethuluzi lokungenisa, futhi akugcini konke. Umphumela owusizo walokhu ukuthi uhamba kuphela namakhadi aphumelele ukuhlolwa kwekhwalithi.

Ukusebenzisa zombili izinhlelo kungenye inketho. I-Gizmo ingakusiza ukuqonda inkulumo noma isethulo, ikunike izinhlobo ezahlukene zokuzilolonga. I-Nibomo ingagcina iqoqo elincane lamakhadi ahloliwe anengaphambili nengemuva ukuze ubuyekeze nge-FSRS. Ukuwahambisa phakathi kwazo kusenziwa ngesandla ngoba i-Gizmo ayikhiphi amakhadi.

Khetha i-Nibomo uma usuvele wazi ukuthi yini efanele ikhadi elinengaphambili nengemuva ozoligcina isikhathi eside, futhi i-FSRS, ukufunda ngeselula ngaphandle kwe-inthanethi okuchazwe emibhalweni, ukukhipha idatha noma ukuzisingathela kubaluleke kakhulu kuwe kunezinhlobo zemibuzo nemivuzo.

I-Gizmo iyisebenzisa ukuguqula izinto zokufunda ezibanzi zibe indawo yokufunda enezici eziningi. I-Nibomo iyisebenzisa endleleni egxile emakhadini, lapho unquma khona ukuthi yini egcinwayo futhi ehlelelwa ukubuyekezwa.

Uma le ndlela egxile ezicini ezimbalwa isondele endleleni yakho, hlola [izici ze-Nibomo](/zu/features/) noma ulandele [umhlahlandlela wokuqalisa](/zu/docs/getting-started/).
