Looking for **Knowt Live** because someone has a game ready? Open [Knowt's game join page](https://www.knowt.com/join) and enter the six-digit code on the host's screen. Knowt's current documentation calls the live game feature **Knowt Play**; that's the name to look for in the product. Its [getting-started guide](https://help.knowt.com/en/articles/12010990-getting-started-with-knowt-play) explains the basics.

If you're hosting, start with a small set of checked questions and leave time to discuss mistakes. Getting everyone into the game is the first job. Giving each learner something specific to review afterward makes the session useful beyond the final score.

**Documentation checked: September 22, 2026.** This walkthrough is based on Knowt's help center, not hands-on testing. The first-session plan and study examples below are editorial suggestions.

## Joining a game someone else is hosting

On the website, enter the host's code on the join page and select **Next**, or scan the host's QR code. In the mobile app, use **+ → Join a game** and enter the code there.

You can join as a guest unless the host requires sign-in for class materials. In **Classic**, your device shows colored answer tiles; read the question and choices on the host's display before selecting a tile. A phone showing only buttons can be working exactly as intended. These details follow [Knowt's joining instructions](https://help.knowt.com/en/articles/16905169-how-to-join-a-knowt-play-game).

Check what the invitation is for before entering a **Knowt join code**. A live game uses the numeric code above. A class invitation instead uses a six-character code under **Classes → Join a class**, followed by section selection. Follow [the class-joining instructions](https://help.knowt.com/en/articles/16905158-how-to-join-a-class-and-find-your-assignments) if your teacher asked you to enroll in a class.

## How to host Knowt Play

For your first session, use an existing flashcard set or assessment:

1. Open the set and select **Knowt Play**, or open the assessment and select **Play**.
2. Choose a mode and its available settings in the lobby.
3. For a game with device joining, share the displayed code or QR code and check the participant list. For **Clash**, set up teams on the host screen; players don't join on their devices.
4. Select **Start game**. In Classic, discuss the answer before advancing to the next question.
5. Open **View stats** afterward to inspect results.

Knowt's [host guide](https://help.knowt.com/en/articles/16905166-how-to-host-a-knowt-play-game) documents the lobby and game controls. To change question types in a game made from an assessment, edit the assessment outside the lobby.

Knowt says playing from existing flashcards, notes, and assessments is unlimited across plans. Generating games with AI from uploads uses the free plan's AI allowance. Starting with material you already have keeps the first attempt simple. See [Knowt's explanation of playing and AI generation](https://help.knowt.com/en/articles/12010990-getting-started-with-knowt-play). For broader questions about subscriptions or other study features, read our separate [Knowt review](/blog/knowt-alternative/).

## Pick a mode for the kind of practice you want

The mechanics below follow [Knowt's mode documentation](https://help.knowt.com/en/articles/16905168-knowt-play-game-modes-and-settings). The suggested uses are editorial recommendations.

| Mode | What happens | When to try it |
|---|---|---|
| Classic | Everyone answers the current question using the host's display | A first session with discussion between questions |
| Race | Players compete to answer everything correctly first; mistakes reset them | Familiar material where a reset won't derail the group |
| Clash | In-person teams choose from a board on the host screen; no device joining | A group that wants to discuss answers aloud |
| Blitz | Players try to get the most correct answers within a time limit | A short round on material already understood |
| Survival | An incorrect answer eliminates a player | An optional finishing round with a group that enjoys elimination games |

Start with Classic if you're trying to find out what people misunderstand. For unfamiliar material, elimination can leave someone watching just when they need more practice. Save Survival for a group that wants that competition.

## A manageable first session

Try this with one small topic, such as metric prefixes. Allow roughly twelve minutes, and extend the discussion if a question exposes a gap. These timings are a planning example, not a product limit.

Before people arrive, prepare six checked questions: two straightforward recalls, two easily confused pairs, and two applications. Read every answer option yourself. A question with two defensible answers needs editing before it becomes a timed game.

Use the first two minutes to get everyone connected. For Classic, confirm that the person furthest from the shared display can read the smallest answer choice. In a remote group, check that the host's shared screen is readable alongside the answering device.

Spend about six minutes on the questions. After a revealing mistake, ask how someone reached that answer before explaining the correction. A learner who knew the fact but tapped the wrong tile needs a different follow-up from someone who reversed a definition. If the discussion needs longer, use fewer questions.

Keep the last four minutes for individual follow-up. Have each learner choose at most two uncertain facts, including lucky guesses. Write a short question for each and answer it without the multiple-choice options. Leave with those cards and one worked problem.

## When the session doesn't behave as expected

| What you see | What to check next |
|---|---|
| A code doesn't get you into the expected activity | Ask whether it is a game code or class invitation. Compare it with the host's current screen. |
| Only colored tiles appear on a student's device | In Classic, look at the host's display for the question. Check screen visibility before restarting. |
| The game asks for an account | Ask the host whether sign-in is required for these class materials. |
| There's no joining step | Check whether the host chose Clash, which uses the in-person board. |
| Question-type controls can't be changed | If the source is an assessment, return to it and edit there. |

The [host guide](https://help.knowt.com/en/articles/16905166-how-to-host-a-knowt-play-game) describes an account requirement switch. The current [joining guide](https://help.knowt.com/en/articles/16905169-how-to-join-a-knowt-play-game) ties required sign-in to class materials, as does Knowt's older [additional details page](https://help.knowt.com/en/articles/12111502-additional-details). Check the available controls in your lobby before asking the whole group to create accounts.

## Turn one wrong answer into a useful card

Suppose a learner selects “million” when asked what lowercase `m` means as an SI prefix. The correction is specific: `m` means milli, `10^-3`; uppercase `M` means mega, `10^6`. [NIST's prefix table](https://www.nist.gov/pml/owm/metric-si-prefixes) gives the authoritative symbols and values.

“Review metric prefixes” leaves too much work for later. Make the missing distinction explicit:

| Card front | Card back |
|---|---|
| As an SI prefix, what does lowercase `m` mean, and what is its multiplier? | Milli; `10^-3`, or one thousandth. |
| How do the SI prefixes `m` and `M` differ? | `m` is milli, `10^-3`. `M` is mega, `10^6`. Case changes the meaning. |

Then work through a conversion: `5 mm = 5 × 0.001 m = 0.005 m`. In `mm`, the first `m` is the prefix and the second is the metre symbol. Our [metric-prefix guide](/blog/metric-prefixes-flashcards/) has more examples of these distinctions.

Manually put the checked cards wherever you already review. Try them again tomorrow without answer choices, then attempt a fresh conversion. If the conversion still fails, work through it before adding more cards. The [quiz-results-to-flashcards workflow](/blog/how-to-turn-quiz-results-into-flashcards/) develops that follow-up further.

For your next session, bring back one of those distinctions in a new question. You'll have something specific to check: can the learner now explain the difference and use it?
