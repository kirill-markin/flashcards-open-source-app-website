Alaska is AK, Alabama is AL, and Arkansas is AR. The first two letters of a state's name won't always give you its postal abbreviation, which is where a quick lookup helps.

For a lookup, find the state in the alphabetical table below. For study, cover the code column and try to supply each answer, then switch columns. Recognizing a pair on the page and producing it from memory are different tasks.

A state abbreviation is separate from a ZIP Code. In an address, the two-letter code identifies the state; the ZIP Code is the numeric part that follows it. If a form has separate fields for state and ZIP Code, enter each in its own field.

Washington, DC uses **DC**, and Puerto Rico uses **PR**. They have postal abbreviations, but neither belongs in a table of the 50 states. USPS's appendix also includes territories and other postal destinations; use the [full USPS reference](https://pe.usps.com/text/pub28/28apb.htm) if that's what you need.

## Start with the codes you mix up

An alphabetical list is handy for finding an answer, but it also lets the surrounding rows act as clues. Start by comparing the names you confuse, then mix them with unrelated states to check whether you can recall each answer on its own.

![Similar keys being sorted into separate compartments of a small tray](/blog/us-state-abbreviations.png)

### Alaska, Alabama, Arkansas, Arizona

Keep these four together for an initial comparison:

- **Alaska → AK:** notice the K in Alaska.
- **Alabama → AL:** the first two letters work here.
- **Arkansas → AR:** again, the first two letters.
- **Arizona → AZ:** notice the Z in Arizona.

Use these observations as memory cues. Once you've looked at the group, cover it and answer “AK means which state?” Then try “What is Arkansas's code?” Check the reverse questions too: Alaska to AK, and AR to Arkansas. You may find one direction easier.

### The eight M states

Michigan, Minnesota, Mississippi, and Missouri all begin with “Mi.” Only Michigan uses MI. Learn their complete pairs rather than trying to shorten every name by the same rule.

| State | Code | Detail to notice |
| --- | --- | --- |
| Michigan | MI | Uses the opening MI |
| Minnesota | MN | The second code letter is N |
| Mississippi | MS | The second code letter is S |
| Missouri | MO | The second code letter is O |
| Massachusetts | MA | Uses the opening MA |
| Maryland | MD | Begins with M and ends with D |
| Maine | ME | Begins with M and ends with E |
| Montana | MT | Includes the T in Montana |

If you answer “Missouri” when shown MS, write down that exact confusion: **MS = Mississippi; MO = Missouri**. Reviewing the pair gives you a specific distinction to work on. Rereading all eight names can hide which one caused the problem.

### Iowa, Idaho, Illinois, Indiana

Idaho is ID, Illinois is IL, and Indiana is IN. Iowa is **IA**, using its first and last letters. Practice IA separately if you keep guessing IO, then mix it back into the group.

### Washington state and Washington, DC

**WA means Washington state. DC means the District of Columbia.** Use “Washington state” on your own card fronts so the prompt is unambiguous. A card that says only “Washington abbreviation?” leaves unnecessary room for interpretation.

## Decide what you need to recall

A geography assignment can ask for several different skills. Match your practice to the question you'll actually face.

| Task | Example prompt | Expected answer |
| --- | --- | --- |
| State to code | What is Minnesota's USPS abbreviation? | MN |
| Code to state | Which state uses MN? | Minnesota |
| Map location | Identify a highlighted state on a blank map | The state's name |

The table supplies the answers for the first two tasks. For a map test, use a blank map with an answer key and practice identifying the states by location. State capitals need their own prompts too, such as “What is Minnesota's capital?” Keep those cards separate from abbreviation questions so each answer tells you which fact you remembered.

Before checking, mark any answer you guessed or had to think through for a while. Keep those marks even if the answers turn out to be correct; they help you choose what to practice next.

## Turn mistakes into two-way practice

For each missed or uncertain pair, make two small cards. For example:

| Front | Back |
| --- | --- |
| Missouri — USPS abbreviation? | MO |
| USPS abbreviation MO — which state? | Missouri |

If you confused MO with MS, add Mississippi's two cards too. Keep one answer per card, and separate the reverse cards with other questions so you aren't answering from the card you just saw. Our [guide to writing better flashcards](/blog/how-to-make-better-flashcards/) covers how to keep prompts specific.

On the next review, answer before revealing the back and record mistakes honestly. Return to those cards in a later session to check whether the answers still come to mind. Add more states as you have time to review them; you don't need to introduce every card in one sitting.
