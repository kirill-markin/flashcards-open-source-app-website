Gizmo's current help documents a PDF export: open a deck's three-dot menu, choose **Print**, then save from your browser's print dialog. Getting a file is only part of the job, though. A matching question with every pair already lined up can become an answer sheet before you start studying.

For a mixed deck, check whether the saved pages still ask something you can answer on paper. A tidy page can preserve all the words while giving away the task.

## Save your Gizmo cards as a PDF

Gizmo's [deck-management instructions](https://help.gizmo.ai/en/articles/12995587-how-do-i-make-changes-to-my-decks) give this route:

1. Open the three-dot menu at the top right of the deck.
2. Choose **Print** to open the browser's print menu.
3. Choose **Save as PDF**, select your settings, and save the file.

The same help page says decks made by Gizmo can also be printed through their top menu. It doesn't establish availability for every account, plan, or platform. If **Print** is missing from your menu, use the help page's contact option to ask about your account and device.

In Chrome, the print window lets you choose a destination and adjust print settings; see [Google's printing instructions](https://support.google.com/chrome/answer/1069693?hl=en). Use the paper size you intend to print on. Save with a recognizable name, such as `biology-cell-structures-2026-10-28.pdf`, then open that file.

Keep the source deck available for comparison. Inspect the saved PDF before sending it to a printer or taking it somewhere without internet.

## Check what each question still asks

Gizmo lists [seven flashcard types](https://help.gizmo.ai/en/articles/16527223-what-types-of-flashcards-can-i-make). Some involve choosing, rearranging, or revealing things during a quiz. The linked help pages don't specify how each type appears in a PDF.

The table below is a checklist for your output. The suggested repairs are paper-study advice; they aren't claims about Gizmo's printed layout or export controls.

| Card type | Check in your saved PDF | If the question needs adapting |
| --- | --- | --- |
| Q&A | The complete prompt and answer are present, including necessary symbols | Put the answer where you can cover it while reading the prompt |
| Multi-select | All options appear, and correct selections aren't exposed in the question | Letter the options and keep the complete correct set in a separate key |
| Fill the blanks | The passage has enough context to answer, with the intended words hidden | Replace the tested words with blank spaces and record accepted answers separately |
| Order items | The question doesn't reveal the required sequence | Shuffle a labeled list and specify the rule for ordering it |
| Match pairs | Both groups are complete, with no lines or arrangement giving away the matches | Shuffle one group and answer with number–letter pairs |
| True or False | The statement is complete and its answer is hidden | Leave space to mark True or False; put the answer and any correction in the key |
| Image question | The diagram is legible and the labels being tested aren't revealed | Make a numbered diagram with a separate label key |

Start with one example of every type your deck contains. Include the longest question and any card that needs an image or mathematical notation. This small sample tells you what needs attention before you check the whole file.

If answers appear beside questions, the PDF may work as a reference sheet. For self-testing, copy the affected material into a document and make a question sheet with a separate key. Check any copied text and diagrams against the source. The [guide to writing better flashcards](/blog/how-to-make-better-flashcards/) has more examples of making prompts specific enough to answer.

## Three questions you can adapt for paper

Matching, ordering, and multi-select questions need more than a prompt and one answer. These original examples keep the required action clear. For a worksheet, copy the prompts, options, and answer spaces below into a document; put the key on a separate page.

### 1. Matching: shuffle the answer group

Match each SI unit to the quantity it measures. Use each letter once.

| Unit | Quantity |
| --- | --- |
| 1. kilogram | A. time |
| 2. second | B. length |
| 3. metre | C. mass |

**Your answer:** 1 → ___; 2 → ___; 3 → ___.

Printing each unit beside its matching quantity would supply the answer. The shuffled column preserves the matching task. For a larger exercise, check that each numbered item has exactly the intended match; overlapping descriptions can make a question ambiguous.

### 2. Ordering: state the direction

Put these masses in ascending order, from smallest to largest. Write the letters in order.

- A. 1 kg
- B. 250 g
- C. 2 kg
- D. 1,500 g

**Your answer:** ___ → ___ → ___ → ___.

“Put these in order” would leave the direction unclear. Specify the rule and keep the supplied list out of the correct order. If two items tie, say whether either order is acceptable.

### 3. Multi-select: keep the whole answer set

Select all the numbers divisible by 3. There may be more than one correct answer.

- A. 6
- B. 8
- C. 9
- D. 14
- E. 15

**Your answer:** ____________________.

For this exercise, a fully correct response must include every correct option and no incorrect options. State that rule on the question sheet so the learner knows how to mark the result.

### Answer key

1. **Matching: 1 → C, 2 → A, 3 → B.** A kilogram measures mass, a second measures time, and a metre measures length.
2. **Ordering: B → A → D → C.** In grams, the values are 250, 1,000, 1,500, and 2,000.
3. **Multi-select: A, C, and E.** The numbers 6, 9, and 15 equal 3 × 2, 3 × 3, and 3 × 5. Neither 8 nor 14 is divisible by 3 without a remainder. Selecting only A is incomplete; selecting A, C, D, and E adds an incorrect option.

The key needs to preserve the full response: every pair, every position, or every correct selection. Recording one correct choice from a multi-select question changes what you can check.

## Decide whether the file is ready to use

Once the sample works, compare every intended source question with the PDF or your adapted worksheet. Count questions, then check their content: equal totals can still hide a duplicated question and a missing one. Check the corresponding answers too.

Give each adapted question an identifier and use it in the key. Keep a short repair list, such as “Q12: label visible” or “Q19: option D missing,” and resolve it before printing. This is especially useful when a question spans several lines or pages.

Print one copy and attempt a few questions with the key out of sight. Check small labels, page breaks, and any color distinctions in diagrams. If you'll use the PDF offline, open the saved file with the connection off before leaving.

A usable paper copy passes three checks: every intended question is present, you can attempt it without seeing its answer, and the key lets you check the complete response.

## Keep the source deck too

A readable PDF can preserve material for a lesson, a trip, or desk study. A restorable deck backup also needs the structure and state required to recreate the deck. Saving pages alone doesn't demonstrate that you can restore it.

The linked Gizmo help pages document PDF export. They don't establish editable CSV or APKG export, restoration from PDF, or transfer of review scheduling. If migration is your goal, verify those capabilities separately before relying on a PDF as your only copy.
