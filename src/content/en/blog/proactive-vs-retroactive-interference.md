Imagine learning that rehearsals happen upstairs, then learning that they've moved downstairs. Later, someone asks about the rehearsal room and you answer “upstairs.” That could be a mistake or a perfectly good answer. It depends on whether they asked for the current room or the previous one.

**Proactive interference happens when earlier learning interferes with remembering newer information. Retroactive interference happens when newer learning interferes with remembering earlier information.** These are the directions described in [OpenStax's psychology chapter on memory](https://openstax.org/books/psychology-2e/pages/8-3-problems-with-memory). To tell them apart, identify the memory the question asks for and the learning that gets in its way.

A wrong answer alone doesn't tell you its cause. The original practice problems below make the interference explicit where you're meant to classify it: one memory hinders recall of another. Your job is to work out the direction. Other problems deliberately leave out a necessary detail or describe no interference.

## Start with the answer the question wants

Write down four details before choosing a label:

| Detail | What to record |
| --- | --- |
| Earlier learning | What the person learned first |
| Later learning | What they learned afterward |
| Target memory | The information they're being asked to recall |
| Competing memory | The information getting in the way |

Then read the relationship from competitor to target:

- **Earlier → later: proactive interference.**
- **Later → earlier: retroactive interference.**

“Old” and “new” refer to learning order. Both facts might have been learned this morning. Recalling the first fact today doesn't make it the later learning in the problem.

A short mnemonic is **proactive: the prior learning intrudes**. For retroactive, picture the later learning reaching back. Use the four details to check the mnemonic against the actual question.

## Keep the room change; change the question

Mina first learns that rehearsals happen in the upstairs room. A month later, she learns the new location: downstairs. Consider two possible versions of what happens next.

**Version A:** Someone asks for the current room. The upstairs location keeps coming to mind and interferes with Mina's recall of downstairs.

**Version B:** Someone asks where the group rehearsed before the move. The downstairs location keeps coming to mind and interferes with Mina's recall of upstairs.

| Detail | Version A | Version B |
| --- | --- | --- |
| Earlier learning | Upstairs | Upstairs |
| Later learning | Downstairs | Downstairs |
| Target | Downstairs, the current room | Upstairs, the previous room |
| Competitor | Upstairs | Downstairs |
| Classification | Proactive | Retroactive |

The learning order stays fixed. Switching the requested memory changes which answer counts as an intrusion. In Version A, upstairs gets in the way. In Version B, upstairs would be the correct answer.

The words “old room” don't decide the label. You need to know whether that room is the target or the competitor.

## A second pair without a replaced fact

Imagine a volunteer learning two exhibition guides. On Monday, they learn that a ceramic bowl in Exhibition A came from **Linden**. On Thursday, they learn that a similar bowl in Exhibition B came from **Merrow**. Both place names are invented for this exercise.

Asked about Exhibition B, the volunteer keeps retrieving Linden, making Merrow hard to recall. This is **proactive interference**: the Monday association competes with the Thursday target.

Asked about Exhibition A, the volunteer keeps retrieving Merrow, making Linden hard to recall. This is **retroactive interference**: the Thursday association competes with the Monday target.

Both facts remain correct and worth knowing. Each place name belongs to a different bowl; neither replaces the other. Write “Exhibition A's bowl” or “Exhibition B's bowl” as the target before classifying the problem.

## Try these before reading the answers

For each case, identify the target and choose **proactive**, **retroactive**, **not enough information**, or **neither type is demonstrated**. Explain which detail supports your choice.

1. A student learns that a fictional animal called a *nava* is striped. Later, they learn that a *nema* is spotted. Asked to describe a nema, the student keeps retrieving “striped,” which interferes with recalling “spotted.”
2. A pianist learns an early version of a piece, then a revision with a different ending. Asked to recall the early ending, they can only bring the revision's ending to mind; it gets in the way of the earlier one.
3. A volunteer learns the seating plans for two events, one after the other. Later, the volunteer mixes them up. The account doesn't say which plan they were trying to recall.
4. A student has never seen the symbol used in a question and has never learned its meaning. They leave the answer blank.
5. A guide learns a walking route through the east gate, then a revised route through the west gate. Asked to describe the revised route, the guide recalls west correctly and explains it without difficulty.
6. A learner studies a fictional code where a triangle means “wait.” Later, they study a second code where a triangle means “turn.” When asked for the first code's meaning, “turn” intrudes and makes “wait” difficult to retrieve.

### Answers and the detail that decides each one

1. **Proactive.** The target is the newer nema–spotted association. The earlier nava–striped association gets in the way. Similar names alone wouldn't establish interference; the problem explicitly says the earlier response hinders recall.
2. **Retroactive.** The target is the early ending. The later revision interferes with recalling it. “Early version” tells you which ending is correct for this question.
3. **Not enough information.** We need the requested plan and the response that got in its way. “Mixes them up” doesn't establish a direction or explain exactly what happened.
4. **Neither type is demonstrated.** The requested answer is the symbol's meaning, but the student never learned it. There is no learned target or competing memory in this account.
5. **Neither type is demonstrated.** The target is the newer west-gate route. The guide recalls it without difficulty; the account describes no interference. Simply learning a second route isn't enough to classify an error.
6. **Retroactive.** “Wait” is the earlier target; “turn” is the later competitor. The phrase “first code” determines which meaning the learner needs to retrieve.

These answers classify the relationships supplied by the exercises. If all you know about a real situation is that someone learned two things and later forgot one, you haven't established that one caused difficulty recalling the other.

## Turn a missed answer into a better review prompt

If you reversed a label, keep the scenario on the front of a review card. On the back, identify the target and competitor before giving the term. A correct label with the wrong target still needs work.

Here are three cards you can use:

| Front | Back |
| --- | --- |
| Mina learned upstairs first, then downstairs. Asked for the current room, the earlier location interferes. Name the target, competitor, and type. | Target: downstairs. Competitor: upstairs. Proactive interference. |
| Mina learned upstairs first, then downstairs. Asked for the previous room, the later location interferes. Name the target, competitor, and type. | Target: upstairs. Competitor: downstairs. Retroactive interference. |
| Someone learns two seating plans and later “mixes them up.” What do you need before classifying the interference? | Which plan was requested, and which learned response hindered recall. Learning order alone doesn't establish the direction. |

For a broader study set, the [AP Psychology flashcard guide](/blog/how-to-use-flashcards-for-ap-psychology/) includes cards for concepts and applications. For your next practice question, keep the two learned facts, switch which one is requested, and explain why the label changes before turning the card over.
