One classmate's card says mega means a million. Another says a thousand. Combining their sets puts both answers in reach, but you still need to decide which one to learn.

To **merge Knowt flashcard sets**, go to **Materials**, open a set's three-dot menu, and choose **Combine**. Select the other set or paste its link, then create and save the combined set. Below are both documented routes, followed by an eight-card worksheet with a complete, checked result.

## Combine sets from Materials

Knowt's [official merge guide](https://help.knowt.com/en/articles/10714485-how-can-i-merge-flashcard-sets) gives two routes:

1. Open a set's three-dot menu in **Materials** and choose **Combine**.
2. Select the second set, or paste its link.
3. Choose **Create combined set**, name the result, and save it.

For several sets, use **Materials → Select multiple**, choose the sets, then select **Merge sets → Create combined set**. Name and save the result. The guide also supports combining public sets from other users through their links.

It doesn't establish duplicate handling, final card count or order, review-history transfer, ongoing synchronization with source sets, mobile merge availability, or a maximum number of sets.

Give the working result a recognizable name, such as “Metric symbols — checking.” Keep the source set names and links in a separate note so you can trace a disputed answer. The worksheet below uses simple source labels for that purpose.

### Merge, duplicate, or use a folder?

Choose the action that fits what you want to do:

| Your task | Relevant action |
|---|---|
| Bring material from several sets into a new set | Use the merge route above |
| Make an editable copy of one set | Use [Duplicate](https://help.knowt.com/en/articles/10714459-how-can-i-duplicate-my-flashcards) |
| Organize existing sets together | [Move them into a folder](https://help.knowt.com/en/articles/10714495-how-can-i-move-items-into-folders) |

The **Duplicate** action copies a set. Checking for duplicate flashcards means examining repeated questions inside your material; the shared word can make these two tasks easy to confuse.

## Check these eight source cards

Imagine two classmates share four cards each about metric symbols. A1–B4 are worksheet labels, not Knowt fields.

**These inputs deliberately include mistakes. B1's multiplier is wrong, and both “m means?” questions lack context. Don't use this first table as a finished study set.**

| Source | Front as received | Back as received |
|---|---|---|
| A1 | SI prefix M means? | mega, `10^6` |
| A2 | SI prefix k means? | kilo, `10^3` |
| A3 | m means? | metre (unit) |
| A4 | SI prefix μ means? | micro, `10^-6` |
| B1 | SI prefix M means? | mega, `10^3` |
| B2 | What multiplier does kilo (k) denote? | `1000` |
| B3 | m means? | milli, `10^-3` |
| B4 | SI prefix μ means? | micro, `10^-6` |

Start by comparing the questions and answers, rather than aiming for a smaller card count. Which answer needs correction? Which tasks can be combined? Which matching questions actually need more detail?

For this exercise, the manual decisions produce **five precise recall tasks**. Each decision is explained below, and all eight source records appear in the final table.

### Correct the conflicting mega answer

A1 and B1 ask the same question but disagree about the exponent. Repetition across sources doesn't settle the answer, and neither does the order in which you combined the sets.

[NIST's SI prefix table](https://www.nist.gov/pml/owm/metric-si-prefixes) lists uppercase `M` as mega, `10^6`. Lowercase `k` is kilo, `10^3`. B1 has attached kilo's multiplier to mega. Keep one checked mega card with `10^6`.

For your own subject, take the disputed claim back to a suitable reference: the assigned textbook, an official specification, or another authoritative source. If it remains unresolved, record the open question separately and leave it out of the set you're about to memorize.

### Decide whether the kilo questions earn separate cards

A2 and B2 cover the same mapping, but they don't ask exactly the same question. B2 gives you the name *kilo* and asks only for its multiplier. A2 requires you to recall the name as well.

This worksheet combines them into one prompt asking for both the name and multiplier of `k`. The answer keeps the useful information from each source: “kilo; `10^3`, or 1,000.” That's a deliberate choice for this small set. If your course requires recall in several directions, keep those as explicitly different questions.

A4 and B4 need less judgment: their fronts and backs match exactly. Retain one micro task in the checked set. This is a manual content decision, without assuming Knowt removes either copy.

### Give the two meanings of m separate questions

A3 and B3 have identical fronts and different backs, yet both meanings are valid. NIST lists `m` as the prefix milli, `10^-3`; its [SI units guide](https://www.nist.gov/pml/owm/metric-si/si-units) also lists `m` as the symbol for the metre, the unit of length.

The missing information belongs on the front. Ask about an **SI unit symbol** on the metre card and an **SI prefix** on the milli card. Keep both.

Matching question text can expose an incorrect answer, as with mega, or an incomplete question, as with `m`. Check the meaning before deciding that one record can go.

Eight inputs, five checked tasks. This is the worksheet's result after reconciliation; Knowt's automatic output may differ.

## Save the checked wording in Knowt

Knowt's [editing guide](https://help.knowt.com/en/articles/10716239-how-do-i-create-and-edit-flashcards) documents opening a set from **Materials**, using its three-dot menu and **Edit this set**, or choosing **Edit** on the set page. Change the wording and select **Save**.

Compare the saved content with the five-pair table, including any repeated records. For this small exercise, you can also create a separate clean set: the same guide documents entering terms and definitions in a new set, then choosing **Save & Create**. Entering the five checked pairs gives you a definite result without depending on the merge's duplicate policy.

Before reviewing, check that:

- Every source row A1–B4 has a decision in your worksheet.
- Mega has `10^6`, and the incorrect mega–`10^3` pairing is absent.
- Kilo and micro each have one retained task for this exercise.
- The two lowercase `m` questions explicitly distinguish unit from prefix.
- The saved fronts and backs preserve case, symbols, and negative exponents.

For a larger collection, keep recording the sources and your decisions as you work. A lower card count alone doesn't show whether useful material survived.

## Try the repaired questions from memory

Say or write each answer before revealing the back. Knowt's [Flashcards mode guide](https://help.knowt.com/en/articles/10298062-how-can-i-use-flashcards-mode) documents question-format and shuffle options; use a format that shows the question and leaves its answer for you to recall.

Then try a small application: in `3 mm`, the first `m` means milli and the second means metre, so `3 mm = 0.003 m`. Knowing the prefix and using it in a conversion deserve separate checks. The [metric-prefix guide](/blog/metric-prefixes-flashcards/) has more examples if that's your subject.

Return to the checked cards on later days, adjusting the gaps to what you can recall. Regular recall with spaced review supports long-term retention. Pay attention to mistakes and lucky guesses as you decide what needs another attempt.
