Your Quizlet link opens the right flashcards for you. Your classmate can’t get to the cards. Check who can see the set. If it’s set to **Just me**, only the creator can open it. Ask the creator if you need access to a restricted set you didn’t make. For class material, choose **Certain classes** and check the student’s membership in the exact class. For a friend outside the class, the creator can share a password-protected set. [Quizlet’s guide to set access](https://help.quizlet.com/hc/en-us/articles/360029768352-Trouble-accessing-a-set), [Quizlet’s visibility instructions](https://help.quizlet.com/hc/en-us/articles/360030255191-Changing-a-set-s-visibility)

## Check who can see the set

On the Quizlet website, sign in as the creator and find the set under **Your library → Flashcard sets → Created**. Open **More → Edit** on the set page. In the editor, Quizlet’s visibility guide points to the audience label near the top. If you see a **Settings** gear, look for **Visible to** there. Choose the audience, select **Save** if prompted, then choose **Done** to finish editing on the website. The help pages also give steps for each mobile app. [Quizlet’s visibility instructions](https://help.quizlet.com/hc/en-us/articles/360030255191-Changing-a-set-s-visibility), [Quizlet’s set password instructions](https://help.quizlet.com/hc/en-us/articles/360029771292-Protecting-a-set-with-a-password)

| Visibility | Who can open the set |
| --- | --- |
| **Just me** | Only the creator. |
| **Certain classes** | People signed in to an account that belongs to one of the selected classes. The creator can select classes they created or administer. |
| **People with a password** | Anyone who has the password for this set. |
| **Everyone** | Anyone. The set can appear in search results. |

For material meant for one class, select that class. If you choose **People with a password**, create a password just for the set and send it separately from the link. Keep your Quizlet account password private. Recipients can forward the set password, so use it for material you’re comfortable sharing that way. [Quizlet’s sharing instructions](https://help.quizlet.com/hc/en-us/articles/360030254831-Sharing-sets-and-folders)

If someone can study the cards and needs to change them, check **Editable by**. Quizlet limits editing to the creator by default. For study-only access, leave **Editable by** at **Just me** and adjust who can view the set. [Quizlet’s editing permissions](https://help.quizlet.com/hc/en-us/articles/360037864311-Changing-a-set-s-editing-permissions)

## When one student can’t open a class set

Suppose Jordan can’t open **Cell Transport Review**. The teacher opens the published set, checks that its visibility includes **Biology, Period 2**, and copies the page address. The message to Jordan includes that link, the set title, the creator’s username, and the full class name. A search also turns up **Biology, Period 4**, so Jordan uses the teacher’s username and the full class name to find the assigned section. [Quizlet’s guide to finding your teacher’s class](https://help.quizlet.com/hc/en-us/articles/360030764951-Finding-your-teacher-s-class)

Jordan sends the teacher a direct message with the username shown on the account they were using. It’s `jordan.reviews`. On the Period 2 roster, the teacher finds Jordan’s older account, `jordan.oldnotes`. Jordan can use that enrolled account, or request to join **Biology, Period 2** as `jordan.reviews`. If Jordan requests to join, the teacher approves that username for Period 2 before Jordan retries. [Quizlet’s guide to finding your teacher’s class](https://help.quizlet.com/hc/en-us/articles/360030764951-Finding-your-teacher-s-class)

## Ask the recipient to open a flashcard

Have the recipient reopen the same link from their own Quizlet account. For a class set, use the account on the roster. For a password-protected set, enter the set password when prompted. Ask them to confirm the title and creator, open **Flashcards**, and flip any card. Jordan could reply, “I see *Cell Transport Review* and can flip a card to see both sides.” [Quizlet’s Flashcards instructions](https://help.quizlet.com/hc/en-us/articles/360030988091-Studying-with-Flashcards)

If it still fails, ask them to send the link they opened, the username they were signed in with, the class name if applicable, and the message on screen in a direct reply. Include whether it happened on the website or in the app if you contact support. [Contact Quizlet support](https://help.quizlet.com/hc/en-us/requests/new)

## If you sent a folder or the set is still a draft

If you shared a folder, open the individual set and send its link. A recipient may be able to see the folder while an individual set is still restricted. Check visibility on that set. [Quizlet’s folder instructions](https://help.quizlet.com/hc/en-us/articles/360030986151-Organizing-study-content-with-folders)

If the set is under **In Progress**, the creator should return to the website or app where they started the draft. Check the audience, publish the set, then copy the link from the finished page. A published set can still be restricted to its intended audience. [Quizlet’s draft instructions](https://help.quizlet.com/hc/en-us/articles/360029768912-Editing-draft-sets), [Find and publish a Quizlet draft](/blog/does-quizlet-save-drafts/)
