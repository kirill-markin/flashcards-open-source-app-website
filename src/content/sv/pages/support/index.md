## Kontakt

För produktsupport, hjälp med kontot eller frågor om App Store-granskningen, mejla [kirill+flashcards@kirill-markin.com](mailto:kirill+flashcards@kirill-markin.com).

## Radering av konto

För att radera ditt Nibomo-konto utan att installera appen öppnar du [sidan för kontoradering](https://app.nibomo.com/settings/delete-account). Logga in med samma e-postadress som du använder för ditt konto om du blir ombedd att göra det. Välj `Radera mitt konto`, skriv in bekräftelsefrasen som visas och bekräfta raderingen. Du kan också begära att kontot raderas genom att mejla [kirill+flashcards@kirill-markin.com](mailto:kirill+flashcards@kirill-markin.com).

Raderingen tar bort dina aktuella kontouppgifter, inloggningsuppgifter, medlemskap och arbetsytor där du är den enda medlemmen från den aktiva databasen. Innehållet i delade arbetsytor finns kvar för övriga medlemmar. Nödvändig faktureringshistorik sparas för bokföring, avstämning och rättsliga anspråk. Raderade poster kan finnas kvar i krypterade säkerhetskopior för återställning i upp till 35 dagar. Se vår [integritetspolicy](/sv/privacy/) för fullständig information om lagring.

Att radera ditt Nibomo-konto avslutar inte din Google Play-prenumeration. [Hantera eller avsluta den separat via Google Play](https://play.google.com/store/account/subscriptions).

## Öppen källkod och tekniska rapporter

Nibomo har öppen källkod. För felrapporter, problem med drift på egen server eller tekniska diskussioner kan du också använda [GitHub-repot](https://github.com/kirill-markin/flashcards-open-source-app) och ärendehanteringen där.

## Drift på egen server

Om du inte vill använda den molndrivna betan kan du köra samma stack med öppen källkod själv och driva tjänsten på din egen infrastruktur.

## Förväntade svarstider

Under betaperioden ges support i mån av möjlighet. Vi försöker svara så snabbt som möjligt, men svarstiderna är inte garanterade.
