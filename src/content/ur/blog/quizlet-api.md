18 اگست 2026 تک Quizlet کی دستاویزات میں نہ کسی ایسی عوامی ڈویلپر API کا ذکر ہے جس تک ڈویلپر خود رسائی حاصل کر سکیں، نہ کسی عوامی ڈویلپر پورٹل کا۔ فی الحال کسی آزاد ڈویلپر کے لیے کوئی سرکاری طریقہ موجود نہیں کہ وہ اپنی ایپ رجسٹر کرے، Quizlet API کی کلید حاصل کرے، اور دستاویزات میں بیان کردہ اینڈپوائنٹس سے فلیش کارڈز کا ڈیٹا پڑھ یا لکھ سکے۔

یہ نتیجہ Quizlet کی عوامی دستاویزات کے بارے میں ہے؛ اس کے اندرونی نظام کے بارے میں کوئی دعویٰ نہیں۔ Quizlet میں دوسری مصنوعات اور شراکت داروں کے ساتھ انٹیگریشنز ضرور موجود ہیں۔ اس کی ChatGPT ایپ اور Google Classroom ایڈ آن اس کی دو موجودہ مثالیں ہیں۔ تاہم، ان میں سے کوئی بھی دوسری ایپلی کیشنز کو عام استعمال کے لیے Quizlet کی ڈویلپر API فراہم نہیں کرتا۔

**حقائق کی تصدیق:** 18 اگست 2026۔

> **میرے تعلق کی وضاحت:** میں Kirill Markin ہوں اور Nibomo بنا رہا ہوں، جس کی Agent API اور MCP سرور کا ذکر آگے متبادل کے طور پر ہے۔ Nibomo، Quizlet کے ساتھ مطابقت نہیں رکھتا اور Quizlet سیٹ خودکار طور پر امپورٹ نہیں کرتا۔

## مختصر جواب: Quizlet کی کسی عوامی، سیلف سروس API کی دستاویزات موجود نہیں

اگر آپ نے «کیا Quizlet کی API ہے؟» اس لیے تلاش کیا کہ آپ خود Quizlet میں کام خودکار کرنا چاہتے ہیں، تو فی الحال عملی جواب یہی ہے: **ایسی عوامی API کی دستاویزات موجود نہیں جس تک ڈویلپر خود رسائی حاصل کر سکیں**۔

کئی سرکاری سہولتیں بظاہر API جیسی لگ سکتی ہیں۔ مگر ان میں سے ہر ایک کا دائرہ محدود ہے:

| آپ کی ضرورت | سرکاری طور پر دستیاب طریقہ | کس کام کے لیے موزوں ہے | کیا نہیں ملتا |
|---|---|---|---|
| اپنے بنائے ہوئے سیٹ کا متن منتقل کرنا | [Quizlet کی ویب سائٹ سے ایکسپورٹ](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets) | اصطلاحات اور تعریفوں کی ایک بار کاپی لینا | تصاویر، کاپی کیے گئے سیٹ کی ایکسپورٹ، مطالعے کا سابقہ ریکارڈ یا API تک رسائی |
| کسی عوامی سیٹ کو ویب سائٹ یا LMS کے صفحے پر دکھانا | [Quizlet ایمبیڈ](https://help.quizlet.com/hc/en-us/articles/360032935851-Embedding-sets) | اپنے صفحے کے اندر Quizlet کی شناخت کے ساتھ مطالعے کی سرگرمی دکھانا | کارڈز کا منظم ڈیٹا یا اسے پڑھنے اور لکھنے کی رسائی |
| ChatGPT کی گفتگو سے Quizlet سیٹ بنانا | [ChatGPT میں Quizlet ایپ](https://quizlet.com/blog/quizlet-comes-to-chat-gpt) | `@Quizlet` کے ذریعے سیٹ بنانا اور اس کا پیش نظارہ دیکھنا | اپنی ایپ کے لیے رسائی کی اسناد یا اینڈپوائنٹس |
| Google Classroom میں Quizlet کا کام تفویض کرنا | [Quizlet کا Google Classroom ایڈ آن](https://quizlet.com/blog/quizlet-google-classroom-add-on) | Classroom میں سرگرمیاں تلاش کرنا، تفویض کرنا اور ان کی پیش رفت دیکھنا | اپنی ضرورت کے مطابق بنائے گئے تعلیمی سافٹ ویئر کے لیے عام API |
| Quizlet کے ساتھ اپنی انٹیگریشن بنانا | فی الحال خود رسائی حاصل کرنے کا کوئی طریقہ دستاویزات میں درج نہیں | کسی مخصوص شراکت دار کے لیے الگ انتظام موجود ہو سکتا ہے | سب کے لیے رجسٹریشن، API کلیدیں یا کارڈز پر کام کرنے کی واضح تکنیکی شرائط |
| اپنے فلیش کارڈ ورک اسپیس کے کام خودکار کرنا | [Nibomo Agent API](/ur/docs/api/) یا [MCP کنیکٹر](/ur/docs/mcp-connector/) | ورک اسپیس کے دائرے میں کارڈز اور ڈیکس کو بار بار پڑھنا اور لکھنا | Quizlet کے ساتھ مطابقت یا Quizlet سے خودکار امپورٹ |

فرق واضح ہے: اپنے کارڈز کا متن ایک بار کاپی کرنا ایکسپورٹ کا کام ہے۔ کسی دوسرے صفحے پر Quizlet دکھانا ایمبیڈ کا کام ہے۔ مخصوص انٹیگریشن صرف اسی پروڈکٹ کے طے شدہ طریقۂ کار میں کام کرتی ہے۔ جس سافٹ ویئر کو بار بار کارڈز بنانے، پڑھنے اور بدلنے ہوں، اسے ان کاموں کے لیے واضح دستاویزات والی API درکار ہوتی ہے۔

## ایکسپورٹ، ایمبیڈ اور شراکت داروں کی رسائی عوامی API نہیں ہیں

عوامی API بیرونی ڈویلپرز کے لیے کام کرنے کا طریقہ واضح کرتی ہے: دستاویزات، شناخت کی توثیق کا طریقہ، دستیاب آپریشنز، استعمال کے قواعد اور رسائی کی اسناد حاصل کرنے کا راستہ۔ Quizlet کی موجودہ عوامی سہولتوں میں سے کوئی بھی یہ سب کچھ اس طرح فراہم نہیں کرتی کہ ڈویلپر خود رجسٹر ہو کر کام شروع کر سکے۔

Quizlet کا **ایکسپورٹ** دستی منتقلی کا طریقہ ہے۔ سیٹ بنانے والا ویب سائٹ پر اصطلاحات اور تعریفوں کی ترتیب طے کر سکتا ہے، **متن کاپی کریں (Copy text)** منتخب کر سکتا ہے اور نتیجہ کہیں اور پیسٹ کر سکتا ہے۔ Quizlet کے مطابق تصاویر ایکسپورٹ نہیں ہو سکتیں، کاپی کیے گئے سیٹ ایکسپورٹ نہیں کیے جا سکتے، اور یہ سہولت صرف ویب سائٹ پر دستیاب ہے۔ احتیاط سے ایک بار مواد منتقل کرنے کے لیے یہ مناسب ہے۔ اس سے سافٹ ویئر دو نظاموں کا ڈیٹا مسلسل ایک جیسا نہیں رکھ سکتا۔

**ایمبیڈ** مواد دکھاتا ہے، ڈیٹا تک رسائی نہیں دیتا۔ Quizlet کسی عوامی سیٹ کے لیے جوڑے ملانے (Match)، سیکھنے (Learn)، امتحان (Test)، فلیش کارڈز (Flashcards) یا ہجے کی مشق (Spell) کے موڈ میں HTML کاپی کرنے دیتا ہے۔ ایمبیڈ کی گئی سرگرمی پر Quizlet کا لوگو رہتا ہے اور سیکھنے والے Quizlet کے انٹرفیس ہی میں کام کرتے ہیں۔ آپ کی ایپلی کیشن کو سیٹ ایسے کارڈ ریکارڈز کی شکل میں نہیں ملتا جن میں وہ ترمیم کر سکے۔

**کسی مخصوص پروڈکٹ کے ساتھ انٹیگریشن** کا اپنا طے شدہ طریقۂ کار ہوتا ہے۔ Quizlet، ChatGPT یا Google Classroom کے ساتھ کام کر سکتا ہے، چاہے وہی انٹرفیس ہر ڈویلپر کو نہ دے۔ ان سہولتوں کے اجرا سے ان مخصوص انٹیگریشنز کا وجود ثابت ہوتا ہے؛ اس سے یہ ثابت نہیں ہوتا کہ ان کے پیچھے عام استعمال کے لیے کوئی عوامی Quizlet API بھی دستیاب ہے۔

اسی لیے کوئی پرانا ریپر یا براؤزر کے ڈویلپر ٹولز میں نظر آنے والی ریکویسٹ، Quizlet کی سرکاری طور پر معاونت یافتہ API نہیں بن جاتی۔ اس کے لیے عوامی دستاویزات اور ڈویلپرز کے لیے کام کرنے کی مستحکم تکنیکی شرائط درکار ہیں، جو موجود نہیں۔

## اپنے کام کے مطابق طریقہ منتخب کریں

### ایک بار بیک اپ لینے یا مواد منتقل کرنے کے لیے ایکسپورٹ استعمال کریں

اپنے بنائے ہوئے سیٹ کے لیے Quizlet کا سرکاری ایکسپورٹ طریقہ استعمال کریں۔ چونکہ اس کا آخری مرحلہ **متن کاپی کریں (Copy text)** ہے، اس لیے متن الگ کرنے والی علامتیں درست کرنے یا اسے متعلقہ فیلڈز میں بانٹنے سے پہلے پیسٹ کی ہوئی پہلی کاپی بغیر تبدیلی کے محفوظ رکھیں۔ آپ اصطلاحات اور تعریفیں محفوظ کر رہے ہیں، ایسا ڈیک پیکیج ڈاؤن لوڈ نہیں کر رہے جسے بعد میں بحال کیا جا سکے۔ تصاویر اور مطالعے کا سابقہ ریکارڈ منتقل نہیں ہوتے۔

عملی چیک لسٹ [2026 میں Quizlet سیٹ ایکسپورٹ کرنے کا طریقہ](/ur/blog/how-to-export-quizlet-sets-and-turn-them-into-fsrs-flashcards/) میں ہے۔ اس میں اصل کاپی محفوظ رکھنے اور الگ کاپی پر کام کرنے، UTF-8، ٹیبز، کئی سطروں پر مشتمل تعریفوں، اور کارڈز کے مواد کی منتقلی اور دہرائی کے موجودہ شیڈول کی منتقلی کے فرق پر بات کی گئی ہے۔

ایکسپورٹ ایک بار مواد منتقل کرنے کے لیے مناسب ہے۔ سافٹ ویئر سے روزانہ کارڈز بنانے، دو نظاموں کا ڈیٹا ہم آہنگ رکھنے یا بار بار ترمیم کرنے کے لیے یہ مناسب نہیں۔

### مواد دکھانے کے لیے سرکاری ایمبیڈ استعمال کریں

اگر طلبہ کو کلاس کی ویب سائٹ یا LMS کے صفحے پر کسی عوامی Quizlet سیٹ سے پڑھنا ہے، تو Quizlet کی ویب سائٹ سے ملنے والا ایمبیڈ کوڈ استعمال کریں۔ سرگرمی چنیں، **HTML کاپی کریں (Copy HTML)** منتخب کریں اور کوڈ صفحے میں شامل کر دیں۔ طلبہ کو Quizlet کی ایک ایسی سرگرمی ملتی ہے جس میں وہ حصہ لے سکتے ہیں؛ میزبان سائٹ کو کارڈز کا خام ڈیٹا نہیں ملتا۔

اکثر استاد کو بس یہی سہولت چاہیے ہوتی ہے۔ اسے API کہنا ضرورت کو بلاوجہ پیچیدہ بنا دیتا ہے۔

### ChatGPT یا Google Classroom کے لیے اسی کی مخصوص انٹیگریشن استعمال کریں

Quizlet کے 10 مارچ 2026 کے ChatGPT اعلان میں ایک مخصوص طریقہ بتایا گیا ہے: Quizlet ایپ کو جوڑیں، پرامپٹ کا آغاز `@Quizlet` سے کریں، بننے والے سیٹ کا پیش نظارہ ChatGPT میں دیکھیں، پھر اسے Quizlet میں کھول کر اپنی ضرورت کے مطابق بدلیں اور اس سے پڑھائی کریں۔ اس گفتگو سے Quizlet سیٹ بنانے کا یہ سرکاری طور پر دستیاب طریقہ ہے۔ اس سے آپ کے بوٹ، اسکرپٹ یا ویب سائٹ کو Quizlet API کی ایسی اسناد نہیں ملتیں جنہیں بار بار استعمال کیا جا سکے۔

Quizlet کا 30 جون 2026 کا Google Classroom اعلان بھی اسی طرح ایک مخصوص سہولت کے بارے میں ہے۔ اس ایڈ آن سے اساتذہ مشقی سوالات، فلیش کارڈز اور کھیلوں سمیت سرگرمیاں تلاش کر کے تفویض کر سکتے ہیں، پھر Classroom کے اندر طلبہ کی شرکت اور پیش رفت دیکھ سکتے ہیں۔ Quizlet کے مطابق اس کے لیے Google Workspace for Education Plus ضروری ہے؛ اساتذہ کو اجازت یا ایڈ آن کی فراہمی کے لیے اپنے IT ایڈمنسٹریٹر سے رابطہ کرنا پڑ سکتا ہے۔

اگر ان میں سے کوئی طریقہ پہلے ہی آپ کی ضرورت پوری کرتا ہے تو اسے استعمال کریں۔ اگر آپ کو اپنی ایپلی کیشن بنانی ہے، تو ان میں سے کوئی انٹیگریشن عوامی ڈویلپر رسائی کی جگہ نہیں لیتی۔

### مسلسل خودکاری کے لیے ڈیٹا پڑھنے اور لکھنے کا ایسا انٹرفیس چنیں جس کی دستاویزات موجود ہوں

مسلسل خودکاری کے لیے آپ کے سافٹ ویئر کو ایک ہی کام بار بار قابلِ اعتماد انداز میں کرنا ہوتا ہے: نوٹس سے کارڈز بنانا، ڈیکس کی فہرست لینا، جواب بدلنا یا وقت کے ساتھ ورک اسپیس سنبھالنا۔ کلپ بورڈ کے ذریعے ایکسپورٹ ان کاموں کے لیے کوئی طے شدہ پروگرامنگ انٹرفیس فراہم نہیں کرتا۔

محفوظ راستہ ایسا فلیش کارڈ نظام ہے جو صاف بتاتا ہو کہ بیرونی سافٹ ویئر شناخت کی توثیق کیسے کرے اور ڈیٹا پڑھنے اور لکھنے کے کون سے کام دستیاب ہیں۔ اس کے لیے خودکار کاموں میں Quizlet API کا متبادل اپنانا پڑ سکتا ہے، جبکہ مطالعے کے ان کاموں کے لیے Quizlet استعمال کیا جا سکتا ہے جو اس کی عوامی پروڈکٹ میں دستیاب ہیں۔

## Nibomo بطور API متبادل کیا فراہم کرتا ہے

Nibomo ہر صارف کے ڈیٹا کے ایک ہی محدود حصے تک پہنچنے کے دو طریقے دستاویزات میں بیان کرتا ہے:

- [بیرونی Agent API](/ur/docs/api/) کا آغاز `GET https://api.nibomo.com/v1/` سے ہوتا ہے۔ اس کا ابتدائی تعارفی جواب ایجنٹ کو ای میل OTP سے لاگ اِن کرنے، API کلید بنانے اور ورک اسپیس منتخب کرنے کی رہنمائی دیتا ہے۔ ڈیٹا پڑھنے کے لیے SQL طرز کا query روٹ اور لکھنے کے لیے الگ execute روٹ ہے۔
- [ریموٹ MCP سرور](/ur/docs/mcp-connector/)، `https://mcp.nibomo.com/mcp` پر دستیاب ہے۔ MCP کلائنٹس کو آٹھ ٹول ملتے ہیں: `list_workspaces`، `sql_query`، `sql_execute`، `get_guide`، اور دہرائی کے ٹول `next_review_card`، `reveal_answer` اور `submit_review`۔

آٹھواں ٹول، `get_usage_limits`، صرف اکاؤنٹ کا پلان، حدود اور موجودہ مہینے میں AI کے استعمال کی معلومات پڑھتا ہے۔ یہ کوئی تبدیلی نہیں کرتا، نہ ہی کارڈز پڑھتا ہے۔

دونوں طریقوں کی رسائی منتخب ورک اسپیس تک محدود ہے۔ دستاویزات میں درج وسائل `workspace`، `cards`، `decks` اور `review_events` ہیں، اور ہر اسٹیٹمنٹ کے نتائج زیادہ سے زیادہ 100 قطاروں تک محدود ہیں۔ SQL طرز کا یہ انٹرفیس SQL کی ایک محدود صورت ہے، براہِ راست PostgreSQL نہیں۔ OpenAPI اسکیما موجود نہیں، اس لیے اگر آپ کا طریقۂ کار OpenAPI سے خودکار طور پر بنائے گئے کلائنٹس پر منحصر ہے تو آپ کو دوسرا انٹرفیس درکار ہوگا۔

اس سے ڈویلپر یا AI ایجنٹ اپنے فلیش کارڈز کے کام خودکار کر سکتا ہے۔ یہ Quizlet URL پڑھ نہیں سکتا، Quizlet اکاؤنٹ کی ہم آہنگ نقل نہیں رکھ سکتا اور Quizlet کی غیر دستاویزی رسائی استعمال کرنے والے کلائنٹ کے طور پر کام نہیں کر سکتا۔ Quizlet سے خودکار امپورٹ کی کوئی سہولت نہیں۔ مواد منتقل کرنے کے لیے پہلے اپنے سیٹ کی اصطلاحات اور تعریفیں ایکسپورٹ کریں، متن کا جائزہ لیں، پھر اسے نئے نظام کے کارڈ فیلڈز کے مطابق ترتیب دیں۔ نیا نظام مطالعے کی پیش رفت کا اپنا ریکارڈ بناتا ہے؛ Quizlet میں مطالعے کا سابقہ ریکارڈ ساتھ نہیں آتا۔

API تک رسائی کے علاوہ مصنوعات کے دوسرے فرق دیکھنے کے لیے [Quizlet کے اوپن سورس متبادل کا موازنہ](/blog/quizlet-alternative/) پڑھیں۔

## براؤزر کی نجی ریکویسٹس محفوظ شارٹ کٹ نہیں ہیں

Quizlet کا ویب انٹرفیس، ہر جدید ویب ایپلی کیشن کی طرح، نیٹ ورک ریکویسٹس بھیجتا ہے۔ ایسی کوئی ریکویسٹ مل جانے سے وہ آپ کے پروگرام کے لیے سرکاری طور پر معاونت یافتہ اینڈپوائنٹ نہیں بن جاتی۔

براؤزر کے نجی اینڈپوائنٹس سیشن کوکیز، اندرونی فارمیٹس، غلط استعمال روکنے کے اقدامات اور موجودہ انٹرفیس سے وابستہ مفروضوں پر انحصار کر سکتے ہیں۔ وہ عوامی ورژن نمبر یا نئے طریقے پر منتقل ہونے کی رہنمائی کے بغیر بدل سکتے ہیں۔ اس کے علاوہ، [Quizlet کی شرائطِ خدمت](https://quizlet.com/tos)، جنہیں آخری بار 28 مئی 2026 کو اپ ڈیٹ کیا گیا تھا، اسکریپنگ اور دوسرے خودکار طریقوں سے ڈیٹا نکالنے کے ساتھ ساتھ سروس کے غیر مجاز خودکار استعمال پر پابندی لگاتی ہیں۔

ذاتی اسکرپٹ کو بھی اس بنیاد پر چلانا غیر یقینی اور پُرخطر ہے، کسی پروڈکٹ کی تو بات ہی الگ ہے۔ میں یہاں اندازے سے بنائے گئے اینڈپوائنٹس یا ریورس انجینئرنگ کے مراحل نہیں دوں گا۔

اپنا سیٹ ایک بار منتقل کرنا ہو تو ایکسپورٹ کریں۔ طلبہ کو کسی دوسرے صفحے پر عوامی سیٹ درکار ہو تو اسے ایمبیڈ کریں۔ ChatGPT یا Google Classroom کے انہی مخصوص کاموں کے لیے ان کی متعلقہ انٹیگریشن استعمال کریں۔ بار بار ڈیٹا پڑھنے اور لکھنے کے لیے ایسا سافٹ ویئر چنیں جس کی دستاویزات میں خودکاری کا طریقہ اور تکنیکی شرائط واضح ہوں۔ جب تک Quizlet ایسی دستاویزات شائع نہیں کرتا، آپ Quizlet والا حصہ دستی طور پر بھی انجام دے سکتے ہیں۔
