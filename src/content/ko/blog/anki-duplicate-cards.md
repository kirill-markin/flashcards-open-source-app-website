전에 복습한 질문이 Anki에서 새 카드로 뜹니다. 파일을 가져오면서 같은 노트가 한 번 더 들어왔거나, 한 노트에서 카드가 두 장 만들어졌을 수 있습니다. 이 차이는 삭제할 때 중요합니다. 탐색 창에서 한 행을 삭제하면 그 노트에 속한 카드가 모두 사라질 수 있습니다. 남겨 두려던 반대 방향 카드도 함께 사라지는 겁니다.

**Anki 중복 카드**를 정리하려면 먼저 같은 질문이 왜 나오는지 확인하세요. 서로 다른 노트에서 나온 카드라면 **Notes → Find Duplicates**에서 중복 후보를 찾으세요. 필드 값이 일치하는 노트가 나오면 각 노트의 전체 내용과 카드별 복습 기록을 비교한 뒤, 어느 쪽을 남길지 한 묶음씩 결정하세요.

데스크톱에서 진행하는 이 절차는 2026년 10월 4일에 확인한 Anki 공식 문서와 배포 버전의 소스 코드를 바탕으로 합니다. 아래 가상 예제는 각 단계에서 어떤 결과가 나오는지 예상해 보는 연습입니다.

![체스 동호회 회원이 나무 체스판 위에서 여분의 밝은색 룩 하나를 손때 묻은 룩 두 개와 비교하는 모습](/blog/anki-duplicate-cards.png)

## 무엇이 반복되는지 먼저 확인하기

노트에는 Front(앞면), Back(뒷면) 같은 필드가 들어 있습니다. Anki는 그 필드를 카드 템플릿에 넣어 카드를 만듭니다. 예를 들어 단어 노트 하나에서 단어를 보고 뜻을 떠올리는 카드와 뜻을 보고 단어를 떠올리는 카드가 생길 수 있습니다. 이렇게 같은 노트에서 나온 카드를 형제 카드라고 합니다. 복습 일정은 카드마다 따로 잡힙니다. [Anki 공식 문서의 노트와 필드 설명](https://docs.ankiweb.net/manual/getting-started#notes-%26-fields)

탐색 창(Browse)을 **Cards** 모드로 열고 중복이 의심되는 행마다 **Cards → Info**에서 Note ID를 확인하세요. ID가 같으면 한 노트의 카드이고, 다르면 서로 다른 노트입니다. `nid:123`에서 `123`을 실제 Note ID로 바꿔 검색하면 덱에 상관없이 그 노트에 속한 카드를 모두 볼 수 있습니다. [Anki 공식 문서의 ID 검색](https://docs.ankiweb.net/searching.html#object-ids)

| 확인한 결과 | 가능한 원인 | 다음 단계 |
| --- | --- | --- |
| 같은 노트, 질문 방향이 반대 | 양방향으로 학습하기 위해 만든 형제 카드 | 두 질문이 모두 필요한지 확인 |
| 같은 노트, 카드에 표시되는 질문이 같음 | 카드 템플릿이 중복됐을 가능성 | 템플릿과 카드 미리보기 비교 |
| 서로 다른 노트, 질문이 같아 보임 | 중복 노트일 가능성 | 노트 전체를 비교한 뒤 남길 쪽 결정 |

양방향 학습을 위해 만든 형제 카드가 어떻게 작동하는지는 역방향 카드 가이드에서 확인할 수 있습니다. 한 방향만 잠시 쉬고 싶다면 해당 카드의 복습을 중단하세요. 복습을 중단해도 카드는 컬렉션에 남습니다. [Anki 역방향 카드 가이드(영어)](/blog/anki-reverse-cards/), [Anki 카드 복습 중단 가이드(영어)](/blog/anki-bury-vs-suspend/)

서로 다른 템플릿에서 똑같은 질문이 나온다면 Anki 공식 FAQ의 진단 절차를 따라가세요. 템플릿을 삭제하면 그 노트 유형을 사용하는 모든 노트가 영향을 받습니다. 다른 덱에 있는 노트도 마찬가지입니다. 템플릿 변경은 당장 중복된 질문을 정리하는 작업과 분리해 진행하세요. [Anki 공식 FAQ의 중복 카드 진단 절차](https://faqs.ankiweb.net/extra-copies-of-a-card-are-coming-up.html)

## 검색 범위를 정해 중복 노트 찾기

**Notes → Find Duplicates**를 열고 **Front**처럼 비교할 필드를 선택하세요. 기본적으로 Anki는 그 필드가 있는 모든 노트 유형을 검색합니다. **Optional filter**로 검색 범위를 지정한 뒤 **Search**를 누르세요. [Anki 공식 문서의 중복 찾기 설명](https://docs.ankiweb.net/browsing.html#finding-duplicates)

덱 이름이 `Cleanup practice`라면 다음과 같이 입력하세요.

```text
deck:"Cleanup practice"
```

덱을 검색하면 하위 덱도 포함됩니다. 중복 노트가 여러 덱에 있을 가능성이 있다면 필터를 지우고 컬렉션 전체를 검색하세요. 한 덱에서 중복이 나오지 않아도 다른 덱에 복사본이 있을 수 있습니다. [Anki 공식 문서의 덱 검색 문법](https://docs.ankiweb.net/searching.html#tags-decks-cards-and-notes)

검색 결과에서 그룹을 클릭하면 그 안의 노트를 살펴볼 수 있습니다. **Tag Duplicates**를 누르면 각 그룹의 모든 노트에 `duplicate` 태그가 붙습니다. 남길 노트에도 붙으므로 **`tag:duplicate` 검색 결과를 한꺼번에 삭제하지 마세요.** 태그는 후보를 모으는 데 쓰고, 삭제할 노트는 하나씩 고르세요. [Anki 배포 버전의 태그 지정 코드](https://github.com/ankitects/anki/blob/26.09.3/qt/aqt/browser/find_duplicates.py)

이 검색은 선택한 필드의 값만 비교합니다. 같은 내용을 다른 말로 묻는 질문은 직접 찾아야 할 수 있습니다. 문구가 똑같더라도 학습하는 언어나 수업의 맥락이 다르면 별개의 질문일 수 있습니다.

## 예제 세 쌍에서 남길 노트 고르기

하위 덱이 없는 `Cleanup practice` 덱에 노트 여섯 개가 있다고 가정해 보세요. A와 B는 **Basic (and reversed card)** 유형의 기본 템플릿을 그대로 사용해 각각 카드 두 장을 만듭니다. C부터 F까지는 **Basic**을 사용해 각각 카드 한 장을 만듭니다. 카드 여덟 장은 모두 이 덱에 있습니다. A부터 F까지는 예제에서 쓰는 이름입니다. Anki의 실제 Note ID와 Card ID는 숫자입니다.

| 노트 | Front → Back | 예제의 학습 상태 | 판단 |
| --- | --- | --- | --- |
| A와 B | `le vélo` → `bicycle` | A는 뜻을 묻는 카드 12회, 단어를 묻는 카드 3회 복습. B는 둘 다 새 카드 | A를 남기고 B를 먼저 삭제 후보로 검토 |
| C와 D | `Chemical symbol for silver?` → `Ag` | C는 20회, D는 6회 복습 | 두 카드의 기록을 비교해 복습을 이어갈 쪽 결정 |
| E와 F | E는 `bank` → `financial institution`, F는 `bank` → `side of a river` | 묻는 뜻이 서로 다름 | 둘 다 남기고 질문에 문맥 추가 |

**Front** 필드로 중복을 찾으면 세 쌍이 모두 검색 결과에 나올 수 있습니다. 그중 첫 번째 쌍이 가장 판단하기 쉽습니다. B를 지우기 전에 **모든 필드**와 미디어, 태그, 노트 유형을 비교하고 미리보기에서 질문이 어느 방향으로 나오는지도 확인하세요. B에만 발음 오디오가 있거나 A에는 없는 질문이 나올 수 있습니다.

같은 내용을 익히는 데 도움이 되는 자료가 있다면 필요한 부분만 골라 남길 노트에 복사하고, 결과를 미리보기로 확인하세요. 출처를 나타내는 유용한 태그도 남겨 두세요. 묻는 내용 자체가 달라진다면 새 질문을 만드세요. 기존 복습 기록은 원래 질문에 해당합니다.

C와 D를 비교할 때 복습 횟수는 판단에 참고할 단서입니다. 두 카드의 복습 날짜와 그때 누른 평가 버튼, 현재 복습 간격과 다음 복습 예정 정보를 함께 살펴보세요. 복습 횟수가 많은 카드는 내용을 다시 익히는 데 더 많은 복습이 필요했을 수도 있습니다. 질문과 답이 학습에 도움이 되는지 확인한 뒤 어느 카드의 복습을 이어갈지 결정하세요. 답이 서로 다르면 학습 자료의 출처부터 확인하세요.

C를 남기고 D를 삭제하면 C는 **기존 복습 기록과 일정 그대로** 이어집니다. **Card Info**에서 카드별 기록을 확인할 수 있습니다. 삭제한 노트의 복습 기록은 컬렉션 전체 통계에만 남습니다. 덱별 통계에서는 빠지고 남긴 카드의 기록에도 합쳐지지 않습니다. [Anki의 Card Info 설명](https://docs.ankiweb.net/stats.html#card-info), [삭제된 노트의 통계 설명](https://docs.ankiweb.net/stats.html#more)

판단이 서지 않으면 삭제를 미루세요. 확인할 내용을 적어 두고, 필요하면 그동안 해당 카드의 복습을 중단하세요.

## 중복 노트 하나를 삭제하고 기록과 대조하기

실제 학습 자료를 삭제하기 전에 다른 기기에서 작업한 내용부터 동기화하세요. 그다음 데스크톱을 동기화해 그 내용을 컬렉션에 반영하세요. [Anki 동기화 매뉴얼](https://docs.ankiweb.net/syncing.html)

**File → Export**에서 **Include Media**를 켜고 **Anki Collection Package (`.colpkg`)** 형식으로 저장하세요. 이 백업에는 모든 덱과 복습 일정, 복습 기록이 들어갑니다. 파일은 안전한 곳에 보관하세요. 이 파일을 가져오면 백업에 저장된 컬렉션이 현재 열려 있는 프로필의 컬렉션을 통째로 덮어씁니다. [Anki 공식 문서의 컬렉션 내보내기 설명](https://docs.ankiweb.net/exporting.html#collection-colpkg)

삭제를 먼저 연습해 보고 싶다면 **File → Switch Profile**에서 별도 프로필을 만들어 그곳에 백업을 가져오세요. 연습용 프로필은 AnkiWeb에 연결하지 마세요. 프로필마다 컬렉션이 따로 있어 두 프로필을 같은 계정에 연결하면 한쪽 컬렉션이 다른 쪽을 덮어쓸 수 있습니다. [Anki 프로필 설명](https://docs.ankiweb.net/profiles.html), [APKG와 COLPKG 비교 가이드(영어)](/blog/anki-apkg-vs-colpkg/)

예제에서 노트 A의 두 카드를 A1과 A2라고 부릅니다. A1은 뜻을 묻는 카드, A2는 단어를 묻는 카드입니다. 노트 B의 카드도 같은 순서로 B1, B2라고 부릅니다. **Cards → Info**에서 A의 두 카드에 대해 실제 Card ID, 다음 복습 예정 정보, 복습 간격, 나중에 대조할 수 있는 복습 내역을 적어 두세요. B의 Note ID도 기록하세요. 한 세션 안에서 삭제 전후를 비교하세요. 그사이 A와 B의 카드를 복습하거나 일정을 바꾸지 마세요.

중복 노트는 다음 순서로 한 번에 하나씩 삭제하세요.

1. 탐색 창의 검색어를 지우고 `nid:` 뒤에 B의 실제 Note ID를 넣어 검색하세요. **Cards** 모드에서 모든 결과를 확인하고 두 방향의 카드를 미리 보세요. 실제 자료를 정리할 때는 덱 필터를 빼고 검색해 다른 덱에 형제 카드가 있는지도 확인하세요.
2. **Notes** 모드로 바꾸세요. 결과가 하나인지, 그리고 삭제할 B 노트가 맞는지 확인하세요. 그 행만 선택하고 **Notes → Delete**를 누르세요. **Cards** 모드에서 행 하나를 선택해 이 작업을 실행해도 해당 노트와 그 노트의 모든 카드가 삭제됩니다. [Anki 공식 문서의 Delete 동작](https://docs.ankiweb.net/browsing.html#notes)
3. B의 Note ID를 다시 검색해 결과가 없는지 확인하세요. `cid:` 뒤에 기록해 둔 A의 Card ID 두 개를 쉼표로 구분해 입력하고, 각 카드의 Info를 앞서 적어 둔 내용과 비교하세요.
4. `deck:"Cleanup practice"`를 검색하고 **Notes**와 **Cards** 모드의 결과 행 수를 비교하세요. 남아 있는 노트를 아래 표와 대조하세요.

B만 삭제하면 아래와 같은 결과가 나와야 합니다.

| 확인 항목 | 삭제 전 | 삭제 후 예상 결과 |
| --- | --- | --- |
| 예제 덱 전체 | 노트 6개 / 카드 8장 | 노트 5개 / 카드 6장 |
| 자전거 예제의 카드 | A1, A2, B1, B2 | A1과 A2만 남음 |
| A의 Card ID, 다음 복습 예정 정보, 복습 간격, 복습 기록 | 미리 적어 둔 값 | 카드 ID, 복습 예정 정보, 간격, 기록이 삭제 전과 같음 |
| B의 Note ID 검색 | B의 카드 두 장 | 결과 없음 |
| 은의 원소 기호와 bank의 뜻을 묻는 노트 | C, D, E, F | 네 노트가 모두 남음 |

이 예제에서는 노트 하나를 삭제하면 카드 두 장이 사라집니다. B 대신 A를 지워도 줄어드는 개수는 같습니다. 하지만 이미 복습한 카드가 사라집니다. 개수와 ID를 함께 확인하고, 정리하는 동안 남길 카드의 학습 상태를 초기화하거나 복습 일정을 바꾸지 마세요.

컬렉션 전체의 복습 그래프에는 삭제한 카드의 복습 내역이 계속 잡힐 수 있습니다. 남은 카드의 ID와 **Info**를 대조해 학습 상태가 유지됐는지 확인하세요.

한 그룹의 결과가 기록과 일치하면 다음 그룹으로 넘어가 어떤 노트를 남길지 따로 판단하세요. 별도 프로필에서 연습했다면 확인한 절차를 실제 프로필에서도 진행하세요. 실제 컬렉션을 확인한 뒤 데스크톱을 먼저 동기화하고, 다른 기기에서도 학습을 시작하기 전에 동기화하세요.
