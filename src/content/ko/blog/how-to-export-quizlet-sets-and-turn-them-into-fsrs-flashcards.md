Quizlet에서 **Export(내보내기)** 버튼이 보이지 않는다면 두 가지부터 확인하세요. 원본 세트를 직접 만들었나요? Quizlet 웹사이트를 사용하고 있나요? Quizlet에서는 세트를 처음 만든 사람만 내보낼 수 있고, 이 기능은 웹사이트에서만 사용할 수 있습니다. 복사한 세트는 내 라이브러리에 표시되더라도 내보낼 수 없습니다.

조건을 충족한다면 내보내기 자체는 간단합니다. 웹사이트에서 세트를 열고 **More(더 보기) → Export(내보내기)**를 선택한 다음, 용어와 정의를 구분할 방식을 정하고 **Copy text(텍스트 복사)**를 누르면 됩니다. Quizlet이 카드 덱 파일을 다운로드해 주는 것은 아닙니다. 이미지 없이 텍스트만 클립보드에 복사합니다.

**사실 확인:** 2026년 8월 30일, [Quizlet 공식 내보내기 안내](https://help.quizlet.com/hc/en-us/articles/360034345672-Exporting-your-sets)를 기준으로 확인했습니다.

## 먼저, 내보내기를 사용할 수 있는지 확인하세요

다른 방법으로 Quizlet 플래시카드를 다운로드하려고 하기 전에 아래 내용을 확인하세요.

| 현재 상황 | 내보내기를 사용할 수 있나요? | 다음 단계 |
| --- | --- | --- |
| 원본 세트를 직접 만들었고 Quizlet 웹사이트에서 열었음 | Quizlet 도움말에 따르면 사용할 수 있음 | 아래 절차를 따르세요 |
| iOS 또는 Android 앱을 사용 중임 | 사용할 수 없음. 내보내기는 웹사이트 전용 기능 | 웹 브라우저에서 Quizlet을 열고 로그인하세요 |
| 다른 사용자의 세트를 복사했음 | 사용할 수 없음. Quizlet은 복사한 세트의 내보내기를 지원하지 않는다고 안내함 | 복사본을 만들어도 내보내기는 활성화되지 않습니다 |
| 세트를 볼 수 있지만 직접 만들지는 않았음 | 사용할 수 없음. 열람 권한과 원본 작성자의 소유 권한은 다름 | 작성자에게 원본 파일을 요청하거나, 사용할 수 있는 자료로 다시 만드세요 |

직접 만든 원본 세트인데도 Quizlet 내보내기 버튼이 보이지 않는다면, 해당 세트를 소유한 계정으로 로그인했는지, 복사본이 아닌 원본을 열었는지 확인하세요. Quizlet 도움말에는 별도의 내보내기 경로가 안내되어 있지 않습니다. 이 경우에는 제한을 우회할 수 있다고 주장하는 다운로드 도구를 믿기보다 Quizlet 고객 지원에 문의하세요.

## Quizlet 웹사이트에서 플래시카드 내보내기

직접 만든 세트라면 다음 순서로 진행하세요.

1. Quizlet 웹사이트에 로그인합니다.
2. **Your library(내 라이브러리)**를 선택합니다.
3. **Flashcard sets(플래시카드 세트)**를 선택합니다.
4. 내보낼 세트를 엽니다.
5. **More(더 보기)** 메뉴를 엽니다.
6. **Export(내보내기)**를 선택합니다.
7. 용어와 정의를 구분할 방식을 선택합니다.
8. **Copy text(텍스트 복사)**를 선택합니다.
9. 일반 텍스트 편집기에 결과를 붙여넣습니다.

현재 내보내기 절차는 여기까지입니다. 마지막에 별도의 ‘다운로드’ 버튼은 없습니다.

일반적인 앞면·뒷면 카드라면 용어와 정의 사이에는 탭을, 카드 사이에는 줄바꿈을 사용하는 것을 권합니다. 이는 실용적인 권장 사항이며 Quizlet의 필수 조건은 아닙니다. 정의 문장에는 쉼표가 자주 들어가므로, 보통 쉼표보다 탭을 쓰는 편이 내용을 점검하기 쉽습니다.

카드 두 개를 정리한 파일은 다음과 같은 형태입니다. 각 행의 중간에 탭이 하나씩 들어 있습니다.

```text
photosynthesis	Process plants use to convert light energy into chemical energy
mitosis	Cell division that produces two genetically identical daughter cells
```

## Quizlet에서 내보내면 무엇이 남나요?

Quizlet은 이 기능의 범위를 명확히 한정합니다. 작성자가 직접 만든 세트의 **용어와 정의**를 내보내며, 이미지는 내보낼 수 없다고 안내합니다.

어떤 내용이 보존되는지 판단할 때는 붙여넣은 결과를 기준으로 삼는 것이 가장 안전합니다. 그 결과에 텍스트, 구분자, 줄바꿈이 있다면 파일에 그대로 보존할 수 있습니다. Quizlet 도움말은 폴더, 학습 모드, 서식, 숙련도 상태, 복습 기록, 복습 일정이 함께 옮겨진다고 보장하지 않습니다.

따라서 이것은 카드 텍스트의 사본이지, Quizlet에서 복원할 수 있는 백업은 아닙니다. ‘Quizlet 플래시카드 다운로드’를 검색했다면 이 차이를 알아두세요. Quizlet은 텍스트를 클립보드에 복사하고, 파일은 사용자가 직접 만듭니다.

## 내용을 정리하기 전에 UTF-8 원본부터 저장하세요

언제든 원래 상태로 돌아갈 수 있도록 진행하세요.

1. 내보낸 내용을 일반 텍스트 편집기에 붙여넣습니다.
2. `biology-quizlet-raw.txt` 같은 이름으로 UTF-8 형식으로 저장합니다.
3. 파일을 복제해 `biology-quizlet-working.txt`로 저장합니다.
4. 원본 파일은 그대로 두고 작업용 사본만 수정합니다.

작업용 파일을 가져오기 전에, Quizlet 세트를 열어둔 상태에서 다음을 확인하세요.

- 공백 문자 표시 기능을 켜서 탭과 줄바꿈이 어디에 있는지 확인합니다.
- 용어와 정의 안에 선택한 구분자가 들어 있는지 검색합니다. 탭 하나가 더 있으면 뜻하지 않은 세 번째 필드가 생길 수 있습니다.
- 정의 자체에 줄바꿈이 있는지 살펴봅니다. 이 줄바꿈을 새 카드의 시작으로 잘못 읽을 수 있습니다.
- 파일의 처음, 중간, 끝부분을 Quizlet과 대조합니다. 가장 긴 정의도 포함하세요.
- 파일을 닫았다가 다시 열고 악센트가 붙은 문자, 한글 등 비라틴 문자, 기호, 곡선형 따옴표 같은 문장 부호를 확인합니다.
- 빈 필드, 중복 항목, 형식이 일정하지 않은 행은 임의로 고치지 말고 따로 표시합니다.

카드 하나가 정확히 한 줄을 차지할 때만 줄 수와 카드 수를 비교하세요. 정의가 여러 줄에 걸쳐 있으면 이 방법은 맞지 않습니다.

작업용 사본에 문제가 없어 보여도 원본 파일은 보관하세요. 가져오기 과정에서 필드가 밀리거나 내용이 빠지면 변경되지 않은 원본과 대조할 수 있습니다.

## Quizlet을 CSV로 변환할 때는 파일 형식을 제대로 맞추세요

`.txt` 파일의 확장자를 `.csv`로 바꾸는 것만으로는 변환되지 않습니다. CSV에는 일관된 구분자가 필요하고, 쉼표나 따옴표, 여러 줄에 걸친 내용이 있을 때는 따옴표로 올바르게 감싸야 합니다.

Quizlet 내용을 CSV로 안전하게 변환하려면 다음과 같이 진행하세요.

1. 원본 텍스트 백업은 수정하지 않습니다.
2. 작업용 사본을 스프레드시트에서 열고 Quizlet에서 사용한 것과 정확히 같은 구분자를 선택합니다.
3. 각 항목이 용어와 정의, 두 열로 나뉘었는지 확인합니다.
4. 따옴표, 구분자, 여러 줄에 걸친 정의를 점검합니다.
5. UTF-8 CSV로 내보냅니다.
6. 다른 곳에서 사용하기 전에 CSV를 새로 열어 미리보기로 확인합니다.

스프레드시트는 CSV에 필요한 따옴표 처리를 해줄 수 있습니다. 탭을 쉼표로 일괄 바꾸는 것만으로는 이를 확실하게 처리할 수 없습니다.

## Nibomo에서는 텍스트를 초안으로 만들고 검토한 뒤 저장하세요

[Nibomo](/ko/features/)에는 Quizlet에서 직접 가져오는 기능이 없습니다. Nibomo 웹 서비스에서는 TXT나 CSV 파일을 첨부해 AI의 도움으로 카드 초안을 만들 수 있습니다. 데이터를 손실 없이 이전하는 기능은 아닙니다.

1. Quizlet 원본 파일은 앱 밖에 따로 보관합니다.
2. 정리한 TXT 파일이나 형식을 제대로 맞춘 CSV 파일을 Nibomo AI 채팅에 첨부합니다.
3. 파일에서 어떤 구분자와 필드를 사용하는지 AI에 설명합니다.
4. 카드 몇 개를 미리 보여 달라고 요청하고, 아직 저장하지 말라고 명시합니다.
5. 제안된 카드 수와 앞면·뒷면을 작업용 파일과 비교합니다.
6. 검토한 카드만 저장합니다.

[시작 가이드](/docs/getting-started/)에는 작업 공간 데이터와 첨부 파일을 AI 채팅에서 사용하는 방법이 설명되어 있습니다. 신중하게 진행하려면 다음과 같이 요청할 수 있습니다.

> 이 파일을 탭으로 구분된 용어와 정의 쌍으로 읽어 주세요. 아직 카드를 저장하지 마세요. 샘플로 카드 몇 개의 초안을 만들고, 원문의 표현과 비라틴 문자를 그대로 보존해 주세요. 형식이 잘못되었거나 비어 있거나 의미가 모호한 행은 추측해서 처리하지 말고 별도로 나열해 주세요.

기존 카드의 내용도 정리해야 한다면 이 방식이 유용할 수 있습니다. 다만 모든 행이 정확하게 옮겨졌다는 보장은 아닙니다. [AI 플래시카드를 고치는 방법](/blog/how-to-fix-ai-flashcards/)의 체크리스트를 적용한 뒤, 나머지 카드를 만들기 전에 작은 덱으로 시험해 보세요.

Nibomo에서 만든 카드는 학습 기록이 새로 시작됩니다. Quizlet 텍스트에는 기존 복습 순서를 이어가는 데 필요한 복습 이벤트나 일정 정보가 포함되어 있지 않습니다.

> **이해관계 공개:** 저는 Nibomo를 개발하고 있습니다. 이 절차는 제품의 현재 한계를 반영하며, Quizlet과 완전히 호환된다는 주장은 아닙니다.

## Quizlet에서 Anki로 옮길 때는 Anki의 텍스트 가져오기를 사용하세요

Anki의 [공식 텍스트 가져오기 설명서](https://docs.ankiweb.net/importing/text-files.html)에 따르면, 쉼표·세미콜론·탭으로 필드를 구분한 UTF-8 일반 텍스트 파일을 가져올 수 있습니다.

탭으로 구분한 작업용 사본이라면 다음과 같이 진행하세요.

1. Anki의 가져오기 화면을 열고 UTF-8 텍스트 파일을 선택합니다.
2. 미리보기에서 Anki가 탭을 감지했는지 확인합니다. 감지하지 못했다면 구분자 옵션을 바꿉니다.
3. 노트 유형과 카드를 넣을 덱을 선택합니다.
4. 첫 번째 필드를 앞면에, 두 번째 필드를 뒷면에 연결합니다.
5. 미리보기에서 비어 있거나 밀리거나 불필요하게 추가된 필드가 없는지 확인합니다.
6. 가져오기 전에 중복 처리 및 업데이트 설정을 검토합니다.

Anki는 주석이 아닌 첫 번째 줄을 기준으로 필드 수를 정합니다. 이후 항목에서 필드가 모자라면 빈칸으로 채우고, 필드가 더 많으면 초과한 필드는 가져오지 않습니다. 불필요한 구분자 하나만으로도 행의 구조가 달라질 수 있으므로 미리보기 확인이 중요합니다.

여러 줄에 걸친 정의도 처리 방식을 명확히 정해야 합니다. Anki는 따옴표로 감싼 여러 줄짜리 필드를 지원합니다. 또는 **Allow HTML in fields(필드 내 HTML 허용)**를 켜면 `<br>`을 줄바꿈으로 해석할 수 있습니다. 둘 중 한 가지 방식을 선택하고, 전체 파일을 가져오기 전에 일부를 복사해 시험하세요.

기본 설정에서 Anki는 첫 번째 필드를 기준으로 같은 유형의 기존 노트를 찾아 나머지 필드를 업데이트할 수 있습니다. 가져오기 옵션을 바꾸면 중복 항목을 무시하거나 새 노트로 추가할 수도 있습니다. 기존 Anki 노트를 업데이트하면 그 노트의 Anki 복습 일정은 유지할 수 있지만, Quizlet의 복습 일정이 텍스트 파일을 통해 옮겨지는 것은 아닙니다.

## 새 덱이 제대로 작동할 때까지 원본을 보관하세요

Quizlet의 공식 내보내기 절차는 웹사이트에서 직접 만든 세트의 **Copy text(텍스트 복사)**를 누르는 데서 끝납니다. 스크래핑 스크립트, 추측으로 찾은 비공개 API 엔드포인트, 타사 다운로드 도구는 이와 별개이며 공식 지원 대상이 아닙니다. 이런 도구를 사용한다고 복사본이나 열람만 가능한 세트가 공식 내보내기 대상이 되지는 않습니다.

한 번 복사하는 것이 아니라 주기적인 자동화가 필요하다면, [Quizlet API의 현재 상태](/blog/quizlet-api/)에서 지원 범위를 확인하세요. 직접 만든 세트가 아니라면 작성자에게 원본 파일을 요청하거나 본인의 노트로 더 작은 덱을 다시 만드세요. 예전 항목을 모두 복사하기보다 더 나은 덱을 만들고 싶다면 [더 좋은 플래시카드를 만드는 방법](/blog/how-to-make-better-flashcards/)을 참고할 수 있습니다.

다음 사항을 모두 확인할 때까지 Quizlet 원본 세트를 삭제하지 마세요.

- UTF-8 원본 파일을 백업되는 위치에 저장했습니다.
- 작업용 파일을 다시 열었을 때 문자와 구분자가 예상대로 표시됩니다.
- 여러 줄짜리 필드, 빈칸, 중복 항목, 형식이 일정하지 않은 행을 점검했습니다.
- 이해에 필요한 중요한 이미지 정보는 사용할 수 있는 출처를 바탕으로 다시 보완했습니다.
- 소량의 카드를 시험 삼아 옮겼고, 대상 앱에서 앞면과 뒷면이 정확하게 표시됩니다.

그 후에도 원본 텍스트 파일은 보관하세요. 나중에 가져온 결과가 이상해 보일 때 앱과 별개로 가장 쉽게 대조할 수 있는 자료입니다. 카드를 어디로 옮길지 아직 고민 중이라면 [Quizlet 대안 비교](/blog/quizlet-alternative/)에서 더 넓은 관점의 장단점을 살펴보세요.
