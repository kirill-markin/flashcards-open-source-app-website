[Nibomo](https://app.nibomo.com/?locale=ko)를 열고 카드를 추가할 워크스페이스로 전환한 뒤 **보관함 > 가져오기**로 이동하세요. **다른 앱에서** 아래에서 사용하던 앱을 선택하세요. 파일 형식이 같아도 앱마다 별도의 항목이 있습니다.

아래 방법은 웹 앱에서 사용할 수 있습니다. iPhone, iPad, Mac 또는 Android에서 메뉴나 원하는 항목이 보이지 않으면 웹 앱을 이용하세요. 기기에서 게스트로 사용 중이라면 먼저 그 기기에서 로그인하세요. 웹 앱에서도 같은 Nibomo 계정으로 로그인하고, 카드를 추가할 워크스페이스를 선택한 후 가져오세요.

## 원본 앱과 지원 형식

| 원본 | 준비할 자료 | 가져오는 방법 |
| --- | --- | --- |
| Quizlet | 내보낸 뒤 복사한 텍스트 | Quizlet 가져오기 화면에 붙여넣기 |
| Anki | `.apkg` 덱 또는 `.colpkg` 컬렉션 | **파일 선택** |
| Noji | `.csv` 또는 `.ofc` | **파일 선택** |
| Knowt | `.pdf` | **파일 선택** |
| RemNote | `.apkg`, `.md` 또는 `.txt` | **파일 선택** |
| Brainscape | `.csv` | **파일 선택** |
| StudySmarter | `.csv` | **파일 선택** |
| Cram | `.csv` | **파일 선택** |
| Mochi | `.mochi` | **파일 선택** |
| SuperMemo | `.xml` | **파일 선택** |
| AlgoApp(이전 이름 AnkiApp) | `.zip` 또는 `.xml` | **파일 선택** |
| 그 외의 앱 | `.csv`, `.txt`, `.xlsx`, `.pdf`, `.json`, `.xml`, `.md`, `.docx` 또는 `.zip` | **다른 앱에서 가져오기**에서 파일 선택 |
| 스프레드시트 | 카드의 앞면과 뒷면을 한 줄씩 복사한 텍스트 | **스프레드시트에서 가져오기**에 붙여넣기 |
| Nibomo | Nibomo에서 내보낸 `flashcards.zip` | **Nibomo에서 가져오기**에서 미리 보기 |

메뉴에 이전 이름이 표시되면 AlgoApp 대신 **AnkiApp**을 찾으세요. Anki는 별도 항목입니다.

이전 Excel 형식인 `.xls` 파일은 `.xlsx`나 `.csv`로 다시 저장한 후 가져오세요. 카드의 앞면과 뒷면에 해당하는 두 열을 복사해 [스프레드시트 가져오기 화면에 붙여넣을](#스프레드시트에서-붙여넣기) 수도 있습니다.

## 다른 플래시카드 앱에서 가져오기

1. 사용하던 앱에서 옮기려는 카드를 내보내세요. Quizlet에서는 세트를 열고 **Export**(내보내기)를 선택한 다음 텍스트를 복사하세요. 용어와 정의 사이는 탭, 카드 사이는 줄바꿈으로 구분하면 편리합니다. 내보내기는 Quizlet 웹사이트에서만 가능하며, 직접 만든 원본 세트만 내보낼 수 있습니다.
2. Nibomo에서 **보관함 > 가져오기**로 이동해 해당 앱의 항목을 여세요. Quizlet은 복사한 텍스트를 붙여넣고, 다른 앱은 내보낸 파일을 선택하세요. 목록에 없는 앱에서 PDF 등 지원하는 형식으로 내보낼 수 있다면 **다른 앱에서 가져오기**를 사용하세요.
3. **가져오기 시작**을 선택하세요. 새 AI 채팅이 열리고 가져오기 요청과 함께 파일이나 붙여넣은 텍스트가 전송됩니다. 인터넷 연결이 필요합니다. AI로 가져올 때는 파일당 최대 **30 MiB**까지 지원합니다. 더 큰 파일은 작은 덱이나 세트로 나누어 내보내 보세요.
4. **보관함**에서 결과를 확인하세요. AI 채팅은 작업 중에도 카드를 여러 번에 나누어 저장할 수 있습니다. 중간에 멈추면 전체를 다시 가져오기 전에 이미 저장된 카드를 확인하고 나머지부터 계속해 달라고 요청하세요.

### 소량으로 먼저 확인하기

원본 파일이나 텍스트는 보관하고 작은 덱이나 세트 하나로 시작하세요. 카드 수를 비교하고, 몇 장의 앞뒷면과 태그, 필요한 이미지와 서식을 확인하세요. 저장 전에 샘플을 보고 싶다면 **가져오기 시작**을 누르는 대신 새 AI 채팅에 내보낸 파일을 첨부하고, 몇 장만 저장 없이 보여 달라고 요청하세요.

AI로 가져온 카드는 Nibomo에서 새 카드로 시작합니다. 이전 복습 기록과 복습 예정일은 이전되지 않습니다. 덱 구성, 서식, 미디어가 얼마나 재현되는지는 내보낸 자료에 무엇이 들어 있고 AI 채팅이 어떤 내용을 읽을 수 있는지에 달려 있습니다. 옮긴 카드로 공부하거나 원래 앱에서 자료를 삭제하기 전에 결과를 확인하세요.

## 스프레드시트에서 붙여넣기

먼저 Nibomo에 로그인하세요. 앞면과 뒷면만 있는 카드라면 **보관함 > 가져오기 > 스프레드시트에서 가져오기**를 사용하세요. 제목 행을 제외하고 두 열을 복사해 가져오기 화면에 붙여넣으세요. 스프레드시트의 셀을 복사했다면 앞면과 뒷면 사이에는 **탭**, 카드 사이에는 **줄바꿈**을 사용해 보세요. 텍스트에 다른 구분자가 들어 있다면 설정을 바꾸세요.

카드를 미리 보고 불완전한 행을 수정한 다음 적용할 태그를 선택하세요. 가져오기 버튼을 눌러 카드를 저장하세요. 이 방법에는 AI 채팅이 필요하지 않습니다.

## Nibomo ZIP 가져오기

먼저 Nibomo에 로그인하세요. Nibomo에서 내보낸 `flashcards.zip`은 **보관함 > 가져오기 > Nibomo에서 가져오기**에서 열 수 있습니다. ZIP의 압축을 풀지 않고 파일을 선택하세요. 미리 보기에서 카드와 미디어 개수 및 경고 메시지를 확인한 다음 가져오기를 확정하고, **보관함**에서 개별 카드와 미디어를 살펴보세요. 패키지에 들어 있는 카드, 태그, 미디어를 옮길 수 있습니다. 이 방법에는 AI 채팅이 필요하지 않습니다.
